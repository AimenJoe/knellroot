# 스킬 · 스킬 슬롯 · 피해 타입

`CLAUDE.md`에서 옮긴 규칙이다(0278) — 문장은 그대로이고 같은 힘을 가진다. 고치는 곳: `src/skills/` · `src/world/skill_tick/` · `src/status.rs` · `src/world/ail_tick.rs` · `src/app/skills.rs`.
이 영역의 파일을 고치기 전에 읽고, 구조를 바꿨으면 여기를 고친다. 굵은 머리말에서 문단만 갈랐다.

## 전투 스킬 · 기술 판

전투 스킬(0151 S0 — 판정 전)은 `skills/` 표(0278 R25b — `table`(`SKILLS`) · `form` · `ranks`(`Skill::at` · `Form::grown`) · `ult` · `entries` · `board` …, `pub use`로 `skills::…` 그대로; 줄 = 대기·시동·후딜·모양 `Form`·피해 — 스킬별 숫자는 여기, 전체 배율·기세·게이지는 랩 `skill.*`)와 `world/skill_tick.rs`(받아 두기 `skill_press` → `try_skill` → `tick_skill`(머리 · 꼬리만 — 모양마다의 일은 빠짐없는 match `tick_form`이 `skill_tick/forms.rs`의 메서드 `tick_ring` · `tick_lane` …로, 공용 값 `SkillCx`, 넓은 타의 바탕 `World::sweep`, 0278 R20) → 판정 `skill_area`·`skill_pull`·`upend` → 틱 끝 `skill_books`). 스킬은 기력을 쓰지 않고 저마다의 대기로 돈다 — 스킬이 아닌 것으로 쓰러뜨리면 모든 대기가 당겨진다(기세). 큰 기술은 게이지(평타·패링·딱 맞춘 떼기로만 — 스킬의 타는 `connected`를 건드리지 않는다), 두 버튼 "함께"는 늦추지 않고 시동 안의 바꿔치기(`skill.chord s`). 새 스킬 = `Id` 한 줄 + `SKILLS` 한 줄(+ 새 모양이면 `Form` 한 갈래 — 수와 상관없는 성질(겨누는 법 `Aim` · 4단에서 커지는 치수 `Grow` · 남는 것 `Leaves` · 되찾나)은 `Form::info() -> FormInfo` 한 줄(0278 R16), 수를 쓰는 것(`clip_period` · `Skill::active` · 쪽 `skill_dir` · 움직임 · 틱 · 미리보기)은 컴파일러가 짚는 match) + 터치 그림(`touch::skill_icon`) + 글 + 이펙트 한 갈래 + 시험. 버튼(0223 → **0255** — 사장 "원거리 공격(원거리 마법 포함)은 RB, 근거리 공격은 X"): 버튼 = 일, 무기와 상관없이 — `Bind::Attack` = 근접 공격(월드 `attack`: 콤보·꾹 강타, 원거리 무기는 수류탄), `Bind::Cast` = 원거리 공격(월드 `cast`: 종류의 원거리 수단 — 0274 ②b, 원거리 무기는 사격·꾹 모아 쏘기 · 활은 당기기). 패드 X·RB, 키보드 J·U / 왼쪽·오른쪽 클릭. 맞바꿈은 **터치만**(든 무기 그림의 공격 버튼 = 사격 — `input` poll이 터치의 둘을 바꾼다). 무기 바꾸기 = 바꾸기 버튼 `Bind::Swap`(패드 L3·키보드 X, 0261 — 조합은 걷었다, `World::weapon_swap`). 큰 기술은 스킬 둘 함께 + 따로 붙인 버튼 하나·두 버튼 조합(`Bindings::ult` `UltBind`, `input::chord_fired` — 이룬 버튼의 제 동작은 그 틱에 거둔다 `Actions::drop_press`, 조작 설정의 큰 기술 줄 `controls::Row::Ult`·`CHORD_WAIT`, prefs 칸 36..40). 옛 prefs(`…0003`)는 배치만 기본으로 되돌린다(공개 전 — 옛 배치를 옮겨 주는 코드는 두지 않는다). 쇠뇌는 평타 = 사격(꾹 = 모은 사격)·특수 = 수류탄, 사격은 가까운 적을 찾지 않는다(조준 스틱·커서 > 락온 > 바라보는 쪽 — 마법은 그대로 찾는다). 월드 시험에서 쇠뇌는 `cast`로 쏜다. 끼운 칸은 기록 `skill.1`·`skill.2`(`skills::Worn`), 화면은 아래 "기술 화면".

## 무기 슬롯과 스킬

무기 슬롯과 스킬(0223 V3): 스킬마다 쓸 수 있는 쥔 꼴이 있고(위 — `Skill::hands`·`fits(Grip)` — 방패와 든 한손 무기는 그 종류의 스킬과 방패 트리의 스킬을 다 쓴다, 두 슬롯에 아무렇게나 섞어서, 0281), **무기 칸마다 스킬 둘** — 주무기의 칸은 기록 `skill.1`·`skill.2`, 부무기의 칸은 `skill.sub.1`·`skill.sub.2`(`Progress::sub_skills`), 바꿔 들면 통째로 맞바뀐다(월드 `swap_weapons` + 앱 `on_weapon_swap`). 월드의 `SkillState::rank`는 **지금 든 무기로 쓸 수 있는** 단이다(쥔 꼴이 안 맞는 스킬의 칸은 0 = 빈 칸 — 누름·HUD·터치가 그것만 본다, 배운 단은 `known`, `World::refit_skills`가 무기를 들 때·바꿀 때·끼울 때 맞춘다). 칸의 표지는 주무기 = 금빛 면 `node_badge` · 부무기 = 금빛 테 `sub_badge`, 못 쓰는 칸은 HUD·터치가 아주 흐린 그림으로(`UNFIT_DIM` — 빈 칸과 갈린다). 기술 탭의 끼우기는 `Kits`(주·부무기의 쥔 꼴과 칸)로 — `Do::Wear(0·1)` = 주무기 칸, `Wear(2·3)` = 부무기 칸, 어느 무기로도 못 쓰면 흐린 줄 `Do::Unfit`. 스킬 시험에서 든 검으로 못 쓰는 스킬은 맞는 것을 든다(`wear` → `hold_for`). 개발 창 기술 묶음 끝 줄 "주무기 바꾸기"(`DevStart::Arm` — 아레나에는 장비 탭이 없다, 차례는 `arm_cycle`(`IDS` + 한손 종류는 방패와 함께 — 0278 R19), 무기가 나오는 상자 줄은 `DevStart::WeaponChest(<무기>)`(스테이지 표의 `chest_loot`에서 선다), 모션 보기 줄도 `IDS`에서(`dev_list`) — 시험 스크립트는 세어 누르지 않고 개발 명령 `Arm(<무기>)`·`Arm(Sword+Shield)`로 바로 든다, 0278 R13).

## 피해 타입

피해 타입(0223 V2 — 물리 + 잔불·뿌리·울림·균열, 0270 B에서 + 충격·날카로움·서리·흡수 — 기절·얼어붙음은 잡몹만 휘청, 문지기는 잠깐 느려지기만 · 맞음은 모두 `Enemy::struck` 한 곳 — 얼음 깨기·흡수가 읽는다)은 `status.rs`(순수 규칙 — 적 하나의 `Ail`: 게이지 `build` · 시간 `tick`, 시험)와 `world/ail_tick.rs`(화상이 타고·묶인 적이 서고·울림과 터짐이 둘레로 번진다 — `tick_skill_fields` 바로 뒤), 숫자는 `tuning::AIL_*`·`BURN_*`·`ROOT_*`·`RIFT_*`·`TOLL_*`·`BURST_*`.

**걸리는 법은 하나**: 타입 있는 타가 닿은 자리에서 `world::afflict(en, dose, ev)`(스킬 표의 `Skill::dose()` = `kind` + `build`, `Sweep`·`Touch`의 `dose`) — 가득 차면 그 타입의 일(화상 겹 · 묶임 = 걷지 못함 + 자세 피해 ↑ · 울림 = 둘레 피해 + 게이지 나눔 · 균열 = 받는 피해 ↑ `rift_mult`, `hurt_by` 한 곳). 쓰러진 적(체력 0)에는 걸리지 않는다. 떼의 크기로 곱절이 되는 일은 상한을 둔다(한 틱의 울림 피해는 한 적에 `TOLL_STACK` 번 — 새 번지는 효과도 N마리 × N으로 재 본다, 0223 8절). 적을 되살리거나 가득 채우는 길(문지기 되살리기·제자리로 돌아감)은 `ail`도 지운다.

**면역은 없다**(보스·엘리트·종의 배율 `species::Def::ail` 0.5~1.5만 — 시험), 묶임·균열은 걸릴수록 닳는다. 타입이 스스로 낸 피해는 스킬의 타로 센다(큰 기술 게이지·기세 밖, 화상에는 타마다의 덤이 없다 — `Touch::flat`). 겹침 넷은 `status.rs` 머리말. 보이는 것은 `render/overlays.rs` `ail_marks`(머리 위 마름모 줄 + 발밑 고리)·`fx.rs`의 사건 넷(`Event::Ail`·`Burn`·`Toll`·`AilBurst`), 빛은 `status::INK`(빨강 없음). 새 스킬 = 표의 `kind`·`build`(한 번 쓰면 보통 적은 걸리게), 새 종 = `ail` 넷(도감이 `i18n::ail_leanings`로 한 줄), 새 타입 = `Kind` 한 갈래 + `TYPED`·`INK` + `build`·`tick`의 갈래 + 월드의 일 + 글 둘 + 시험. 기존 스킬 시험이 재는 피해에는 타입의 몫이 든다(불티의 화상·가로지르기의 금).
