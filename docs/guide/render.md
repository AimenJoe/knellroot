# 렌더 · 빛 · 색 · 성능

`CLAUDE.md`에서 옮긴 규칙이다(0278) — 문장은 그대로이고 같은 힘을 가진다. 고치는 곳: `src/render/` · `src/scenery.rs` · `src/backdrop.rs` · `src/flora.rs`.
이 영역의 파일을 고치기 전에 읽고, 구조를 바꿨으면 여기를 고친다. 굵은 머리말에서 문단만 갈랐다.

## 렌더는 월드를 읽기만

렌더는 월드를 읽기만. 코드는 `render/` 폴더(0159 R1 — `mod`가 프레임의 차례, 그리는 것은 `actors`·`props`·`overlays`·`skill_fx`·`telegraph`·`terrain`·`items`, 셈은 `light`·`batch`·`post`·`shadow`·`shapes`): 새로 그리는 것은 맞는 파일에 이름 있는 함수 하나 + 차례를 정하는 함수의 한 줄. 렌더 타깃 → 정수 배율(물리 픽셀로 센다, 0006) → HUD는 화면 패스. 렌더 타깃 크기는 화면에 맞춘다(`render::fit_internal` — 배율은 높이 / `INTERNAL_H` 반올림, 크기는 화면 / 배율, 0046) — 내부 해상도를 상수로 박지 않는다. Android는 몰입 모드(패치한 miniquad `setFullScreen`, `PATCHED.md`).

## 적은 바닥에서 떠 보여야 한다

적은 바닥에서 떠 보여야 한다(0170): 잿빛은 받은 빛의 색이 된다 — 남보라 달빛 아래 "색을 잃은" 적이 바닥과 같은 밝기·같은 색이 됐었다(잰 수 0.96배). 적 모델에만 `light::enemy_tint`(밝기 `render.enemy lift` · 달빛의 물 빼기 `render.enemy ash`)를 곱한다 — 새 적·새 지역의 빛을 만들면 **적과 그 둘레 바닥의 화소를 재서**(밝기 1.4배 안팎·채도 차) 확인하고, 흐리게도 본다. 방랑자는 파스텔(색)로, 적은 색 없는 밝은 잿빛으로 갈린다.

## 화면의 대비는 배우와 빛에

화면의 대비는 배우와 빛에(0140): 바닥·벽은 조용하게(줄눈·칸마다의 밝기 차를 키우지 않는다 — 변주는 큰 얼룩으로), 그림자는 또렷하게(빛 : 그늘 2.5배, `render::floor_shade`로 구운 그림자와 캐릭터 그림자를 같은 진하기로), 건물을 배우처럼 그릴 때는 `ACTOR_LIFT`를 되돌린다. 화면에 올릴 때의 셈(선 둘·톤·번짐)은 내부 해상도 타깃 `post`에서 한 번만 — 화면 해상도로 돌리지 않는다. 그림을 고치면 같은 장면을 앞·뒤로 찍고 흐리게도 본다(눈이 어디로 가나).

## 세계의 색은 생물의 색상대를 비운다

**세계의 색은 생물의 색상대를 비운다(0249)**: 지역마다 빛·땅·하늘이 다르다(`backdrop::Env`의 `light: SkyLight`·`floor: FloorLook` — 바닥·벽·바위·턱·줄눈까지, 렌더가 `set_sky`로 넣는다 — 색 상수를 `scenery`·`light`에 전역으로 두지 않는다). 세계는 보라 250~340°(망토·침식 뿌리)·빨강(예고)을 채도 0.12 위로 쓰지 않고, 호박 15~55°(불빛·눈빛·갈 곳)는 흙빛(채도 0.26 아래)으로만 — 시험 `world_colors_keep_off_the_creatures_hues`. 새 지역 = `Env` 하나(바탕빛 색상이 다른 지역과 30° 넘게 — `each_region_has_its_own_light`), 색을 바꿀 때는 밝기(선형 휘도)를 지키고 게임 화면 바닥 밝기를 앞·뒤로 잰다(색끼리 곱한 빛·툰 단이 휘도를 안 지킨다).

## 반투명한 것은 배우 뒤에

**반투명한 것은 배우 뒤에 그린다(0220)**: macroquad 기본 3D 파이프라인은 반투명 면도 깊이를 쓴다 — 빛줄기·빛기둥을 배우보다 먼저 그리면 그 안의 몸이 깊이에 가려 사라진다. 단단한 스테이지 물건은 `stage_props`(배우 앞), 빛은 `stage_glows`(배우 뒤).

## 주위 환경

주위 환경(0063)은 `backdrop.rs`(렌더의 일부)·`flora.rs`(굽는 지형에 얹는 나무·덤불·벽 뿌리 — 잎은 흔든 이십면체, 각진 것은 뿌리만, 걷는 칸에는 두지 않는다): 높이 안개는 걷는 땅 아래에만(`Scenery::walk_min`), 하늘·산등성이·달은 땅보다 먼저·법선 패스 밖, 먼 클립(200m) 안에(시험). 아지랑이는 카메라 숙임으로(`haze_by_pitch`).

## 바람

바람(0142): 구운 지형에서 움직일 것은 정점의 **법선 칸 넷째 값**에 몫을 싣는다(`scenery::sway` — 1 = 가만히, 1 + s = 풀 끝·잎, 1 − f = 불꽃). 색 패스(`wind_material`)와 법선 패스가 같은 GLSL `sway()`를 쓴다 — 한쪽만 고치면 윤곽선이 몸에서 떨어진다. 밑동·줄기·돌은 0(뿌리째 미끄러지지 않게, 시험). 줍는 것·솟는 뿌리처럼 모델 없이 그리는 덩이는 정육면체가 아니라 꼴로(`shaded_tris` + `octa_faces`·`ball_faces`·`spike_faces`), 빛기둥 속의 몸은 `loot_front`로 앞에 두고 `loot_body`로 어두운 테를 준다.

## 시야 밖 거르기 · 재기

**시야 밖 거르기·재기(0258)**: 렌더는 카메라 여섯 면(`render::Frustum`, 프레임 들머리 `Renderer::frustum`)으로 지형 덩어리(`Scenery::bounds` — 바람 몫 `SWAY_PAD`)·상주 묶음(땅 칸 `resident::CELL_M`마다 상자)·적(구 + `ENEMY_CULL_PAD`)을 거른다(연구소 `render.cull` 0 = 옛 길). 새로 지도 전체에 깔리는 것을 그리면 상자를 두고 거른다 — 늘 넉넉하게(그림자·흔들림 몫). 어디에 시간이 드는지는 짐작하지 말고 잰다: 개발판 PC `KNELL_PROF=<초> KNELL_BOOT=<개발 창 줄 이름> [KNELL_WINDOW=1920x1080] [KNELL_LAB=render.cull=0]`(`src/prof.rs` 구간 `prof::span` — 웹·운영판은 빈 함수, xvfb에서는 소프트웨어 GL이라 구간끼리의 비만 본다). 2배로 그릴 때 마무리 패스는 선만 두 배 타깃에서, 번짐·톤·가장자리는 반으로 줄이며(`grade_mat`). 빌드는 `opt-level = 3`(0258 — "z"보다 계산 30~60% 빠름, 웹 gzip +5%). 배치(`Batch::send`·`send_outline`)는 넘긴 배열을 용량째 돌려받는다(0259 — 0에서 다시 키우면 프레임이 튄다), 빛 셈의 프레임 값은 모델마다 한 번 `light::LitCtx::now()`.

## 그리기 배치 · 상주 지형

그리기 배치(0135): 한 그리기 호출은 정점 10,000·색인 15,000 미만 — 모을 때는 `render::fits`(둘 다 센다, Meshy 모델은 색인 ≈ 정점 × 2.4). 새 배치를 만들면 이것으로 끊는다.

**상주 지형(0186)**: macroquad는 메시를 GPU에 두지 않는다 — 움직이지 않는 지형(빛 지도 바닥 + 가리지 않는 덩어리)은 `render/resident.rs`가 지역에 들어설 때 miniquad 고정 버퍼로 한 번 올리고(`get_internal_gl` → `flush` 뒤 같은 렌더 패스·투영으로), 셰이더는 원래 재질과 같은 원본 상수(`WIND_VS`·`SHADOW_VERTEX`·`NORMAL_VS`)를 함께 쓴다 — 지형 재질을 고치면 둘 다 바뀐다. 다시 구우면 옛 버퍼를 지운다. 랩 `render.resident` 0 = 옛 길(A/B), Metal은 옛 길.
