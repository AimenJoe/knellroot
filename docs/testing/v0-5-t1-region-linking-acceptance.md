# T1 지역 잇기 수용 테스트

- 기준 결정: [0118 지역 잇기](../decisions/0118-region-linking.md)
- 기준 커밋: `dadab282` (2026-11-08, `release/v0.5`)
- 목적: T1 구현의 코드상 보장과 실제 플레이 확인 항목을 분리한다.
- 상태: 테스트 절차 정리. 아래 수동 플레이 항목은 실행 결과를 기록하기 전까지 미검증이다.

## 정본 동작

1. 새 판의 진행 순서는 성소(0m) → 떠난 마을(40m)이다.
2. 첫 문지기를 이기고 핵을 거두면 해당 판에서만 성소 바닥 길이 열린다. 새 판에서는 첫 문지기를 다시 이겨야 한다.
3. 첫 지역의 핵 획득은 핵 알림·카드만 표시한다. 결과 화면은 마지막 지역 문지기 뒤에만 표시한다.
4. 마을 끝의 문지기는 C3 전까지 자리를 지키는 임시 배치다. T1에서 둘째 문지기 보스전을 확정하지 않는다.
5. 마을에서 성소로 올라오면 이 판에 이긴 문지기는 다시 서 있지 않고 바닥 길은 열린 채 유지된다. 일반 적은 다시 서며, 엘리트는 0113 규칙을 따른다.
6. 마지막으로 쉰 지역은 현재 지역과 무관하게 유지된다. 다른 지역에서 쓰러지면 마지막으로 쉰 지역의 화로에서 다시 선다.
7. 화로 사이 순간 이동은 제공하지 않는다.

## 코드 수준에서 확인된 기반

- `stage::STAGES`와 `StageDef::depth_m`: 지역 순서와 깊이 표.
- `StageOut::CoreTaken`, `Descend`, `Ascend`: 중간 핵 획득과 지역 이동 결과 분리.
- `Phase::Down`: 핵을 거둔 뒤 성소 바닥 길로 내려가는 단계.
- `RunAt { stage, rest, gate_open, down }`: 마지막 쉼터의 지역·번호와 판 진행 상태 저장.
- `enter_stage`: 플레이어 객체와 잔불을 새 지역 월드로 옮김.
- `seed_run`: 지역별 상자 번호와 이 판에서 이긴 문지기의 바닥 길 상태 복원.
- `descent::Passage`: 화면이 완전히 덮인 가운데 지역을 한 번 바꾸고 깊이를 한 방향으로 이동.

## 수동 플레이 수용 테스트

아래 항목은 실제 게임을 실행해 결과를 기록한다.

### T1-01 새 판과 핵 보상

- [ ] 새 판은 성소에서 시작한다.
- [ ] 첫 문지기를 이기고 핵을 거두면 핵 알림·카드만 표시되고 결과 화면은 표시되지 않는다.
- [ ] 성소 바닥 길이 열리고, 그 판에서만 내려갈 수 있다.
- [ ] 새 판을 시작하면 첫 문지기를 다시 이겨야 바닥 길이 열린다.

### T1-02 내려가기와 도착

- [ ] 바닥 길 표지 D에서 내려가는 상호작용이 시작된다.
- [ ] 지층 단면 전환 중 화면이 완전히 덮인 순간 지역이 정확히 한 번 바뀐다.
- [ ] 깊이 표시는 성소 0m에서 마을 40m로 한 방향으로 진행된다.
- [ ] 전환이 끝나 마을에 도착한 직후에는 오르는 길 U를 밟았다는 이유만으로 즉시 되돌아가지 않는다.

### T1-03 오르기와 재진입

- [ ] 마을 어귀 U에서 성소로 올라갈 수 있다.
- [ ] 성소로 돌아오면 이번 판에 이긴 첫 문지기는 다시 나타나지 않는다.
- [ ] 성소 바닥 길은 열린 채 유지된다.
- [ ] 일반 적은 다시 서고, 엘리트는 0113의 처치 기록 규칙을 따른다.
- [ ] 화로 간 순간 이동 UI나 기능은 없다.

### T1-04 지역 간 쉼터 복원

- [ ] 성소에서 쉰 뒤 마을로 이동하고, 마을에서 쉬면 마지막 쉼터가 마을로 갱신된다.
- [ ] 마을에서 쉰 뒤 성소로 이동해 쓰러지면 마을 화로에서 다시 선다.
- [ ] 마을에서 쉰 뒤 저장·종료하고 이어하면 마지막 쉼터 지역과 위치가 유지된다.
- [ ] 반대 순서(마을에서 쉼 → 성소에서 쉼 → 마을에서 쓰러짐)도 성소 화로에서 복원된다.
- [ ] 쉼터를 한 번도 사용하지 않은 판은 0032의 기존 규칙을 유지한다.

### T1-05 전역 상태 보존

지역을 이동하거나 다른 지역 화로에서 복원할 때 다음 상태가 의도치 않게 초기화되지 않는지 확인한다.

- [ ] 체력·기력·등잔·탄약 등 플레이어 현재 상태
- [ ] 장착 무기와 성장·장신구 효과
- [ ] 잔불
- [ ] 지역별 상자·숨은 물건·엘리트·문 기록
- [ ] 지역별 쉼터 및 판 진행 상태

## 검토 메모 / 미결 사항

- `run.down`은 현재 이 판에서 이긴 문지기 수를 저장한다. 현재 두 지역에서는 충분하지만, 지역이 늘어날 때도 이 의미가 명확한지 재검토한다.
- 상자 ID는 지역 번호 × 1000 + 지역 내 번호다. 지역당 상자 수가 1000 미만이라는 전제를 유지한다.
- `src/stage/village.rs`의 문지기는 C3 전까지 자리를 지키는 임시 배치다. `StageDef::boss_wakes_on_entry = false`로 보스전을 막고, 잠든 상태는 `Enemy::active()`에서 제외되어 공격·락온 대상이 아니다. 자동 테스트로 이 상태를 검증한다.
- 깊이 숫자(0m·40m)는 연출용 표기이며 C1·T2에서 재검토할 수 있다.

## 테스트 결과 기록

수동 테스트를 실행한 뒤 기기·빌드·날짜와 실패 항목을 이 절에 추가한다. 빌드 성공만으로 위 수동 플레이 항목을 통과 처리하지 않는다.
