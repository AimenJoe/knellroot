# Meshy v1 방랑자 → 게임 (2026-11-04 실험)

## 변환(`tools/art/blender/meshy_convert.py`)
`convert_raw_naive_baked.png`: 원본(삼각형 101k) | 그냥 줄이기 + 원래 UV 텍스처 128 | 정점 합치기 + 줄이기 + 새 UV + 색 굽기 256.
- 그냥 줄이면 하얀 금: ① glTF로 가져오면 UV 이음매마다 정점이 갈라져 있어 줄일 때 경계가 벌어진다 → 먼저 합친다(57,152 → 50,651).
  ② Meshy UV는 아주 잘게 쪼개져 있어 텍스처를 줄이면 조각 경계가 번진다 → 줄인 메시에 UV를 새로 펴고(Smart UV 89°) 원본 색을 굽는다.
- 굽기 함정: 구울 그림을 재질 입력에 이어 두면 "Circular dependency"로 검정, apt Blender 4.0.2는 OpenImageDenoiser 없이 빌드돼 노이즈 제거가 켜져 있으면 조용히 검정 → 끈다.
- 결과: glTF 정점 2,174(방랑자 예산 2,400 안) · 삼각형 2,404 · 텍스처 256. 원본과 거의 같아 보인다.
