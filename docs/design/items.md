# 아이템 설계(초안) — 화로·등잔·잔불·장신구·무기

> 0026에서 정한 것(사장 2026-11-03): **구역을 잇는 선형(소울라이크)**, 회복 = **충전식 병**, 쓰러져도 **화폐는 잃지 않음**, 첫 구현 = 회복·화로 + 장신구 칸 + 무기 여럿.
> **0027(같은 날)**: 점프를 기본 동작(A / F)으로 넣고 **소모품 퀵슬롯은 뺐다** — 조작이 느는 값을 소모품으로 갚음. 아래에 소모품은 없다.
> 이름은 초안(세계관 D2 미정, 0004). 수치는 모두 `tuning.rs`·표 한 줄 — 랩에서 맞춘다.
> 근거: KB `concepts/action-rpg-stats-and-equipment.md`(세 겹), `concepts/roguelite-healing-and-currency.md`(회복·화폐·잃지 않기), 엘든 링(병·축복 — wiki.gg·Fextralife, 2차), Dead Cells·Nightreign(로그라이트에서도 충전식 병, 2차).

## 0. 세 겹
| 겹 | 무엇 | 얻는 곳 | 지속 | 코드 |
|---|---|---|---|---|
| 무기 | 공격의 **모양**(속도·거리·부채꼴·연속타·스태미나) | 상자·보스·상인 | 영구(가짐) | `weapons.rs` 표 |
| 장신구 | **수치 보정**(맞바꿈 섞임) 3칸 | 상자·보스·상인 | 영구(가짐) | `charms.rs` 표 → `Mods` |
| 성장 | **큰 보상**: 등잔 횟수·회복량·최대 체력 | 문지기의 핵 | 영구 | `progress` |
| 화폐 | **잔불**(적이 떨굼) | 떼·통 | 영구, **잃지 않음** | `progress.embers` |
- 합치기는 한 곳: `Stats = 기본 + 무기 + Σ장신구 + 성장` — 더하기는 합, 배율은 곱, 끝에 상한(KB). 월드는 `Stats`만 읽는다(체력·스태미나·피해를 상수로 박지 않는다 — 지금 `PLAYER_HP`를 `stats.max_hp`로).

## 1. 화로(체크포인트)
- 구역마다 1~2개(침묵의 성소: 입구, 문 앞). 지금 소품 `brazier` 중 하나가 "쉼 화로"(꺼져 있다가 처음 닿으면 켜짐 — 장소 기억).
- **상호작용**(Y / G)으로 쉰다: 체력·등잔 가득, **기록**(저장), 떼가 되살아난다(문지기·연 상자·주운 것은 그대로). 화로 메뉴: 쉬기 · 성장(핵) · 장비 · 떠나기.
- 쓰러지면 마지막으로 쉰 화로에서 다시. 잃는 것: 위치·진행(떼 되살아남)·그 사이 마신 등잔. **잔불은 그대로**(KB: 줍는 손맛과 부딪치지 않게).

## 2. 등잔(충전식 병)
- 처음 3회, 한 번에 체력 2(최대 5 중). 화로에서 다시 찬다.
- 마시는 동안 0.8초 느리게 걷고 공격 못 함 — "언제 마실지"가 기술(소울라이크). 앞 0.35초는 **들기**, 그 순간 **삼킨다**(등잔 −1, 체력 +2), 뒤 0.45초는 내리기.
- **급할 때 연타해도 안전하게**(사장 "물약이 더 큰 문제 아냐?", 0030):
  - 한 번 누르면 마신다. 다시 누르기 취소는 **없다**(연타하면 마시기·취소가 번갈아 나와 회복이 안 된다).
  - 마시는 동안과 끝난 뒤 0.3초의 누름은 **버린다**(쌓지 않는다) — 연타해도 한 모금씩, 체력이 오른 것을 본 뒤에 다음 모금.
  - **체력이 가득이면 마시지 않는다**(등잔 그대로, 횟수가 깜빡). **등잔이 0이면 아무 동작 없이** 횟수만 깜빡 + 빈 소리 — 빈 병 몸짓으로 묶지 않는다.
  - 등잔은 **삼키는 순간에만** 준다. 들기(앞 0.35초) 동안 회피하면 끊기고 등잔 그대로 — 어깨 버튼을 실수로 눌렀으면 회피 한 번으로 무른다. 들기 동안 맞아도 끊기고 등잔 그대로(대가는 맞은 피해와 시간). 삼킨 뒤 내리기는 못 끊는다.
  - 시험(구현 때): RB 연타 3초 — 마신 수 = 시간 ÷ (0.8 + 0.3)을 넘지 않고, 가득일 때 0, 회피로 끊으면 등잔 그대로.
- 성장: 문지기의 핵 → 화로에서 **고르기**(등잔 +1회 / 회복량 +1 / 최대 체력 +1, KB "옆으로 넓히기"). 
- 마시기는 따로 버튼 하나(아래 8). HUD 왼쪽 아래에 남은 횟수.

## 3. 장신구(3칸)
- 표 한 줄 = (이름, 보정, 맞바꿈). 처음 여섯: 단단한 껍질(체력 +1), 가벼운 발(회피 스태미나 −30% / 받는 피해 +1), 종지기의 귀(패링 창 +0.06초), 굶주린 뿌리(처치마다 스태미나 회복 / 등잔 −1회), 무거운 손(피해 +1 / 공격 속도 −15%), 잔불 주머니(잔불 +50%).
- 갈아 끼우기는 화로·멈춤 메뉴 어디서나(시험 비용 0 — KB). 칸이 차 있으면 바꾸기.

## 4. 무기 여럿
- 무기 = 공격의 모양(KB). 표 `weapons.rs`: 선딜·활성·후딜·거리·부채꼴·피해·스태미나·내딛기·연속타(1~3)·연속 창. 처음 넷:
  | 무기 | 성격 |
  |---|---|
  | 방랑자의 검(지금) | 보통, 2연타 |
  | 대검 | 느림·넓은 부채꼴·피해 2·스태미나 많이, 단타 |
  | 쌍단검 | 빠름·짧음·3연타, 패링 뒤 치명타 +1 |
  | 창 | 길고 좁음, 긴 내딛기, 2연타 |
- 그림: 무기마다 GLB 하나(Blender 스크립트), 방랑자의 `hand_r` 뼈 자리에 붙인다(지금 검 부위는 숨김). 휘두르는 동작은 공통 + 속도 배율(공속 = 시계 배율, KB).
- 강공격은 공격 버튼 꾹(0030, 들어감) — 무기마다 강타 모양(범위·모으는 시간)을 표 한 줄에 둔다.

## 5. 화폐 — 잔불
- 떼가 떨군다(튀어나옴 + 0.35초 지연 + 넉넉한 자석 + 오르는 소리 — KB). 화로 근처 상인(나중)·성장에 쓴다.
- 쓸 곳이 생기면 화로가 빛난다(KB "쓸 곳이 보여야").

## 6. 기록(저장) — 선형이라 필수
- 무엇: 잔불, 성장, 가진 무기·장신구, 낀 것, 마지막 화로, 켠 화로, 쓰러뜨린 문지기, 연 상자·주운 것.
- 어디: 웹 localStorage 글 한 칸(`knell.save.<슬롯>`), 데스크톱·Android 기록 폴더 `save<슬롯>.txt`(`prefs.rs`와 같은 폴더). 형식 = 키=값 줄(첫 게임 profile, 키 이름은 바꾸지 않는다).
- 언제: 화로에서 쉴 때, 문지기를 이겼을 때, 타이틀로 나갈 때. 슬롯은 처음엔 하나(이어하기 / 새로 하기).

## 7. 입력(0024 배치표에 줄 더하기)
| 동작 | 패드 | 키보드 |
|---|---|---|
| 점프(0027, 들어감) | A | F |
| 상호작용(쉬기·상자·줍기, 0032 들어감) | Y | G |
| 등잔 마시기(0030·0031, 들어감) | **RB** | R |
- 저장 칸은 뒤에 붙이고, 새 칸이 비면 그 동작만 기본값(점프에서 이미 그렇게 고침 — `Bindings::decode`).
- 상호작용은 화로·상자 곁에서만 뜬다(안내에 `input::prompt`). 소울라이크의 Y(양손 쥐기)는 우리에게 없어서 비어 있던 자리.
- 등잔 = RB(0030): 엄지를 스틱에서 떼지 않고 마신다. 어깨 버튼을 실수로 누른 것은 "들기 동안 회피하면 등잔 그대로"로 무른다(위 2 — 다시 누르기 취소는 연타와 부딪혀 뺐다). 강공격은 RT가 아니라 공격 꾹(0030)이라 RB는 등잔 몫.

## 8. HUD
- 왼쪽 아래: 등잔 그림 + 남은 횟수.
- 오른쪽 위: 잔불 수(주울 때 잠깐 커짐).
- 멈춤 메뉴에 "장비"(무기·장신구 3칸).

## 구현 순서(단계마다 배포할 수 있게)
1. **A — 화로·등잔·상호작용**(등잔 0031, 쉼터 0032로 들어감 — 쉼터 `R`에서 상호작용 = 가득 + 다시 일어설 곳, 쓰러지면 거기서·진행은 쉬던 때로): 쉼 화로(켜기·쉬기·되살아남), 등잔 3회(마시기 동작·끊김), 쓰러지면 마지막 화로에서, 입력 줄 둘(상호작용·마시기), HUD 등잔. (세션 안에서만 기억)
2. **B — 잔불·기록**: 떨어짐·자석·줍기, 기록 파일(위 7), 타이틀 "이어하기".
3. ~~C — 퀵슬롯 소모품~~ — 0027에서 뺌. 상자(Y로 열기)는 D에서 장신구·무기 보상으로.
4. **D — 장신구**: 표·`Mods`·`Stats`, 장비 메뉴, 상자·문지기 보상.
5. **E — 무기**: 무기 표·연속타·공속, 무기 GLB 넷(Blender), 붙이기.
6. **F — 성장**: 핵 고르기(등잔·회복량·체력), 화로 빛남.
