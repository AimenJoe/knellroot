# v0.5.0 둘째 지역 — 떠난 마을의 남은 주민

- 상태: 주민 공통 원칙은 CANON, 대사 초안은 0129에서 그대로 확정(사장 2026-11-09), 배치·말풍선·재방문은 구현(0122)
- 결정: 0115, 0116, 0122
- 지역 방향: 0069의 떠난 마을
- 선행 지역: 0번째 지역 「침묵의 성소」

## 목적

첫 지역이 탐험과 자리 잡은 적, 지름길의 구조를 소개했다면 둘째 지역은 누군가 살던 장소와 지금도 이어지는 일상을 보여 준다. 주민은 퀘스트 제공자나 세계관 해설자가 아니다. 전투와 별개로 자기 일을 이어 가는 여러 작은 동물이며, 평범한 일상을 이어 간다.

정서의 목표는 **고요함과 쓸쓸함**이다. 마을을 떠난 이유를 설명하지 않고, 남은 주민이 왜 이곳에 머무는지도 설명하지 않는다.

## 주민 외형 원칙(CANON / 0036)

- 주민은 여러 작은 동물이다. 특정 종은 아직 정하지 않는다.
- 귀여움 문법은 0036을 따른다. 큰 머리·낮은 위치의 큰 눈·입 없는 얼굴·둥근 실루엣을 기본으로 삼는다.
- 주민을 인간형 NPC로 대체하지 않는다. 세 주민의 종과 외형은 시각 시안 단계에서 별도로 검토한다.

## 지역 구성(PROPOSED)

| 구역 | 역할 | 주요 요소 |
|---|---|---|
| 위쪽 거주지 | 생활 흔적과 첫 주민 소개 | 집 아궁이, NPC-V01 |
| 뿌리 사이 골목 | 물과 뿌리의 풍경 | 물방울, 항아리, NPC-V02 |
| 아래쪽 광장 외곽 | 주민 생활과 전투 공간의 경계 | 천막·수선 흔적, NPC-V03 |
| 광장/심층 진입부 | 탐험·전투 | 주민 안전 구역과 분리된 적 배치 |
| 보스 구역 | 지역의 전투 마무리 | 주민의 생활 공간과 직접 연결하지 않음 |

위 표는 역할 구분이며 최종 지형도나 진행 순서를 확정하지 않는다. 실제 맵은 현재 스테이지 구조와 이동·전투 동선을 확인한 뒤 설계한다.

## 주민 공통 규칙(CANON)

- 주민들은 서로 떨어져 각자 살아간다.
- 짧고 제한적인 대사만 사용한다.
- 여러 작은 동물로 묘사한다. 특정 종이나 개별 이름을 게임 글에 확정하지 않고 화면 표기는 "주민"으로 통일한다.
- 방랑자에게 무심한 경계를 보인다.
- 전투 중 안전한 생활 구역에 머문다.
- 보스 처치 후에도 같은 위치에서 생활을 이어 간다.
- 주민과 대화하지 않아도 지역과 보스 진행이 가능하다.

### NPC-V01 — 불을 지키는 주민(PROPOSED)

- 위치: 위쪽 거주지
- 생활 행동: 집 아궁이를 살피고 불을 지킨다. 쉼터 화로와 다른 시설이며 외형도 구분한다.
- 대사 초안:
  - 「불은 아직 쓸 만해.」
  - 「추우면 문을 닫아.」
  - 「오늘도 왔군.」
- 재방문 변화: 화로의 불빛이 조금 살아난다.
- 이벤트 ID: `V01-E01` / 「꺼지지 않는 불」

### NPC-V02 — 물을 모으는 주민(PROPOSED)

- 위치: 뿌리 사이 골목 안쪽
- 생활 행동: 뿌리에서 떨어지는 물을 항아리에 받는다.
- 대사 초안:
  - 「밟지 마. 물을 받고 있어.」
  - 「이쪽이 더 잘 떨어져.」
  - 「항아리가 하나 더 필요하겠어.」
- 재방문 변화: 기울어진 항아리가 바로 세워져 있다.
- 이벤트 ID: `V02-E01` / 「넘친 항아리」

### NPC-V03 — 낡은 것을 꿰매는 주민(PROPOSED)

- 위치: 아래쪽 광장 외곽
- 생활 행동: 옷과 천을 수선한다.
- 대사 초안:
  - 「그쪽도 찢어졌나?」
  - 「새것보다 오래된 게 편하지.」
  - 「아직 쓸 수 있어.」
- 재방문 변화: 찢어진 천막 일부가 수선되어 있다.
- 이벤트 ID: `V03-E01` / 「오래된 천」

## 상호작용 흐름(PROPOSED)

1. 플레이어가 주민의 상호작용 거리 안에 들어오면 주민이 짧게 반응한다.
2. 대사는 주민 머리 위 말풍선으로 표시한다. 별도 대화창을 열거나 게임을 멈추지 않는다.
3. 말풍선은 몇 초 뒤 사라진다. 플레이어가 다시 상호작용하면 다음 대사를 표시한다.
4. 대사 표시 중에도 이동·전투·적의 행동은 계속된다. 주민은 생활 행동을 이어 간다.

대화 횟수는 재방문 이벤트의 조건이 아니다. 주민을 한 번도 만나지 않아도 이벤트와 무관하게 지역 진행은 가능해야 한다.

## 전투 안전 설계(CANON)

주민을 전투에 끌어들이지 않는 것은 AI 동작보다 레벨 배치로 먼저 해결한다.

- 주민의 생활 위치를 적의 시야·추적·동료 깨우기 범위에서 분리한다.
- 광역 공격과 돌진이 생활 구역을 덮지 않도록 한다.
- 주민은 전투 참여자나 적의 유효 타깃으로 등록하지 않는다.
- 플레이어의 근접 공격, 투사체, 수류탄, 땅 돌리기(멈출 때의 휘청·밀림)는 주민에게 닿지 않고 통과한다.
- 락온과 자동 조준은 주민을 타깃으로 선택하지 않는다.
- 전투 중 주민이 도망치거나 숨는 별도 대피 AI는 만들지 않는다.
- 플레이어가 적을 주민 쪽으로 유인하는 상황도 맵의 거리·벽·높이·길막으로 억제한다.

## 보스 처치 전후

보스 처치는 주민의 생활 상태를 바꾸지 않는다.

- 위치 유지
- 생활 행동 유지
- 방랑자에 대한 태도 유지
- 별도의 축하·감사·보상 대사 없음

보스 처치 플래그와 주민 진행 상태를 결합하지 않는다.

## 저장과 재방문(구현 — 0116 조건, 0122)

- 주민의 배치와 생활 행동은 지역 재진입 시 일관되게 복원한다.
- 주민별로 처음 목격한 판을 기록한다.
- 그 판이 끝나기 전에는 재방문 환경 이벤트를 발동하지 않는다. 같은 판에서 지역을 나갔다 돌아와도 발동하지 않는다.
- 첫 목격 판이 끝난 뒤 다른 판에서 마을에 다시 들어오면 해당 주민의 환경 변화가 한 번 적용된다.
- 변화는 저장 가능한 단방향 상태이며 다시 실행하거나 되돌리지 않는다.
- 대화 횟수나 보스 처치 여부와 이벤트 조건을 묶지 않는다.
- v0.4.1 세이브에는 관련 필드가 없으므로 기본값으로 초기화한다.
- 기존 세이브를 새 구조로 읽을 때 필드 누락으로 실패하지 않아야 한다.
- 실제 저장 키: 시작한 판 수 `runs`와 주민을 처음 본 판 `residents.seen`(`V01:판 번호`)을 기록하고, 그보다 뒤의 판에서 마을에 들어서면 `residents.changed`로 한 번 바뀐다. 아래 개념 모델은 그 전의 설계다.

개념 상태:
```text
VillageProgress
  hearth_keeper.event_changed
  water_collector.event_changed
  cloth_mender.event_changed
```

## 구현 전 확인 사항(닫음 — 0121·0122)

- 판 식별·세이브 기본값: 0122(`runs`·`residents.seen`·`residents.changed`, 옛 기록은 판 0·본 주민 없음).
- 비타깃: 주민은 월드의 적이 아니다 — 맞지도, 락온·자동 조준되지도 않고, 적의 대상도 아니다. 몸은 방랑자만 밀어낸다(0122).
- 안전 구역: 모든 적의 끈 + 3m 밖(0121).
- 말풍선: 머리 위 3.5초, 떠 있는 동안 다시 누르면 다음 말(0122). 화면 가장자리·모바일에서 읽히는지는 판정(0116 Z6).
