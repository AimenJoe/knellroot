# Knellroot — 컨셉 (one-pager, 초안 2026-11-03)

> 기준 문서. 이름은 Knellroot(0005), 세계관은 nail의 먼 뒷이야기로 닫았고(D2 = a, 0004) 세부는 **초안**이다. 바뀌면 여기와 결정 기록을 함께 고친다. 현재 단계는 3(구조·메타·저장 — v0.3.0 "남는 판", 0064). PoC(`phase-0-poc.md`)는 닫았다(0019), 첫 구역은 v0.2.0(0060).

## 한 문장
**레트로 로우폴리 3D 세계에서, 쿼터뷰로 침식된 것들의 떼를 쓸어 넘기다가 락온을 거는 순간 숄더뷰로 내려가 거대한 문지기와 1:1로 맞서는 ARPG.**

## 왜 이 게임인가
- 첫 게임(nail)에서 검증한 것: 읽을 수 있는 예고·회피/받아치기·히트스톱의 손맛, 표로 넓히는 코드, 결정 기록. 이것을 **3D와 두 시점**이라는 새 축에 옮긴다.
- 두 전투의 대비가 핵심 경험이다. 쿼터뷰 = 규모·군중 제어·광역, 락온 숄더뷰 = 개별 존재의 위압감·패턴 읽기·거리 조절(소울류).
- 스택은 유지(Rust + macroquad). 3D 로더·스키닝·조명은 엔진이 안 해 주므로 **상자 + 부위 강체 애니메이션**(마인크래프트보다 조금 정교한 수준)으로 제한한다 — 취향이 아니라 엔진을 바꾸지 않기 위한 결정(`0001`).

## 코어 루프(초안)
1. 구역에 들어선다(짧은 통로 → 뜰).
2. 떼가 몰려온다: 쿼터뷰, 광역 공격·회피·군중 처리.
3. 문지기(보스)가 길을 막는다: 플레이어가 **직접** 락온 → 숄더뷰. 예고 읽기, 회피, 빈틈 공략.
4. 핵이 드러난다 — 짧은 보상 연출, 다음 구역으로.
- 구조: **구역을 잇는 선형 + 화로 체크포인트**(0026, 소울라이크). 회복은 충전식 등잔, 화폐(잔불)는 잃지 않는다. 아이템 설계 `docs/design/items.md`.

## 전투
- 공통 틀: 이동 + 기본 공격 + 회피 + (특기). 규칙은 하나, 모드마다 다른 것은 **카메라·타깃팅·입력 기준**뿐(`0003`).
- 쿼터뷰: 부채꼴·원형 판정, 다수 동시 타격, 짧은 회피.
- 락온: 대상 기준 전후좌우(스트레이프), 대상 쪽으로 공격, 회피 타이밍·패링(패링은 버튼 — 0025, L1·L-Shift).
- 전투감 레이어(히트스톱·흔들림·넉백·피격 플래시·소리)는 PoC부터.

## 세계관 뼈대(초안, ChatGPT 브레인스토밍 2026-11-03 → `docs/research/`)
《뿌리 아래의 종말》 — 죽은 줄 알았던 세계의 뿌리가 다시 자란다. 뿌리가 닿은 곳에서는 죽은 것이 움직이고 산 것이 형태를 잃는다(**침식**). 과거를 잃은 방랑자가 지하의 **종소리**를 따라 내려간다. 보스를 쓰러뜨리면 **핵**이 남고, 방랑자의 몸도 거기 반응한다. 뿌리는 명백한 악이 아니고, 플레이어와 세계의 관계도 밝히지 않는다.
- 첫 구역 "침묵의 성소": 무너진 입구 → 뿌리의 뜰(떼) → 닫힌 성소(문지기 등장) → 결투(락온) → 살아 있는 잔해(핵·종소리). 5~12분.
- 플레이어: 이름 없는 방랑자(검 하나, 후드). 일반 적: 뿌리의 잔재(근접·느림·수로 압박) → 가시짐승(돌진) → 뿌리의 씨앗(바닥 예고·공간 통제). 첫 보스: 잠들지 않는 문지기(내려치기·돌진·뿌리 파동 셋, 체력 반 아래 핵이 밝아짐).
- **첫 게임과의 관계(D2 = a, 0004 — 2026-11-05 닫음)**: nail과 **같은 세계의 먼 뒷이야기**. 큰 나무가 마지막 꽃을 피우고 누룩 할매가 놓아준 뒤 수백 년 — 엔딩을 뒤집지 않는다(할매는 돌아오지 않고 적이 아니다, 새싹 아래 마을은 망한 게 아니라 떠났다). nail 이웃의 이름은 쓰지 않고 흔적으로만, nail을 몰라도 읽히게. 보라 뿌리의 뜻(추천: 할매가 놓아준 뒤 남은 "주인 없는 실")·둘째 구역(추천: 떠난 마을)은 v0.4.0 제안 0069에서 정한다. 열린 질문 여섯은 그대로.

## 톤·그림
**"작고 따뜻한 것이 크고 조용한 어둠을 걷는다"** — 이야기는 다크 판타지 미스터리 그대로, 그림은 **색 = 생명**(0037, `docs/art/direction.md`): 살아 있는 것(방랑자 — 두건 쓴 작은 너구리, 등잔·쉼터 불)은 파스텔과 따뜻한 빛, 뿌리가 먹은 것(침식)은 같은 귀여운 꼴인데 색을 잃은 잿빛 + 보라 뿌리, 세계는 숯빛 검정 대신 해 질 녘 남보라, 위험만 빨강. 둥근 것은 산 것, 뾰족한 것은 뿌리. 2등신·눈은 크고 낮게·입 없음. 렌더는 깊이 + 빛 2~3단 + 짙은 자두빛 1px 외곽선(0033). 모델은 Blender 스크립트(상자 + 둥근 덩어리 `Geo.blob`, 0036) → glTF. 옛 안(PS1풍 숯빛·돌 회색)은 0037로 바뀌었다.
