# 0단계: PoC + Lab — 되나? 어떤 값이 좋나?

콘텐츠 전에 가장 비싼 질문부터. 질문마다 **통과 기준·시간 상한·대안**을 코드보다 먼저 적는다(KB `guides/poc-and-lab-before-content.md`). 판정은 사장(+ 한 사람).

## 질문 P1~P6
| # | 질문 | 통과 기준(사람 판정 + 숫자 하나) | 상한 | 넘기면 |
|---|---|---|---|---|
| **P1** | macroquad 3D로 쿼터뷰 떼싸움이 읽히나 | 잡몹 20이 한 화면에서 구분되고 바닥 예고가 보인다. 웹에서 60fps(실기 브라우저) | 2026-11-10 | 내부 해상도·그림자·조명(정점 색) 조정, 그래도 안 되면 P4 전에 중단 검토 |
| **P2** | 쿼터뷰 ↔ 숄더뷰 전환이 튀지 않고, 벽에서 카메라가 벽 안으로 안 들어가나 | 락온 켜고 끌 때 "우왁"이 없다(멀미 없음, 사람 둘). 기둥 곁에서 벽 뒤 화면이 없다. 전환 중 조작이 꼬이지 않는다 | 2026-11-10 | 전환 시간·FOV 격차·주시점 가중치를 랩에서 다시, 그래도 안 되면 "보스전만 숄더뷰 고정 컷"(전환 연출 포기) |
| **P3** | 락온 전투 조작이 소울류답나 | 스트레이프·거리 벌리기·회피·빈틈 공격이 패드로 된다. 보스 예고 셋을 읽고 피한다 | 2026-11-17 | 입력 기준(대상 기준 vs 카메라 기준)을 바꿔 본다 |
| **P4** | 상자 모델 + 부위 강체 애니메이션 파이프라인이 성립하나 | Blockbench 상자 둘 + 회전 1채널 glTF를 로더가 읽어 돈다 → 캐릭터 하나(대기·걷기·공격·회피·피격) | 2026-11-24 | `.bbmodel` 직접 파싱, 그래도 안 되면 Fyrox/Bevy 전환 검토(`0001`의 출구) |
| **P5** | 떼 20~40 + 보스 + 예고 + 그림자에서 웹 60fps인가 | 데스크톱 Chrome 60, 핸드헬드급 Android Chrome 30 이상. 드로콜 수 기록 | 2026-11-24 | 아틀라스 하나·CPU 변형·한 배치(KB macroquad 3D)로 다시 |
| **P6** | 땅 돌리기(쟁반 쏟기, 0012)가 이 게임의 동작이 되나 | ↺↻로 돌릴 때 멀미 없음(사람 둘). 둘러싸였을 때 돌리면 떼가 쏟아져 휘청이는 게 보이고 시원하다. 어깨 버튼·R3 락온이 손에 맞는다. 카메라 회전 최대 < 260°/s(측정, 지금 199) | 2026-11-17 | 회전 시간·쏟음 세기·대기를 랩에서 다시, 그래도 멀미면 "끊어 돌리기"(0.1초), 그래도 아니면 쏟음만 남기고 카메라는 0011로 |

P1·P2·P3·P6은 **이 PoC(상자)에서**, P4·P5는 모델이 들어온 뒤. P6은 콘텐츠가 아니라 핵심 메커닉이라 지금 본다(사장 2026-11-03).

## 범위(In) — 이 PoC
- 상자 플레이어·보스·잡몹, 바닥 격자·기둥·아레나 턱. 모델·텍스처 없음.
- 카메라 리그 둘 + 보간 + 당기기(상자 충돌). 가림 페이드는 없음(P2 통과 뒤 필요하면).
- 이동·회피·공격(선딜/활성/후딜, 부채꼴 판정, 한 스윙 한 번)·히트스톱·흔들림·넉백. 소리 없음.
- 락온: 버튼으로 걸고/풀기, 거리·방향·보스 우대 점수, 죽거나 멀면 풀림. 대상 바꾸기 없음.
- 적: 잡몹(추적·예고·휘두르기·쉬기), 보스(접근·예고·부채꼴 휘두르기·쉬기). 체력 띠. 패턴 하나.
- 땅 돌리기(0012): ↺↻ 90°, 둘레 적의 쏟음·휘청·벽 쿵, 보스 무게, 대기.
- 랩(`docs/lab.md`), 시나리오 다섯, 헤드리스 스크린숏(`tools/test/shot.js`).

## 범위 밖(Out)
모델·애니메이션(P4), 소리, 패링, 특기, 아이템·성장, 방 생성·구역 연결, 이야기·컷씬·글(i18n), 저장, Android·iOS 빌드, 성능 랩(P5). (터치는 0006으로 넣음)
