# 0118. 지역 잇기(v0.5.0 T1) — 판의 차례·내려가는 길·오르는 길·지역마다 이어하기

- 날짜: 2026-11-08
- 상태: **채택·구현**(`release/v0.5`). 0116 4절 T1. 사장 2026-11-08 인터뷰 셋 — 다 추천대로.
- 스터디: KB `concepts/conveying-descent`(1차: nail 0156·0204 — 검정 대신 지층 단면, 깊이 숫자 표 하나, 이름 카드는 새 지대에 처음 닿을 때, 굽는 동안 작은 움직임은 실제 시간으로).

## 정한 것(인터뷰)
| 물음 | 고른 것 |
|---|---|
| 새 판에서 첫 문지기를 다시 이겨야 내려가나 | **판마다 다시** — 판의 차례 = 성소 → 떠난 마을. 문지기를 이기고 핵을 거두면 **그 판에서만** 성소 바닥 길이 열린다. 성문 지름길(0113)은 그대로라 둘째 판부터 짧다. 핵 셋까지(0105)와 맞는다 |
| 판의 끝(결과 화면) | **마지막 지역 문지기 뒤** — 첫 문지기 핵은 핵 알림·카드만, 바닥 길이 열린다. 둘째 문지기(C3) 전까지 마을 끝에는 **싸우는 임시 문지기**(첫 문지기 모델 — 이기고 핵을 거두면 판이 끝난다)를 둔다. PR #10 검토에서 예전 문장 "자리만 지키는"이 "싸우지 않는"으로 읽혀 분명히 했다(사장 2026-11-08 — 판 전체를 결과 화면까지 돌려 보려고) |
| 마을에서 성소로 올라가면 | **이 판에 이긴 문지기는 없고 바닥 길은 열린 채, 서 있는 적은 다시 선다**(엘리트는 0113대로 이 판에 쓰러뜨린 것 빼고) |

## 구조
- **스테이지 표** `stage::STAGES`(차례 = 깊이). `StageDef::depth_m`(지하 m, 연출 표 — 성소 0, 떠난 마을 40, 값은 C1·T2에서 다시 볼 수 있다).
- **지도 표지**: `D` 내려가는 길(성소 문지기 뒤 — 핵을 거둔 뒤에만 열림, `Phase::Down`), `U` 오르는 길(마을 어귀). 표지에서 한 번 벗어난 뒤 다시 밟아야 움직인다(도착하자마자 되돌아가지 않게).
- **결과**: `StageOut::CoreTaken`(마지막 아닌 지역의 핵 — 앱이 핵 보상만), `Descend`·`Ascend`(앱이 지층 단면 전환을 열고 가운데에서 지역을 바꾼다 — 지형 굽기가 그 뒤에 숨는다), `Cleared`는 마지막 지역에서만.
- **판 상태(앱)**: 지금 지역 `stage`, 이 판에 이긴 문지기 수 `down`, 마지막으로 쉰 곳 `RunAt { stage, rest, gate_open, down }`(지역을 바꿔도 남는다). 다른 지역에서 쉬었는데 여기서 쓰러지면 그 지역으로 바꿔 거기서 선다. 쉰 적이 없으면 0032대로 끝.
- **기록**: `run.stage`·`run.down`(새 키 — 없으면 0). 상자 번호는 지역마다 `지역 × 1000 + 번호`(성소는 그대로 — 옛 기록이 이어진다). 숨은 물건·엘리트·문은 이미 `find_prefix`로 지역마다.
- **장치가 없는 지역**: 문 장치도 물결도 없으면 처음부터 문이 열린 단계(`GateOpen`).
- **개발**: 개발 창 "둘째 지역으로"(마을 어귀에서, 이 판에 첫 문지기를 이긴 셈).

## 하지 않은 것
- 지역 환경(뿌리 천장·빛줄기)은 T2, 마을 지도는 C1 — T1의 마을은 빈 상자 지도.
- 화로 사이 순간 이동(0116).

## 확인(헤드리스, 2026-11-08)
- 처음엔 단면이 기둥마다 빛을 달리해 세로 줄무늬로 읽혔다 → 띠마다 한 빛(번갈아)으로 바꾸니 지층으로 읽혔다(KB conveying-descent "큰 덩어리 먼저"와 같은 결).
- 열린 바닥의 어두운 원판이 갈 곳 빛기둥 밑동에 덮여 안 보였다 → 바닥 길 8m 안에서는 기둥을 걷고(멀리서는 길 안내 그대로), 원판은 바닥에서 5cm 띄운다.
