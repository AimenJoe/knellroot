# 0176. 덧옷 — 줍는 걸칠 것, 방어력 숫자 없이

- 날짜: 2026-11-14
- 상태: **결정**(사장 2026-11-14) — 만듦, 판정 전(체크리스트 32).
- 바탕: 0064 M3(장신구 — `Stats` 한 곳)·0105(숨은 물건 `stage::Find`)·0068(아이템 그림 `item_view`)·0130(도감)·0157(주인공의 생김새는 그림 먼저)·0143(맞음 피드백 — 맞음을 받는 한 자리)·lore `ecology.md` 10절(장신구 = 옛 흔적)·KB `concepts/action-rpg-stats-and-equipment.md`.

## 사장의 말
"방어구는 아이템이고 줍는 거지, 거기에 뭐가 효과가 있을 수도 있고. 다만, lore에 맞게 너무 RPG식은 말고."

## 정한 것
1. **이름은 "덧옷"**(방어구·갑옷이 아니다): 방랑자의 옷 위에 걸치는 것 하나. 칸은 하나 — 장비 탭의 다섯째 칸(인형 왼쪽 아래, 무기 칸 밑).
2. **줍는다**: 숨은 물건의 새 종류 `Find::Garb`(지도 글자 `M`, 기록 이름 `<스테이지>.garb.<n>`). 가진 덧옷은 따로 적지 않고 주운 숨은 물건(`finds`)에서 센다(`garb::owned` — 종소리 조각과 같은 꼴). 걸친 것만 기록 `garb.worn`(가진 것이 아니면 벗은 채로 읽는다). 아무것도 안 걸쳤으면 주울 때 바로 걸친다(장신구가 빈 칸에 끼워지는 것과 같다). 상자 차례(위에서부터 = 기록 번호)를 건드리지 않으려고 상자가 아니라 숨은 물건으로 — 옛 기록이 그대로 이어진다.
3. **방어력·받는 피해 숫자는 없다** — 덧옷이 바꾸는 것은 **맞을 때 몸이 어떻게 되는가**와 그 무게뿐:
   - 맞을 때 밀림(`Mods::knock` → 랩 `hurt.knock`을 휜다)·맞을 때 휘청임(`Mods::flinch` → `hurt.stun`)
   - 회피 기력·기력 회복(이미 있는 줄)
   - 공짜는 없다: 덜 밀리는 옷은 회피가 무겁고, 더 밀리는 옷은 가볍다(시험).
   - 맞아도 아예 안 밀리고 안 휘청이는 몸은 만들지 않는다(밀림·휘청임 배 0.35~1.8 — 맞음이 읽혀야 한다, 0143).
   - 월드는 덧옷을 모른다: `Stats::tune`이 휜 랩 값을 맞음의 한 자리(`wanderer_takes_hit`)가 그대로 읽는다.
4. **설명은 말로만**("가볍다. 회피에 기력이 덜 들고…"), 숫자는 장비 탭이 견줄 때(`값 → 값 ▲▼`)와 상태 줄(새 줄 "맞을 때 밀림"·"맞을 때 휘청임")에서만. 장신구의 설명이 숫자로 시작하는 것과 다르게 — "너무 RPG식은 말고".
5. **세 벌**(표 `garb.rs` — 새 덧옷 = 줄 하나 + 지도 `M` + 글 셋 + 모델 부위):

| 덧옷 | 놓인 곳 | 몸 | 세계 안의 말 |
|---|---|---|---|
| 해진 순례 망토 | 침묵의 성소, 성벽길 북쪽 끝 | 가볍다 — 회피 기력 ×0.85 · 기력 회복 ×1.1 · 밀림 ×1.35 · 휘청임 ×1.2 | 먼 길을 걸어온 옷. 어디서 왔는지는 해진 자락만 안다. |
| 뿌리껍질 덧옷 | 침묵의 성소, 뿌리 굴의 화로 곁 | 무겁다 — 밀림 ×0.45 · 휘청임 ×0.55 · 회피 기력 ×1.3 | 뿌리의 껍질을 겹겹이 엮었다. 뿌리처럼 버틴다. |
| 그을린 가죽 앞치마 | 떠난 마을, 불 지키는 주민의 집 뒤 | 덜 휘청인다 — 휘청임 ×0.6 · 밀림 ×0.8 · 회피 기력 ×1.1 | 불 곁에서 오래 일한 사람의 것. 그을음이 겹겹이 앉았다. |

   입구 폐허에는 두지 않는다(초반에 강해지는 것이 몰리지 않게, 사장 2026-11-08). 마을의 "꿰맨 천"(장신구, 체력 +10)과 겹치지 않게 마을의 덧옷은 앞치마로 했다.
6. **세계관**(lore `ecology.md` 10절에 한 줄): 떠난 이들이 남긴 옷 — 기능은 몸이 맞음을 받는 꼴과 무게뿐, 방어력·힘을 주지 않는다, 누가 입었는지는 정하지 않는다(장신구 = 옛 흔적과 같은 결).
7. **보이는 곳**: 장비 탭 다섯째 칸(칸 커서 — 왼쪽 열 무기·덧옷, 오른쪽 열 장신구 셋, 좌우는 같은 높이로, 빨리 바꾸기는 공격 버튼), 후보 목록(벗기 + 가진 것), 도감 셋째 묶음 "덧옷"(못 찾은 것은 "???"와 놓인 곳), 바닥의 줍는 것(개어 놓은 천 꼴의 납작한 덩이 + 옅은 라벤더 빛기둥 — 등잔 금빛·한 모금 민트·조각 크림과 갈린다), 아이템 그림 셋(`charms.py`의 `garb_*` 부위 — 코드로 찍은 상자·덩어리, AI 생성 없음).

## 하지 않은 것
- **몸에 걸친 모습**: 인형·싸움 화면의 방랑자는 그대로다. 0157 — 주인공의 생김새에 코드로 새 꼴을 덧붙이지 않는다(천·살 같은 흐르는 꼴은 도형을 붙이면 그 도형으로 읽힌다). 걸친 모습이 필요하면 그림 먼저(앞·뒤·옆) → 사장 확인 → 메시를 다시 받는다.
- 덧옷 강화·여러 칸(머리·몸·발)·무게 체계: RPG식이 되는 길이라 하지 않았다.
- 가게에서 사기: 줍는 것만.

## 판정에서 볼 것(체크리스트 32)
- 덧옷의 차이가 싸움에서 **몸으로** 느껴지나(뿌리껍질로 떼 속에서 버티기 · 망토로 구르며 빠지기).
- 숫자 없이 말로 쓴 설명이 충분한가, 또는 견줄 때의 숫자가 너무 RPG 같나.
- 놓인 곳 셋이 찾을 만한가(너무 쉽거나 너무 숨었나).
- 걸친 모습을 그릴지(그림 먼저 — 0157).
