# 0192 — 슬롯 덮어쓰기·지우기는 묻는 창으로

- 날짜: 2026-11-14
- 상태: 채택(개발판)
- 사장: "시작하기로 기존 세이브파일 덮어쓸 때, 얼럿이 나와야 해. 단순히 텍스트를 바꾸는 것으로는 인지가 잘 안 됨."

## 바꾼 것
- 0066의 "두 번 누르기"(첫 누름에 단추 글이 "정말 덮어쓸까요?"로 바뀜)를 걷고, **묻는 창**(`Scene::Ask` — `flow::Ask::Overwrite(슬롯)`·`Erase(슬롯)`)을 띄운다.
  다른 되돌릴 수 없는 일(처음부터·타이틀로·되돌리기·거두기)과 같은 꼴이다(CLAUDE.md "되돌릴 수 없는 일은 `Scene::Ask`").
- 물음에 그 슬롯의 이름과 요약(장 · 지역 · 시간)을 넣는다 — 무엇을 잃는지 보이게. 단추 = 덮어쓰기(지우기) / 취소, 커서는 **취소**에서(`flow::ask_default`).
- 덮어쓰기 = 묻는 창을 닫고 그 슬롯을 비운 뒤 새로 시작(`App::overwrite_slot`). 지우기 = 닫고 지운 뒤 슬롯 창에 남는다 — 마지막 기록이면 타이틀로(`App::erase_slot`).
- 규칙은 순수한 `flow::slot_pick(load, filled, col, slot) -> SlotDo`(시험), 글 `ask_overwrite`·`ask_erase`(옛 `slot_*_sure` 자리, 한·영).
- 시험 `tools/test/save.js`: 한 번 누르면 묻는 창만 · 취소는 그대로 · 왼쪽 + 확인 = 덮어쓰기.
