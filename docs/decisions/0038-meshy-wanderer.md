# 0038. 방랑자 몸을 AI 모델로 — Gemini 그림 → Meshy → 부위로 잘라 뼈에 붙임

- 날짜: 2026-11-04
- 상태: 채택(사장: "3d 모델링을 다른 툴에 맡긴다면, 다시 우리 t3ssel8r 스타일로 만들 수 있는 거 아니여? 디테일 살려서?" → Meshy 결과를 보고 "응 1번 진행하고 카메라 비켜두는 쪽으로 해봐. 그리고.. 모션!").
- 0037 "색 = 생명"의 방랑자 디자인은 그대로. 바뀌는 것은 **몸을 만드는 길**뿐이다. 코드 모델은 `wanderer.py make_blocks()`에 남긴다.

## 왜
- t3ssel8r 쪽 룩의 절반은 렌더(낮은 해상도·외곽선·띠 빛 — 이미 있다), 절반은 **모양과 칠한 텍스처**다. 스크립트 상자 모델에는 텍스처가 없다(`docs/research/2026-11-03-t3ssel8r-style.md`).
- 디테일의 한계는 화면이다: 방랑자 키는 쿼터뷰 약 20px·락온 약 50px. 그래서 "디테일 = 큰 색 덩어리"로 그리게 했다(`tools/art/tiny_preview.py`로 Gemini 그림을 미리 거름).

## 길(다시 하는 법)
1. Gemini(나노바나나) 정면·옆 그림 — 프롬프트 `docs/art/gemini-prompts-0038.md` "t3ssel8r 쪽"(A-pose·흰 바탕·평평한 빛·넓은 평면색). 원본 `tools/art/sources/ai/knellroot/`.
2. Meshy Image to 3D(무료 = Meshy 6 Lite·CC BY 4.0, 월 10개 다운로드) → GLB 원본 `tools/art/sources/meshy/raccoon_v1.glb`(삼각형 101k).
3. `meshy_convert.py`: 머리로 가운데 맞추기·키 1.4m → UV 이음매에서 갈라진 정점 합치기 → 줄이기 → 새 UV(Smart 89°) → 원본 색을 Cycles로 굽기(256) → `raccoon_v1_low.glb`(glTF 정점 1,899).
   함정: 그냥 줄이면 하얀 금(갈라진 정점·잘게 쪼갠 UV). 구울 그림을 재질에 이어 두면 검정(순환), apt Blender는 노이즈 제거가 없어 켜져 있으면 조용히 검정.
4. `wanderer.py make()`: `Model.external`이 면 가운데 자리로 부위(머리 = 두건 아래 가장자리 z 0.628 위, 팔 = 어깨 → 손끝 원기둥, 다리 = 치마 밑, 꼬리 = 뒤·왼쪽)를 나눠 지금 뼈에 강체로 붙인다. 칼·등잔은 코드 그대로.
   로더는 이미지 하나만 읽는다 → `merge_textures`가 구운 텍스처(왼쪽 반)와 코드 아틀라스(오른쪽 위)를 512×256 한 장으로. glTF에서 온 사용자 법선은 지워 접힌 면을 각지게(뒤집힌 면 검사).
- 결과: 정점 2,235/2,400·삼각형 2,352·이미지 1, 동작 17 그대로. 다른 모델 열하나는 같은 스크립트로 다시 내보내도 바이트까지 같다.

## 모션
- 동작 표(0034)는 그대로 새 몸에 붙는다(`docs/art/meshy-0038/result-v2/motion_*.png`, `tools/art/blender/motion_strips.py`).
- 새 몸에 맞춘 것: 목은 두건 가장자리에서 잘라 고개를 젖혀도(마시기·맞기) 자른 자리가 안 보이게. 걷기는 짧은 다리 + 큰 머리라 **뒤뚱**(몸 옆 기울기 ±7°, 머리는 반대로 4°)·**통통**(지날 때 더 오름, 고개 끄덕)·꼬리 ±24°. 쉬기에 고개 갸웃·꼬리 ±14°.
- 팔은 장갑 손 + 소매 끝만 돈다(윗소매는 몸에) — 크게 휘둘러도 소매가 찢어져 보이지 않는다.

## 락온 카메라(보류 — 사장 판정)
- 두건이 몸보다 넓어 락온 때 과녁 아래쪽을 가린다. 어깨·주시점·높이 다섯 벌을 게임에서 찍었다(`result-v2/lock_camera_variants.png`). 원근 때문에 보스도 같이 밀려 **카메라만으로는 다 비켜나지 않는다**. 1.6 / 2.3 / 3.0(어깨 / 주시점 / 높이)이면 핵·머리는 늘 보이고 바닥 예고도 더 보인다.
- 그런데 0009의 시험 "전환이 대상의 어느 쪽에서든 비슷하게 부드럽다(최악/최선 < 1.8배)"가 깨진다: 지금 값이 이미 1.77배이고, 어깨를 조금만 비켜도 1.84~2.07배(최악은 258°/s로 한계 340 안). 기준을 고치는 것은 판정이라 **기본값은 그대로 두었다**. 랩(F1)에서 `cam.lock.*`로 바로 해 볼 수 있다.
