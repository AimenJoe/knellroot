# 0247 — 방랑자 v3 몸: 그림 A → Meshy 7.1 → 자동 리깅 → v2 동작 옮겨 담기

- 날짜: 2026-11-19
- 번호: 처음 0246으로 적었으나 main에서 갈라 만든 호스팅 PR #30(운영 웹판 `/play`)이 0246을 먼저 써서 0247로 옮겼다(커밋 메시지의 0246 = 이 결정).
- 상태: **만듦**(판정 전 — 체크리스트 91-8)
- 사장: "Meshy 에서 모델 자체를 더 최근 모델로 뽑으면?" → "그림부터 그려야 겠어. 이미 지금 몸 비율이 귀여움을 주니 잘생기게 뽑히도록 … 나노바나나 … 이미지 생성해서" → 시안 셋 가운데 "A 로 가자"

## 왜
0245(텍스처 512)로는 게임에서 차이가 작았다. 거칠어 보인 까닭은 Meshy-6 원본 텍스처의 얼룩, 보라 두건이 보라 세계와 섞이는 것, 각진 면이었다.
0157대로 그림 먼저: 지금 비율(큰 머리·짧은 몸)을 지키고 얼굴·옷의 대비를 살린 그림 A(크림색 튜닉·또렷한 눈매·줄무늬 꼬리)를 사장이 골랐다.

## 한 것
1. 그림 A(나노바나나 pro) → Meshy Image to 3D **7.1**(`meshy_image3d.py --model latest`) → `raccoon_v3.glb`.
2. Meshy Rigging API(`tools/art/meshy_rigging.py`, 새 스크립트 — mixamo 템플릿 + 손가락) → `raccoon_v3_rig.glb`(뼈 65, 동작 없음).
3. **동작은 다시 사지 않는다**: `meshy_rig.py --retarget raccoon_v2_rig.glb`가 v2의 동작 49개를 같은 이름의 `mixamorig:*` 뼈 29개로 옮겨 담는다.
   - 뼈마다 쉬는 자세가 달라(Meshy 자동 리깅은 몸마다 뼈의 방향·돌림이 다르다) 원본의 쉬는 틀 → 대상의 쉬는 틀을 뼈 방향 + 몸 앞(−y)의 두 축으로 맞추고,
     매 프레임 대상의 월드 회전 = 원본 자세 · 원본 쉼⁻¹ · 맞춤⁻¹ · 대상 쉼. 뼈 방향만 맞추면 그 축 둘레(엉덩이·척추 = 몸의 방위)가 비어 몸이 비뚤게 선다.
   - 엉덩이의 움직임은 엉덩이 높이의 비(0.68)로 줄인다. 원본에 없는 뼈(두건·망토·꼬리 `Bone_*`)는 쉬는 자세 그대로(v2에서도 동작이 없었다).
   - v3 리깅의 엉덩이 뼈는 몸이 앞을 보는데 13° 돌아 있었다 — 엉덩이 뼈의 z를 "몸 앞"으로 읽는 셈(`own_yaw`·`wanderer_skin.py`의 정면 맞춤·시험)이 쇠뇌를 23° 비뚤게 겨눴다. 쉬는 자세의 돌림(roll)만 몸 앞으로 맞춘다(꼴은 그대로).
4. v3에는 왼손가락 뼈가 없다 — 등잔·활을 쥐는 자리는 손뼈의 꼬리 쪽으로, 오른손의 손목 → 가운데 손가락 뿌리 길이만큼(`wanderer_skin.py knuckle`).
5. 정점: 몸 2,825(`--target 2850`) + 무기·등잔 → `wanderer.glb` 4,773 / 예산 4,800. 텍스처 512(0245).

## 고침(같은 날, 사장 "기본 모션의 머리 각도가 이상해")
- 처음 판은 뼈마다 원본의 **방향**을 베꼈다(쉬는 틀 맞춤). v3 리깅은 목뼈가 뒤로 29°·등뼈가 23~29° 다른 자리에 있어(몸통 뼈의 자리는 몸마다 다르다)
  목이 앞으로 꺾여 머리가 가슴 앞으로 쏠리고 옆으로 기울었다. → 원본이 쉬는 자세에서 **바뀐 몫**(월드 회전)만 대상의 쉬는 자세에 얹는다
  (Pt = Ps · Rs⁻¹ · Rt — 두 몸 모두 A 자세라 팔 차는 10° 안팎).
- 엉덩이 높이의 비만으로 옮기면 다리가 다른 몸의 발이 땅을 파고들었다(내려찍기 착지 −0.3m). → 프레임마다 대상의 가장 낮은 발이 원본의 가장 낮은 발이
  오르내린 만큼(비)만 오르내리게 엉덩이를 위아래로 민다. 엎드린 동작(쓰러짐·깨어남)은 큰 머리가 땅에 조금 묻힌다 — v2도 같았다(−0.2~−0.5m).
- 모션 보기의 인형이 서 있는 틀로 고정돼 쓰러짐·내려찍기 착지·깨어남이 칸 밖으로 잘렸다 → 동작마다 휜 몸 정점이 쓸고 가는 틀에 맞춰 물러선다
  (`render::items::sweep_box`·`doll_eye`, 시험 `the_motion_doll_frames_the_whole_sweep_and_keeps_standing_moves_the_same_size`).
