# 0273 — 용어 정리: 시스템의 말은 통용어로, 세계의 이름은 그대로

- 날짜: 2026-11-25
- 상태: 채택
- 사장(2026-11-24): "용어도 다른 게임 참조해, 주/곁이 아니라 주무기·보조무기, 주특성·보조특성 이런 식으로 해야지." → 지어 쓴 새 말을 고친 뒤
  "응 기존 용어도 정리해".

## 원칙
1. **시스템의 말**(플레이어가 규칙을 읽는 말 — 스킬·쿨타임·등급·강화 …)은 한국어 ARPG에서 통하는 말을 쓴다. 지어낸 말·직역한 말(창 = window)을 쓰지 않는다.
2. **세계의 이름**(이 게임에만 있는 것의 이름 — 잔불·등잔·화로·문지기·덧옷·종소리 조각, 속성의 이름 여덟)은 그대로 둔다. 소울의 "룬·성배병"처럼
   고유명은 게임의 몫이다. 단 고유명 곁의 **하는 일**은 통용어로 적는다("잔불 +10 — 분해").
3. 한 뜻에 한 말. "기술"과 "스킬"처럼 둘이 섞인 것은 하나로.
4. 새 말이 필요하면 먼저 다른 게임(엘든 링·디아블로 4·로스트아크·몬스터 헌터 한국어판)의 말을 찾는다.

## 고치는 범위
- **화면의 글**: `i18n/ko.rs`·`en.rs`의 값만(키 이름·기록 키·코드 식별자는 그대로 — 기록이 깨지지 않는다). 글자가 바뀌니 글꼴 서브셋을 다시 만든다.
- **문서**: 이 뒤로 쓰는 문서·체크리스트·커밋은 새 말로. 지난 결정 문서는 고치지 않는다(그때의 말로 남긴다) — `CLAUDE.md`에는 이 표를 가리키는 한 줄과
  자주 나오는 옛말 ↔ 새 말의 짝만 적는다.
- 코드의 이름(`Plate`·`Vein`·`Key`·`Grip`)은 그대로 — 영어 식별자는 화면에 나가지 않는다.
