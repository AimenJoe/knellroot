# 0056. 원거리 강공격: RB를 쥐어 모으기

- 날짜: 2026-11-04
- 상태: 채택·구현(사장: "원거리 공격(근접무기 장착시에는 마법등)도 모으는 강공격 넣어줘")

## 정한 것
- **근접 강공격(0030)과 같은 틀**:
  - RB를 누르는 순간 보통 탄이 나간다(누른 순간 반응 — KB melee 노트 "평타는 누르는 순간").
  - 쏜 뒤에도 RB를 `cast.hold start s`(0.25) 넘게 쥐고 있으면 **모으기**(`PState::CastCharge`)로 넘어간다.
  - 떼면 모은 탄이 나간다.
    - `cast.charge s`(0.7)를 다 모았으면 무기 표의 `charged`.
    - 덜 모았으면 피해·자세 피해가 반이고, 꿰뚫기·휘청이 없다.
- **값**: 떼는 순간 칸 하나(마법) 또는 볼트 하나(쇠뇌)를 쓴다. 쓸 칸·볼트가 없으면 모으기로 가지 않는다.
- **무기마다 모은 탄**(`weapons.rs` `Weapon::charged`):

  | 무기 | 모은 탄 |
  |---|---|
  | 검 | 크고 꿰뚫는 빛 덩이(피해 3, 휘청 0.6초) |
  | 망치 | 느리고 아주 큰 덩이(피해 4, 자세 피해 8, 휘청 1초) |
  | 지팡이 | 빠르고 멀리 가며 줄 선 적을 다 꿰뚫는다 |
  | 쇠뇌 | 시위를 끝까지 당긴 볼트(피해 5, 꿰뚫음, 수류탄을 맞히면 터짐) |

- **모으는 동안**:
  - 느리게 걷고(`cast.walk x`), 조준 스틱·락온·이동 쪽으로 돈다. 회피로 끊는다.
  - 손에 빛이 자라고 발밑 고리가 차오른다. 다 모이면 깜빡이고 `Event::Charged`가 난다.
  - 동작: `cast_charge`(두 손을 모아 빛을 키움)·`xbow_charge`(어깨에 대고 당김).
- **탄 크기**: `Bolt::scale`로 그림과 맞는 반지름이 커진다.
- **입력**: `Actions::cast_held`를 키·패드·Android·터치(마법 버튼을 짚은 손가락)에서 읽는다.
- **고친 것**: 틱이 눌림을 가져간 뒤에도 "쥐고 있음"은 남아야 한다(`input::carry`). 처음에는 RB를 빠뜨려 한 프레임의 둘째 틱부터 모으기가 끊겼다 — 헤드리스 화면에서 찾았다. 랩을 열었을 때도 RB가 지나가게 했다.
- **시험**: `holding_rb_charges_a_stronger_magic_bolt`, `the_crossbow_charges_a_piercing_shot`, `held_buttons_survive_take`.
- **얼린 값**: `CAST_HOLD_START`·`CAST_CHARGE`를 덧붙였다.
