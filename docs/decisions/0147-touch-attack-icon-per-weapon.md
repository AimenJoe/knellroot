# 0147. 터치 공격 버튼의 그림은 든 무기 — 검·망치·지팡이·쇠뇌·주먹

- 날짜: 2026-11-11
- 상태: **구현**(`release/v0.6`, 판정 전). 0146의 "남은 것"에 대해 사장 2026-11-11: "응 어차피 종류는 정해졌으니까."
- 바탕: 0146(13×13 도트 픽토그램)·0051(무기 표 — 검·망치·지팡이·쇠뇌, 0076 맨손). 첫 게임 nail은 터치 그림을 캐릭터 표에서 고른다(0172).
- 그림: `docs/art/touch-0146/weapon-icons.png`(다섯 그림, 어두운·밝은 바탕), `sword-and-fist.png`(검을 든 화면 · 장비 창에서 맨손으로 바꾼 뒤).

## 정한 것
- 공격 버튼은 **든 무기의 그림**을 그린다: 검 = 칼(0146 그대로), 망치 = 비스듬한 망치, 지팡이 = 끝에 구슬이 달린 막대, 쇠뇌 = 활 + V자 시위 + 몸통, 맨손 = 주먹.
- 고르는 곳은 `touch::attack_icon(weapons::Id) -> Kind` 한 곳, `_` 없는 match — 새 무기를 더하면 여기서 그림을 정하지 않고는 컴파일이 안 된다.
- 그림만 있는 종류(`Kind::Hammer`·`Staff`·`Crossbow`·`Fist`)는 모닥불(`Kind::Rest`)과 같은 꼴: 버튼 배치에는 없고 그릴 때만 공격 자리에 들어간다. 자리·크기·판정은 그대로.
- 쇠뇌는 넷을 그려 보고 골랐다: 활 + 가로 시위는 우산으로, 화살을 건 활은 물고기로 읽혔다 — 당겨진 **V자 시위**가 쇠뇌를 말한다.

## 시험·확인
- 단위 시험(0146의 시험에 더함): 새 그림 넷도 13×13·칸 수 범위·다른 모든 그림과 12칸 이상 다름, 무기 다섯의 공격 그림이 서로 다르다.
- 헤드리스 폰(`tools/test/touch.js`): 장비 창에서 맨손으로 바꾼 뒤 공격 버튼이 주먹으로 바뀐다(`sword-and-fist.png`).
- **확인 못 한 것**: 망치·지팡이·쇠뇌를 든 게임 화면(새 기록은 검·맨손뿐이라 터치 시험이 거기까지 안 간다 — 그림은 미리보기 판으로만), 실제 폰에서의 읽힘.
