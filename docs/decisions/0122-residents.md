# 0122. 떠난 마을의 남은 주민(v0.5.0 C7) — 상자 배우·말풍선·무심한 경계·재방문 기록

- 날짜: 2026-11-08
- 상태: **채택·구현(상자 배우 — 모델은 0061 체크리스트로 판정 뒤)**(`release/v0.5`). 0115(주민 공통 규칙·전투 안전 설계), 0116 2절(아궁이·재방문 조건·공격이 닿지 않음·머리 위 말풍선), 설계 문서 `docs/design/stages/abandoned-village-residents.md`(NPC-01~11). 새로 정할 것은 없어 인터뷰 없이 — 0116이 정한 대로.
- 스터디: nail의 말 걸기 말풍선(판 + 테두리 + 짧은 글, 0065 "UI 기본틀은 nail에서"), nail `story.rs`(한 사람의 늘 하는 말·한 번의 변화).

## 정한 것(구현)
- **주민 = 표 한 줄** `residents::RESIDENTS`: 기록 이름(`V01`·`V02`·`V03` — 이벤트 ID의 앞), 지도 표지(`1`·`2`·`3`), 생활 행동(`Work`: 아궁이·물 받기·천 꿰매기), 늘 하는 말 셋 + 재방문 뒤의 한마디, 몸빛.
- **싸움에 끼지 않는다**: 주민은 월드의 적이 아니다 — 맞지도, 락온·자동 조준되지도 않고, 적의 대상도 아니다(0116 "공격이 지나간다"). 몸은 방랑자만 밀어낸다(`World::bodies` — 탄·적은 지나간다). 자리는 레벨 배치로 안전하다(0121, 모든 적의 끈 + 3m 밖).
- **무심한 경계**: 5m 안에 오면 천천히 돌아보고, 멀어지면 제 일 쪽으로 돌아간다. 먼저 다가오지 않는다.
- **말 걸기**: 곁(2.2m)에서 점프 버튼(상호작용) — 안내 줄 "버튼 말 걸기". 멈추지 않는다: 머리 위 말풍선이 3.5초 떠 있다 사라진다, 떠 있는 동안 다시 누르면 다음 말(셋을 돈다). 말을 걸지 않아도 진행된다(NPC-11).
- **재방문**(0116): 주민을 10m 안에서 처음 본 판을 기록(`residents.seen` = `V01:판 번호`), **그보다 뒤의 판**에서 마을에 들어서면 한 번 바뀐다(`residents.changed`, 단방향 — 다시 되돌리지 않는다). 판 번호 = 새 판을 시작할 때마다 하나(`runs` — 결과 화면의 다시·처음부터·쉰 곳 없는 이어하기; 쉰 곳이 있는 이어하기는 같은 판). 바뀌면:
  - 불 지키는 사람: 아궁이 불빛이 살아난다(빛 웅덩이·불꽃이 커진다) — "장작을 조금 더 구했어."
  - 물 모으는 사람: 기울어진 항아리가 바로 서 있다 — "항아리를 바로 세웠어. 이제 넘치진 않겠지."
  - 꿰매는 사람: 찢어진 천막이 한 장으로 꿰매져 있다 — "천막을 조금 꿰맸어. 아직 멀었지만."
  - 바뀐 뒤엔 그 한마디가 말의 맨 앞에 선다.
- **문지기와 묶지 않는다**: 처치 여부는 주민 상태를 바꾸지 않는다(설계 문서 "보스 처치 전후").
- 대사는 설계 문서 초안(PROPOSED) 그대로 + 영어. 다듬기는 C4(글).
- 옛 기록: 키가 없으면 판 0·본 주민 없음(NPC-07).
- 개발: "둘째 지역 주민 곁에서(말 걸기)".

## 시험
- 주민은 적이 아니고 몸은 셋, 멀리선 안 보이고 다가가면 한 번 기록, 돌아본다, 곁에서 상호작용 = 말 걸기(쉬기 같은 다른 일 없음), 몸이 방랑자를 밀어낸다.
- 말: 셋을 돈다, 바뀐 뒤엔 한마디가 맨 앞. 재방문: 같은 판은 아니고 뒤의 판만, 한 번 바뀌면 그대로.
- 기록: 판 수·본 주민·바뀐 주민이 왕복하고 옛 기록은 비어 있다.

## 판정에서 볼 것(사람, 0116 Z6)
- 마을이 "고요하고 쓸쓸한, 누가 사는 곳"으로 읽히나, 주민이 싸움을 방해하지 않나.
- 말풍선 3.5초·다시 누르기가 손에 맞나(패드·터치), 돌아보는 몸짓이 "무심한 경계"로 읽히나.
- 다음 판에 다시 와서 바뀐 것을 알아차리나.
