# 0197 — 뒤로 뛰기 회피 · 락온 옆걸음의 다리 · 뒷걸음 보폭 · 쇠뇌 겨눔 유지 · 장치 당기기 · 구르기·마법 다듬기

- 날짜: 2026-11-15
- 상태: 채택(개발판, 판정 전)
- 사장: "Back jump도 쓰고, 나머지 동작들, 수정할 수 있는 건 수정하자" (0196 "그대로 둔 것"의 이어)

## 바꾼 것
| 무엇 | 어땠나 | 고친 것 |
|---|---|---|
| 뒤로 피하기 | 입력 없이 피하면(뒤로) · 락온 중 뒤로 피하면 몸은 앞을 보는데 **앞구르기** 동작으로 뒤로 미끄러졌다 | 회피 방향이 몸이 보는 쪽의 반대(안쪽 곱 < −0.5, `BACKSTEP_DOT`)면 **뒤로 뛰기**(원본 Back_Jump — 웅크렸다 뒤로 뛰어 받는다, 0.25초). 원본의 뒤로 간 쪽 = 몸의 뒤(`FACE_TRAVEL`) |
| 구르기 | 원본 1.17초(일어서기까지)를 0.25초에 4.7배로 눌렀고, 원본이 왼쪽 앞 37°로 굴러 가는 쪽과 몸이 어긋났다 | 몸통 구간만(뜀 → 말림 → 웅크려 닿음, 3.8배), 몸을 돌려 구르는 쪽 = 앞(`FACE_TRAVEL`). 일어서기는 서기로 섞일 때 |
| 락온 옆걸음 | 게걸음 동작이 없어 **앞으로 걷는 동작으로 옆으로 미끄러졌다** | 다리(엉덩이)를 가는 쪽으로 돌리고 첫 등뼈를 되돌려 윗몸은 과녁에 둔다(렌더만 — `move_anim`이 돌림 각을, 한도 80°, 부드럽게 따라감). 110°보다 뒤로 가면 뒷걸음, 다리는 가는 쪽의 반대로 |
| 뒷걸음 | 원본 보폭이 걷기의 0.6배·주기 1.5배라 같은 빠르기로 돌리면 발이 땅을 미끄러졌다(발 빠르기 0.37 vs 걷기 0.90) | 걸음 시계를 2.4배로(`WALK_BACK_RATE` — 시험이 발 빠르기를 걷기와 15% 안으로 본다) |
| 쇠뇌 쏜 뒤 | 쏠 때마다 옆으로 선 겨눔 ↔ 정면 서기를 0.14초에 홱 돌았다(연사면 매번) | 쏜 뒤 서 있으면 0.7초 겨눈 채 머물고(`AIM_HOLD`), 내릴 때는 0.35초에 걸쳐 섞는다(`AIM_BLEND`) |
| 장치 당기기 | 몸짓이 없었다 | 끌어모으기 원본 M13(손을 뻗어 잡고 몸으로 당김)을 0.65초 몸짓으로 — 줍기와 같은 길(`App::gesture` 이름 + 시각, 서 있는 동안만) |
| 마법 쏘기 | 왼손을 내미는 순간 바로 거둬 손만 까딱였다 | 내밀고(0.075초) 내민 채 버티고(0.25초까지) 거둔다 |

시험: `locked_on_sideways_steps_turn_the_legs_and_backwards_walks_back`, `walk_back_steps_keep_pace_with_the_ground`,
`gesture_lengths_match_the_model`, 스테이지 시험의 `take_pulled`.

## 남은 것
- 마법 동작(M06)은 버팀을 늘려도 내미는 손이 몸 옆이라 쿼터뷰에서 작다 — 더 크게 하려면 새 동작(손바닥을 앞으로 내밀어 빛을 쏘는 1초짜리)을 받는다.
- 지팡이 강타는 도는 베기라 그대로. 말 걸기·읽기는 몸짓 없음(말풍선·글 판이 말한다).
