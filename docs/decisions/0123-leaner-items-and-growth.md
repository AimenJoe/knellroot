# 0123. 아이템·성장을 덜 후하게 — 회복·잔불·숨은 물건·장신구·나무·횟수

- 날짜: 2026-11-08
- 상태: **채택·구현**(`release/v0.5`). 사장 2026-11-08: "아이템은 아직도 너무 후해서, 난이도를 많이 떨어뜨림" → 인터뷰(여럿 고르기)에 **전부**(등잔 횟수·회복량, 잔불, 숨은 물건·상자, 장신구·나무 효과, 전체 횟수).
- 얼린 값을 바꾼다(0013): `flask.raise s` 0.35 → 0.45, `flask.time s` 0.8 → 1.0 — 이 기록이 그 판정(`docs/tuning-frozen.txt` 다시 씀).
- 0117(v0.4.2)에서 입구 강화를 덜고 가게 값을 올린 뒤의 둘째 걸음. 원칙은 0095(판정 창은 늘리지 않는다)·0102 그대로.

## 정한 것
| 무엇 | 전 → 후 | 왜 |
|---|---|---|
| 등잔 기본 횟수 `FLASK_CHARGES` | 3 → **2** | 숨은 등잔 +1을 찾아야 3(탐험의 보상이 다시 값이 있다) |
| 마시기 | 들기 0.35 → **0.45초**, 끝 0.8 → **1.0초** | 회복량(2)은 두고, 싸움 한가운데서 마시는 값을 키운다 — 틈을 읽어야 마신다 |
| 숨은 물건(성소) | 한 모금 2 → **1**, 종소리 조각 3 → **2** | 한 모금 둘이면 한 번에 4를 채웠다. 뒤 차례를 뺐다(앞 것의 기록 이름은 그대로 — 옛 기록이 이어진다) |
| 숨은 물건(마을) | 한 모금 1 → **0**(조각 하나만) | |
| 적 잔불 | 잔재 2 → **1**, 가시짐승 3 → **2**, 등딱지짐승 4 → **3**, 꼬투리 3 → **2**, 문지기 40 → **30** | 한 판(성소 다 깸) 약 150 → 약 60 |
| 엘리트 | 잔불 ×3 → **×2**, 처음 쓰러뜨림 덤 30 → **15** | |
| 상자 겹침 잔불 `CHEST_EMBERS` | 15 → **10** | |
| 등급 2 잔불 배율 | ×1.6 → **×1.3**(올림) | 마을 잔재 2·가시짐승 3 |
| 레벨 값 | 40 + 20×L → **50 + 25×L** | 첫 판 레벨 1, 둘째 판에도 1, 넷째 판 3(전: 1·2·4). 15까지 3,375(전 2,700) |
| 레벨 한 단 | 기력 +12 → **+8**, 충전 +10% → **+6%**(3·5단), 자세 +12% → **+8%** | 생명(+1 체력)·힘(피해 +1 단계)은 그대로 — 정수라 더 줄이면 단이 비어 보인다 |
| 장신구 | 잔불 주머니 +50% → **+25%**, 가벼운 발 회피 기력 −30% → **−20%**, 종지기의 귀 패링 창 +0.06 → **+0.04초** | 단단한 껍질(체력 +1)·문지기의 손(피해 +1·공속 −15%)·굶주린 뿌리(대가 있음)는 그대로 |
| 나무 칸 | 흐름 자세 2 → **1.5**, 맺음 1.5 → **1.3**, 틈 2 → **1.5**, 비껴서기 2 → **1.5** | 자세 깨기가 너무 쉽게 났다 |
| 가게 값 | 그대로(0117) | 잔불이 줄어 사실상 더 비싸다 |

## 하지 않은 것
- 화로에서 등잔이 다시 차는 것은 그대로(소울 규칙 — 쉬는 값은 적이 다시 서는 것).
- 회복량 2를 1로(체력 5에서 한 모금 20%는 짧다 — 마시는 시간으로 값을 매겼다).
- 마법 칸·수류탄 횟수(0111·0051) — 싸움 동사라 아이템과 따로 판정.

## 시험
- 레벨 값 합·빠르기(60/판)·단마다 수치, 등급 2 잔불(올림), 숨은 물건 넷과 기록 이름, 장신구 패링, 힘 5 자세 ×1.4, 기력 단의 막대 길이. 헤드리스 `save.js`(잔불 115 → 레벨 −50 → 주머니 −60 = 5).

## 판정에서 볼 것(사람)
- 첫 판·둘째 판에 성장이 "느리지만 있다"인가, 등잔 2번이 성소에서 빠듯하지만 되는가.
- 마시는 1초가 위험하게 느껴지나(쓸 때를 고르게 되나).
