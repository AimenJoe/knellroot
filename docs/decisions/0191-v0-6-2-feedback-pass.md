## 정한 것
1. **내부 해상도 540줄 + 2배로 그려 줄이기가 기본**(0190의 C + B): `render.rows` 540 · `render.ssaa` 1, `docs/tuning-frozen.txt` 다시 씀.
   1080 화면 = 배율 2(한 도트 2px), 그리는 타깃 1920×1080을 960×540으로 줄여 올린다. **배율이 1이면 2배를 끈다**(`fit_screen` —
   720줄 화면은 540을 고르면 720줄 그대로라 키운 계단이 없는데 네 배를 그릴 까닭이 없다). 인형·도감 그림도 같은 도트(0190).
2. **상태 탭의 큰 기술 줄에 키캡**: 두 스킬 버튼 함께 = "Q+E"(패드 "LT+RT", 지금 배치의 이름, 터치는 화면 버튼이 곧 안내라 없음).
3. **오른쪽 칸(상세)의 굴림 표시 = 가는 막대**: 전에는 ▲▼ 글자가 값 바로 옆이라 "50 → 60 ▲"의 오름 표지처럼 읽혔다. 칸 오른쪽 끝의 홈 +
   보이는 몫만큼의 손잡이(`tabs::draw_pane`). 모든 탭의 오른쪽 칸이 같이 쓴다.
4. **도감 넷째 묶음 = 무기**(적 · 장신구 · 덧옷 · 무기 — 끝에 붙여 옛 묶음 번호는 그대로): 가진 것 = 그림 + 이름 + 설명(설명에 세계 안의 말이
   들어 있다), 못 가진 것 = "???" + 나오는 곳. 맨손은 늘 있다. 나오는 곳 글은 `stage/sanctuary.rs`의 상자 차례(성벽길 쇠뇌 · 뜰 남동 단 지팡이 ·
   뿌리 굴 망치)를 따른다.
5. **설정 "시점 가로 감도"·"시점 세로 감도"**: 25~300%(25·50·75·100·125·150·200·250·300, 기본 100) — 자유 숄더뷰의 오른쪽 스틱·마우스·화면 끌기
