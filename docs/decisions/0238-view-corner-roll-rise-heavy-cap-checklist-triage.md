# 0238 — 시점 버튼은 구석에 · 구른 뒤 일어나기를 떼어 냄 · 모아 베기 숙임 상한 · 판정 체크리스트 정리

- 날짜: 2026-11-18
- 상태: **결정 + 만듦**(개발판 `release/v0.7`, 판정 전)
- 사장: "사용하지 않는 버튼을 숨길때, 저 시점 변환 버튼은 늘 쓸수 있으니 구석에 박아둬야지, 저 좌우회전이 없더라도 화면이 비어보이지 않지.
  위 니가 지적한 사항들 구현해주고. 아직 판정되지 않은 것들 중에 닫을 건 닫고 나머지는 나한테 물어봐, 대신 아직 판정하지 않음 이란 선택지
  넣어서. 아니면 설문조사 형식도 괜찮고."

## 1. 시점 버튼은 오른쪽 위 구석(0236을 고침)
- 0236은 땅 돌리기 둘을 숨겨도 시점 버튼을 옛 자리(돌리기 왼쪽)에 두어, 숄더뷰에서 오른쪽 위 구석이 비고 버튼 하나가 허공에 떠 보였다.
- 늘 쓸 수 있는 시점을 구석(멈춤과 마주 보는 자리)에, 돌리기 둘은 그 왼쪽(한 칸 띄워)으로 — 돌리기가 숨어도 줄의 끝은 그대로.
  시험 `the_shoulder_view_hides_the_turn_pair_and_empty_skill_slots`(구석 자리·돌리기는 그 왼쪽), `tools/test/touch.js` 배치 표.

## 2. 구른 뒤 일어나기(0237의 "남긴 것")
- 0.25초에 한 바퀴가 빨랐다 — 회피 시간(얼린 값, 0013)은 그대로 두고 **일어나기를 회피 뒤로 떼어 냈다**: 회피 0.25초는 구르기만(1 → 21 한 바퀴 → 23 닿음,
  구르는 몫 0.12 → 0.185초), 일어나기 `dodge_rise`(원본 23 → 38, 0.2초)는 회피가 끝나 서기·걷기·달리기(월드의 `Idle`)로 갈 때 렌더가 잇는다
  (`gait::rise_after_roll` — 순수, 시험 `a_roll_rises_into_the_calm_state_and_yields_to_any_action`). 공격·다시 회피 같은 동작이면 바로 그 동작(손맛은 그대로).
- 일어나기는 구르기와 같은 각으로 돌린다(`FACE_TRAVEL` 값에 다른 동작 이름 — 이음매가 맞게).

## 3. 모아 베기 숙임 상한(0237의 "남긴 것")
- Charged_Slash(모으기·강타가 같은 원본)의 머리 꺾임 58~68° → `LEAN_CAP` 몸 30° · 머리 30°(검 1·2타와 같은 규칙).
