# 0225 — 무기의 특색: 쥔 꼴로 갈리는 스킬 · 망치의 물리력 · 지팡이의 마법력

- 날짜: 2026-11-17
- 상태: 만듦(판정 전 — 체크리스트 77번)
- 사장: "망치는 물리력을, 지팡이는 마법력에 대한 특색이 있어야겠어. 한손검은 방패와 조합하면 방패 기술 사용 가능, 방패 없이는 결투 기술을
  사용 가능하게. 특색이 있으면 좋겠다."
- 잇는 결정: 0223 V3(무기 갈래마다 쓸 수 있는 스킬) · 0224(방패는 보조무기 칸에)

## 1. 무엇이 모자랐나

0223 V3의 갈래는 셋(한손·양손·원거리)이었다. 망치와 지팡이가 같은 "양손"이라 쓰는 스킬이 똑같았고, 한손검은 방패를 들든 말든 같았다 —
0224에서 방패를 "바꿔 들기와 맞바꾸는 것"으로 만들었지만 방패를 든 손이 **할 수 있는 일**은 막기 하나뿐이었다.

## 2. 쥔 꼴 다섯

스킬이 묻는 것을 "무기 갈래"에서 **손에 쥔 꼴**(`weapons::Grip`)로 바꿨다.

| 쥔 꼴 | 무엇을 들었나 | 특색 |
|---|---|---|
| 결투 | 한손 무기, 방패 없이 | 결투 기술 — 파고들고 빠지는 것 |
| 방패 | 한손 무기 + 방패 | 방패 기술 — 받아내고 밀어내는 것 |
| 망치 | 망치 | 물리력 — 타입 없는 스킬의 피해·자세 피해 ×1.3 |
| 지팡이 | 지팡이 | 마법력 — 스킬이 쌓는 타입 게이지 ×1.5 |
| 원거리 | 쇠뇌 | (그대로) |

## 3. 스킬마다 쓸 수 있는 꼴

| 스킬(타입) | 결투 | 방패 | 망치 | 지팡이 | 원거리 | 전(0223) |
|---|---|---|---|---|---|---|
| 휘돌이(물리) | ● | ● | ● | | | 근접 모두 |
| **가로지르기**(균열) | ● | | | | | 근접 모두 |
| 끌어모으기(뿌리) | ● | ● | ● | ● | ● | 모두 |
| 버팀(잔불) | ● | ● | ● | ● | | 근접 모두 |
| **땅울림**(물리) | | | ● | | | 양손 |
| 되울림(울림) | | ● | | ● | ● | 한손·원거리 |
| **던지기**(균열) | ● | | ● | | | 근접 모두 |
| 잔불 흩기(잔불) | | | | ● | ● | 모두 |
| **제비걸음**(물리) | ● | | | | | 한손 |
| **막아치기**(울림) | | ● | | | | 한손 |
| 뿌리 솟기(뿌리) | | | | ● | ● | 모두 |

- **결투 기술**(방패 없이만): 가로지르기 · 던지기 · 제비걸음 — 몸을 던지는 것들. 방패를 들면 못 쓴다.
- **방패 기술**(방패가 있어야): 막아치기 · 되울림 — 받아내고 되돌리는 것들.
- **망치**: 물리 스킬 둘(휘돌이 · 땅울림 — 땅울림은 망치만)에 물리력이 실린다. 던지기(망치를 던진다)도 쥔다.
- **지팡이**: 쥐는 스킬 다섯이 모두 타입 있는 것 — 물리 스킬은 없다(시험). 마법력이 타입을 더 빨리 건다.
- 꼴마다 넷 이상(결투 6 · 방패 5 · 망치 5 · 지팡이 5 · 원거리 4), 첫 줄의 스킬 넷은 결투(처음 줍는 검·맨손)로 쓸 수 있다(시험) —
  새 판의 첫 스킬이 손에 든 것과 안 맞아 막히지 않는다. 그래서 버팀은 방패 기술로 묶지 않았다(첫 줄).

## 4. 왜 이렇게

- **덤은 스킬에만**: 망치의 평타·강타, 지팡이의 탄은 건드리지 않았다(얼린 기본값 0013 — 무기 표의 숫자는 그대로). 특색은 스킬의 쪽에 얹어서
  "이 무기로는 이 스킬이 세다"가 된다. 한 곳씩: 물리력은 `World::skill_eff`, 마법력은 `World::dosed`.
- **벌은 없다**: 망치로 타입 스킬을 쓰면 약해지는 식의 감점은 넣지 않았다 — 특색은 "잘하는 것"으로만. 못 쓰는 스킬이 이미 값이다.
- **타입과 맞물림**: 지팡이의 ×1.5는 한 번에 안 걸리던 적(엘리트·버티는 종)이 한 번에 걸리는 차이다. 결의 칸(0223 11절)·아이템 옵션(타입 게이지)과
  곱해진다 — 타입 빌드의 무기가 지팡이다.
- **방패의 값이 커졌다**: 0224에서 방패는 바꿔 들기(둘째 스킬 묶음)를 내주고 막기를 얻었다. 이제 스킬 둘이 바뀐다 — 결투 기술을 내주고 방패 기술을 얻는다.

## 5. 보이는 것

- 기술 탭의 스킬 상세 "쓰는 무기" 줄: 결투 기술·방패 기술은 이름으로("결투 기술 — 한손 무기, 방패 없이"), 그 밖은 꼴의 목록.
  지금 쥔 꼴과 안 맞으면 밝게.
- 장비 탭의 무기 상세에 **특색** 줄(검·맨손 = 방패 기술/결투 기술 · 망치 = 물리력 +30% · 지팡이 = 마법력 +50% — 숫자는 표에서 읽는다).
- HUD·터치: 쥔 꼴과 안 맞는 스킬 칸은 흐리게(0223 V3 그대로) — 방패를 들고 내릴 때도 칸이 바뀐다(`World::set_shield` → `refit_skills`).

## 6. 정할 것(사장)

- 스킬의 묶음(위 표) — 어느 스킬을 어느 꼴에 줄지는 `skills.rs` 표의 `hands` 한 칸.
- 수치 둘(`weapons::ART_FORCE` 1.3 · `ART_CHANNEL` 1.5).
- 방패 기술·결투 기술이 둘·셋뿐이다 — 꼴마다 새 스킬을 더하는 일(동작·그림·이펙트가 든다)은 따로 정한다.
- 쇠뇌의 특색은 두지 않았다(조준·탄창이 이미 특색).

## 7. 시험

- `skills`: 꼴마다 넷 이상 · 첫 줄은 결투로 · 방패 기술·결투 기술이 둘 이상씩 · 지팡이가 쥐는 스킬은 모두 타입 있음 · 망치만의 스킬.
- `world/tests/arts.rs`: 방패를 들고 내리면 칸이 바뀐다(배운 단은 그대로) · 망치는 물리 스킬에만 배 · 지팡이는 쇠뇌로 게이지만 차는 첫 불티에 불을 붙인다.
- 옛 스킬 시험: 땅울림의 수는 물리력이 얹힌 값으로(`forced`), 타입 스킬은 배 없는 쇠뇌로 잰다.

## 8. 독립 리뷰(맥락 없이 이 변경만 읽힘)가 찾아 고친 것

- **남아 있는 것은 쓴 순간의 무기를 따른다**: 던진 무기·불티가 타마다 "지금 든 무기"의 마법력을 읽었다 — 검으로 던지고 날아가는 동안 지팡이로 바꿔 들면
  돌아오는 타가 ×1.5를 받았고, 지팡이로 흩은 불티는 바꿔 들면 배를 잃었다. 쌓는 양을 쓴 순간에 적어 둔다(`Blade::dose`·`Field::dose` — 시험).
- **못 쓰는 스킬의 알림이 한 줄 자리를 넘었다**("이 스킬을 쓰려면: 방패 기술 — 한손 무기와 방패") → "지금 쥔 것으로는 못 쓴다"로 줄이고,
  쓰는 무기의 목록은 상세 칸의 "쓰는 무기" 줄이 말한다.
- **튜토리얼의 "쓰기" 걸음이 막힐 수 있었다**: 첫 스킬을 배웠는데 쥔 꼴과 안 맞으면(방패를 사서 든 채 가로지르기) 누를 것이 없는데 걸음이 기다렸다 →
  쓸 수 있는 칸이 있을 때만 그 걸음을 세운다(막히는 걸음을 만들지 않는다 — 0167).
- 상태 탭의 끼운 스킬 그림: 쥔 꼴과 안 맞으면 흐리게(싸움 화면의 흐린 칸과 같은 말).

남긴 것: 옛 기록에서 끼워 둔 스킬이 새 규칙으로 안 맞게 되면 칸이 흐릴 뿐 옮겨 끼워 주지는 않는다(공개 전 — 옮기는 코드는 두지 않는다. 기술 탭의
"쓰는 무기" 줄이 밝게 알린다). 큰 기술 "한 줄기"의 타입 게이지에도 지팡이의 마법력이 얹힌다(스킬과 같은 길) — 망치의 물리력은 큰 기술에 얹히지 않는다.
되울림의 고리는 울릴 때 든 무기를 따른다(몸에 건 것이라).
