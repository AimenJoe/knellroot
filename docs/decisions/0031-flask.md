# 0031. 등잔(충전식 회복) — RB / R, 연타에 안전하게

- 날짜: 2026-11-04
- 상태: 채택·구현(화로는 아직 — 다시 차는 것은 스테이지를 새로 시작할 때). 설계는 `docs/design/items.md` 2·7, 버튼은 0030.
- 지금(2026-11-05 결정 검토, 0066 때): 버튼 RB → Y(0048), "화로 없음" → 쉼터 0032, "삼킨 뒤 회피 안 먹음" → 0057 캔슬, 체력·등잔 상한 → 능력치(0064 M3 `Stats`).
- 사장: "물약이 더 큰 문제 아냐?" → (연타 규칙을 설계에 적음) → "등잔 만들자".

## 규칙
- **RB / R** 한 번 = 한 모금(`PState::Drink`). `flask.time s` 0.8초, 그동안 `flask.walk x` 0.35배로 걷고 공격·패링 못 함.
- **들기 `flask.raise s` 0.35초에 삼킨다**: 등잔 −1, 체력 + `flask.heal` 2(5를 넘지 않는다), `Event::Gulp`(발밑에서 따뜻한 고리가 오른다).
- 삼키기 **전** 회피 → 끊기고 등잔·체력 그대로(어깨 버튼 실수는 회피 한 번으로 무른다). 삼키기 전 맞음 → 끊기고 등잔 그대로. 삼킨 뒤 내리기는 못 끊는다(회피도 안 먹는다).
- **연타**: 마시는 동안의 누름은 버리고, 끝난 뒤 `flask.lock s` 0.3초도 버린다 — 누름이 쌓여 연달아 마시지 않는다. 다시 누르기 취소는 없다.
- **가득이거나 0** → 몸짓 없이 HUD 등잔이 붉게 깜빡(`Event::FlaskDenied`) — 빈 병 몸짓으로 묶지 않는다.
- 횟수 `FLASK_CHARGES` 3(성장으로 늘릴 값이라 랩 값이 아닌 상수, `PLAYER_HP`처럼). 화로가 생기면 거기서 다시 찬다.

## 붙인 것
- 입력: `Bind::Flask = 7`(R·RB), 저장 칸 16·17(prefs `CELLS` 18). 옛 저장(칸 0)은 등잔만 기본값, **그 기본 키·버튼을 사용자가 이미 다른 동작에 붙였으면 비어 있는 첫 키·버튼**(배치가 통째로 기본값으로 날아가지 않게 — `Bindings::decode`, 점프 칸에도 같이 적용). 랩이 열려 있으면 R은 랩 되돌리기라 등잔으로 읽지 않는다.
- HUD: 스태미나 아래 등잔 셋(불 켠 것 = 남은 것). 터치: 점프 위(돌리기 줄과 사이) 등잔 그림 버튼 — 엄지가 공격에서 멀리 가야 닿아 실수로 덜 누른다. 조작 설정에 "등잔" 줄(줄 간격은 아래 안내 위까지 들어가게 저절로 줄인다 — 여덟 줄에서 "돌아가기"가 안내와 겹쳤다).
- 방랑자 동작 `drink`(왼손을 입에, 0.35초에 닿는다).
- 시험 다섯: 한 모금(체력·횟수·가득 넘지 않음), 가득·0이면 깜빡만, **RB 연타**(누름 1~9틱 × 사이 2~14틱 × 3초 — 마신 수 ≤ 3초 ÷ 1.1초, 시작한 마시기는 모두 삼킴, 가득이면 0번), 삼키기 전 회피로 무르기·삼킨 뒤 회피 안 먹음, 삼키기 전 맞으면 등잔 그대로. 옛 저장 두 경우(prefs).
- 수치 `flask.*` 다섯 줄(얼린 값 뒤에 붙임, 0013), 랩 "Flask".

## 다시 볼 조건
- 0.8초가 떼싸움에서 너무 길어 아무도 안 마시면 `flask.time`·`flask.walk`를, 너무 쉬우면 들기를 늘린다.
- 삼키기 전에 맞아도 등잔이 남는 것이 너무 너그러우면(맞으면서 계속 시도) 맞으면 줄게 바꾼다.
- 소울 시리즈의 실제 규칙(도중 누름·피격 시 소모)은 확인 못 했다 — 찾으면 비교해 적는다.
