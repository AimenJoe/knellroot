# 0157. 두건을 원본으로 되돌린다 — 코드로 덧붙여 고칠 수 없는 것

## 누구의 잘못인가
Blender가 아니다 — 스크립트가 시킨 대로 만들었다. **만든 쪽(Claude)의 판단과 방식의 잘못**이다.
1. **방식**: 이 레포의 모델 도구는 도형(상자·돌린 꼴·꺾인 관)을 코드로 놓는다. 단단한 물건(무기·종·항아리·기둥)에는 맞는다. **천·살처럼 흐르는 꼴**은 조형(스컬프팅)과 칠(텍스처)의 일이라, 도형을 덧붙이면 그 도형의 원형이 읽힌다 — 띠 = 넥타이, 원뿔 = 고깔, 아래로 벌어진 테 = 투구.
2. **판단**: 세 번 모두 "검사 통과·렌더에 보임"으로 끝냈다. 그것은 기하가 맞다는 뜻이지 **무엇으로 읽히는가**의 답이 아니다. 주인공의 생김새는 사장의 눈이 판정한다 — 그 눈을 거치기 전에 세 번 다 개발판에 올렸다.
3. **뿌리**: 원본 메시의 뒤통수가 민짜 공이다(앞모습 그림 한 장에서 Meshy가 지어낸 것). 뒤가 비어 있는 것은 **그림이 없어서**다 — 덧붙여서 메울 일이 아니었다.

## 앞으로의 규칙
- 주인공·보스처럼 생김새가 정체성인 모델에는 **코드로 새 꼴을 덧붙이지 않는다**. 고칠 수 있는 것은 자리(꼬리를 가운데로)·해상도(텍스처·정점)·면 고르기까지.
- 생김새를 바꾸려면 **그림 먼저**(앞·뒤·옆) → 사장 확인 → 그 그림으로 메시를 다시 받거나 사람이 조형. 올리기 전에 그림으로 묻는다.
- 단단한 소품·무기는 지금 도구로 계속한다(0139·0155).

## 두건을 실제로 고치는 길(사장이 고른다)
| 길 | 무엇 | 드는 것 | 결과의 믿음 |
