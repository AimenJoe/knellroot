# 0131. 떨어진 아이템 — 상자는 바닥에 떨군다, 종류 색 빛기둥(가까이서 서서히)

- 날짜: 2026-11-09
- 상태: **채택·구현**(`release/v0.5`). 사장 2026-11-09: "떨어진 아이템 표시도 변경 필요해, 디아블로식 빛기둥 형태 어때?" → 인터뷰: 대상 = **떨어져 있는 아이템, 상자를 열면 아이템이 떨어짐(바로 습득되는 것이 아니라)** · 거리 = 가까이서만 서서히 · 구분 = 가늘고 짧게 + 종류 색.
- 스터디:
  - KB `wayfinding-without-a-minimap`(1차, 0060 W1): 갈 곳 빛기둥은 호박색 하나 — "그 색 = 갈 길, 다른 데 같은 색을 쓰면 규칙이 무너진다". 그래서 떨어진 것은 **호박색을 쓰지 않고**, 갈 곳 기둥보다 **훨씬 가늘고 낮게**.
  - 2차(위키·가이드): 디아블로 3은 전설 드롭에 기둥 + 소리 + 지도 표시, 4는 기둥을 3보다 낮췄다, 색 = 값(색으로 가치를 한눈에).

## 정한 것
| 무엇 | 규칙 | 어디 |
|---|---|---|
| 상자 | 열면 아이템이 상자 위에서 포물선으로 튀어나와(0.45초) 옆 바닥(방랑자 쪽에서 65° 비껴 1.3m)에 내려앉는다. 내려앉기 전엔 못 줍는다(여는 누름이 곧바로 줍지 않게). **주울 때 얻고 그때 기록**(장신구·무기·이미 가졌으면 잔불) — 줍지 않고 지역을 떠나면 다음에 상자는 다시 닫혀 있다(잃지 않는다) | `StageRun::drops`·`take_looted`, `app/progress.rs` |
| 줍기 | 같은 상호작용 버튼, 차례: 떨어진 것 · 숨은 물건 > 열기 > 당기기 > 쉬기. HUD "줍기" | `stage/mod.rs`, `hud.rs` |
| 빛기둥 | 안쪽 밝은 심(반지름 0.1, 높이 2.6m) + 바깥 옅은 껍질 + 위로 오르는 반짝임 셋 + 발밑 테, 숨 쉬듯. 방랑자에게서 10m 안 = 다 보임, 14m 밖 = 없음(그 사이 서서히) — 숨은 물건의 뒤지는 맛(0117)을 남긴다 | `render::loot_beam`·`loot_fade` |
| 색 | 상자에서 떨어진 것 = 흰빛 · 등잔 = 옅은 금빛 · 한 모금 = 민트 · 종소리 조각 = 크림. 호박빛(갈 곳)은 쓰지 않는다 | `LOOT_*` |
| 떨어진 것 그림 | 천천히 돌며 떠 있는 흰 마름모(상자 단계 — 장신구·무기 모델로 바꾸는 것은 나중) | `stage_props` |
| 개발 | 스테이지 "둘째 지역 상자 곁에서(떨어진 아이템)" | `app/dev.rs` |

## 시험
- `a_chest_opens_once_…`: 열면 얻지 않고 바닥에 하나, 발밑이 아닌 옆, 내려앉기 전엔 못 줍고, 주우면 그 상자 번호, 바닥이 빈다.
- 헤드리스: 개발 "상자 곁에서" → F → 튀어나와 상자 옆에 흰 빛기둥 + "F 줍기".

## 판정에서 볼 것(사람)
- 기둥이 너무 옅거나 짧지 않나(디아블로 4보다도 낮다), 10~14m가 "가까이 가면 보인다"로 느껴지나.
- 상자를 열고 한 번 더 누르는 것이 번거롭지 않나 — 디아블로식 "떨어지는 맛"이 그 값을 하는지.
- 숨은 물건이 너무 쉽게 찾아지지 않나.

## 하지 않은 것
- 떨어진 것의 그림을 실제 장신구·무기 모델로(지금은 흰 마름모), 떨어지는 소리 층(지금은 여는 소리 + 줍는 소리).
- 잔불 조각에는 기둥을 세우지 않는다(자석으로 저절로 모인다 — 화면이 어지러워진다).
