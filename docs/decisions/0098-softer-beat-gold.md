# 0098. 박자 금빛을 옅게

- 날짜: 2026-11-07
- 상태: **채택·구현**(개발판)
- 사장: "박자 노란색도 너무 강한 노란색이니 조금만 더 옅게."

## 결정
- 박자 가족의 금빛을 노랑에서 흰빛 쪽으로 옮기고(채도 낮춤) 진하기를 30% 안팎 내린다. 같은 가족이 함께 옅어진다:
  - 박자 부채꼴 "지금"(0087): 채움 (1, .86, .35, .45) → (1, .92, .64, .30), 테두리 (1, .92, .55, .85) → (1, .95, .76, .60).
  - 박자 타 휘두름 `BEAT_GOLD`(0076): (1, .82, .30, .32) → (1, .90, .62, .24).
  - 발밑 박자 고리(0076): 바깥 진하기 .9 → .65·안 .6 → .45, 색도 같이 옅게.
  - 머리 위 음표, 기력 막대·볼트 반짝임(HUD): 같은 옅은 금빛, 반짝임 진하기 .9 → .7.
- 바꾸지 않은 것: 딱 맞춰 떼기의 금빛 고리(0078), 락온 표시(대상 발밑 노란 고리·머리 위 마름모 — 박자와 다른 표시).
