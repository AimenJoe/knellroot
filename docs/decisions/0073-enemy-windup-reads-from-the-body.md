# 0073. 적 공격은 몸으로 읽힌다 — 들어 올림 → 정점에서 버팀 → 맞는 틱에 내리침

- 날짜: 2026-11-07
- 상태: **채택·구현**(개발판). 손맛 판정 전.
- 사장: "이건 소울라이크이기도 하기 때문에 공격 준비 모션이 더 잘 보이게 만드는 게 맞아, 예고 인디케이터는 그냥 도움을 줄 뿐"

## 읽은 것
- **KB:**
  - `believable-cute-character-motion`: 적의 예비 동작은 길게, 과장은 게임 카메라 거리에서 읽히게, 부피 그대로.
  - `melee-light-and-charged-attack-feel`: 예고 "다 찬" 상태가 실제로 보여야 한다(nail 0188).
- **웹(2차):**
  - DS3 공격 해부(Game Developer): 시작 자세가 공격을 알린다. 신호 + 공격은 ≥ 340ms. 내리치는 순간은 "물리를 휘어" 즉각적으로.
  - Signals & Light: 예비 자세가 결과를 말해야 한다. VFX·SFX는 동작과 한 몸이어야 한다.

## 원인(지금 동작이 잘 안 읽힌 이유)
`_windup` 동작이 따로 없는 공격(잔재 내려찍기, 문지기 내려찍기·뿌리 파동)은 **한 동작의 앞 절반**을 예고 길이에 늘여 틀었다. 동작마다 정점 위치가 달라서 두 가지가 틀어졌다.

- **정점에 닿지 못한다:**
  - 문지기 내려찍기는 다 든 자세가 동작의 60%, 파동은 62.5%다. 예고 동안 50%까지만 가서 다 든 자세가 화면에 한 번도 서지 않았다.
  - 잔재는 38%가 정점이라, 예고 끝 23% 동안 이미 내리치고 있었다. 버팀이 없다.
- **그림이 판정보다 늦게 내리친다:** 문지기 내려찍기는 맞는 틱(휘두르기 0초)에 곤봉이 아직 위에 있었다. 내리친 자세는 83ms 뒤에 나왔다.

## 결정
- **동작마다 열쇠 표**(`render::STRIKE_KEYS`: 모델·동작·정점 초·맞음 초). Blender 스크립트의 키 시각과 같다.
  - 잔재 attack 0.5/0.62, 문지기 slam 0.9/1.0, wave 1.0/1.12.
  - 표에 없으면 동작 길이의 40%/50%.
  - 시험 `strike_keys_name_real_clips_in_order`가 GLB 안의 동작과 순서를 본다.
- **예고 시간 → 동작 시각**(`windup_clock`):
  - 예고의 `WINDUP_REACH` 0.6까지 들어 올린다. 천천히 멈추게 한다.
  - 그 뒤 정점에서 **버틴다**.
  - 마지막 `WINDUP_SNAP` 0.08초(예고의 1/4 이하)에 **내리친다**. 예고가 끝나는 틱 = 맞는 틱 = 내리친 자세.
  - 휘두르기·파동은 맞음 시각부터 제 빠르기로 끝맺는다.
  - 시험 `a_windup_rises_holds_at_the_peak_then_snaps_down_on_the_hit_tick`.
- **몸의 단서**(돌진의 `charge_windup`에도):
  - 들어 올리는 동안 키를 늘린다(×1.06, 옆은 1/√ — 부피 그대로). 뒤로 0.1rad 젖히고, 내리칠 때 돌아온다.
  - 예고 동안 눈·핵 빛이 +0.6까지 차오른다.
  - 버티는 동안 몸이 옆으로 떨린다(±2.5cm).
  - 버팀이 시작되는 순간 눈·핵이 0.1초 번쩍인다(+1.2).
  - 몸 전체를 밝히지 않는다. 맞았을 때의 흰 번쩍임과 헷갈리기 때문이다.
- **예고 시간·판정은 그대로**(얼린 값 0013). 그림만 바꿨다.
- 바닥 예고 그림은 0072대로 옅은 보조로 남긴다.

## 확인
- 헤드리스 연속 캡처(보스 아레나 90장)에서 확인했다.
  - 파동: 두 팔을 다 든 자세가 여러 프레임 선다.
  - 내려찍기: 곤봉을 든 자세에서 버틴 뒤 내리친다.
  - 핵 빛이 차오르는 것도 보인다.
- 시험 224, clippy 세 대상, save·shot·touch·mouse를 통과했다.

## 사람이 볼 것
- 버팀(예고의 약 40%)이 "이제 온다"로 읽히는지, 늘어지게 느껴지는지.
- 떨림·번쩍임이 너무 작거나 크지 않은지(`WINDUP_*` 상수, `render.rs`).
- 잔재·가시짐승은 몸이 작아 쿼터뷰 거리에서 자세 차이가 작다. 부족하면 Blender 동작 자체의 정점 자세를 더 과장한다(`tools/art/blender/*.py`, 다시 굽기).
- 바닥 예고를 설정에서 끄거나 줄일 수 있게 할지(nail 0198 "공격 예고 진하기" 꼴) — 사장이 정한다.
