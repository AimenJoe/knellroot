## 2. 정할 것(인터뷰로 — 사장)
1. **보라 뿌리의 뜻**(0069 정할 것 1): 가. 주인 없는 실(추천) / 나. 더 오래된 것. — lore README "열린 것" 표.
2. **둘째 지역**(0069 정할 것 2): A. 떠난 마을(추천, 다섯 막의 2막 "떠난 자들의 흔적") / B. 실 굴. 이름 초안("잠든 마을"·"웅크린 것"·"뿌리의 씨앗"·"깨진 종지기")을 lore 규칙과 맞대 다시 고른다(0102 금지어 — 뿌리의 ~·흡수·각성, 1막 종·울림 제한은 2막에서 풀 것인가).
3. **방랑자 = 포포처럼 손이 실을 느낌**(0069 정할 것 3, 말하지 않는 고리): 걸어 둘지(추천: 둔다).
4. **도감**(0069 C5): v0.5.0에 넣을지(추천: 넣는다 — 지역이 둘, 엘리트 성질·잔류형 현상도 관찰로 적을 곳).
5. **ECO-10 지역 생태끼리 주고받나**(0101 — 둘째 지역 설계 전): 안을 내 묻는다(예: 첫 지역의 잔재가 둘째 지역에선 다른 역할 — 청소자).
6. **ECO-05 죽은 것이 움직이는 조건**(새 적 전): 재활동체 행동 규칙.
7. **구역 등급 값**(0112): 등급 2의 체력·자세·잔불 배율, 피해 2가 몇 등급부터인가.
8. **잔류형을 정본으로**(0112 남는 엘리트): ecology "후보" → CANON?
9. **둘째 문지기의 꼴**(0069 C3): 거리·공간형(울림 고리 두 겹·조각 부채꼴·끌어 돌진 띠) 그대로?
10. **두 지역을 잇는 법**(T1): 첫 문지기 핵 → 성소 바닥이 열리는 길 → 지층 단면 전환(KB conveying-descent) — 그 사이 화로를 두나, 첫 지역으로 되돌아갈 수 있나(지름길·화로 사이 이동).
