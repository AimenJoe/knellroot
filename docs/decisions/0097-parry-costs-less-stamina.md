# 0097. 패링 기력 15 → 5

- 날짜: 2026-11-07
- 상태: **채택·구현**(개발판, 얼린 기본값 바꿈 — 0013)
- 사장: "패링의 기력소모 낮춰줘. 이미 타이밍 손해 및 뎀지 손해가 있는데 기력까지 소모하는건 너무 가혹해."

## 전
- 패링 누름 = 기력 15(0025), 튕기면 +25(0088). 빗나간 패링은 타이밍(동작이 끝날 때까지 못 움직임)·피해(그 공격에 맞음)에 기력까지 잃었다.

## 결정
- `parry.stamina cost` 기본 **5**(랩 값, `docs/tuning-frozen.txt` 갱신). 튕기면 +25(0088) 그대로 — 성공은 +20, 실패는 −5.
- 장르(KB `timing-parry` "패링에 기력을 매기는 꼴은 게임마다 갈린다", 2차): Sekiro는 기력이 없고 Dark Souls 3·Elden Ring은 "조금". 실패의 값은 이미 타이밍·피해로 치르므로 기력은 연타를 막는 만큼만 둔다 — 연타는 패링 대기(0025)가 이미 막는다.
- 바꾸지 않은 것: 기력이 0이면 패링도 막힌다(모든 행동과 같은 규칙, 0018 — "조금이라도 있으면 된다"). 0에서도 패링을 열지는 판정 뒤에.

## 손맛 판정(사람)
- 패링을 노려 볼 만해졌는지, 그래도 아무 때나 누르는 패링이 되지는 않는지.
