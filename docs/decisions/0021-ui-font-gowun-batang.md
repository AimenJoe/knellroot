# 0021. UI 글꼴 = 고운바탕(서브셋)

- 날짜: 2026-11-03
- 상태: 채택·구현(사장: 후보 열하나를 보고 "고운바탕, 함렛 중에 고르자. 호환성이 더 좋은 녀석으로")

## 후보와 비교
후보 그림: `docs/art/font-candidates-pixel.png`(Galmuri 셋·물마루·네오둥근모·둥근모꼴), `font-candidates-serif.png`(송명·함렛·고운바탕·나눔명조·디필레이아) — 같은 문구를 실제 게임 화면(2배)에 찍음.

| | 고운바탕 | 함렛 |
|---|---|---|
| 한글 | 11,172자 전부 | 2,788자(KS X 1001 2,350 + α) |
| 굵기 | 보통·굵게 따로 된 정적 파일 | 가변 글꼴 하나(wght 100~900, 기본 400) |
| 엔진 | 그대로 | macroquad의 fontdue 0.9.5에 가변 축 API가 없다(소스 확인) → 기본 400만, 굵게 못 씀 |
| 라틴 확장 A | 127/128 | 124/128 |
| ◆◇…·▲▼▶ | 있음 | 있음 |
| 키릴·가나·한자 | 없음 | 없음 |

→ 고운바탕(fontTools로 cmap·fvar을 세어 확인, 2026-11-03).

## 넣는 법
- `tools/fonts/subset_ui.py`가 Google Fonts 원본(각 8MB, 레포 밖)에서 **i18n 표 글자 + ASCII·라틴-1·라틴 확장 A + 쓰는 기호**만 남긴다: 보통 95KB·굵게 93KB(KS X 1001 2,350자를 다 넣으면 두 파일 2.7MB — `--ks`). 새 글자를 쓰면 다시 돌리고, `cargo test`의 글꼴 시험이 빠진 글자를 잡는다(KB `reference/fonts/cjk-pixel-fonts.md`의 서브셋 방식).
- 본문 13px × 렌더 배율, 큰 제목(2배 이상)은 굵게. 명조라 텍스처 필터는 Linear(소수 DPI에서 매끈하게).
- Galmuri11 Condensed는 뺐다. 개발 화면(랩·개발 줄)은 기본 글꼴 그대로.

## 다시 볼 조건
- 러시아어·일본어 등을 더할 때: 고운바탕에 없으므로 언어별 글꼴(서브셋)을 하나씩 — 첫 게임과 같은 구조.
- 1배(480×270 창)에서 본문이 흐리면 GLYPH를 올리거나 HUD 숫자만 픽셀 글꼴로.
