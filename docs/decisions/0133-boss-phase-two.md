# 0133. 보스 2단계 — 짧은 전환(맞지 않음·밀쳐냄) + 새 수 하나 + 잇기

- 날짜: 2026-11-10
- 상태: **채택·구현**(`release/v0.5`). 사장 2026-11-09: "보스전투, phase 2 만들자" → 인터뷰: 대상 = **두 보스 모두** · 전환 = **짧은 전환**(무릎 → 터짐·밀쳐냄 → 2단계) · 더할 것 = **새 수 하나 + 잇기** · 체력 막대 = **표시 없음**(처음 겪을 때 놀라게).
- 앞서: 0128에서 사장 "2페이즈 혹은 3페이즈의 보스도 나중에 추가되어야겠다". 지금까지의 "반 아래 깨어남"(0125·0128)은 예고·쉼·걸음 배율 + 고리·조각 수 + 페인트뿐이었다 — 아래 스터디가 말하는 "수치만 바꾼 단계".
- 스터디:
  - KB `recurring-boss`(nail 0233, 1차): 반 아래 다음 틱에 한 번 깨어남·배율 — 2단계의 바닥. Hades 복수의 여신은 체력 구간마다 기술이 열린다(2차).
  - 2차(디자인 글·튜토리얼): 체력·피해만 올린 단계는 "긴 싸움 하나"일 뿐 — 새 수·위험·무대 변화로 도구를 바꾼다. 새 수는 1단계에서 익힌 답을 비틀어야 공정하다(세키로 잇신, 말레니아의 2단계는 새 수지만 읽히는 동작). 전환은 공격 고리를 멈추고 잠깐 맞지 않게(튜토리얼 수준 — 길이·연출의 근거는 찾지 못함). 한 싸움에 1~3단계, 마지막 보스가 셋.

## 모의(0126 봇, 새 수 피하기도 성공률 p로)
- 종지기 · 첫 도착 몸(B): p 0.5 → 65%, 0.7 → 98% — 90% 승리 문턱이 그대로 p≈0.6(0127과 같은 자리). 완벽한 봇(p=1)은 피해 0 = 새 수 모두 피할 수 있다.
- 문지기 · 맨몸(A): p 0.5 → 95%(0126 "p≈0.5에서 90%"와 같은 자리).
- 즉 2단계는 "더 빡빡한 문턱"이 아니라 **읽을 것이 바뀌는 단계** — 세기(사람 판정)는 아래에서.

## 판정(사람)
- 전환이 "단계가 바뀐다"로 읽히나 — 무릎·핵 빛·터짐·흔들림이 충분한가, 2초가 길거나 짧지 않나, 밀쳐냄이 억울하지 않나.
- 뿌리 기둥 줄: 원이 줄지어 깔리는 것을 보고 옆으로 비키게 되나(뛰려다 맞지 않나 — 고리와 달리 뛰어도 맞는다는 것이 모양만으로 읽히나).
- 종 내던지기: 원판이 내 자리에 깔리는 것을 보고 빠지나, 떨어진 자리의 고리를 뛰게 되나, 날아가는 종이 보이나.
- 잇기: 돌진을 피한 직후의 내려치기·울림이 공정한가(쉼이 없다는 것이 몸으로 읽히나).
- 막대 표시 없음: 처음 겪을 때 놀람이 좋은가, 억울한가.

## 뒤로 미룬 것
- 3단계(사장 "2페이즈 혹은 3페이즈")는 다음 지역의 마지막 보스부터(스터디: 마지막 보스가 셋).
- 전환의 무대 변화(바닥 위험)는 인터뷰에서 고르지 않았다.
