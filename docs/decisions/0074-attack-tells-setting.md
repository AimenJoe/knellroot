# 0074. 설정 "공격 예고" — 바닥 예고 진하기 0~100%(끔 포함), 기본 50%

- 날짜: 2026-11-07
- 상태: **채택·구현**(개발판)
- 사장: "응 공격예고 옵션에 넣자"(0073의 "예고 인디케이터는 그냥 도움을 줄 뿐"에 이어)

## 결정(nail 0198 꼴 — 0065: nail에 있는 꼴은 그대로 가져온다)
- 설정 → **공격 예고**: 0~100%, 10%씩, **기본 50%**. 화면 흔들림 바로 아래에 둔다.
- **세기:** 값/70%를 바닥 예고 잉크(채움·테두리)·바탕·가운데 X 투명도에 곱한다.
  - 70%가 0072의 값(잉크 0.3)이다. 기본 50%는 약 0.21이다(`render::TELLS_BASE`).
- **0% = 끔**(값 글 "끔"). nail은 0%를 두지 않았다. 거기서는 예고가 놀이 정보의 전부였기 때문이다.
  - 여기는 0073으로 준비 동작이 몸으로 읽히고, 바닥 그림은 보조다(소울라이크는 바닥 그림이 없는 쪽이 장르 기본).
- **그대로인 것:**
  - 퍼지는 뿌리 파동(공격 자체)은 이 값을 따르지 않는다. 피해 판정이 있는 실제 위험이기 때문이다.
  - 준비 동작 단서(떨림·눈/핵 번쩍)도 따르지 않는다.
- **저장:** prefs 칸 26(+1). 옛 저장(0)은 기본값으로 읽어 MAGIC은 그대로다. 앱 → `View::tells`(0..1) → `render::telegraph`의 배율.
- **글:** `menu_tells` "공격 예고" / "Attack tells". 글꼴 서브셋에 '예'를 더해 다시 만들었다(`tools/fonts/subset_ui.py`).

## 확인
- prefs 시험: 칸 26 읽기·쓰기, 옛 저장은 기본값.
- 시험 224, clippy 세 대상.
- 헤드리스 save·shot·touch·mouse·pwa. 설정 창 스크린숏에서 줄이 넘치지 않는 것을 봤다.
