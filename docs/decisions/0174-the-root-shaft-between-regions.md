# 0174. 지역 사이 전환 — 뿌리가 얽힌 굴을 걸어 내려간다(3D)

- 날짜: 2026-11-13
- 상태: **결정**(사장 2026-11-13 — "스테이지간 이동 애니메이션이 nail에서 그냥 따온거라 어울리지 않아" → 세 안 가운데 "C") — 만듦, 판정 전(체크리스트 30).
- 바탕: 0118(지역 잇기 — 지층 단면 전환, nail 0156·0204 꼴)·0037(각진 것은 뿌리만)·0061(3D 도트)·0157(주인공의 생김새에 코드로 새 꼴을 붙이지 않는다)·0171(종).
- 고치는 것: 0118 T1의 "지층 단면 전환" — 이 기록이 대신한다. 깊이 표·깊이 글·지역 이름 카드·오르는 길은 그대로.

## 왜 안 어울렸나
0118의 전환은 첫 게임(nail)의 것을 그대로 옮긴 것이었다 — 화면에 2D 지층 단면을 덮고 가운데 굴을 동그라미 몇 개의 방랑자가 내려간다. nail은 2D 도트 게임이고 주인공이 두더지라 "땅을 파 내려간다"가 그 게임의 그림이자 이야기였다. Knellroot는 3D 도트이고, 방랑자는 파지 않는다 — 걷는다. 이름부터 뿌리(root)인 게임의 지역 사이가 남의 그림이었다.

## 세 안과 고른 것
| 안 | 내용 | 값 |
|---|---|---|
| A | 눈을 감았다 뜨기(0171의 눈꺼풀) + 종 + 이름 카드 | 반나절. 이동을 보여 주지 않는다 |
| B | 통로로 걸어 들어가 어둠에 잠기고 반대편에서 나온다 | 지역마다 통로 지형이 필요 |
| **C** | **뿌리가 얽힌 수직 굴을 카메라가 따라 내려가는 3D 장면** | 가장 어울린다. 새 그림이 든다 |

C를 "새 그림(메시)을 받아야 한다"고 적었지만, 굴에 서는 것은 벽(흙·돌)과 뿌리다 — 둘 다 단단한 것이라 코드 도형으로 짓는 것이 이 레포의 규칙에 맞는다(0037 각진 것은 뿌리만, 0157 "단단한 소품·무기는 코드 도형으로" — 식생의 벽 뿌리 `flora::wall_root`와 같은 네모 단면 줄기). 방랑자는 있는 모델·있는 걷기 동작을 그대로 쓴다. 새 메시 없이 만들었다.

## 정한 것
1. **장면**: 지름 10m쯤의 수직 굴. 벽을 따라 도는 **큰 뿌리**(굵기 1.2m — 윗면이 평평하다) 위를 방랑자가 걸어 내려간다. 카메라는 굴 안, 방랑자의 맞은편에서 조금 비켜 조금 위 — 방랑자와 같이 굴을 돈다(140°쯤). 벽은 깊이의 흙빛 띠(얕은 갈색 → 깊은 남보라, 0118의 색 키 그대로), 받치는 뿌리·늘어진 잔뿌리·벽을 타는 뿌리·박힌 돌·호박빛 옹이.
2. **빛**: 등잔(방랑자 곁의 따뜻한 빛 — 벽을 지나가며 비춘다) · 위 지역에 달이 있으면 위의 틈에서 떨어지는 달빛 줄기(위에 가까울수록) · 아래에서 올라오는 닿을 곳의 안개빛(아래에 가까울수록). 굴 속에는 한쪽에서 오는 달빛이 없다. 떠다니는 먼지는 실제 시간으로.
3. **올라가는 길은 같은 굴을 거꾸로**: 큰 뿌리를 걸어 오른다(뒷모습), 깊이 글은 줄고, 조금 길다(3.9초 — 내려가기 3.4초. KB `conveying-descent` "돌아오는 길도 보인다 · 먼 길").
4. **시간표**(`descent.rs`): 떠남 0.35초(떠나는 곳이 어두워진다) → 굴 3.4/3.9초(어둠에서 나왔다 어둠으로) → 닿음(0.12초 다 어둡게 + 0.5초 밝아진다). 모두 4.4초·4.9초 — 0118은 1.6·1.9초였다. 길어진 만큼 **굴을 지나는 동안 아무 버튼 = 건너뛰기**(굴이 어둠으로 들어가는 데로 — 자주 오가는 길에서 지치지 않게. 닿는 쪽의 밝아짐은 본다).
5. **지역은 떠나는 곳이 다 어두워진 순간에 바꾼다.** 굴 장면 동안 월드는 그리지 않고, 닿을 곳의 월드는 닿는 쪽의 어둠 뒤에서 처음 그려진다 — **지형 굽기의 멈칫이 어둠에 숨는다**(0118은 단면이 덮인 가운데에서 바꿨다 — 움직이는 단면이 그 순간 멎었다).
6. **종**: 굴의 한가운데쯤에서 종이 한 번(`sfx::Id::Knell` — 0171의 종). 떠날 때의 소리(`Wake`)는 그대로.
7. **깊이 글**은 굴을 지나는 동안 화면 아래 가운데에(0118 그대로 — "땅 위" → "지하 40m"), 굴의 어둠과 같이 옅어진다. HUD·화살·터치 버튼은 굴 장면 동안 걷는다. 닿으면 지역 이름 카드(0118 그대로).
8. **월드는 전환을 모른다**(그대로): 규칙은 순수한 `descent.rs`(시간표·길·카메라 — 시험), 그림은 `render/descent.rs`(월드와 같은 타깃·같은 화면 공간 선·같은 마무리 패스), 덮는 어둠과 글은 앱의 화면 패스.

## 만든 것
- `src/descent.rs`: `Passage`(`phase`·`dark`·`along`·`travel`·`depth`·`skip`·`step` → `Tick { swap, bell, done }`), 굴의 꼴 상수(`SHAFT_R` 5.2 · `PATH_R` 3.7 · `ROOT_R` 0.6 · `SWEEP` 2.4rad · `DROP` 5m), `path`·`walker`·`eye`, 흙빛 `soil`.
- `src/render/descent.rs`: 굴을 전환마다 한 번 짓고(면 2천 개쯤 — 벽·뿌리·돌·옹이), 프레임마다 빛을 다시 받아(등잔이 움직인다) 보낸다. `Renderer::draw_shaft`.
- `src/app/mod.rs`·`play.rs`: 굴 단계에는 월드 대신 `draw_shaft`, 화면 패스의 어둠·깊이 글(`hud::draw_depth`), 건너뛰기·종.
- 그림: `docs/art/descent-0174/01-down.png`·`02-up.png`.

## 시험
- `the_region_swaps_once_in_the_dark_and_the_world_stays_hidden_until_arrival` — 지역은 다 어두운 순간에 한 번, 닿는 쪽의 첫 틱들도 다 어둡다, 깊이는 한쪽으로, 종은 한 번.
- `the_wanderer_walks_the_great_root_down_or_up_facing_the_way` — 내려가면 늘 아래로·길의 아래쪽을 보고, 올라가면 거꾸로. 발은 뿌리 윗면. 걷는 빠르기 초당 2~5m.
- `the_camera_stays_inside_the_shaft_and_keeps_the_wanderer_in_view` — 벽을 뚫지 않고, 방랑자가 시야 한가운데 가까이, 한 틱에 튀지 않는다.
- `skipping_jumps_to_the_shafts_fade_out_and_never_past_the_swap`.
- `the_wall_faces_inward_and_the_great_root_carries_the_walker` — 벽은 굴 안을 보고, 걷는 자리마다 발 아래 뿌리의 윗면이 있고, 굴 한가운데(카메라와 방랑자 사이)는 비어 있다.
- 헤드리스: 개발 창 "마을"(내려가기)과 임시로 뒤집은 판(올라가기)을 실제 시간으로 찍어 봄 — 콘솔 오류 0.

## 못 본 것
- 굴을 도는 카메라(초당 40°쯤)의 멀미 — 사람 판정.
- 실기에서 굴 장면의 프레임(면 2천·빛 다시 받기는 가볍지만 재지 않았다)과 닿는 쪽 굽기의 멈칫이 정말 어둠에 숨는지.
- 종의 크기(헤드리스는 소리를 못 듣는다).
- 셋째 지역부터의 굴(깊이의 흙빛이 더 어둡다 — 지금은 지역이 둘).

## 다시 볼 조건
- 굴이 길게 느껴지면 굴의 길이(`SHAFT_DOWN`·`SHAFT_UP`)를 줄인다 — 도는 각(`SWEEP`)을 같이 줄여 걷는 빠르기를 지킨다(시험이 2~5m/s를 본다).
- 지역마다 굴의 생김새를 달리하고 싶으면(둘째 굴은 돌, 셋째는 종의 쇠 …) `build`에 지역의 씨앗·팔레트를 준다.
