# 0094. 연구소는 개발 창 안에만, 소품의 가림 상자는 모델 그대로

- 날짜: 2026-11-07
- 상태: **채택·구현**(개발판)
- 사장: "아직 연구소 메뉴가 바깥(첫 화면 메뉴나 멈춤 화면 메뉴)에서도 표시됨. 락온 모드에서 배경이 아닌 오브젝트는 투명화되지 않아서 시야를 가림."

## 결정
### 연구소
- 바깥 메뉴(타이틀·멈춤)에서 연구소 줄을 뺀다. 개발판 타이틀은 [이어하기]·시작하기·설정·개발, 멈춤은 계속·장비·설정·개발·처음부터·타이틀로(0090).
- 연구소는 개발 창 도구 탭 첫 줄에서만 연다(0083). 운영판에는 원래 없다.
- 시험 `menus_have_dev_below_settings_and_no_lab`. 헤드리스 스크립트의 타이틀 길(leak·mouse)을 한 줄 짧게.

### 소품의 가림 상자
- 0091로 문을 넣은 뒤 남은 "배경이 아닌 오브젝트"는 지형으로 굽는 소품(기둥·뿌리·화로·돌무더기·벽 조각·종)이다.
  - 소품은 원래 옅어졌지만, 가림 상자가 부딪힘 상자(종류별 반폭·높이)라서 놓치는 자리가 있었다.
  - 그 상자는 회전(yaw)을 모르고 모델보다 좁다: 벽 조각 깊이 ±0.4 대 모델 −0.45..0.83m, 부러진 기둥 0.6 대 조각 1.07m, 뿌리 0.5 대 0.77m, 종 0.8 대 0.98m.
  - 돌무더기는 상자가 없어 옅어지지 않았다.
- 가림 상자 = **구운 정점의 실제 범위**(`scenery::vert_bounds`). 돌린 모델·상자보다 큰 모델도 감싼다. 부딪힘은 그대로 종류별 상자다.
- 시험 `prop_occlusion_box_wraps_every_baked_vertex`.

## 같이 알게 된 것
- 서비스 워커는 `skipWaiting`을 쓰지 않는다(0062: 실행 중인 게임에 새 파일이 섞이지 않게). 그래서 설치한 앱·열린 탭은 **다음 실행부터** 새 판이다.
- 개발판에서 고친 것이 안 보이면 타이틀 오른쪽 위의 해시(0079)가 최신인지 먼저 본다. 아니면 앱·탭을 다 닫고 다시 연다(한 번 더 필요할 때가 있다).
