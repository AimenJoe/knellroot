# 0179. v0.6.0을 지금 배포 — 무기 강화(W1)는 v0.6.1로

- 날짜: 2026-11-14
- 상태: **결정**(사장 2026-11-14 "지금 v0.6.0 배포 준비해 줘, 1은 0.6.1로 배포하자")
- 바탕: 0134(v0.6.0 "다듬기" 마일스톤 — J0·J1·P1·W1·I1)·0079(버전 규칙 — 마이너 = 마일스톤 하나, 패치 = 고친 것·더한 것).

## 정한 것
- v0.6.0은 J0(체크리스트)·J1(판정 반영 — 0173·0175~0178까지)·P1(PC 빌드)·I1(iOS 1단계)로 배포한다. `Cargo.toml` 0.6.0, Android `version_code` 18, 릴리스 노트 `docs/releases/v0.6.0.md`.
- **W1 무기 강화는 v0.6.1**(패치 번호로 — 사장이 정함). 시작할 때 0134의 짧은 인터뷰(몇 단·무엇을 올리나·재료와 자리·표시·기록 키)부터. 0134의 "판정(v0.6.0을 닫을 때)"의 무기 강화 줄도 v0.6.1로 옮긴다.
- 체크리스트의 판정 전 칸(31~34 등)은 그대로 남는다 — 판정에서 고칠 것은 v0.6.x로.

## 왜
- 0175~0178(탭·종·걸음·쓰러짐·덧옷·굴·수류탄)까지 판정 반영이 쌓였고, 무기 강화는 인터뷰부터 시작하는 새 성장 줄이라 기다리면 배포가 늦어진다.
