# 0194 — 개발 창 묶음 정리 + 무기별 모션 보기

- 날짜: 2026-11-15
- 상태: 채택(개발판)
- 사장: "개발 메뉴에 무기별로 확인해 볼 수 있을 만한 메뉴가 없네, 그리고 성능 줄이 성능에 없는 등 체계적으로 정리된 게 아닌 듯."

## 바꾼 것
- 개발 창의 묶음을 **하는 일**로 가른다(`app/dev.rs` `DEV_CATS`·`DEV_LIST`):
  | 묶음 | 줄 |
  |---|---|
  | 도구 | 연구소 · 빈 아레나(놀이터) |
  | 모션(새로) | 무기마다 한 줄 — 검 · 망치 · 지팡이 · 쇠뇌 · 맨손 → 모션 보기 |
  | 기술(새로) | 기술 끼우기 · 기술 다 올리기 · 고르기 바꾸기 · 기술 아레나 · 쟁반 아레나(도구·전투에서 옮김) |
  | 스테이지 | 그대로 |
  | 전투·적 | 적·보스 아레나만(기술 아레나 둘은 기술로) |
  | 성능 | 성능 줄(도구에서 옮김) · 부하 40 · 부하 80 |
- **모션 보기**(`app/motions.rs`, `Scene::Motions { weapon, speed, spin, t_ms }`): 위 무기 탭(탭 넘기기·누르기), 왼쪽 동작 줄(그 무기의 평타·대시·강타
  모으기·강타·마법/쇠뇌·수류탄 + 공통 몸·막기·피하기·맞음 + 기술·큰 기술 — `motions::rows`, 순수·시험), 오른쪽 인형(`Renderer::draw_doll_anim`)이
  고른 동작을 되풀이(끝 자세에서 0.35초 머문다), 시간 막대에 **판정 구간**(게임의 `hit_times`·`heavy_times`·기술 표 `Clip::seg` 그대로)을 호박색으로,
  지금 시각·길이·빠르기 숫자. 좌우 = 30°씩 돌리기, 확인 = 빠르기(1 → ½ → ¼ → 멈춤).
- 장면이 상태를 들고 다닌다(0066 — `App`에 화면 필드를 두지 않는다): 매 틱 `Stack::retag`로 맨 위 칸의 장면 값만 바꾼다(커서·창은 그대로).
- 헤드리스 길을 새 자리로(`shot.js`·`fx.js`·`mouse.js`·`leak.js`), `shot.js`가 모션 보기 두 장(`00j1`·`00j2`)을 찍는다.
- 시험: 묶음별 첫 줄들의 자리(스크립트 길), 무기마다 그 무기의 동작이 다 있고 모델에 있으며 판정 구간이 동작 길이 안.
