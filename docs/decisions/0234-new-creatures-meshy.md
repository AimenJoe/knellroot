- 사장: "새 캐릭터들 제대로 모델링 되어있니?" → (아니다 — 다섯이 코드 모델·빌린 모델) → "1, 2 진행해줘"(1 = 작업층 셋의 프롬프트, 2 = 그림 → 평가 → Meshy)

  회색 박스에서 잔재·등딱지짐승·이끼 덮인 문지기 모델을 빌려 씀), 0157(주인공·보스의 생김새 = 그림 → 사장 확인 → 메시), 0132(나노바나나 → Meshy 흐름),

## 정한 것
1. **작업층 셋의 프롬프트** `docs/art/gemini-prompts-0234.md`(0185 꼴 — 첨부 그림·실루엣에서 읽혀야 할 것·종을 고른 까닭):
   되풀이꾼 = 두더지 광부(삽 같은 앞발·찌그러진 안전모·꺼진 등 — 마을의 물 모으는 주민과 같은 종, ECO-10), 등짐꾼 = 카피바라 짐꾼(등의 돌짐이 몸과
   갈리는 색 — 깨지는 부위), 권양지기 = 늙은 오소리(흰 줄 얼굴·긴 팔·한 손목의 쇠고랑·가슴 금의 핵). 곡괭이·사슬·갈고리는 그리지 않는다(코드 도형, 0208).
2. **그림은 Claude가 직접 받는다** — `tools/art/nanobanana.py`. 세션의 Gemini 키는 무료 등급이라 이미지 모델 한도가 0이었고(429), **Meshy Image to Image
   API의 `nano-banana-pro`**로 받았다(첨부 그림을 data URI로 — 웹에서 붙이는 것과 같다). 한 장 9 크레딧. 첫 장에서 어긋난 것(되풀이꾼의 긴 팔·막대 뿌리,
   등짐꾼의 갈라진 가지 뿌리·하마 얼굴, 권양지기의 근육·작은 머리)은 프롬프트 끝에 "IMPORTANT FIXES"를 붙여 다시 받았다(프롬프트 문서에 그대로 적었다).
   다섯 장 모두 `tiny_preview.py`로 게임 크기(20·50px, 보스 60·150px)에서 특징이 남는지 봤다. 원본 `tools/art/sources/ai/knellroot/<이름>_v1_front.png`,
   묶음 `docs/art/refs-0234/`.
3. **Meshy Image to 3D는 API로** — `tools/art/meshy_image3d.py`(텍스처·빛 지우기 `remove_lighting`·3만 삼각형 리메시·네 방향 미리보기). Meshy 6 = 30 크레딧.
   되풀이꾼은 Meshy 6이 엉덩이 뒤로 큰 덩어리를 지어내서 7.1(`latest`, 30 크레딧)로 다시 받았다 — 7.1 메시는 정점 ~330 아래로 안 줄어(줄이면 다리가 뾰족) 목표 1400.
4. **게임 모델**(Blender 스크립트 — 뼈 이름·동작은 그 전 것을 그대로 이어받아 게임 코드는 거의 그대로):
   - 이끼먹이 `mossgrazer.py` — 뼈·동작은 1차 그대로(뜯기·깡충), 몸만 Meshy(정점 696). 옛 코드 몸은 `make_blocks()`.
   - 되풀이꾼 `repeater.py` — 잔재의 동작 표(`root_husk.acts`), 오른손 뼈 `pick`에 코드 곡괭이(자루는 앞, 날은 세로 — 두 팔을 머리 위로 들었다 내려찍기 =
     곡괭이질), 정점 1550(예산 1650). 종 표 `model: "repeater"`, `STRIKE_KEYS`에 잔재와 같은 0.5·0.62.
   - 등짐꾼 `packbearer.py` — 가시짐승의 동작 표(`thorn_beast.acts(m, leg_k, rear_k)` — 짧은 뭉툭발이라 다리 각 0.45배·일어서기 0.5배, 기본값은
     가시짐승 그대로 — 바이트까지 같음을 확인), **짐은 따로 부위 `load`**(모래빛 면을 색으로 + 짐 위 결정은 높이로) — 자세가 처음 깨지면 렌더가 그
     노드를 숨긴다(`render/actors.rs`, `Enemy::load_lost`). 코드로 얹던 돌덩이(`overlays::packbearer_loads`)는 걷었다. 줄인 몸이 길이 1.95m라 0.85배.
5. **보스 둘(이끼 덮인 문지기·권양지기)은 그림까지** — 0157에 따라 사장 확인 뒤 Meshy. 그림 `docs/art/refs-0234/bosses_v1.png`.

- 이끼먹이의 게임 안 모습은 헤드리스에서 못 잡았다(정원 시작 자리에서 멀다) — 미리보기만 봤다. 사람이 정원에서 볼 것.
