# 0054. 글자는 화면과 상관없이 한 크기로만 굽는다

- 날짜: 2026-11-04
- 상태: 채택·구현(사장: "아직 전체화면 왔다갔다하면 글씨가 검은색이 되어버리는걸?")
- 0049를 고친다.

## 왜
- 0049는 굽는 크기에 상한(56px)만 두었다. 그런데 UI 배율이 그린 화면 높이를 따라가서(0046), 전체 화면을 켜고 끌 때마다(주소창이 있고 없음 → 창 높이가 바뀜) 본문 글자를 **새 크기로 또 구웠다**.
- macroquad 글자 캐시는 지우지 않는다. 그래서 크기가 하나 늘 때마다 아틀라스가 커졌다.
- 헤드리스 폰(915×412·915×360, DPR 2.625)에서 창 높이를 오가니 첫 번에 4096²가 됐다. KB의 "큰 아틀라스에서 Android Chrome 검은 글자"와 같은 조건이다.

## 정한 것
- 굽는 크기 = 물리 약 48px(`ui::BAKE`)이다. 글자 크기 정수는 `round(48 / DPI)`이고 **DPI로만** 정한다. 보이는 크기는 모두 `font_scale`로 맞춘다.
- 미리 굽기의 열쇠도 (언어, DPI)뿐이다. 배율이 바뀌어도 다시 굽지 않는다.
- 결과(같은 헤드리스 측정): 창 높이를 여섯 번 오가도 아틀라스는 1024²에 머문다. 1920×969 ↔ 1080 ↔ 900 ↔ 700도 마찬가지다. 렌더 타깃은 바뀔 때마다 옛 것을 지운다(누수 없음).
- 대가: 1080p 본문(52px)은 48px을 1.08배 키워 그린다. 4K에서는 조금 무르다.
- 시험: `glyphs_bake_at_one_size_whatever_the_screen`.
