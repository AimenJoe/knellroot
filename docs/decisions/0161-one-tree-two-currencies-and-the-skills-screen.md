# 0161. 나무 하나 · 화폐 둘(잔불 = 몸과 장비, 기술 점수 = 기술) · 기술 화면부터

- 날짜: 2026-11-12
- 상태: **결정**(사장 2026-11-12, 0160의 시안을 보고) — "화폐도.. 장비용 화폐랑 기술용 화폐 정도로만 나뉘어야 할 듯. 어느 정도 방향 맞는 것 같으니 가 보자."
- 바탕: 0160(제안과 시안 그림 `docs/art/gui-0160/`), 0158(기술 점수·다섯 단·줄), 0102·0106(나무와 마디), KB `meta-progression-unlock-planning`·`game-menu-scene-stack-and-focus`.

## 정한 것
| 무엇 | 결정 |
|---|---|
| 화폐 | **둘**. **잔불** = 몸과 장비(레벨·가게·되돌리기의 값 — 그리고 앞으로의 무기 강화). **기술 점수** = 기술(스킬·큰 기술·패시브 칸). 마디(핵·종소리 조각)는 화폐가 아니라 기술 점수의 **샘**이 된다 |
| 기술 점수 | 가진 점수 = 총 레벨 + 엘리트 첫 쓰러뜨림 + **핵(보스를 이길 때마다, 보스마다 셋까지) + 종소리 조각** − 쓴 점수. 지금 내용으로 15 + 6 + 6 + 3 = 30. 0158의 "보스 첫 쓰러뜨림 +1"은 핵의 수로 바뀐다 |
| 나무 | **하나**: 갈래 셋(흐름·맞받기·자리) × 줄 셋(처음부터 / 쓴 점수 4 / 쓴 점수 8). 패시브 15칸(칸마다 1점)과 스킬 여덟(다섯 단)·큰 기술 셋(세 단)이 같은 판에 선다 |
| 패시브의 잠금 | "앞 칸을 열어야 다음 칸"을 걷는다 — 줄(쓴 점수)만 본다. 갈래마다 첫 둘은 첫 줄, 셋째·넷째는 둘째 줄, 다섯째는 셋째 줄 |
| 옛 기록 | 갈래마다 연 칸 수(`tree.*`)는 앞에서부터 그만큼 연 것으로 읽는다. 연 칸은 쓴 점수로 센다 — 잃는 것이 없다 |
| 되돌리기 | 잔불을 내고 스킬·큰 기술·패시브를 한꺼번에(0158의 값 그대로) |
| 화면 | 0160 시안의 방향으로. **기술 화면 하나를 먼저** 실제로 만들어 게임 화면으로 확인한 뒤 나머지 탭(상태·장비·도감·가게·설정)과 창 합치기로 간다 |

레벨이 잔불로 오르고 레벨마다 기술 점수가 생기는 것은 그대로다(잔불이 기술에 닿는 길은 이것 하나 — 사장의 "장비용 / 기술용"과 어긋나면 레벨의 값을 다시 본다).

## 첫 걸음에서 만드는 것
1. 셈과 기록: 점수의 샘(핵·조각), 패시브 칸을 판의 셈으로, 줄 잠금, 옛 기록 읽기, 되돌리기.
2. **기술 화면**(화로·멈춤 공용 — 화로에서만 올리고 되돌린다, 끼우기는 어디서나): 칸 그림 격자 + 고른 칸의 상세 + 아래 안내. 지금의 나무 창·기술 판·멈춤의 기술 창을 대신한다. 화로와 멈춤의 "나무" 줄은 없어진다.
3. 패시브 15칸의 도트 그림(13×13).

나머지 탭과 창 합치기, HUD는 이 화면을 본 뒤에.

## 한 것(첫 걸음, 2026-11-12 — 판정 전)
- **셈·기록**: 기술 점수의 샘이 레벨 + 엘리트 + 핵(문지기마다 셋까지) + 종소리 조각으로(`Progress::skill_points`), 패시브 15칸은 판의 칸(`skills::Board::cells` — 옛 `Progress::tree`), 줄 잠금은 쓴 점수 하나(`ROW_NEEDS`), 되돌리기는 스킬·큰 기술·패시브를 한꺼번에. 판에 서는 것의 차례는 `skills::ENTRIES`(스물여섯 — 스킬 여덟·큰 기술 셋·패시브 열다섯).
- **옛 기록**: `tree.<갈래>` = N은 앞에서부터 N칸을 연 것으로 읽고 쓴 점수로 센다. 새 키 `tree.cells.<갈래>` = 연 자리들("1,2,5"), 옛 키에는 앞에서부터 이어 연 수를 계속 적는다(옛 판이 읽어도 터지지 않는다). 목표 핀(`tree.pin`)은 걷었다 — 읽지도 쓰지도 않고 줄만 지닌다. 개발판 기록이 새 셈에서 넘치면(옛 "보스 첫 쓰러뜨림 +1"이 핵의 수로 바뀌어) 스킬·큰 기술만 처음으로 돌아가고 연 패시브 칸은 남는다.
- **기술 화면**(`app/skills.rs`, 창 틀은 `app/frame.rs`): 왼쪽 칸 그림 격자(갈래 셋 × 줄 셋 — 스킬은 네모·패시브는 동그라미·큰 기술은 팔각, 금빛 = 가진 것 / 민트 점선 = 지금 할 수 있음 / 흐림 = 잠김, 칸 아래 단 점, 귀퉁이에 끼운 칸 번호와 고르기), 오른쪽 상세(이름·갈래·상태 한 줄·설명·단마다 주는 것·고르기 둘), 아래 안내 + 되돌리기 단추. 확인 = 그 칸에 할 수 있는 일의 작은 목록(올리기·열기 / 칸 1·2에 끼우기 / 고르기 바꾸기) — 사는 일만 묻는 창. 화로에서는 올리고 되돌리고, 멈춤에서는 끼우기만. 옛 나무 창(`app/tree.rs`)·기술 판(`app/board.rs`)·멈춤의 기술 목록은 없앴고, 화로와 멈춤의 "나무" 줄도 없다(화로: 레벨·기술·가게·떠나기 / 멈춤: 계속·장비·도감·기술·설정 …).
- **그림**: 패시브 15칸의 13×13 도트(`icons.rs` — 터치 버튼 그림과 같은 꼴, 서로 12칸 이상 다르다는 시험).
- **확인**: 시험 482 + 무시 2(셈·기록 옮기기·걸음·목록·상태 줄), clippy 다섯, `tools/test/hearth.js`(한국어·영어 — 한 단 사기·고르기 뒤집기·패시브 열기·모든 칸의 상세·잠긴 칸·되돌리기·멈춤의 끼우기 + 단을 미리 찍은 기록 열 × 화로·멈춤, F4 넘침 0), CI가 도는 넷. 화면 크기 넷(16:9·4:3·휴대폰·넓은 화면)에서 봄.
- **이 걸음에서 정한 작은 것**: 격자의 오른쪽 끝에서 오른쪽·맨 아래 줄에서 아래 = 되돌리기 단추(화로) · 가장자리에서 커서가 돌지 않는다 · 좁은 화면에서는 아래 안내를 자르기 전에 줄인다 · 묻는 창이 뜨면 되돌리기 단추를 그리지 않는다.
- **아직 아닌 것**: 나머지 탭(상태·장비·도감·가게·설정)과 창 하나로 합치기, HUD — 이 화면을 사장이 본 뒤에. 줄 이름표("쓴 점수 4부터")가 칸에 바짝 붙어 있다(4:3에서 더) — 다듬을 자리.
