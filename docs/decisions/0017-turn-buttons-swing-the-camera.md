# 0017. 땅 돌리기 좌우 버튼 = 카메라가 그쪽으로 돈다(0015를 되돌림)

- 날짜: 2026-11-03
- 상태: 채택·구현. 0015를 대신한다.

## 경위
- 0012: RB = `turn_cw` = 땅이 화면에서 시계 방향 = 카메라가 자기 오른쪽으로 돈다(먼 쪽이 오른쪽으로, 가까운 쪽은 왼쪽으로).
- 0015: 사장 "좌우가 반대로 맵핑돼야 할 듯" → "가까운 쪽 기준"으로 뒤집음(RB = 땅 반시계).
- 0017: 다시 "LB RB로 회전하는 거, 좌우가 바뀌어야 하지 않나" → 물어서 확인: **"RB = 카메라가 오른쪽으로"**(사장 선택). 0012의 뜻으로 돌아간다.
- 배운 것: "좌우가 반대"는 기준(카메라·먼 쪽·가까운 쪽)에 따라 뜻이 갈린다 — 방향 요청은 처음에 "버튼을 누르면 무엇이 그쪽으로 가는가"로 물어 확인한다.

## 결정
- 오른쪽 버튼(RB·E·터치 오른쪽) = `turn_cw`(카메라가 오른쪽으로, 땅은 화면에서 시계 방향), 왼쪽 버튼 = `turn_ccw`.
- 터치 그림: 위쪽 반원 화살표(↶ ↷), 화살촉이 누르는 쪽 끝에서 아래로 — 먼 쪽이 그쪽으로 간다.
- 시험: `the_right_turn_button_swings_the_camera_right`(터치), `a_clockwise_turn_swings_the_camera_to_its_right`(카메라 자리가 돌기 전 화면 오른쪽으로 움직인다).
