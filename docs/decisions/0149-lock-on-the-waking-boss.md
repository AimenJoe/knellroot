# 0149. 깨어나는 중인 보스도 락온에 잡힌다

- 날짜: 2026-11-11
- 상태: **구현**(`release/v0.6`, 판정 전). 사장 2026-11-11: "보스전에서 보스가 깨어나기 전에 타겟팅이 안 돼서 엉뚱한 적에게 락온 되는 경우가 있어."

## 원인
- 보스는 성소에 들어서면 2초(`WAKE_TIME`) 동안 깨어난다. 그동안 상태는 잠듦(`EState::Dormant`)이고, 락온 후보는 "싸움에 낀 적"(`Enemy::active()` — 잠든 적 제외)만 봤다.
- 그래서 그 2초에 락온을 누르면 보스는 후보에 없고, 락온 거리(18m) 안의 다른 깬 적 — 벽 너머의 잡몹까지 — 이 잡혔다. 보스 우대 점수(−0.5)도 후보가 아니니 쓸모가 없었다.

## 고침
- `Enemy::waking`(스테이지가 깨우기 시작할 때 켜고, 다 깨면·화로에서 되돌릴 때 끈다) + `Enemy::lockable()` = 싸움에 낀 적 **또는 깨어나는 중인 잠든 적**.
- 락온 고르기(`tick_lock`)·대상 넘기기(`handoff_target`)·터치 락온 버튼을 띄울지(`lock_candidate`)가 `lockable()`을 본다. 보스 우대 점수가 그대로 붙어, 더 가까운 잡몹이 있어도 보스가 잡힌다.
- **그대로 둔 것**: 아직 깨어나기 시작하지 않은 잠든 보스는 잡히지 않는다(성소 밖에서 잡몹과 싸울 때 락온이 멀리 잠든 보스로 가면 안 된다). 깨어나는 동안 보스는 여전히 맞지 않는다.
- 월드는 스테이지를 모른다 — 깃발 하나만 받는다.

## 시험
- `lock_on_takes_the_boss_while_it_is_still_waking`: 깨어나기 전에는 후보가 아니다 → 성소에 들어서면 후보(터치 버튼도 뜬다) → 2m 옆에 깬 잡몹이 있어도 보스가 잡힌다 → 다 깨면 깃발이 내려가고 락온은 그대로.
- **확인 못 한 것**: 게임 화면에서의 재현(시험으로만 확인). 벽 너머의 적이 락온에 잡히는 것 자체(시야 검사 없음)는 그대로다 — 보스전 밖에서도 거슬리면 따로 고친다.
