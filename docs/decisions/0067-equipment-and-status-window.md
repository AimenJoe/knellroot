# 0067. 장비 창 + 상태 창 — 스터디와 제안

- 날짜: 2026-11-05
- 상태: **채택 — 안 D**(사장 2026-11-05 "응 d 로 가자", 아래 5). 처음 물음: "Item 장비창도 필요함. 상태창이랑 같이 보이는게 좋을것 같기도..? 스터디 해보자". 정할 것 2(고르기)는 D의 칸 먼저, 3(잠긴 칸 보이기)·4(숫자)는 추천대로 — 바꾸려면 말해 달라.
- 지금: 멈춤 → 장비(0064 M3) = 무기 줄 + 장신구 세 칸(◀ 이름 ▶로 돌려 끼움) + 아래 설명 두 줄. 능력치는 어디에도 숫자로 안 보인다(HUD의 체력·등잔 수만).

## 1. 우리가 이미 아는 것
**KB `concepts/action-rpg-stats-and-equipment`**
- 무기 = 모양, 장신구 = 수치(맞바꿈), 성장 = 영구. 코드는 합친 `Stats` 하나.
- "장신구를 고르려면 **플레이어 쪽 숫자**가 필요하다(공격력·공속 %·대기 초). 적은 말로."
- 칸은 작게(2~3), "가득일 때 끼면 먼저 낀 것과 바꾸면 메뉴가 짧다".
- 함정: 상태 줄이 늘면 칸이 넘친다 → **보정이 있을 때만 그 줄을 보인다**, 줄 간격 여유.

**nail(일시정지 탭 여덟, `app/pause.rs`)** — 상태와 가방이 **따로 탭**
- 상태 탭: 두 칸(왼쪽 체력·힘·공속·회피 대기·게이지 / 오른쪽 무기·재화) + 아래 필살기·장신구 이름과 설명.
- 가방 탭: 칸 격자(무기·장신구 그림, 낀 것은 "E") + 오른쪽에 고른 것의 이름·설명·콤보 수.
- 탭 넘기기 Q·E, 가방은 좌우가 칸 옮기기라 끝에서 더 밀면 옆 탭(0248 R30 `PauseTab.lr`).
- 아쉬움: 장신구를 바꾸며 상태가 어떻게 바뀌는지 보려면 탭을 오가야 한다.

**추천: A.** 그리고 멈춤 창에 셋째 화면(도감·저널)이 생길 때 nail 탭 표(`PauseTab`)로 바꾸면서 A를 "장비" 탭 하나로 넣는다(그때 B와 합쳐짐 — 지금 미리 탭을 만들 필요는 없다).

### A의 배치(480×270 기준, 창 440×240)
```
┌ 장비 ─────────────────────────────── 잔불 30 ─ ✕ ┐
│ 무기   ◀ 순례자의 검 ▶      │ 최대 체력   5        │
│ ─────────────────────────── │ 등잔        3회 · +2 │
│ 낀 것  [껍데기][주머니][ 빈 ]│ 피해        2        │
│ ─────────────────────────── │ 공격 속도   100%     │
│ 가진 것                      │ 회피 기력   100%     │
│ ▶[껍데기 E][가벼운 발][귀 E] │ 패링 창     0.18초   │
│  [굶주린 뿌리][무거운 손]... │ 잔불        +50%  ▲  │
│                              │ (바꾸면: 값 → 값 ▲▼) │
│ 가벼운 발 — 회피 기력 −30% · 받는 피해 +1          │
└──────────────────────────────────────────────────┘
```
- **왼쪽**: 무기 줄(◀ 이름 ▶ — 지금 그대로), 낀 칸 셋, 가진 것(장신구 여섯 칸 격자, 낀 것은 "E", 아직 못 얻은 것은 잠긴 칸 + 얻는 곳 한 줄).
- **고르기는 Hollow Knight 꼴**: 가진 것에서 확인 = 끼기(빈 칸에) / 빼기(낀 것이면). 칸이 가득이면 **마지막에 고른 칸과 바꾼다**(KB "가득일 때 끼면 바꾸면 메뉴가 짧다"). 낀 칸에서 확인 = 빼기.
- **오른쪽 상태**: 늘 보이는 줄(체력·등잔·피해·공격 속도)과 **보정이 있을 때만** 보이는 줄(받는 피해·회피 기력·패링 창·처치 시 기력·잔불). 무기 줄에 있으면 무기 정보(콤보 타 수·강타·RB 마법/사격).
- **미리보기**: 커서가 가진 것·무기에 있으면 "끼면 이렇게": 바뀌는 줄만 `5 → 6 ▲`(좋아짐 = 호박색 ▲, 나빠짐 = 붉은 ▼, 같으면 그대로). 색 + 화살표 + 숫자 셋 다(색약 규칙 0150 방식).
- 아래: 고른 것의 설명 두 줄(지금 그대로).
- 좁은 화면(세로가 긴 폰): 오른쪽 칸을 아래로 내린다(두 칸 → 위아래), 넘치면 굴림(0059).

### 코드(0066 뼈대 위에)
- 순수 함수 `equip::preview(progress, 바꿈) -> (Stats, Stats)`와 "보일 줄" 고르기 `equip::status_rows(stats, base) -> Vec<(이름, 값, 변화)>` — 시험(맞바꿈 장신구는 ▲·▼가 함께, 보정 없는 줄은 숨김).
- 화면은 제 그림(격자 + 두 칸이라 줄 표 몰이꾼 밖) — 누를 자리는 `Hit::Cell`·`Row` 그대로, 포커스는 무기 줄 → 낀 칸 → 가진 것(위아래·좌우, 격자는 돌지 않는다 — Xbox 112).
- 글: 상태 줄 이름 열 개 남짓 + 잠긴 칸 글(한국어·영어), 서브셋 다시.

## 4. 정할 것(사장)
1. A(한 창 두 칸) / B(탭) / C(줄만) 가운데 — 추천 A.
2. 고르기: Hollow Knight 꼴(가진 것을 골라 끼기·빼기) / 지금처럼 칸을 골라 ◀▶ 돌리기 — 추천 HK 꼴(가진 것이 한눈에 보인다).
3. 못 얻은 장신구를 잠긴 칸으로 보일까(얻는 곳 힌트) — 추천 보인다(KB meta-progression "다 보이는 칸").
4. 숫자를 얼마나: 지금 안은 모두 숫자(%·초). 분위기를 위해 일부를 말로(nail 도감처럼)?— 추천 플레이어 쪽은 숫자(KB).

### 우리에게 맞는 것·안 맞는 것
- **맞는 것**
  - **인형**: 장비 = 칸이라는 생각이 그대로 그림이 된다. 귀여운 방랑자가 고른 무기를 든 모습을 보는 즐거움(0037 "작고 따뜻한 것").
  - **비교 미리보기**: 안 A와 같은 결론.
  - **"자세히" 접기**: 상태를 요약(체력·피해·공속)만 두고 나머지는 접으면 좁은 화면에 맞다.
- **안 맞는 것**
  - **격자 가방**: 무작위 떨굼이 많은 게임의 짐 정리 도구다. 우리는 장비가 열 개(무기 넷·장신구 여섯), 소모품 없음(0027), 무작위 떨굼 없음 — 격자·크기는 일만 늘린다.
  - **PC식 마우스 끌어 놓기**: 패드·터치가 먼저인 우리와 안 맞는다. 디아블로 스스로 콘솔판에서 버렸다.

### 안 D: 디아블로 콘솔식 인형(A와 합친 것)
```
┌ 장비 ──────────────────────────── 잔불 30 ─ ✕ ┐
│        [장신구1]         │ ▶ 가벼운 발            │
│ [무기]  (방랑자 3D)  [장신구2] │   껍데기  E           │
│        [장신구3]         │   잔재의 귀            │
│ 체력 5 · 피해 2 · 공속 100%  │ 회피 기력 100% → 70% ▲ │
│ (자세히 ▼)               │ 받는 피해 0 → +1   ▼  │
└──────────────────────────────────────────────┘
```
- 왼쪽 **인형**: 가운데 방랑자(지금 든 무기를 든 3D 모델, 천천히 돈다), 둘레에 무기 칸 하나 + 장신구 칸 셋. 십자키로 칸을 고른다(콘솔 디아블로 III처럼 **칸 먼저**).
- 칸을 고르면 오른쪽에 **그 칸에 낄 수 있는 것** 목록(가진 것만, 낀 것은 E) — 커서를 옮기면 아래 상태가 바뀔 값으로(`값 → 값 ▲▼`). 확인 = 끼기, 뒤로 = 칸으로.
- 인형 아래 상태 요약 세 줄, "자세히"(Y·△ 같은 버튼 하나)로 전체 상태를 펼친다(디아블로 III).
- **비용**: 3D 인형은 작은 렌더 타깃 하나 + 고정 카메라로 방랑자만 그리는 패스(그림자 지도에 이미 렌더 타깃을 쓴다 — 길은 있다). 반나절~하루 시험(스파이크)으로 확인 필요. 안 되면 인형 자리에 초상 그림으로.

## 6. 구현(2026-11-05, 안 D)
- **인형 스파이크 성공**: `Renderer::draw_doll` — 깊이 붙은 작은 타깃(64×96) + 고정 카메라 + 화로 불빛 하나로 방랑자만(든 무기만 보이게, 게임과 같은 숨쉬기 동작·외곽선), 화면에 정수배(창 크기에 맞춰 3배 안팎). 몸은 앞을 보며 ±0.55라디안 천천히 흔든다(얼굴·무기가 늘 보이게). 화면 패스 중에 불러도 카메라를 돌려놓는다.
- **화면** `app/equip.rs`: 칸 넷(무기 — 이름이 길어 조금 넓게 · 장신구 셋), 위아래 = 칸, 좌우 = 바로 돌려 끼우기(옛 창의 빠른 길 그대로), 확인·탭 = `Scene::EquipPick { slot }`(스택 위 칸 — 닫으면 그 칸으로)에서 후보: 무기 넷 / 빈 칸 + 장신구 여섯(못 얻은 것은 흐린 "잠김", 설명 = 얻는 곳 — 상자·문지기·화로). 다른 칸에 낀 장신구를 고르면 두 칸을 맞바꾼다(`wear`, 같은 것 두 칸 금지 — 시험).
- **상태**: `stats::lines`(순수, 시험) — 늘 보이는 셋(최대 체력·등잔·공격 속도) + 기본값과 다른 줄만, 미리보기는 바뀌는 줄만 `값 → 값 ▲/▼`(호박색 ▲ 좋아짐 · 붉은 ▼ 나빠짐 — 받는 피해·회피 기력은 작을수록 좋음). 값 폭을 먼저 재고 이름을 남는 폭에.
- 글: 상태 줄 이름 열·무기 설명 넷(키 이름 없이)·잠김·얻는 곳 셋(한국어·영어), 서브셋 다시. 옛 장비 줄 표(`EquipRow`)는 없앴다.
- 확인: 단위 시험 208, 헤드리스 여섯(`save.js`의 장비 길 — 칸 3에서 좌우로 끼우기 — 그대로 통과), F4 넘침 검사 한국어·영어 0건, 스크린숏 `docs/art/ui-0067/`.
