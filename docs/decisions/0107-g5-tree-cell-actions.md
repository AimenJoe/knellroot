## 0102에서 바꾼 것(지금 게임에 맞춰)
- **받아내기**: "패링이 적 자세에 주는 몫 +50%" → 지금 패링은 자세 피해가 **없다**(휘청 + 드러남만). 기준이 없어 "자세 막대를 25% 채운다(문지기 반)"로. 글도 고침.
- **맞서는 자**: "못 받는 공격도 패링하면 피해 반" → 받는 피해가 정수(1 + 장신구)라 반은 0이나 1. "막는다 — 튕기지는 못한다"로(드러남·휘청·반격 없음). 글도 고침.
- 해석으로 정한 것: 이어지는 박자의 "셋째 타"는 박자에 누른 순간(맞은 순간이 아니다), 맺음타의 ×1.5는 마지막 타 뒤 박자로 이은 첫 타, 빈틈은 적의 `Recover` 상태, 착지의 순간은 바깥 고리만(안쪽은 두 번 맞지 않게).
