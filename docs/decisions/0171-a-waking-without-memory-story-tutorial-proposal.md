## 답부터 — 좋습니다, 그리고 이미 정본입니다
"과거를 잃은 방랑자"는 정해진 설정이다. 지금 게임은 그것을 **말한 적이 없다** — 시작 글은 종소리와 뿌리만 말하고("땅 밑에서 종이 울린다. 아무도 치지 않는 종이."), 방랑자가 왜 아무것도 모르는지는 비어 있다. 기억 없이 깨어나는 시작은 새 설정이 아니라 **있는 설정을 처음으로 보여 주는 것**이다.

그리고 그것이 튜토리얼의 까닭이 된다:
- 왜 싸우는 법을 다시 배우나 → 잊었다. 그런데 **몸은 기억한다**.
- 왜 스킬이 하나도 없나(0166·0167) → 잊었다. 몸의 걸음 넷을 마치면 하나가 돌아온다(0169 — 알림이 이미 "몸이 기억해 냈다"다).
- 왜 화로에서 자라나 → 불 곁에서 잊은 것이 돌아온다(growth.md: 화로 곁에서 쉬고 몸에 익는다).
- 무엇을 잃었는지는 말하지 않는다 — 미스터리는 그대로다(방향 1: 천천히 공개).

## 제안
### 가. 첫 장면(새 판에서 한 번)
1. 검은 화면. 종이 한 번 운다.
2. 눈꺼풀이 열리듯 위아래에서 밝아진다. 방랑자가 **엎드려 있다가 일어난다**(새 동작 하나 — 꼴은 그대로).
3. 가운데 두 줄, 지금의 시작 글과 같은 말씨(속말·대사가 아니라 서술):
   - "눈을 뜬다. 이름도, 걸어온 길도 떠오르지 않는다."
   - "몸만이 무언가를 기억한다."
4. 이어서 지금의 시작 글 둘(종소리 · 뿌리)과 구역 이름. 그 뒤 튜토리얼의 첫 걸음.

### 나. 힌트가 눈에 띄게 + 몸의 말로
- **판 위에**(0165의 말씨): 어두운 판 + 위쪽 호박색 줄. 지금은 글이 바닥 위에 그냥 떠 있다.
- **걸음 점 일곱**(지난 것 민트 · 지금 호박 · 남은 것 빈 고리)이 "[2/7]"을 대신한다.
- **머리 줄을 크게**: 키캡 + 할 일 + 세는 수("0 / 3"는 호박색으로 따로).
- **풀이 줄은 몸의 기억으로**: 기능을 설명하는 글("가까이 가서 적을 벤다") 대신 —

| 걸음 | 머리 줄 | 풀이(몸의 기억) |
|---|---|---|
| 걷기 | 걸어 본다 | 다리가 먼저 길을 안다 |
| 공격 | [버튼] 공격 0 / 3 | 손이 검의 무게를 기억한다 |
| 회피 | [버튼] 회피 | 몸이 먼저 비킨다 — 누르고 있으면 달린다 |
| 패링 | [버튼] 패링 | 닿는 순간을 팔이 안다 |
| (상) | 몸이 기억해 냈다 — 기술 점수 +1 | (지금 그대로) |
| 배우기 | 쉼터의 화로에서 쉰다 | 불 곁에서 잊은 것이 돌아온다 — 기술 탭 |
| 쓰기 | [버튼] 되찾은 기술을 쓴다 | 쓰고 나면 숨을 고른다 — 차면 다시 |
| 한 단 | 쉼터의 화로에서 쉰다 | 잔불이 몸에 스민다 — 상태 탭 |

  무기가 다섯이라 "검"을 박지 않는다(growth.md) — "손이 쥔 것의 무게를 기억한다"로 하거나 든 무기의 이름을 넣는다.
- 걸음이 넘어갈 때 짧은 소리 하나(지금은 빛만 바뀐다).

### 다. 하지 않는 것
- 말하는 안내자는 세우지 않는다(이 판에서는) — 방랑자는 혼자 깨어난다. 첫 주민은 둘째 지역에서 만난다(0115).
- 무엇을·왜 잊었는지, 누가 깨웠는지는 쓰지 않는다.
- 싸움을 멈추는 대화창은 없다(0167 그대로).

## 정할 것
1. **이 방향으로 갈까** — 기억 없이 깨어나는 첫 장면 + 몸의 기억으로 말하는 힌트.
2. **글의 말씨**: 서술("눈을 뜬다. …" — 제안) / 방랑자의 속말("…여기가 어디지") / 글 없이 장면만.
3. **깨어나는 자리**: 지금의 시작 자리(쉼터에서 9m) / 꺼진 화로 곁에서 깨어나고 **처음 쉴 때 불이 붙는다**(첫 쉼이 사건이 된다 — 화로 하나의 그림·상태가 더 든다).
4. **일어나는 동작**을 새로 만들까(Blender 동작 하나 — 생김새는 건드리지 않는다, 0157) / 화면이 밝아지는 것만으로.
5. 힌트의 판·점·큰 글(나)은 이야기와 따로 먼저 넣을 수 있다 — 먼저 넣을까.
6. (0170에서 넘어온 것) 문을 찾는 동안의 길 안내로 **종소리가 들리는 쪽**을 둘까.
