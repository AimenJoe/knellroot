# 0266 — 하나뿐인 장비도 판다(잔불로·내려놓기)

- 날짜: 2026-11-22
- 상태: 채택 · v0.8.0
- 사장(2026-11-22): "장비가 하나밖에 없을때 팔수 없었던 것도 수정해서 배포하자."

## 왜
- 0223 V4·0226은 "그 바탕의 마지막 하나"를 거두지도 내려놓지도 못하게 했다(가진 바탕이 사라지지 않게). 쓰지 않는 하나뿐인 무기·장신구를
  가방에서 치울 길이 없었다 — 가방 30칸이 차면 더 그렇다.

## 정한 것
- 끼지 않고 잠그지 않은 것은 무엇이든 잔불로 바꾸고(화로)·내려놓는다(어디서나) — 하나뿐인 것도. `Bag::spares` = 끼지 않은 것,
  진짜 여벌(같은 바탕이 남는 것 — 상황 힌트·가방의 "여벌" 표지)은 `Bag::extras`.
- 마지막 하나를 치우면 가진 바탕에서 뺀다(`Progress::part_with` — 무기·방패·장신구 목록, 그것을 가리키던 낀 자리). 안 빼면 저장 앞의 맞추기
  (`settle_items`)가 보통 것을 다시 만든다. 내려놓은 것을 다시 주우면 `take_item`이 되돌린다. 가게의 장신구는 다시 살 수 있다.
- 도감은 한 번 가졌던 것을 그대로 보인다 — 기록 `codex.had`(`codex::paid_key` 이름들).
- "여벌 정리"는 그대로 바탕마다 가장 값진 하나를 남긴다 — 하나뿐인 것은 정리로 사라지지 않는다(한 번에 하나씩 손으로만).
- 낀 것·잠근 것은 여전히 못 판다(잠금이 지키는 길).
