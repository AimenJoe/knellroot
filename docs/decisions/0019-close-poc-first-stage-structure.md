## PoC를 어떻게 닫나(정직하게)
- P1·P2·P3·P6은 스크린숏·헤드리스 측정과 사장의 웹·핸드헬드 플레이로 "쓸 만하다"까지 왔다. **사람 둘 판정 세션은 하지 않았다.**
- P4는 Blender bpy 스크립트 → GLB → 로더로 진짜 캐릭터(방랑자 대기·걷기·공격·회피·피격·돌리기)가 돈다(Blockbench 대신 Blender — 앞선 대화에서 사장이 고름, KB `reference/assets/retro-3d-models-blockbench-gltf.md`에 기록). **P5 실기 측정(PC·Android Chrome)은 아직** — 1단계 판정 항목으로 넘긴다(`docs/phase-1-first-stage.md`).
- "P1~P3이 닫히기 전에 콘텐츠를 쌓지 않는다"(CLAUDE.md)는 사장 지시로 넘는다. 그 대신 콘텐츠는 **표와 파일 하나씩**으로만 늘게 짠다(아래) — 판정에서 뒤집혀도 지우기 쉽게.
- 값은 그대로 얼려 둔다(0013). 랩은 개발판에 남는다(F1, 개발 메뉴는 나중).

## 구조(첫 게임 nail에서 가져온 것 — KB `guides/second-game-project-day-one.md`)
| 무엇 | 어디 | 늘리는 법 |
|---|---|---|
| 장면(타이틀 → 싸움 → 멈춤 → 끝 → 결과, 개발판은 PoC 시나리오) | `app/mod.rs`(하는 것)·`app/flow.rs`(정하는 것, 순수 함수 + 시험) | 장면 = `Scene` 한 줄 + flow 함수 + 그림 함수. 흐름을 바꾸면 flow 시험(nail 0230 R15) |
| 스테이지 | `stage/mod.rs`(글자 지도 → `Level`, 진행 대본 `StageRun`) + `stage/<이름>.rs`(`StageDef` 하나) | 새 스테이지 = 파일 하나(지도·구역·물결·보스·글 키). 월드는 스테이지를 모른다 — 스테이지가 월드를 지켜보며 적을 세우고 문을 여닫는다 |
| 적 종류 | `species.rs` 표(수치·행동 방식·모델 이름) + `enemy.rs`(행동 방식의 상태 기계) | 새 종류 = `Kind` 한 줄 + 표 한 줄(+ 새 행동이면 `Behavior` 하나). nail `species.rs`(0021)와 같은 꼴 |
| 글 | `i18n/{ko,en}.rs` 키-필드 표, `Tr` | 필드 하나를 더하면 모든 언어에 더해야 컴파일된다. 시험: 모든 글자가 글꼴에 있다·자리표시자가 같다 |
| 글꼴·메뉴 | Galmuri11 Condensed(OFL, nail에서 복사), `ui.rs` | 정수 배율 = 렌더 배율. 커서 없이(위·아래 + 확인), 터치는 뗄 때(nail 0199) |
| 모델 | `assets/models/*.glb` → `build.rs`가 표로 넣음 → `models.rs` `Library` | 파일을 넣으면 등록된다(이름 = 파일 이름). 없으면 상자. `glow_` 부위는 스스로 빛남. 상태 → 동작 이름 후보(`render::enemy_anim`) |
| 지형 그림 | `scenery.rs`: 레벨을 한 번 굽는다(바닥 석판·벽 덩어리·소품 모델) | 빛(달빛 + 화로)은 정점 색에 미리 — 기본 셰이더가 법선을 안 읽는다(KB `reference/macroquad/3d-rendering.md`) |
| 글·막대 | `hud.rs` | 렌더가 돌려준 `Frame`에 같은 배율로 |

## 바꾼 값
- 잡몹·보스 수치 넷(`mob.speed`·`mob.tele s`·`boss.tele s`·`boss.swing arc`)을 랩 표에서 빼고 종류 표로 옮겼다(SPECS 69 → 65, `docs/tuning-frozen.txt` 다시 찍음). 보스 값(예고 0.9초·부채꼴 110°)은 같고, **잡몹은 바뀌었다**: 걸음 3.5 → 2.6 m/s(뿌리의 잔재는 느리고 무겁다 — 떼로 둘러싸는 압박), 예고 0.5 → 0.55초. 빠른 쪽은 새 종류 가시짐승(3.8 m/s, 7m 안에서 0.65초 예고 뒤 곧은 돌진)이 맡는다.
- 잠든 적(`EState::Dormant`)은 맞지도, 락온·자동 조준·땅 돌리기에 잡히지도 않는다(`Enemy::active`).

## 첫 스테이지 "침묵의 성소"
`docs/phase-1-first-stage.md`. 남쪽 무너진 입구 → 좁은 길 → 뿌리의 뜰(물결 셋: 잔재 → 잔재 + 가시짐승 → 더 많이) → 문이 열림 → 북쪽 닫힌 성소(들어서면 문이 닫히고 잠든 문지기가 2초에 걸쳐 깨어남) → 결투(문지기: 부채꼴 내려치기·돌진·세 번째마다 퍼지는 뿌리 파동, 반 아래에서 빨라짐) → 핵을 거두면 끝.
