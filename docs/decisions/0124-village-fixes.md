# 0124. 떠난 마을 손질 — 사다리 지름길 걷기, 성소만큼의 밀도, 빛줄기가 몸을 비춘다

- 날짜: 2026-11-08
- 상태: **채택·구현**(`release/v0.5`). 사장 2026-11-08 판정 셋.

## 1. 사다리 지름길을 걷는다(0121 고침)
- 사장: "지름길이 유용한지 모르겠다 — 사다리를 활성화하고 지나온 길을 다시 갔다 오는 경우가 있어 별로". 까닭: 종탑 터 바로 앞에 화로가 있어 돌아갈 길이 짧고, 장치가 광장(가는 길 가운데)에 있어 당기려면 되돌아가야 했다. 인터뷰 — **없애기**(추천).
- 사다리 길·문 `G`·장치 `V`·`StageDef::gate_shortcut`(마을만 쓰던 지름길 문 규칙)·글 `card_ladder`를 걷었다. 고리는 성소에만, 지역마다 지름길을 억지로 두지 않는다. 장치 카드 칸 `card_lever`는 남긴다(성소).

## 2. 밀도를 성소만큼
- 사장: "첫 번째 지역보다 몹들의 밀집도가 덜해". 마을 서 있는 적 15 → **33**(잔재 13·가시짐승 5·등딱지짐승 5·꼬투리 6·청소자 4) + 엘리트 셋. 성소는 39 + 셋(지도 넓이는 비슷).
- 지키는 것(시험): 주민 자리는 모든 적의 끈 + 3m 밖, 화로 곁 안전, 도착 자리(오르는 길 곁)는 비운다, 모든 바닥에 닿는다.

## 3. 빛줄기가 몸을 비춘다(0119 고침)
- 사장: "빛을 받는 부분은 실제 캐릭터는 빛을 받는 것처럼 보이지 않는다". 까닭: 빛줄기의 빛이 화로처럼 둥글게 퍼지는 약한 점광(반지름 6m, 바닥 2.5m 위)이라 거리 제곱 감쇠·툰 3단에서 거의 0이 되고, 땅속 달빛 0.4 아래에서 차이가 안 났다.
- `stage::Light::shaft`: 빛줄기는 **기둥 빛** — 가로 반지름(`SHAFT_R` 1.7m — 바닥 웅덩이와 같게) 안이면 높이와 상관없이 위에서 내리꽂고, 가운데일수록·위를 보는 면일수록 밝다(`render::lit`, 세기 `SHAFT` 1.1, 툰 2단). 굽는 바닥·배우가 같이 받는다.
- 시험: 기둥 안 몸은 밖의 1.5배 넘게 밝고, 머리(위를 보는 면)가 더 밝고, 높이로 줄지 않는다.

## 판정에서 볼 것(사람)
- 빛줄기 아래를 지날 때 방랑자·적이 "빛 속에 들어섰다"로 읽히나(너무 하얗지 않나).
- 마을 싸움 밀도가 성소와 비슷하게 느껴지나, 주민 곁이 여전히 조용한가.
