## 전(0075)
- 줄 표 메뉴 하나였다: `묶음 ◀ 싸움 ▶` 줄 · `무기 ◀ ▶` 줄 · 시작할 것들 · 돌아가기, 아래 설명.

## nail(0269, `src/app/title.rs` `draw_dev`·`scenario::Cat`)
- 위에 묶음 탭이 한 줄로 다 보인다(좌우·Q/E·탭).
- 왼쪽은 그 탭의 줄(굴림), 오른쪽은 고른 줄의 이름·설명, 아래 안내 "좌우: 묶음 · 위아래: 고르기 · 확인: 시작 · 뒤로: 타이틀".
- 목록은 시작할 것만 있다. 표 하나(`Entry { cat, name, desc, scenario }`)에서 묶음별로 거른다. 도구 탭이 맨 앞이다.

## 결정
- `app/dev.rs`의 제 그림 창이다(장비 창처럼 — 0066 "표가 안 맞는 화면은 제 그림"):
  - 창 틀 + ✕(창 밖 누름 = 나가기)
  - **묶음 탭 줄**: 도구 · 스테이지 · 전투·적 · 성능. 고른 탭은 밝은 단추이고, 좌우·땅 돌리기(Q/E)·탭 누르기로 바꾼다.
  - **왼쪽 줄**(`ui.list`, 넘치면 굴림)과 **오른쪽 이름·설명**(세로 선으로 가름), **아래 안내 한 줄**
- **표 한 곳** `DEV_LIST: [(DevCat, DevStart)]`:
  - 도구 = 연구소 · 빈 아레나
  - 스테이지 = 입구부터 · 문 앞
  - 전투·적 = 보스 아레나 · 기둥 + 보스 · 잔재 + 가시짐승 · 무리 20 · 쏟기
  - 성능 = 부하 40 · 부하 80
- **무기 줄·돌아가기 줄 없음**: 무기는 게임 안 장비 창(Select·Tab)에서 바꾼다. 아레나는 지금 든 무기로 시작한다. 뒤로 = 나가기.
- 글은 0080대로 설정 언어를 따른다(`i18n/dev.rs` `TAB_*`·`DEV_HINT`).
- 시험 `every_scenario_sits_once_and_no_group_is_empty`:
  - 시나리오마다 꼭 한 줄, 빈 묶음 없음
  - 스크립트가 쓰는 자리(전투·적 첫 줄 = 보스 아레나, 성능 첫 줄 = 부하 40)
- 헤드리스 길:
  - 문 앞: 오른쪽 하나 · 아래 하나(`shot.js`)
  - 보스 아레나: 오른쪽 둘(`shot.js`·`mouse.js`)
  - 부하: 오른쪽 둘 + 숫자 7(`leak.js`)
- 0075의 개발 판 규칙(기록 슬롯에 쓰지 않음)은 그대로다.
