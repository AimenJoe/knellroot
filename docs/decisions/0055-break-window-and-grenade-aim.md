# 0055. 자세가 깨진 동안 폭딜 창, 보스 자세 막대, 수류탄 겨누기

- 날짜: 2026-11-04
- 상태: 채택·구현(사장: "응 저 넷으로 가. 자세 막대 있어야 폭딜 하는 재미가 있을듯. 진행해.")

## 정한 것
1. **폭딜 창**:
   - 0051에서는 자세가 깨지면 휘청 + "다음 한 대 치명타"뿐이었다.
   - 이제 깨진 동안(`Enemy::broken`, 잡몹 1.5초·보스 1초) **모든 타격**이 × `poise.break damage x`(1.5, 올림)로 들어간다. 첫 대는 치명타 덤까지 받는다.
   - 근접·마법·볼트·수류탄·여진·내려찍기에 모두 적용한다(`world::hurt_by` 한 곳).
   - PoE2 Heavy Stun의 "깨면 무방비로 몰아치기"를 우리 휘청 길이에 맞춘 것이다.
2. **보스 자세 막대**:
   - 보스 체력 띠 바로 아래의 가는 줄로, 차오른 만큼 크림색이다. 깨지면 금빛으로 깜빡인다.
   - 그래야 "조금만 더 몰아치면 깬다"가 보인다.
   - 막대 비율은 월드가 매 틱 `Enemy::poise_frac`에 적는다. HUD는 랩 값을 모른다.
3. **수류탄 겨누기**(0051에서 남긴 것):
   - 쇠뇌 X를 손이 떠나기 전까지 쥐고 있으면, 손을 든 채 멈춰 겨눈다.
   - 떨굴 자리는 조준 스틱·이동 쪽(없으면 바라보는 쪽) 가장 먼 거리(`far`)이고, 거기에 폭발 반지름 고리를 그린다. 떼면 그리로 던진다.
   - 톡 누르면 0051처럼 가까운 자동 조준 자리에 던진다.
- 시험·얼린 값:
  - `filling_the_poise_bar_breaks_the_enemy`에 폭딜 배율 확인을 더했고, `holding_the_grenade_aims_far`를 새로 넣었다.
  - 얼린 값 `POISE_BREAK_DAMAGE` 한 줄을 덧붙였다.
