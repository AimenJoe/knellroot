# 0080. 연구소·DEV 창도 한국어로

- 날짜: 2026-11-07
- 상태: **채택·구현**(개발판)
- 사장: "그리고 다 영어네..?"

## 전
- 0013은 개발 화면을 영어로 두었다.
- 연구소(랩)의 줄 넷·묶음 열여섯·값 이름 143(`cam.quarter.pitch deg` 꼴)·알림, DEV 창의 줄·묶음·시나리오 이름·설명이 모두 영어였다.

## 결정
- 연구소·DEV 창의 글은 **설정 언어를 따른다**. 한국어면 한국어, 영어면 예전 글 그대로다.
- 글은 `src/i18n/dev.rs` 한 곳에 둔다:
  - 쌍 `Pair`(한국어, 영어) + `t()`
  - 랩 값 이름 표 `SPEC_KO`, 묶음 `GROUP_KO`, 시나리오 `SCENARIO_KO`
  - `src/i18n/` 안이라 글꼴 서브셋이 글자를 넣는다.
- 연구소 값 줄은 한국어 이름이다(예: "쿼터뷰 숙임(도)"). 아래 설명 줄에는 **원래 이름**(`cam.quarter.pitch deg`)을 함께 둔다. 내보낸 줄·`tuning.rs`·대화에서 값을 같은 이름으로 가리키게.
- DEV 창의 무기 줄은 무기 이름 표(`weapon_name`)를 쓴다(예전엔 `Sword`).
- **그대로 둔 것**: F3 개발 줄(아레나 이름·성능 수치)은 기본 글꼴이라 한글이 안 나온다. 영어 그대로다.
- 시험:
  - `every_lab_value_has_one_korean_name`: 값을 더하거나 이름을 바꾸면 표에도 한 줄. 묶음 수·시나리오도 본다.
  - 글꼴 시험이 개발 글까지 본다.
- 대가: 같은 글꼴을 운영판도 쓰니 서브셋이 613 → 726자, 굵기마다 약 177 → 234KB.
  - 운영판만 따로 줄이려면 개발 글자를 뺀 글꼴을 하나 더 만들어야 한다. 지금은 하지 않는다.
