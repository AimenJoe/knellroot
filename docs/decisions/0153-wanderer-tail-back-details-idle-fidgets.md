# 0153. 방랑자 — 꼬리를 등 가운데로, 뒷모습의 디테일, 서 있는 몸짓

- 날짜: 2026-11-12

- 사장 2026-11-12: "우리 플레이어블 캐릭터의 모델링 수정 필요해, 디테일 살려 주고 꼬리가 너무 한쪽으로 치우쳐져 있는 듯. 아이들 모션 같은 것도 넣어 주고.."
- 바탕: KB `guides/ai-mesh-to-rigid-part-model.md`·`concepts/believable-cute-character-motion.md`, 0036(귀여움 문법)·0038(Meshy 몸)·0039(2차 동작)·0061(게임 거리의 px 먼저).

## 왜 그렇게 보였나
- **꼬리**: Meshy 원본에서 꼬리가 왼쪽 엉덩이에서 **옆으로** 뻗는다(위에서 보면 뒤가 아니라 왼쪽 60° — `source-meshy.png`). 게임은 방랑자를 거의 늘 뒤·위에서 보니, 몸 왼쪽으로 삐져나온 덩어리로 보였다.
- **디테일**: 게임 눈에 가장 오래 보이는 것은 **뒷모습**인데 거기에는 무늬 없는 두건 뒤통수와 옷 등판뿐이었다. 얼굴·목도리·가슴의 종은 모두 앞에 있다. 거기에 텍스처 256·정점 1,900으로 줄여 꼬리 줄무늬와 눈이 뭉개져 있었다.
- **서 있기**: 1.2초 고리 하나(숨 한 번 = 꼬리 한 번) — 박자가 같아 기계처럼 보이고, 오래 서 있어도 아무 일도 없었다.

## 한 것
| 갈래 | 무엇 | 어디 |
|---|---|---|
| 줄이기 | 원본에서 다시: 정점 1,900 → 2,800, 텍스처 256 → 512(꼬리 줄무늬·눈·볼이 또렷) | `meshy_convert.py … 1.4 2800 512` → `sources/meshy/raccoon_v1_low.*` |
| 꼬리 | 부위로 자른 뒤 꼬리만 **등 가운데로 돌려 붙이고 50° 세웠다**(뒤에서 줄무늬가 세로로 보인다). 잘린 자리(몸의 구멍·꼬리 밑동)는 한 점으로 오므려 닫는다 | `wanderer.py` `recenter_tail`·`TAIL_AT`·`TAIL_LIFT` |
| 두건 꼬리 | 뒤통수에서 늘어진 두건 끝 + 크림 띠 + **금빛 종**(가슴의 종과 짝). 제 뼈(`hood_tip`)로 걸을 때·몸짓 때 따로 흔들린다 | 같은 파일 `hood_tip_geo` |
| 허리 주머니 | 왼쪽 엉덩이 뒤의 갈색 주머니(크림 덮개·금빛 단추) — 꼬리를 옮긴 자리를 덮는다 | `pouch_geo` |
| 숨 고리 | `idle` 1.2초 → **2.4초**: 숨 두 번, 그 사이 고개가 한쪽씩 갸웃, 꼬리는 숨보다 느리게 한 번 오간다(박자를 어긋나게) | `acts` |
| 몸짓 셋 | `idle_look`(둘러보기 2.6초) · `idle_shake`(털기 1.3초 — 움츠렸다 좌우로 털고 쭉 편다) · `idle_bell`(종 만지기 2.2초) | `acts` |
| 트는 규칙 | 서고 5초 뒤 첫 몸짓, 그 뒤 8~13초마다 **표 순서로 하나씩**. 숨 고리의 끝에서만 시작(몸짓은 숨 고리의 0초 자세에서 시작해 거기로 돌아온다 — 동작 사이 보간이 없어도 안 튄다). 움직이면 그 자리에서 끊긴다. **조용할 때만**: 락온이 아니고 14m 안에 깨어 있는 적이 없을 때 | `src/idle.rs`(순수 — 시험 넷), `render.rs`가 들고 있다(월드는 모른다) |

## 만들며 겪은 것
- **잘린 구멍을 면으로 메우면 안 됐다**: 줄인 메시의 잘린 가장자리는 들쭉날쭉해서 `holes_fill`이 접힌 조각을 만들고, 그 하나가 내보낸 법선과 감김이 어긋났다(`check_glb` "뒤집힌 삼각형"). 가장자리를 **한 점으로 오므리면**(`pointmerge`) 새 면이 없어 그런 일이 없다 — 색(UV)도 그대로다.
- **가져온 메시는 UV 이음매마다 정점이 갈라져 있다** → 열린 가장자리를 찾기 전에 정점을 합쳐야 한다(안 하면 이음매가 모두 "구멍"으로 잡힌다 — 몸에서 100개 넘게).
- **같은 색의 덧붙임은 게임 거리에서 안 읽힌다**: 두건 꼬리를 두건과 같은 라벤더로만 했더니 쿼터뷰(56px)에서 음영 차이뿐이었다 → 끝마디를 크림으로, 종을 크게.

## 확인한 것 / 못 한 것
- 확인: `check_glb`(뒤집힌 면 0·동작 길이·예산), `cargo test` 400(몸짓 규칙 넷 포함), clippy 다섯 갈래, 헤드리스 Chromium — 빈 아레나에서 몸짓이 도는 것·보스 아레나의 쿼터뷰와 락온 뒷모습, CI 연기 시험 넷.
- 못 한 것: 몸짓 하나하나를 게임 화면에서 틱마다 보지는 못했다(연속 숏으로 고개·꼬리가 바뀌는 것만 — 자세는 Blender 미리보기로 봤다). 장비 창 인형·도감에서의 모습은 자동 시험이 도는 것만 봤다. 폰·핸드헬드의 프레임(정점이 1.4배).

## 사장이 볼 것
- **두건 꼬리와 종은 새로 더한 생김새다**(원본 그림에 없다). 어울리지 않으면 `hood_tip_geo` 한 덩이를 빼면 된다 — 주머니도 같다.
- 꼬리의 세움(`TAIL_LIFT` 50°)과 크기(`TAIL_SIZE`), 몸짓의 잦기(`idle::FIRST`·`GAP`).
- 더 나아가려면: 두건 뒤·옷 등판 자체의 무늬는 텍스처에 그려야 한다(Meshy 원본을 다시 뽑거나 그림을 새로 — 뒷모습 그림을 같이 줘야 한다).
