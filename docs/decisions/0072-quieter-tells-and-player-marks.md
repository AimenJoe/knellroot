# 0072. 적 예고·패링·공격 표시를 옅게 — 채움 = 테두리 같은 투명도 0.3, 겹치지 않게

- 날짜: 2026-11-07
- 상태: **채택·구현**(개발판)
- 사장: "공격 예고도 색을 더 옅게 하자, 게임에 방해되지 않도록 패링도, 공격도 너무 진해."

## 읽은 것
- KB `concepts/melee-light-and-charged-attack-feel.md`의 예고 면 절(nail 0183~0188).
- nail 0192·0196(투명도 0.3 → 0.25).
- KB `guides/color-vision-check-for-games.md`: 투명도만 내리면 밝은 바닥에서 사라진다.

## 원인
예고가 진했던 이유는 투명도 값만이 아니었다.
- 이전 값: 바탕 0.16 위에 채움 0.42를 **겹쳐** 그렸고(합쳐 ≈ 0.51), 테두리는 0.7로 채움 위에 또 겹쳤다.
- nail 0186이 고친 실수가 그대로였다: 겹친 자리만 진해지고, 테두리가 늘 채움보다 진해서 "다 찬 순간"이 오지 않는다.

## 결정
- **적 예고**(`render::telegraph`):
  - 채움과 테두리는 같은 잉크 `TELE_A` 0.3.
  - 채움과 바탕은 테두리 띠(`TELE_RING_W` 0.12m) 안쪽까지만 깐다. 테두리와 겹치지 않아 다 찼을 때 한 덩어리가 된다.
  - 바탕 `TELE_BASE_A` 0.04. 못 받는 공격의 X는 1px 선이라 `TELE_MARK_A` 0.5.
  - 퍼지는 고리(Ring) 예고의 자라는 고리도 테두리 안쪽까지만 간다.
  - 색(붉은 하나)·모양·시점(0070 돌진은 몸에 닿을 때)은 그대로다.
- **퍼지는 뿌리 파동**(공격 자체): 0.75 / 0.3 → 0.45 / 0.18.
- **플레이어 표시:**

  | 표시 | 이전 | 지금 |
  |---|---|---|
  | 평타 범위 부채꼴 | 0.35 | 0.18 |
  | 강타 부채꼴(다 모음 / 덜 모음) | 0.45 / 0.35 | 0.25 / 0.18 |
  | 패링 창 반달 | 0.35 | 0.15 |
  | 패링 창 테두리 | 0.8 | 0.4 |
  | 패링 성공 고리 | 0.9 | 0.55 |

  - 모으기 고리(게이지)·내려찍기·등잔 고리는 그대로다. 짧거나 정보가 있는 게이지다.

  - 부채꼴·고리 모두 어두운 돌바닥에서 아직 잘 보인다.
  - 문지기 퍼지는 고리의 먼 쪽 테두리가 가장 옅다.
