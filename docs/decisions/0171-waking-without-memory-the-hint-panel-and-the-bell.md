## 답부터 — 좋습니다, 그리고 이미 정본입니다
"과거를 잃은 방랑자"는 정해진 설정이다. 지금 게임은 그것을 **말한 적이 없다** — 시작 글은 종소리와 뿌리만 말하고("땅 밑에서 종이 울린다. 아무도 치지 않는 종이."), 방랑자가 왜 아무것도 모르는지는 비어 있다. 기억 없이 깨어나는 시작은 새 설정이 아니라 **있는 설정을 처음으로 보여 주는 것**이다.

그리고 그것이 튜토리얼의 까닭이 된다:
- 왜 싸우는 법을 다시 배우나 → 잊었다. 그런데 **몸은 기억한다**.
- 왜 스킬이 하나도 없나(0166·0167) → 잊었다. 몸의 걸음 넷을 마치면 하나가 돌아온다(0169 — 알림이 이미 "몸이 기억해 냈다"다).
- 왜 화로에서 자라나 → 불 곁에서 잊은 것이 돌아온다(growth.md: 화로 곁에서 쉬고 몸에 익는다).
- 무엇을 잃었는지는 말하지 않는다 — 미스터리는 그대로다(방향 1: 천천히 공개).

## 제안
### 가. 첫 장면(새 판에서 한 번)
1. 검은 화면. 종이 한 번 운다.
2. 눈꺼풀이 열리듯 위아래에서 밝아진다. 방랑자가 **엎드려 있다가 일어난다**(새 동작 하나 — 꼴은 그대로).
3. 가운데 두 줄, 지금의 시작 글과 같은 말씨(속말·대사가 아니라 서술):
   - "눈을 뜬다. 이름도, 걸어온 길도 떠오르지 않는다."
   - "몸만이 무언가를 기억한다."
4. 이어서 지금의 시작 글 둘(종소리 · 뿌리)과 구역 이름. 그 뒤 튜토리얼의 첫 걸음.

### 나. 힌트가 눈에 띄게 + 몸의 말로
- **판 위에**(0165의 말씨): 어두운 판 + 위쪽 호박색 줄. 지금은 글이 바닥 위에 그냥 떠 있다.
- **걸음 점 일곱**(지난 것 민트 · 지금 호박 · 남은 것 빈 고리)이 "[2/7]"을 대신한다.
- **머리 줄을 크게**: 키캡 + 할 일 + 세는 수("0 / 3"는 호박색으로 따로).
- **풀이 줄은 몸의 기억으로**: 기능을 설명하는 글("가까이 가서 적을 벤다") 대신 —

| 걸음 | 머리 줄 | 풀이(몸의 기억) |
|---|---|---|
| 걷기 | 걸어 본다 | 다리가 먼저 길을 안다 |
| 공격 | [버튼] 공격 0 / 3 | 손이 검의 무게를 기억한다 |
| 회피 | [버튼] 회피 | 몸이 먼저 비킨다 — 누르고 있으면 달린다 |
| 패링 | [버튼] 패링 | 닿는 순간을 팔이 안다 |
| (상) | 몸이 기억해 냈다 — 기술 점수 +1 | (지금 그대로) |
| 배우기 | 쉼터의 화로에서 쉰다 | 불 곁에서 잊은 것이 돌아온다 — 기술 탭 |
| 쓰기 | [버튼] 되찾은 기술을 쓴다 | 쓰고 나면 숨을 고른다 — 차면 다시 |
| 한 단 | 쉼터의 화로에서 쉰다 | 잔불이 몸에 스민다 — 상태 탭 |

  무기가 다섯이라 "검"을 박지 않는다(growth.md) — "손이 쥔 것의 무게를 기억한다"로 하거나 든 무기의 이름을 넣는다.
- 걸음이 넘어갈 때 짧은 소리 하나(지금은 빛만 바뀐다).

### 다. 하지 않는 것
- 말하는 안내자는 세우지 않는다(이 판에서는) — 방랑자는 혼자 깨어난다. 첫 주민은 둘째 지역에서 만난다(0115).
- 무엇을·왜 잊었는지, 누가 깨웠는지는 쓰지 않는다.
- 싸움을 멈추는 대화창은 없다(0167 그대로).

## 정할 것
1. **이 방향으로 갈까** — 기억 없이 깨어나는 첫 장면 + 몸의 기억으로 말하는 힌트.
2. **글의 말씨**: 서술("눈을 뜬다. …" — 제안) / 방랑자의 속말("…여기가 어디지") / 글 없이 장면만.
3. **깨어나는 자리**: 지금의 시작 자리(쉼터에서 9m) / 꺼진 화로 곁에서 깨어나고 **처음 쉴 때 불이 붙는다**(첫 쉼이 사건이 된다 — 화로 하나의 그림·상태가 더 든다).
4. **일어나는 동작**을 새로 만들까(Blender 동작 하나 — 생김새는 건드리지 않는다, 0157) / 화면이 밝아지는 것만으로.
5. 힌트의 판·점·큰 글(나)은 이야기와 따로 먼저 넣을 수 있다 — 먼저 넣을까.
6. (0170에서 넘어온 것) 문을 찾는 동안의 길 안내로 **종소리가 들리는 쪽**을 둘까.

## 만든 것
### 가. 깨어나는 첫 장면(새 기록에서 한 번)
시간표(`src/wake.rs` — 순수 규칙, 60Hz 틱):

| 초 | 화면 | 소리·몸 |
|---|---|---|
| 0 | 검은 화면 | |
| 0.8 | | 큰 종 한 번(`sfx::Id::Knell`) |
| 2.6 ~ 5.2 | 눈꺼풀이 조금 열렸다 도로 감기고(한 번 떨린다) 천천히 다 열린다 — 덜 뜬 동안은 화면도 어둡다 | 방랑자는 엎드린 채(동작의 0초) |
| 3.7 | 첫 줄 "눈을 뜬다. …" | |
| 5.6 ~ 9.6 | 카메라가 가까이(거리의 0.42)에서 제 거리로 물러난다 | `wake` 동작: 숨 → 고개 → 두 팔로 밀고 → 웅크려 앉았다 → 일어서며 휘청 |
| 7.0 | 둘째 줄 "몸만이 무언가를 기억한다." | |
| 9.6 ~ 10.3 | 글이 걷힌다 | |
| 9.9 ~ 10.6 | 위아래 띠(화면의 8.5%)가 걷힌다 | |
| 10.6 | 끝 — 기록에 `woke=1`, 그제야 시작 글 둘·구역 이름, 그 뒤 튜토리얼 | 조작이 돌아온다 |

- **타이틀 바탕부터**: 새 기록이면 타이틀 뒤의 방랑자가 꺼진 화로 곁에 엎드려 있다(장면의 0초 자세 — 따로 만든 그림이 아니다).
- **글은 아래 3분의 1에**(시안은 가운데였다 — 가운데는 방랑자의 몸이다. 일어나는 몸짓을 글이 가린다).
- **몸은 화면에 옆으로**: 처음에는 시작 방향(화면 위쪽)으로 눕혔더니 뒤통수의 두건이 몸짓을 다 가렸다 — 머리를 화로 쪽 옆으로 돌려 눕힌다(`lay_by_hearth`).
- **건너뛰기**: 멈춤 버튼(Esc·Start — 오른쪽 아래에 키캡 + "건너뛰기"). 건너뛰면 눈을 한 번 깜빡이고(누운 몸 → 선 몸의 튐을 가린다) 끝의 띠 걷힘만 남는다. 터치는 화면 버튼을 걷어 두었으니 싸움 버튼 자리 어디든(안내 글이 선 오른쪽 아래 = 공격 버튼 자리).
- 장면 도중에 끄면 다음에 다시 처음부터(끝나야 `woke=1`). 개발 창의 판·이어하는 판에는 없다.
- **월드는 이 장면을 모른다**: 입력 없이 그냥 흐른다(방랑자는 월드에서는 서 있다). 렌더가 장면의 시각으로 `wake` 동작을 틀 뿐이다(`View::wake`). 그동안 스테이지 대본(시작 글·구역 카드·곁의 할 일)·튜토리얼·종소리의 시계는 멈춘다.
- 말하는 안내자·대화창은 없다(제안의 "다" 그대로) — 누르는 것은 건너뛰기뿐이다.

### 나. 꺼진 화로
- 시작 자리: 입구 폐허의 화로에서 **2.8m**(예전 8.9m) — 쉬는 거리(2.4m) 바로 밖이라 일어나자마자 "쉬기"가 뜨지는 않는다. 깨어 있을 적이 10m 안에 서지 않는다(시험).
- 새 기록의 그 화로는 **불꽃도 빛도 없이** 굽는다(`Level::cold` — 빛을 빼고, 모델의 `glow_` 부위를 굽지 않는다). 불티도 없다(빛 목록에서 나온다).
- **거기서 처음 쉬면 불이 붙는다**: 번쩍임 + 솟는 불티(`Fx::kindle`) + 쉬는 소리, 지형을 다시 구워 따뜻한 빛 웅덩이가 생긴다. 그 순간을 1.5초 본 뒤에 화로의 창이 열린다(창이 화면을 다 덮는다 — 바로 열면 못 본다). 기록 `hearth.lit=1`.
- 다른 화로에서 먼저 쉬어도 그 화로는 꺼진 채다 — 불은 거기서 쉴 때 붙는다.
- 옛 기록(이 키들이 없는 것)은 이미 깨어나 걷던 방랑자다: 장면도 꺼진 화로도 없다.

### 다. 힌트 판
- 어두운 판(`hud::draw_hint`) + 위쪽 호박색 줄, 화면 아래 가운데. 폭은 글에 맞추되 화면의 반을 넘지 않는다(터치의 엄지 자리 사이).
- **걸음 점 일곱**: 지난 것 민트 · 지금 호박(크게) · 남은 것 빈 고리. "[2/7]"은 없다.
- **머리 줄 1.2배**: 키캡 + 할 일, 세는 수("0 / 3")는 글 밖에 호박색으로 따로(`Hint::count`). 넘치면 줄을 바꾸지 않고 글을 줄인다(키캡과 할 일이 갈라지면 안 읽힌다).
- **풀이 줄 = 몸의 기억**(아래 표). 넘치면 줄을 바꾸고 판이 위로 자란다.
- 곁의 할 일 글("F 쉬기")은 판 위로 비킨다. 가장자리 화살(갈 곳·적)과 종소리의 물결도 판에 걸리면 판 위로(처음 찍은 화면에서 적 쪽 화살이 세는 수를 가렸다).
- 보스 띠가 같은 자리를 쓰는 동안은 그리지 않는다.
- **걸음이 넘어갈 때 소리 하나**(`sfx::Id::Recall` — 낮고 부드러운 두 음 E5 → A5. 박자의 '팅'·사는 소리와 다르게). 상이 오는 틱은 상의 소리가 대신한다.

| 걸음 | 머리 줄 | 풀이(한국어) | 풀이(영어) |
|---|---|---|---|
| 걷기 | 걸어 본다 | 다리가 먼저 길을 안다 | The legs know the way first |
| 공격 | [버튼] 공격 0 / 3 | 손이 쥔 것의 무게를 기억한다 | The hand remembers the weight it holds |
| 회피 | [버튼] 회피 | 몸이 먼저 비킨다 — 누르고 있으면 달린다 | The body moves first — hold to run |
| 패링 | [버튼] 패링 | 닿는 순간을 팔이 안다 | The arm knows the moment a blow lands |
| (상) | 몸이 기억해 냈다 — 기술 점수 +1 | | The body remembers — +1 skill point |
| 배우기 | 쉼터의 화로에서 쉰다 | 불 곁에서 잊은 것이 돌아온다 — 기술 탭 | By the fire, the forgotten returns — Skills tab |
| 쓰기 | [버튼] 되찾은 기술을 쓴다 | 쓰고 나면 숨을 고른다 — 차면 다시 | Then a breath — and it is ready again |
| 한 단 | 쉼터의 화로에서 쉰다 | 잔불이 몸에 스민다 — 상태 탭 | Embers sink into the body — Status tab |

- 무기가 다섯이라 "검"을 박지 않았다("손이 쥔 것").
- 영어는 시작 글의 말씨에 맞춰 "you"를 쓰지 않는다(The legs · The hand · The body) — 상의 알림도 "Your body" → "The body".
- **잃은 것**: 풀이 줄이 기능을 설명하지 않는다("가까이 가서 적을 벤다"·"기술 점수 +1"이 없다). 어디로 갈지는 화살·빛기둥(0170)이, 화로에서 무엇을 할지는 탭의 이름("기술 탭"·"상태 탭")과 창이 말한다 — 모자란지는 판정에서(27-6).

### 라. 종소리의 길 안내
- **언제**(`src/knell.rs` — 순수 규칙): 닫힌 문의 장치를 찾는 동안(`StageRun::bell_from`) · 다른 길 안내(갈 곳의 빛기둥·튜토리얼의 쉼터)가 없고 · 장치가 9m보다 멀 때. 찾기 시작하고 12초 뒤에 처음, 그 뒤 17초마다(환경음의 먼 종 12초 고리와 맞물리지 않게).
- **싸우는 동안은 울리지 않고 시계도 멈춘다**(깨어 있는 적이 10m 안).
- **무엇이**: 큰 종 한 번(`sfx::Id::Knell` — 으뜸 D3에 종의 겹 다섯, 3.6초) + 소리가 온 쪽의 화면 가장자리에서 안쪽으로 번지는 호 셋(3.2초, `hud::draw_knell`). 장치가 화면 안이면 그 자리에서 퍼지는 고리 둘.
- **화살이 아니다**: 늘 떠 있지 않고, 가리키지 않고 번진다. 빛은 종의 쇠(창백한 푸른 흰빛) — 갈 곳의 호박색(0060)·적 쪽의 잿빛(0170)과 갈린다.
- 소리는 좌우로 나뉘지 않는다(macroquad의 소리는 모노로 낸다) — 방향은 그림이 말한다.
- 문이 열리면 갈 곳의 빛기둥이 맡는다(전부터). 둘째 지역에도 장치가 있으면 같은 규칙이 돈다.
