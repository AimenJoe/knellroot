# 0213 — 쇠뇌는 RB로 쏜다 · 사격 자동 조준 없앰 · 튜토리얼의 잔불·등잔

- 날짜: 2026-11-15
- 상태: **결정 + 구현**(개발판, 판정 전 — 체크리스트 66번)
- 사장: "튜토리얼에서, 잔불 모으는게 너무 일찍 나오고 물약 먹는 안내가 없음. … 그리고 아무래도 쇠뇌는 rb로 발사하는게 맞겠어. 자동 조준 없애고."
- 바탕: 0048·0051(RB 마법·쇠뇌 사격 자리), 0151(쇠뇌 X 사격 · RB 수류탄으로 맞바꿈), 0014(공격 자동 조준), 0210(쇠뇌 다시 맞추기), 0211(튜토리얼 고치기).

## 1. 쇠뇌의 버튼 — 0151의 맞바꿈을 걷는다
- 0151은 "어느 무기든 X = 평타"로 맞추려고 쇠뇌만 X = 사격 · RB = 수류탄으로 바꿨다(`world::weapon_buttons`). 이제 맞바꿈이 없다: **RB = 사격**(꾹 = 모은 사격 · 공중 = 내려 쏘기 · 박자), **X = 수류탄**. 월드 안쪽 이름(`attack` = 수류탄, `cast` = 사격)은 처음부터 그 자리였다 — 버튼과 안쪽 이름이 다시 같아졌다.
- 왜: 사격은 마법(지팡이·검·맨손의 RB)과 같은 "쏘는 일"이라 손이 같은 버튼을 찾는다 — 무기를 바꿔도 "쏘기 = RB"가 남는다.
- 터치: 큰 공격 버튼의 그림 = 수류탄, RB 버튼의 그림 = 쇠뇌(`touch::attack_icon`·`cast_icon`). 상황 힌트 "쥐었다 뗀다"는 쇠뇌를 들었으면 RB 키캡.
- 마우스 기본 배치(왼쪽 클릭 = X, 오른쪽 클릭 = RB)에서는 쇠뇌 사격이 오른쪽 클릭이 된다 — 조작 설정에서 바꿀 수 있다.

## 2. 사격은 가까운 적을 찾지 않는다
- 이전(0048): 사격 방향 = 조준 스틱(커서) > 락온 대상 > `cast.range m` 안의 가장 가까운 적 > 바라보는 쪽.
- 이제 쇠뇌는 **조준 스틱(커서) > 락온 대상 > 바라보는 쪽** — 가까운 적 찾기를 뺐다. 겨누는 것이 손의 일이다(사장 "자동 조준 없애고").
- 마법(RB)은 그대로 찾는다 — 사장이 말한 것은 쇠뇌. 근접 공격의 휘두르는 순간 자동 조준(0014, 3 m)도 그대로.
- 공중 사격(0111)은 쏘는 쪽 ±15° 안의 적까지 거리로 내려 쏘는 각을 정한다 — 쪽을 바꾸지 않으니 남긴다.
- 시험: `the_crossbow_fires_on_rb_where_it_faces_without_auto_aim`(옆의 적을 두고 쇠뇌는 앞으로, 지팡이는 그 적으로 · X = 수류탄). 쇠뇌 시험들은 `cast`로 쏜다, 무기 시간당 피해 탐침은 `primary`(무기의 첫 공격 버튼)로.

## 3. 튜토리얼
| 사장의 말 | 왜 그랬나 | 고친 것 |
|---|---|---|
| 잔불 모으는 게 너무 일찍 나온다 | 0211 T4가 "한 단 올리기" 걸음을 숨기지 않게 했다 → 스킬을 쓰자마자 "잔불을 모은다 0 / 50"이 판에 오래 떠 있었다 | 값의 **반**(`tutorial::GATHER_FROM` 0.5)이 모이면 뜬다 — 곧 닿을 목표로. 그 전에는 조용하다 |
| 물약(등잔) 안내가 없다 | 등잔 힌트(0211 T2)는 몸의 걸음(걷기~패링)이 끝날 때까지 기다렸다 — 그런데 처음 크게 맞는 때가 바로 패링 걸음이다. 그때 지나가면 기록에 "봤다"가 남지 않았어도 다시 반 아래로 갈 일이 드물었다 | 등잔만은 **몸의 걸음 동안에도** 뜬다(살아남는 일이 먼저 — 걸음 판 대신 몇 초). 그리고 **마셔 볼 때까지** 체력이 반 아래로 내려갈 때마다 다시 뜬다(반 위로 돌아오면 다시 걸림). 기록의 비트(`tut.tips`)는 보여 줄 때가 아니라 **마실 때** 선다 |

- 다른 상황 힌트(락온·쥐었다 떼기)는 그대로 — 몸의 걸음을 기다리고, 한 번 보면 끝.
- 시험: `situational_tips_come_once_when_their_moment_comes`(등잔은 몸의 걸음 동안에도 · 마시면 끝 · 다른 것은 기다림), `a_hint_shows_only_when_its_deed_can_be_done`(반 아래는 조용, 반부터 "n / 값"). 헤드리스 `tutorial.js`의 `7q`는 잔불 30 / 50.

## 바꾸지 않은 것
- 걸음 일곱·상·레벨 값(0169·0109·0123). 쇠뇌의 수치(0210).
