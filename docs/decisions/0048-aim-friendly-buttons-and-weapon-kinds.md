# 0048. 조준과 같이 쓰는 버튼 배치, 무기 갈래

- 날짜: 2026-11-04
- 상태: 채택(사장 2026-11-04: 배치 "안 A", 원거리 한도 "근접 명중으로 충전", 수류탄은 아래 "정한 것" 2) — **1단계 구현**(배치·RB 마법), 무기 표는 다음.
- 계기(사장 플레이 피드백, v0.1.2):
  - X 공격은 오른쪽 스틱으로 겨누면서 누를 수 없다.
  - 등잔은 다른 버튼으로 옮기고, RB는 마법 같은 원거리로 쓴다(오른쪽 스틱과 같이).
  - 상호작용은 다른 동작과 버튼을 같이 쓴다.
  - 공격은 무기마다 달라야 한다: 여러 콤보, 느리고 센 한 방, 원거리, 수류탄(수류탄이 X) — "ARPG의 재미".
- 근거:
  - KB `concepts/controller-layout-and-remapping.md`(조준과 같이 누를 버튼은 어깨에, 상호작용 겹치기), `concepts/action-reuse-gating.md`(근접 명중으로 차는 칸), `concepts/melee-light-and-charged-attack-feel.md`, `docs/design/items.md` 4절.
  - 다른 게임 사례는 모두 2차 출처: Hyper Light Drifter, Death's Door, Minecraft Dungeons, Enter the Gungeon, Tunic, Diablo IV, Dead Cells·Hades 개발자 인터뷰 기사.

## 왜 엄지가 문제인가
얼굴 버튼(X·A·B·Y)과 오른쪽 스틱은 같은 오른손 엄지다. 그래서 "겨누면서 누르기"는 얼굴 버튼으로는 안 되고 어깨(RB·RT)로만 된다. 장르 관례도 트리거로 쏜다(HLD LT 조준 + RT 사격, Minecraft Dungeons RT 원거리 — 2차). 얼굴 버튼의 동작은 자동 조준(0014)이나 이동 방향으로 겨눈다.

## 배치안
| 동작 | 지금(0024·0030·0031) | 안 A(바꿈 최소, 추천) | 안 B(트리거 관례) |
|---|---|---|---|
| 근접(무기 주 공격, 꾹 = 강타) | X | X(자동 조준·이동 방향) | X |
| 원거리·마법(오른쪽 스틱 조준, 안 쥐면 자동 조준) | — | **RB**(톡 = 바로 쏨, 꾹 = 조준선 → 떼면) | **RT** |
| 수류탄(포물선, 자동 조준 자리에 떨어짐) | — | 무기 칸으로(아래) 또는 Y | Y |
| 등잔 | RB | **Y** | D패드 ↓ 또는 Y |
| 점프 + 상호작용 | A / Y | **A**: 쉼터·물건 곁이고 깨어 있는 적이 가까이 없으면 상호작용, 아니면 점프. 화면에 "A 쉬기" | 같음 |
| 회피 / 패링 / 락온 | B / LB / R3 | 그대로 | B / **LT** / R3 |
| 땅 돌리기 | LT / RT | 그대로 | **LB / RB** |

- **안 A**의 장단점:
  - 장점: 익힌 손이 거의 그대로다.
  - 걱정: 자주 누를 RB가 땅 돌리기 RT 바로 위다. 대책은 RT 문턱을 높이고, RB 직후 짧게 RT를 무시하는 것이다.
- **안 B**의 장단점:
  - 장점: "꾹 눌러 겨누고 쏘기"가 트리거라 자연스럽다.
  - 단점: 패링이 트리거로 가면 누르는 거리만큼 늦다(타이밍 패링에 불리). 배치를 다시 익혀야 한다.
- **상호작용을 공격·회피와 겹치지 않는 이유**: 싸움 중에 연타하는 버튼과 겹치면 문·상자를 못 연다(Diablo IV의 불만 — 2차). 점프는 연타하지 않는다.

## 무기 갈래(처음 넷 — 빠름·보통·무거움·원거리를 한 칸씩)
같은 표(`weapons.rs`, 0026 계획)의 칸만 다르게 채운다. 콤보는 데이터다.

| 갈래 | X 연타 | X 꾹(강타) | 성격(언제 회피로 끊나) |
|---|---|---|---|
| 검(지금) | 3연타 보통 | 넓게 가로 베기 | 활성 뒤 |
| 대검·망치 | 1~2타, 느리고 셈 | 원형 내려치기 + 보스 휘청, 모으며 걷기 ×0.3 | 후딜 뒤에만 |
| 쌍단검 | 4~5연타 빠름 | 찌르며 돌진, 드러난 적에 치명타 +1 | 언제나 |
| 폭탄 주머니(수류탄) | **포물선 투척**, 도화선 0.6~0.8초, 반지름 약 2m, 자동 조준한 적 자리 | 멀리·여럿 | 던지는 동작 시간 |

- 표의 칸은 다섯 묶음이다.
  - `hits[]`(선딜·활성·후딜·피해·모양·거리·각·내딛기·넉백·휘청·스태미나·회피 캔슬 시점)
  - `combo_window`
  - `heavy`(모으는 시간·`walk_mul`·모양)
  - `air`(내려찍기 / 공중 투척)
  - `projectile`(빠르기·중력·도화선·반지름·관통)
- "수류탄이 X"는 **폭탄 주머니를 들면 X가 던지기**로 읽었다. 근접 대신 폭탄을 드는 무기 하나라는 뜻이다. 따로 버튼을 원하면 안 A의 Y와 등잔이 겹치므로 등잔을 D패드로 옮겨야 한다.
- **RB 원거리·마법의 한도**: 칸 3~4개.
  - **근접으로 맞히면 칸이 찬다**(HLD·Death's Door, 2차). 원거리만 쏘며 버티는 플레이를 막고 근접을 중심에 둔다.
  - 쉼터에서 가득 찬다.
  - 스태미나는 쓰지 않는다(회피와 같은 통을 다투지 않게).
- 창(items.md)은 다섯째 후보로 미룬다.

## 정한 것(사장 답)
1. 배치는 **안 A**: 근접 X, 원거리·마법 RB(오른쪽 스틱 조준), 등잔 Y, A = 점프 + 상호작용, 나머지 그대로.
2. **주 공격이 X냐 RB냐가 무기에 따라 갈린다**(사장: "근접 무기는 원거리 공격이 마법류일 것이고, 원거리 무기는 주요 공격이 RB일 테니, 마법 계열의 공격은 근접 무기를 착용했을 때의 X가 대치되는 형식"):
   - 근접 무기: **X = 근접 콤보(주)**, **RB = 마법(보조)**.
   - 원거리 무기: **RB = 조준 사격(주)**, **X = 수류탄(보조)** — 근접 무기의 마법 자리를 수류탄이 맞바꾼다.
   - 그래서 무기 표 한 줄 = (X 동작, RB 동작) 짝. 위 "폭탄 주머니"는 원거리 무기의 X 쪽으로 옮긴다.
3. 원거리·마법 한도는 **근접 명중으로 충전**(칸 3, 한 대 0.25칸, 쉼터에서 가득). 원거리 무기의 주 공격(RB 사격)은 무기 표에서 따로 정한다(탄창·재장전 등 — 같은 "근접으로 찬다"를 쓰면 원거리 무기는 칸이 차지 않으니).

## 1단계 구현(2026-11-04)
- 입력: `Bind::Interact` 칸(8)을 `Bind::Cast`(RB·U)로, 등잔은 Y·R. 저장 칸 뜻이 바뀌어 `prefs` MAGIC 0x…0002(옛 저장은 언어만 살리고 배치는 기본값). 조작 설정 줄: "점프 / 상호작용"·"마법".
- 상호작용: 스테이지가 매 틱 `World::interact_here`(쉼터 곁 + 깨어 있는 적이 가까이 없음)를 적고, 그 자리에서 점프 버튼 = 쉬기(뛰지 않음). 적이 가까우면 그대로 점프하고 "적이 가까워 쉴 수 없다"를 띄운다. 터치는 쉼터 곁에 뜨는 모닥불 버튼 그대로.
- 마법: `PState::Cast`(0.12초에 탄, 0.4초에 끝, 쏘는 동안 걷기 ×0.5, 몸은 쏘는 쪽 고정, 나간 뒤 회피로 끊음, 평타 후딜도 끊고 바로 쏜다). 쏘는 쪽 = 조준 스틱 > 락온 > 12m 안 가장 가까운 적 > 바라보는 쪽. 탄 `World::bolts`: 16m/s·12m·피해 1(드러난 적 치명타)·처음 닿는 깨어 있는 적 하나·기둥·높은 땅에서 사라짐. 칸 3(`Player::mana`), 근접 한 대 `cast.per hit` 0.25, 쉼터 가득. 못 쏘면 HUD 칸 깜빡 + `Event::CastDenied`. 랩 `cast.*` 일곱(얼린 값에 덧붙임).
- 잘못 누름 막기: 마법을 누른 뒤 0.25초는 땅 돌리기 누름을 버린다(`CAST_TURN_GUARD` — RB 밑이 RT).
- 그림: 라벤더 빛 덩이 + 꼬리, 쏘는 자세는 패링 자세를 빌림(전용 동작은 나중). HUD 등잔 오른쪽 둥근 칸 셋. 터치는 별 버튼(아래 줄 점프 왼쪽).
- 시험: `a_cast_spends_a_charge_and_the_bolt_hits`, `melee_hits_refill_the_magic_and_an_empty_cast_is_denied`, `a_bolt_stops_at_a_pillar`, `the_jump_button_interacts_where_the_stage_allows`, prefs 옛 표식.

## 처음 제안 때 정해야 했던 것
1. 배치: 안 A / 안 B / 다른 것.
2. "수류탄이 X"의 뜻: 폭탄을 드는 무기(X가 던지기) / 따로 버튼.
3. 원거리 한도: 근접 명중으로 충전 / 시간 대기 / 다른 것.
4. 순서 제안: 배치·RB 원거리 하나 → 무기 표(검을 표로 옮기기) → 대검 → 쌍단검 → 폭탄. 무기 모델은 Blender 스크립트로 `hand_r`에 붙인다.
