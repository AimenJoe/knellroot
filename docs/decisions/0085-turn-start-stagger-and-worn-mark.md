# 0085. 땅 돌리기 시작 휘청은 CC도 · "착용 중"은 낀 물건에만

- 날짜: 2026-11-07
- 상태: **채택·구현**(개발판)
- 사장: "기본적으로.. 빈칸이 '착용중'일순 없겠지, 착용중인 장비가 없으면 커서만 거기두고 착용중이 표시되진 않으면 됨. 화면돌리기의 '휘청'은 cc 포함이야."

## 1. "착용 중"
- 0077에서 모든 칸이 "지금 것"에 "착용 중"을 붙였다. 빈 칸(장신구)·맨손(무기)도 그랬다.
- 이제 표시는 **낀 물건에만** 붙는다(`equip::wears_something`). 빈 칸·맨손이면 커서만 거기서 시작하고 표시는 없다.

## 2. 땅 돌리기 시작 휘청 = CC
- 0084의 시작·끝 휘청은 카메라 굴림만이었다. 사장 뜻은 **적에게도** 휘청(CC)이다.
- **시작**: 돌기 시작하는 순간 `spill.range m` 안의 적이 `turn.start stagger s`(기본 0.25초, 새 랩 값) 휘청인다.
  - 예고가 끊기고, 몸은 도는 쪽(둘레 방향)으로 젖힌다. 보스는 `spill.boss mass`로 나눈다(0.25 / 무게).
  - 짧은 휘청 하나다. 0029가 없앤 "도는 동안 붙잡기"(1초 가까이 묶는 CC)로 돌아가지 않는다 — 휘청이 풀리면 도는 동안 다시 쫓아온다.
- **끝**: 그대로다 — 멈추는 순간 쏟기(밀림) + `spill.stagger s` 휘청 + 히트스톱 + "탁" + 카메라 반대쪽 휘청.
- 카메라 굴림(0084)은 그대로 둔다(화면의 휘청 + 적의 휘청이 같은 순간).
- 얼린 표에 한 줄을 더했다(0013, 새 값).
- 시험:
  - `turning_staggers_enemies_in_range_briefly_when_it_starts`: 범위 안 = 휘청·예고 끊김, 밖 = 그대로, 보스는 짧게, 쏟기 전에 풀림.
  - 쏟기 시험 둘은 "멈춘 적" 전제를 지키도록 누른 뒤 다시 세운다. 시작 휘청이 세워 둔 적을 깨워 쫓아오게 했다.

## 손맛 판정(사람)
- 0.25초가 "작은" 휘청인지. 시작 CC가 땅 돌리기를 탈출기로 너무 세게 만들지 않는지(대기 4초).
