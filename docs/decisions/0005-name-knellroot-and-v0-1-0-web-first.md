## 이름
- **Knellroot** — knell(죽음을 알리는 종) + root(뿌리). 발음 **넬루트**(/nɛl.ruːt/, k 묵음, 앞 강세). 글만 보면 "크넬루트"로 읽기 쉬우니 상점·로고 곁에 발음을 적는다.
- 왜 "blight"가 아닌가: Steam 상점 검색(2026-11-03)에 "blight" 10개(Blight: Survival 위시리스트 150만, Rogue Blight, Blightstone …). 흔한 영어 단어라 검색·상표 둘 다 약하다.
- 확인한 것(2026-11-03): Steam 상점 검색 API 0건, itch.io 검색 0건(Knellmoor만), 웹 검색 0건. **확인 안 한 것**: 상표(KIPRIS·USPTO·EUIPO), 도메인·SNS 핸들, Google Play 패키지·App Store — 0.1.0 전에 사장이 상표를 보고, 패키지 아이디는 `io.github.aimenjoe.knellroot`로 미리 잡는다.
- 코드 이름 = 게임 이름 = 레포 이름 `knellroot`. 0004의 D1은 닫는다. 세계 안의 종(鐘)에 "맥놀이(Maengnol)"를 쓸지는 D2와 함께.
