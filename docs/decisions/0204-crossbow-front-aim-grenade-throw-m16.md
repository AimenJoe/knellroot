# 0204 — 쇠뇌 = 정면에서 두 손으로 겨누기(날개 가로) · 수류탄 = M16 휘둘러 던지기

- 날짜: 2026-11-15
- 상태: 채택(개발판, 판정 전)
- 사장: "쇠뇌도 너무 옆으로 돌아서고.. 쇠뇌를 세로로 드는 문제가 있어. 수류탄 투척도 모션 줬는데 안 쓴 거야?"

## 까닭
- **옆으로 돌아섬**: 쇠뇌 겨누기·쏘기 원본이 활쏘기(Archery_Shot)다. 활은 몸을 옆으로 세우고 왼팔을 뻗는다 — 0196이 활 줄(오른손 → 왼손)을
  정면에 맞추느라 몸 전체를 옆으로 돌렸다.
- **세로로 듦**: 같은 0196이 쇠뇌의 둘째 축(쉬는 자세에서 날개 쪽)을 하늘로 세웠다 — 날개가 세로로 섰다.
- **수류탄**: 받은 던지기(셋째 묶음 M07)를 쓰고 있었다. 그런데 재 보니 오른손이 동작 내내 0.15~0.29 m 높이에서 거의 안 움직인다
  (가장 빠를 때 2.5 m/s 밑) — 던지기가 만들어지지 않은 원본이라 안 쓴 것처럼 보였다. 둘째 묶음의 이름 없는 동작(`_01a1db4a…`)도 서 있기뿐이다.

## 바꾼 것
| 동작 | 옛 | 새 |
|---|---|---|
| `xbow_charge` | Archery_Shot 45~60(시위 당기기, 몸 옆) | 시전 mage_soell_cast_8 20 → 28: 두 손을 어깨 높이로 앞에 내민 채 |
| `xbow_shoot` | Archery_Shot 86~100 | 같은 원본 28 → 26(놓음) → 8(반동으로 가슴께까지 당김) → 22(다시 내밂) |
| 쇠뇌 방향 | 오른손 → 왼손 줄, 날개 = 하늘 | 몸 앞(`XBOW_FWD`), 날개 = 가로(쉬는 자세의 쇠뇌 그대로) |
| `throw` | M07(손이 거의 안 움직임) | M16 8 → 15(머리 위로 든다) → 24(놓음, `throw.startup` 0.2초) → 34, 놓는 순간 몸 정면(원본은 몸 왼쪽으로 돌며 던진다) |

- 시험 `wanderer_clips_start_and_end_facing_front_and_do_not_spin`: 옛 "쇠뇌는 옆으로 서서 겨눈다"를 "쏘는 동안 몸이 정면(±25°)"으로 바꿈.
  `the_crossbow_points_where_the_bolt_goes`(쇠뇌 끝이 앞)는 그대로 통과.
- M16은 기술 "던지기"(`sk_throw`)도 쓴다 — 수류탄과 던지는 꼴이 닮았다(둘 다 던지기라 그대로 둔다).
