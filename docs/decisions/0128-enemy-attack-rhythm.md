# 0128. 적 공격의 엇박 — 지연·빠른 변형·연속 공격·페인트, 바닥 예고의 "언제"는 설정으로

- 날짜: 2026-11-09
- 상태: **채택·구현**(`release/v0.5`). 사장 2026-11-09: "다른 소울라이크랑은 다르게 정박/엇박이 별로 없는 것 같은데… 너무 정박에 때리면 난이도가 확 내려감." 인터뷰 넷:
  - 수단: 지연·연속·빠른 변형·페인트 **넷 다**. 덧붙여 "2페이즈 혹은 3페이즈의 보스도 나중에 추가되어야겠다" → 아래 "다음 일".
  - 바닥 예고: **타이밍을 켤 때만 지금의 채움**, 끄면 공격 지점의 색 농도가 짙어지고 정해진 농도에서 맞는다.
  - 범위: 보스·엘리트 많이, 잡몹 조금.
  - 지연 신호: 몸 + 소리.

## 왜 정박이었나(코드에서 찾은 까닭)
1. **종마다 예고 길이가 하나**(`Def::tele` — 잔재 0.55·가시짐승 0.5·문지기 0.9·종지기 0.9초). 같은 적은 늘 같은 간격으로 쳤다.
2. **바닥 예고가 정확한 타이머였다**(nail 0186~0188 꼴: 채움이 테두리에 닿는 틱 = 맞는 틱). 몸을 안 보고 바닥만 봐도 박자를 알았다. 0073 "모션이 주, 예고는 보조"와 어긋났다.
3. **모든 공격이 한 방**(되풀이 엘리트의 한 번 더 빼고) → "예고 … 맞음 … 쉼"이 한 박자.
4. 준비 동작도 같은 비율(들어 올림 60% → 버팀 → 내리침)이라 그림의 박자도 같았다.

## 스터디(KB에는 적 박자 노트가 없었다 — 플레이어 박자만)
- 2차(설계 글·포럼, 개발사 1차 출처 없음):
  - 지연 공격은 반사적으로 굴리는 손을 벌하고, 반응 대신 박자 맞추기를 시킨다.
  - **공정 조건**: 지연은 몇 가지 길이로만(외울 수 있게), 몸으로 읽혀야 한다, 모든 공격이 속임이면 지친다, 받아낼 길(패링·무적 구르기)이 있어야 한다.
  - 소리·이펙트는 동작과 한 몸이어야 한다. 읽히지 않는 무작위 박자는 "나쁜 시간의 조리법".
  - 세키로식 보스 박자는 3~5타 묶음, 묶음 안 간격이 리듬.
  - 0073의 DS3 공격 해부: 신호 + 공격 ≥ 340ms.

## 모의(0126 장치, 40판, 봇 시간)
- 봇은 상태를 읽어 속지 않는다. 그래도 **보스가 쉬는 틈이 줄어** 문지기 · 맨몸 · p 1.0이 17 → 26초.
- 사람이 엇박에서 덜 받아낸다고 두고(`SIM_OFFBEAT=0.75` — 가정, 확인 못 함) 90% 승리에 드는 성공률:
  - 문지기 · 맨몸: 0.5 → 약 0.65
  - 종지기 · 첫 도착 몸: 0.6 → 약 0.65~0.7
  - 종지기 체력(58)은 그대로 둔다 — 사람 판정 뒤에.

## 판정에서 볼 것(사람)
- 지연(더 젖힘·떨림·들이쉬는 소리)이 "늦게 친다"로 읽히나, 0.35 / 0.6초 둘이 외워지나.
- 타이밍 끔 예고가 "언제"를 너무 숨기나 / 아직 너무 알려 주나.
- 잡몹 지연 25%가 필드 싸움을 지치게 하지 않나.
- 페인트(반 아래 보스)가 불공정하게 느껴지지 않나 — 바뀐 공격의 예고·소리가 따로 난다.
