# 0163. 기술 화면의 격자는 위아래로 굴린다

- 날짜: 2026-11-13
- 상태: **결정**(사장 2026-11-13, 0161의 게임 화면을 보고 — "응 괜찮아 보이네, 화면은 상하 스크롤 가능해야 하고") — 만듦, 판정 전.
- 바탕: 0059(넘치는 목록은 굴린다 — 줄 간격을 줄여 맞추지 않는다)·0068(설명 칸은 읽는 사람이 굴린다)·0076(손가락으로 고른 줄은 창을 옮기지 않는다), KB `game-menu-scene-stack-and-focus`.
- 그림: `docs/art/gui-0161/10-scroll-top.png`·`11-scroll-bottom.png`·`12-scroll-bottom-acts.png`.

## 왜
0161의 격자는 줄 셋을 보이는 높이에 꼭 맞춰 넣었다 — 줄 이름표("쓴 점수 4부터")가 칸에 바짝 붙었고(4:3에서는 겹쳤다), 줄이 하나라도 늘면 자리가 없다. 맞추려고 줄이는 대신 굴린다(0059와 같은 규칙).

## 정한 것
- **굴리는 것은 격자의 몸**(갈래 머리 아래 ~ 창의 끝). 갈래 머리(흐름·맞받기·자리)와 오른쪽 상세 칸, 아래 안내는 그대로 서 있다.
- 줄 띠를 넉넉히(62·62·43 → 72·72·56 — 이름표와 칸 사이를 띄운다). 내용이 보이는 높이를 넘는 만큼만 움직인다.
- **커서가 창을 끈다**: 십자로 옮긴 칸의 "보일 구간"(윗칸 = 띠의 이름표부터 단의 점까지, 아랫칸 = 칸부터 띠의 끝까지, 셋째 줄 = 띠 통째)이 보이게 가장 적게. 손가락·마우스로 고른 칸은 창을 옮기지 않는다(같은 자리의 둘째 탭이 그 칸에 닿게, 0076).
- **휠·끌기**는 격자 위에서 격자를, 상세 칸 위에서 상세 칸을 굴린다(오른쪽 스틱은 전처럼 상세 칸). 가려진 쪽에 **▲▼**(누르면 두 칸).
- 끝에 걸친 칸은 잘라 그린다(가위 — `ui::clip`). 잘린 글(이름표·귀퉁이 표지)은 그리지 않는다 — 다 보일 때만.
- 확인하면 뜨는 작은 목록은 굴린 자리의 칸 곁에.

## 코드
`ui::ListView`의 판 창(`span`·`reveal`·`nudge`·`span_more` — 줄 창과 같은 스택 칸에 산다), `ui::clip`, `app/skills.rs`의 `reveal_span`·`grid_scroll`, 누를 자리 `Hit::Field`. 시험: 판 창의 셈, 모든 칸의 보일 구간이 보이는 높이에 들어가고 위 ↔ 아래 걸음마다 그 칸이 보인다.

## 확인
시험 484 + 무시 2, clippy 다섯, `hearth.js`(한국어·영어 넘침 0 — 모든 칸을 지난다), CI가 도는 넷. 화면 크기 넷에서 봄.
