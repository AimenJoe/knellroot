## 정한 것 1 — 소품 v2
- **꼴은 기하로, 색은 한 칸으로**: 돌 쌓기 무늬 칸을 버리고 큰 마름돌 몇 덩어리를 실제로 쌓는다. 돌 사이 금·모서리 선은 깎인 모서리와 렌더의 선 둘(0061)이 긋는다(KB "바닥 결은 기하로"와 같은 원리). 칸은 무늬·테두리 없는 단색(`k_*`).
- **둥근 것과 각진 것을 가른다**(0037 기둥 2): 건물의 돌은 모서리를 깎고(`stone`), 기둥 북·그릇·종은 정점을 같이 써 매끈하게(`lathe(smooth=True)` — 툰 띠가 감긴다), **뿌리·결정·테만 면마다 각지게**(밝은 선이 붙는 곳).
- **팔레트를 구운 지형에 맞춤**: `k_stone` = `scenery.rs` `WALL`(#5f5c7a), 어두운 단 `k_dark` #454463, 밝은 돌 `k_light` #7d7997(가장 밝은 칸도 방랑자보다 어둡게 — direction.md).
- `common.py`에 더한 것(`Geo`):
  - `stone(...)` — `box`와 같은 치수·기울임에 모서리 깎기(Blender `bmesh.ops.bevel`, 깎을 모서리 무리 `t`·`v`·`b`). 깎은 돌 하나 = glTF 정점 64(면마다 따로).
  - `lathe(c, profile, mat, sides, smooth, hard, …)` — 돌려 만든 꼴. 띠마다 칸을 달리할 수 있다(불꽃의 색 띠).
  - `limb(pts, radii, mat, sides, …)` — 꺾인 관(뿌리·버팀대·불꽃 혀). 네모 단면은 한 모서리가 위를 봐서 등줄기에 밝은 선이 붙는다.
  - 매끈한 면 묶음 번호(같은 묶음 + 같은 자리 = 같은 정점) — 둥근 몸과 각진 테를 한 부위 안에 섞는다.
  - 아틀라스 아래 절반(비어 있던 y 64~)에 `k_*` 스무 칸. 다른 모델의 텍스처는 **빈 칸만** 바뀐다 — 소품 밖 열한 모델의 기하·동작 바이트가 그대로이고 바뀐 화소의 옛 색이 모두 빈 칸 회색임을 스크립트로 확인.
- 모델마다:
  | 모델 | v1 → v2 | 정점(예산) |
  |---|---|---|
  | `wall_segment` | 돌 쌓기 무늬 상자 넷 → 마름돌 여덟 덩어리를 엇갈려 쌓고 오른쪽 위가 무너짐, 틈을 타고 꼭대기를 넘는 뿌리 | 352 → 904(960) |
  | `pillar_broken` | 45° 겹친 상자 → 네모 받침 + 둥근 북 셋(위는 밀리고 기울어 부러진 면) + 굴러떨어진 북 + 감아 오른 뿌리 | 288 → 522(560) |
  | `root_clump` | 기운 막대 여덟 → 비틀려 솟은 밑동 + 땅을 기다 끝이 들리는 뿌리 넷 + 가시 둘, 끝 마디만 밝은 보라 | 260 → 448(480) |
  | `brazier` | 팔각 겹상자 + 각뿔 불꽃(끝 1.12m) → 받침·기둥·둥근 그릇 + 각진 테, 불꽃은 휘어 오른 큰 혀 + 곁 혀 둘(끝 1.42m), 밑동 엷은 불씨 → 호박빛 → 짙은 호박빛 띠 | 196 → 367(440) |

- **치수·노드·뼈·동작 이름은 v1 그대로**(부딪힘 상자는 스테이지가 종류별 반폭으로 따로 갖는다). 종의 입술 높이 z 1.05는 내던지는 종(0133)이 쓰므로 지켰다.
- **정점**: 소품은 스테이지에 60개 안쪽(성소: 기둥 15·뿌리 11·돌무더기 10·벽 조각 4·화로 18·종 1)이라 예산을 모델마다 올렸다(`check_glb.py` `BUDGET`). 성소 전체로 구운 정점이 약 1만 4천 는다(한 번 굽는 지형 — 그리기 호출 수는 그대로).

## 정한 것 2 — 손대는 물건 셋을 모델로
| 모델 | 꼴 | 게임(`render.rs` `stage_props`) |
|---|---|---|
| `chest` 장신구 상자 | 갈색 나무 궤 + 둥근 뚜껑(뼈 `lid`) + 놋쇠 띠 + 호박빛 자물쇠 `glow_lock`. 동작 `open` 0.4초 | 닫힘 = 0초 + 자물쇠가 숨 쉰다(스스로 빛나는 정도 0.55~1.15), 열림 = `open` 끝 자세 + 자물쇠 감춤 |
| `stone_tablet` 새긴 돌 | 위가 좁은 선돌 + 깨진 어깨 + 새긴 줄 셋 `glow_carve` + 이끼 밑동 | 기울기·방향은 예전 셈 그대로, 새긴 줄은 곁에 서면 1.15·아니면 0.42 |
| `lever` 문 장치 | 돌 기둥 + 갓돌 + 손잡이(뼈 `handle`) + 쥘 곳 `glow_grip`. 동작 `pull` 0.4초 | 당기기 전 = 0초, 당긴 뒤 = 끝 자세 + 쥘 곳 감춤 |
- 모델 파일이 없으면 예전 상자 그림(대체로 남김 — 주민·적과 같은 규칙).
- 배우처럼 그린다(`Batch::model`): 툰 빛·1.35배·외곽선·그림자·화면 공간 선을 받는다.
- **상자 색**: 처음엔 문·종 틀과 같은 짙은 나무(#5a4650)였는데 푸른 달빛 아래에서 돌과 같은 잿보라로 읽혔다 → 따뜻한 갈색(#7c5340) + 놋쇠(#c09a5c). 빛을 받지 않던 옛 상자 색을 그대로 옮기면 안 되고, 빛(바탕 0.29·0.28·0.40)을 곱한 뒤의 색으로 고른다.
- 시험 `stage_object_models_have_the_parts_the_renderer_asks_for`: 렌더가 이름으로 찾는 부위·동작(상자·새긴 돌·장치·종·문·핵·화로)이 모델에 있다.

## 남긴 것(하지 않은 것과 까닭)
1. **주민 텍스처의 잔무늬**: 128px에 구운 Meshy 색이 31px 크기에서 얼룩. 고치는 길은 (a) 텍스처 색을 몇 단으로 줄이는 후처리(큰 색 덩어리 — 그림이 바뀐다) (b) 256으로 다시 변환(주민마다 5분, 잔무늬는 그대로 또렷해질 뿐). 사장이 Gemini → Meshy로 직접 받은 그림이라 판정 없이 손대지 않았다.
2. **적의 잿빛 밝기**: 0060 W3 판정(0.6배). 등딱지짐승만 유독 어두운 것은 체크리스트 2-4의 숫자로 남김.
3. **주민 생활 물건 셋**(아궁이·항아리·천막 — 재방문 변화가 있다), 떨어진 아이템, 개발 아레나의 기둥은 아직 상자. 다음 차례 후보.
4. 상자·장치의 여닫는 동작은 모델에 있지만 게임은 처음·끝 자세만 쓴다(스테이지에 여닫는 시계가 없다) — 움직이게 하려면 `StageRun`에 시각 하나.
5. 화로 불꽃은 굽는 지형의 일부라 움직이지 않는다(v1과 같다).

## 판정(사람)
- 소품 여덟이 지형·캐릭터와 같은 그림으로 읽히나, 벽 조각·기둥의 뿌리가 "침식"으로 읽히나.
- 화로: 그릇과 불꽃이 따로 읽히나, 불꽃이 너무 크거나 누렇지 않나(쉼터 표지).
- 문: 널·띠가 문으로 읽히나, 이맛돌이 과하지 않나.
- 상자: 갈색·놋쇠가 세계 팔레트에서 튀지 않나(손댈 수 있다는 표시로는 충분한가).
- 새긴 돌: 밝은 선돌이 어두운 바닥에서 눈에 띄나(6-5), 새긴 줄이 곁에서 밝아지는 것이 보이나.
- 종: 청동으로 읽히나.
