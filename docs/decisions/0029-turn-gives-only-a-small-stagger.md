# 0029. 땅 돌리기의 쏟기를 약하게 — 짧은 휘청만

- 날짜: 2026-11-04
- 상태: 채택·구현. 0012의 쏟기(실어 붙잡기·멀리 밀기·벽 쿵)를 줄인다. 도는 규칙(몸·화면 같이 90°)은 0028 그대로.
- 사장: "이게 괜찮음. 화면돌리기는 최소한의 스테거링 주는걸로 약화하자."
- 얼린 값(0013)을 바꾸는 판정: 사장 지시. 랩 A/B는 하지 않았다 — 개발판에서 손으로 본다.

## 왜
- 0028로 땅 돌리기는 "가는 쪽을 바꾸는 이동 도구"가 됐다. 그런데 4초마다 범위 8m 안의 적을 **도는 동안(약 0.9초) 붙잡고 + 0.9초 휘청 + 최대 3m 밀고 + 벽에 부딪히면 피해 1**을 줬다 — 대기 4초 중 1.8초를 묶는 CC다. 패링·회피보다 세서 싸움이 "돌리기 쿨 기다리기"가 된다.

## 바꾼 것
| 값 | 전 | 후 |
|---|---|---|
| 도는 동안 적 붙잡기(`EState::Carried`) | 있음 | **없앰**(그대로 쫓아오고 친다) |
| `spill.slide per m` | 0.35 | 0.05 |
| `spill.slide max m` | 3.0 | 0.25 |
| `spill.stagger s` | 0.9 | 0.3 |
| `spill.boss stagger s` | 0.3 | 0.1 |
| `spill.slam dmg` / `spill.slam stagger +s` | 1 / 0.8 | 0 / 0 |
- 그대로: 범위 8m, 바깥 몫, 보스 무게, 대기 4초, 발 딛기 0.25초, 멈추는 순간의 히트스톱·"탁". 휘청은 여전히 예고를 끊는다(0.3초 뒤 다시 시작).
- 밀림이 짧아 벽 쿵(`SLAM_SPEED`)은 기본값에서는 거의 나지 않는다. 규칙은 남겨 두고 시험은 랩 값(옛 밀림)을 넣어 본다.
- 시험: `while_the_ground_turns_the_enemies_keep_coming`(붙잡지 않고, 멈추면 짧게 휘청), 쏟기·보스·벽 쿵 시험을 새 값에 맞춤. `docs/tuning-frozen.txt` 다시 얼림.

## 다시 볼 조건
- 휘청 0.3초도 예고를 끊어 보스를 4초마다 끊을 수 있다. 남발되면 "공격 중인 적은 몸만 흔들리고 끊기지 않게"를 본다.
- 너무 밋밋하면 밀림(`spill.slide max m`)부터 랩에서 올린다.
