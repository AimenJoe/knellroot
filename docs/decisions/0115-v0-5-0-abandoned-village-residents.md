# 0115. v0.5.0 — 떠난 마을의 남은 주민

- 날짜: 2026-11-08
- 상태: **지역 방향·주민 공통 원칙 채택**, 세부 NPC 구성·배치는 제안(PROPOSED)
- 대상: `release/v0.5`의 v0.5.0 둘째 지역
- 번호: 브랜치(`feature/v0.5-abandoned-village-residents`)에서는 0114였으나 준비 문서 0114와 겹쳐 0115로 옮김(2026-11-08). 남은 질문은 0114 "정할 것"과 함께 인터뷰로.

## 0116에서 정한 것(2026-11-08 인터뷰)
- 주민 = **여러 작은 동물**(귀여움 문법 0036), 화면 글은 종족명이나 "사람" 대신 **"주민"**.
- 떠난 이유: 게임 안에선 MYSTERY, 개발자 답은 0116(큰 나무의 새싹이 자란 뒤 후손이 땅 위로 올라감) — 단서는 이와 어긋나지 않게.
- V01의 불 = **집 아궁이**(쉬는 화로와 다른 불).
- 재방문 = **그 주민을 처음 본 판이 끝난 뒤 다른 판에서 마을에 다시 들어섬**(주민마다 한 번, 단방향, 기록).
- 플레이어의 근접 공격·투사체·수류탄·땅 돌리기는 주민에게 **닿지 않고 지나간다**. 락온·자동 조준도 주민을 고르지 않는다.
- 대화는 **머리 위 말풍선**으로 표시하고 게임을 멈추지 않는다. 잠시 후 사라지며 다시 상호작용하면 다음 줄을 보여 준다.

## 배경

0069의 방향인 **떠난 마을**을 이어받는다. 이 마을은 멸망한 곳이 아니다. 마을을 이루던 이들은 땅 위로 올라갔고(개발자 답, 0116), 지금은 여러 작은 동물 주민 일부가 각자의 삶을 이어 간다. 플레이어와 주민에게 떠난 이유는 여전히 미스터리다. 첫 구역인 침묵의 성소와 달리, 이곳은 전투만을 위한 폐허가 아니라 누군가 살았던 흔적과 아직 이어지는 일상을 보여 주는 지역이다.

## 채택한 방향(CANON)

| 항목 | 결정 |
|---|---|
| 마을의 정서 | **고요함(quiet)** — 고요하고 쓸쓸하지만 누군가 살았다는 흔적이 남아 있다 |
| 마을을 떠난 이유 | 게임 안에서는 **MYSTERY**. 개발자 답은 0116의 땅 위로 올라간 것 — 단서는 이 답과 어긋나지 않게 |
| 마을의 종 | **깨져 있음(broken)** |
| 남은 주민 | **일부(some)** — 전원이 떠난 것은 아니다 |
| 주민들의 생활 | 서로 떨어져 각자 살아간다 |
| 대화 | 짧고 제한적이다 |
| 성격 | 평범한 일상을 살아가는 작은 동물들 |
| 방랑자에 대한 태도 | 무심한 경계 |
| 전투 중 행동 | 안전한 생활 구역에 머문다 |
| 보스 처치 후 | 같은 장소에 남아 생활을 이어 간다 |

주민들은 방랑자의 정체, 핵, 종소리, 뿌리의 본질을 설명하는 인물이 아니다. 그저 이곳에서 살아가는 작은 동물들이며, 평범한 일상을 이어 간다. 화면 글과 시스템 표기는 종족을 특정하지 않고 "주민"으로 통일한다.

## 제작 제안(PROPOSED)

v0.5.0 구현 규모로 주민 세 명을 제안한다. 인원수와 외형, 정확한 위치는 실제 지역 제작 과정에서 조정할 수 있다.

| ID | 역할 | 제안 위치 | 생활 행동 |
|---|---|---|---|
| NPC-V01 | 불을 지키는 주민 | 위쪽 거주지 | 집 아궁이의 불을 지킨다 |
| NPC-V02 | 물을 모으는 주민 | 뿌리 사이 골목 안쪽 | 뿌리에서 떨어지는 물을 항아리에 받는다 |
| NPC-V03 | 낡은 것을 꿰매는 주민 | 아래쪽 광장 외곽 | 옷과 천을 수선한다 |

각 주민은 생활 행동 하나와 짧은 대사(최대 세 개)를 가진다. 대사는 머리 위 말풍선으로 표시하며 게임을 멈추지 않는다. 말풍선은 잠시 후 사라지고, 상호작용을 다시 누르면 다음 대사를 표시한다. 주민별 대사 초안과 재방문 연출은 `docs/design/stages/abandoned-village-residents.md`를 참조한다.

## 안전과 전투 원칙(CANON)

- 주민은 전투에 참여하지 않는다.
- 주민은 적의 공격 대상이 되지 않으며 전투 AI의 타깃 후보에서도 제외한다.
- 플레이어의 근접 공격·투사체·수류탄·땅 돌리기(멈출 때의 휘청·밀림)는 주민에게 닿지 않고 그대로 지나간다.
- 락온과 자동 조준은 주민을 대상으로 선택하지 않는다.
- 생활 구역은 적의 추적 범위와 광역 공격 범위에서 공간적으로 분리한다.
- 주민을 전투 중 대피시키는 복잡한 AI보다 안전한 구역 배치를 우선한다.
- 보스 처치 여부에 따라 주민의 위치·행동·태도가 바뀌지 않는다.
- 주민과 대화하지 않아도 지역 탐험과 보스 진행이 가능해야 한다.

## 재방문 변화(PROPOSED)

주민의 생활이 조금씩 이어지고 있음을 보여 주는 작은 환경 변화만 둔다. 퀘스트, 보상, 필수 진행 관문으로 만들지 않는다. 대화 횟수와 이벤트 발동 조건을 묶지 않는다.

- V01: 집 아궁이의 불빛이 조금 살아난다.
- V02: 기울어진 항아리가 바로 세워져 있다.
- V03: 찢어진 천막 일부가 수선되어 있다.

이 변화는 저장·복원되어야 하며 중복 실행되지 않아야 한다.

## 미스터리로 남길 것(MYSTERY)

- 주민들이 마을을 떠나지 않는 이유
- 마을을 떠난 이유(게임 안에서만 MYSTERY; 개발자 답은 0116)
- 깨진 마을 종과 더 깊은 곳에서 들리는 종소리의 관계

위 항목을 뿌리의 선택, 특별한 운명, 종소리의 직접적인 영향으로 설명하지 않는다. 현재로서는 인과관계를 정하지 않는다.

## 기존 정본과의 관계

- 0004·0069의 **마을은 멸망한 것이 아니라 떠났다**는 방향을 뒤집지 않는다.
- Naïl의 엔딩과 큰 나무의 마지막 꽃, 누룩 할매가 놓아준 실을 변경하지 않는다.
- 세계관 바이블의 CANON / PROPOSED / MYSTERY 구분을 유지한다.
- 깨진 마을 종을 지하 종소리의 근원이나 원인으로 확정하지 않는다.

## 구현 수용 기준

P0:
- NPC-01 주민들이 각자의 생활 구역에 등장한다.
- NPC-02 주민별 생활 행동이 서로 구분된다.
- NPC-03 접근 시 무심한 경계 반응을 보인다.
- NPC-04 짧은 대사를 머리 위 말풍선으로 표시하고 게임을 멈추지 않으며, 말풍선 종료 후 생활 행동을 이어 간다.
- NPC-05 주민은 전투에 참여하지 않고 적 AI의 공격 타깃이 되지 않으며 플레이어 공격·락온·자동 조준도 주민을 통과하거나 선택에서 제외한다.
- NPC-06 생활 구역은 적 추적·광역 공격 영역과 분리된다.
- NPC-07 v0.4.1 세이브를 정상적으로 불러온다.
- NPC-08 보스 처치 후에도 주민은 같은 장소에서 생활한다.
- NPC-10 주민별 첫 목격 판이 끝난 뒤 다른 판에서 마을에 다시 들어오면 환경 변화가 한 번만 적용되고 저장·복원된다.
- NPC-11 주민과 대화하지 않아도 지역·보스 진행이 가능하다.

P1:
- NPC-09 재방문 시 주민별 환경 변화가 반영된다.

## 구현 메모(PROPOSED)

실제 ECS, 엔티티, 저장 구조를 먼저 확인한 뒤 현재 코드에 맞춰 통합한다. 아래는 개념 예시이며 기존 코드 구조를 규정하지 않는다.

```rust
enum VillagerId {
    HearthKeeper,
    WaterCollector,
    ClothMender,
}

enum VillagerAction {
    TendingHearth,
    CollectingWater,
    MendingCloth,
}

struct VillagerProgress {
    first_seen: bool,
    event_changed: bool,
    // 구현(0122): 판 식별은 runs·residents.seen(V01:판 번호)·residents.changed.
}

struct VillageProgress {
    hearth_keeper: VillagerProgress,
    water_collector: VillagerProgress,
    cloth_mender: VillagerProgress,
}
```

- v0.4.1 세이브 호환을 유지한다. 새 필드가 없는 구버전 기록은 기본값으로 읽는다.
- 주민 진행 상태는 저장·복원한다.
- 주민 상태와 보스 처치 상태를 결합하지 않는다.
- 첫 목격 판이 끝났는지는 0122가 정했다: 시작한 판 수 `runs`와 주민을 처음 본 판 `residents.seen`(`V01:판 번호`)을 기록하고, 그보다 뒤의 판에서 마을에 들어서면 `residents.changed`로 한 번 바뀐다. 단순한 맵 재진입 횟수나 보스 처치 플래그로 대체하지 않는다.
- 주민별 첫 목격 판과 그 판의 종료 이후를 구분한다. 단순한 같은 판의 지역 재진입으로 이벤트를 발동하지 않는다.
- 다른 판에서 마을에 다시 들어왔을 때 주민별 환경 변화가 한 번만 적용되며, 대화 횟수·보스 처치 여부와 묶지 않는다.
