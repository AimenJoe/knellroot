# 0082. 웹은 가로가 기본 — 세로로 든 폰엔 회전 안내, 누르면 가로 잠금

- 날짜: 2026-11-07
- 상태: **채택·구현**(개발판)
- 사장: "landscape 가 기본으로 되도록 해줘"

## 전
- 매니페스트는 0062부터 `"orientation": "landscape"`였다. 홈 화면에 깐 앱(Android)만 따른다.
- 브라우저 탭에서는 터치 기기가 "시작"을 누를 때만 전체 화면 + 가로 잠금을 시도했다(0046). 그 전(타이틀·슬롯 창)과 iPhone은 세로 그대로 떴다.
- KB `reference/web/pwa-install-fullscreen-orientation.md`:
  - 가로 **잠금**은 Android Chrome(전체 화면 안·설치 앱)에서만 된다.
  - iPhone Safari·홈 화면 앱에는 잠금 API가 없다(WebKit이 잠금을 전체 화면 API에 묶어 두었고 iPhone엔 그 API가 없다). 그래서 회전 안내로 메운다(nail 0269).

## 결정
- **세로로 든 터치 기기**(`pointer: coarse` + `orientation: portrait`)면 글 없는 회전 그림(`#rotate`)이 화면을 덮는다. 폰이 세로에서 가로로 돈다.
  - 싸움 중이면 멈춤으로 간다(`screen::portrait_blocked` → `tick_play`).
- **누르면**:
  - 전체 화면을 쓸 수 있으면(Android 브라우저) 전체 화면 + 가로 잠금을 한다. 0.7초 뒤에도 세로면(잠금을 거절한 브라우저) 안내를 걷는다.
  - 전체 화면이 없으면(iPhone) 이번 창에서는 세로로 계속한다(`sessionStorage knell.rotate.off`).
  - 강제하지 않는다 — 세로에서도 작게 돈다. 안내에 갇히지 않게.
- 설치 앱(Android)은 매니페스트대로 가로로 열린다(그대로).
- 키보드·마우스 기기는 안내가 뜨지 않는다.
- 시험: 헤드리스 `touch.js` — 세로 폰 화면에서 안내가 덮이고, 누르면 걷힌다(헤드리스는 잠금이 안 돼 세로로 계속 쪽).

## 남는 한계
- iPhone은 브라우저든 홈 화면 앱이든 가로로 **고정**할 방법이 없다. 폰을 돌리게 안내하는 것까지다.
  - iOS 홈 화면 앱이 매니페스트의 가로를 따르는지는 KB에도 "확인 못 함"이다.
- 진짜로 가로를 고정하려면 iOS 앱 빌드(`build-ios.yml`, Info.plist 가로만)다.
