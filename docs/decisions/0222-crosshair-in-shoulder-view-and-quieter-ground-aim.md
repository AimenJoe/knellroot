# 0222 — 숄더뷰는 크로스헤어 · 쿼터뷰는 조준할 때만 연한 띠(0221 헤어라인 걷음)

- 날짜: 2026-11-16
- 상태: **결정 + 만듦**(개발판 `release/v0.7`)
- 사장: "조준 전 바닥의 헤어라인 필요없음. 숄더뷰일 때 화면에 크로스헤어가 있으면 되고, 그곳으로 발사되도록. 쿼터뷰에서는 조준 시에
  바닥에 공격방향 안내 보여주되, 지금보다 연하게."
- 바탕: 0219(숄더뷰 = 카메라 앞, `aim_line`), 0221(쇠뇌 헤어라인 — 이 결정으로 걷음).

## 결정
1. **바닥 헤어라인 걷음**(0221): 손이 겨누지 않으면 `aim_line`은 없다(쇠뇌도).
2. **숄더뷰 = 화면 가운데 크로스헤어**(`hud::draw_crosshair` — 틈 있는 십자 + 점, 어두운 테): 바닥에는 아무것도 그리지 않는다.
   원거리는 "그곳으로" — 화면 가운데의 시선(카메라 리그)이 지나는 깨어 있는 적의 몸이 있으면 그 적 쪽(`App::crosshair_target` →
   `Actions::aim_at`, 높이는 0218의 곧은 줄), 없으면 카메라 앞으로 곧게(0219). 가운데에 적이 걸리면 크로스헤어가 호박빛으로 좁혀진다
   (붉은색은 쓰지 않는다). 숄더뷰 카메라는 방랑자를 화면 좌우 가운데에 두니 수평 쪽은 가운데 시선과 같다. 숄더뷰에서는 마우스 커서 표시를 그리지 않는다.
3. **쿼터뷰 = 조준할 때만 연한 띠**: 쏘거나 모으는 동안·패드 오른쪽 스틱을 기울인 동안·터치로 끄는 동안. 띠의 몸 0.32 → 0.18, 테 0.95 → 0.6.

## 시험
- `nothing_held_means_no_aim_line_even_with_the_crossbow`, 0219의 `in_the_shoulder_view_the_shot_goes_where_the_camera_looks`.
- 헤드리스 `touch.js`의 숄더뷰 화면: 가운데 크로스헤어, 가운데의 적에 호박빛.
