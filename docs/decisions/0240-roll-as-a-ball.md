# 0240 — 공처럼 구르기: 말아 쥔 몸을 공의 가운데로 한 바퀴

- 날짜: 2026-11-18
- 상태: **결정 + 만듦**(개발판 `release/v0.7`, 판정 전) — 0239를 고친다
- 사장: "미리보기 보면 구르지 않는데?"

## 까닭(잰 것)
- 0239(어른 몸의 구르기 원본 + 바닥 위로 띄우기 + 몸 말기)는 숫자로는 한 바퀴(앞 숙임 0 → 360°)였지만, 옆에서 보면 엉덩이를 0.78 m까지 들고
  거꾸로 서서 세 장을 머물다(물구나무) 등으로 눕고 앉았다 — 높은 점을 축으로 넘었지 바닥을 따라 구르지 않았다. 띄우기는 증상을 덮었을 뿐.

## 고침(`wanderer_skin.py` `ROLL`·`craft_roll`)
- 구르기 0.25초는 원본을 따르지 않고 짓는다: 처음 자세(원본 1 — 살짝 숙임) → 공(원본 31의 웅크림 + `BALL_BEND` 등·목·머리·넓적다리·정강이·팔을
  만다) → 끝 자세(원본 31 — 일어나기가 거기서 잇는다). 공의 가운데(평가한 메시의 상자 가운데)를 축으로 앞으로 한 바퀴(0.02 → 0.21초, 코사인 이음),
  프레임마다 가장 낮은 정점을 바닥 + 2 cm에 붙인다(띄우는 것도 내리는 것도 — 늘 닿아 있다 = 구른다). 엉덩이의 수평 자리는 쉬는 자리에 둔다
  (제자리에서 돌고 게임이 3 m를 옮긴다).
- 원본의 웅크린 끝 자세는 옆으로 27° 기울어 그대로 말면 공이 옆으로 누운 채(몸 축 58°) 돌아 비스듬히 굴렀다 → 공인 동안 몸의 옆축을 구르는 옆축에
  맞춘다(들어갈 때·풀 때 같은 몫으로 섞는다). 잰 값: 공인 동안 몸 축의 옆 기울기 5°, 앞 숙임은 0 → 360°로 한 쪽으로만 돈다.
- 일어나기(`dodge_rise`)는 원본 31 → 38(0.2초), 바닥 위로는 일어나기에만 프레임마다 거의 그대로(`CLEAR_WIDTH` 0.5) — 구르기의 끝과 같은 몫이라
  이음매가 맞는다. 0239의 몸 말기 표(`TUCK`)는 비웠다(공 굴리기가 맡는다).
- 게임 쪽은 그대로(회피 0.25초·3 m·무적, 일어나기는 0238).

## 확인
- 옆·게임 각도 미리보기 12장씩(앞으로 엎어져 머리부터 넘어 한 바퀴 → 웅크림), 모델을 다시 읽어 잰 앞 숙임·옆 기울기, `check_glb`(새 지적 없음), `cargo test` 742.
