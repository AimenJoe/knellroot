- 날짜: 2026-11-05
- 상태: **채택**(2026-11-05, 사장 "응 넣고 진행해줘" — M5 소리를 넣는다, 장신구·성장은 초안대로). 처음 제안: 사장 "0.3.0 의 마일스톤 정리해줘".
- 근거: `docs/concept.md` "단계" 3(구조·메타·저장), `docs/design/items.md`(0026·0027 — 구현 순서 A·E는 들어갔고 B·D·F가 남음), KB `concepts/roguelite-healing-and-currency.md`(잃지 않는 화폐·쓸 곳이 보여야)·`concepts/action-rpg-stats-and-equipment.md`(세 겹·합치기 한 곳), 첫 게임 nail의 기록(`profile.rs`)·소리 표(`sfx.rs`·`make_audio.py`, CC0만).

## 왜 이것인가
- v0.2.0까지는 **한 판이 끝나면 아무것도 남지 않는다**(저장은 설정뿐). 0026에서 정한 구조(구역을 잇는 선형 + 화로 + 잃지 않는 잔불)는 기록이 있어야 선다 — 둘째 구역보다 먼저.
- 둘째 구역(콘텐츠)은 세계관 D2(0004 — 첫 게임과 같은 "뿌리" 모티프를 이을지 바꿀지)가 정해져야 그림·적·이름을 만들 수 있다. 구조는 D2와 상관없다.
- 무기 넷·등잔·쉼터는 이미 있다(0031·0032·0051). 남은 세 겹(장신구·성장·화폐)을 채우면 "같은 문지기를 다른 빌드로 다시"가 생긴다.

## 넣지 않는 것(v0.4.0 후보)
- 둘째 구역 — **세계관 D2를 먼저 정해야 한다**(0004). v0.3.0 동안 사장이 D2를 고르면 v0.4.0 = 둘째 구역.
- 상인, 저장 슬롯 여럿, PC 빌드(nail 0240 워크플로 가져오기), iOS.

## 순서(단계마다 패치로 낼 수 있게)
M2 기록 뼈대(설정 밖 첫 저장 칸) → M1 잔불(기록에 수) → M3 장신구(`Stats` 리팩터 + 표 + 메뉴 + 상자) → M4 성장(핵) → M5 소리. v0.2.0 판정에서 나온 고칠 것은 그 사이 v0.2.x로 먼저.

## 사장이 정할 것

2. 장신구 여섯·성장 셋의 이름·수치(초안 `docs/design/items.md` 3·0) — 고칠 것이 없으면 초안대로.
3. 세계관 D2(v0.4.0 둘째 구역 전에).

## 구현
- **M2 기록(2026-11-05)** — `src/save.rs`:
  - `Record`(키=값 줄, 모르는 키는 지켜 들고 다닌다, 깨진 줄은 건너뜀) → `Progress`(잔불·끝낸 판·판 안의 자리 `RunAt` = 마지막으로 쉰 쉼터 + 문이 열린 뒤인지). 키 이름은 `save::key`에 — 바꾸지 않는다.
  - 저장 자리: 웹 localStorage `knell.save.0`(`web/index.html` `knell_save_len·read·write`, 바이트는 번들의 `wasm_memory`로), 데스크톱·Android `save0.txt`(설정과 같은 폴더 `prefs::data_dir`, 임시 파일 → 이름 바꾸기).
  - 앱(`app/mod.rs`): 싸움 틱마다 판에서 기록할 것을 옮기고(`sync_progress` — 쉰 쉼터, 판을 끝내면 자리 지우고 `clears` +1) **바뀌었을 때만** 쓴다(`persist`). 못 쓰면 경고만, 게임은 한 판처럼 굴러간다.
  - 타이틀: 기록이 있으면 첫 줄 "이어하기"(쉰 쉼터에서 — `StageRun::resume`, 쓰러진 뒤 다시 서는 것과 같은 규칙 0032, 시작 이야기 없음; 자리가 없으면 입구부터 + 남는 것 그대로), 설정 뒤에 "새로 하기"(한 번 누르면 "기록을 지우고 새로 — 한 번 더", 커서를 옮기면 풀림). 설정은 늘 둘째(헤드리스 시험의 길).
  - 멈춤 "처음부터"·결과 "다시"는 판 안의 자리만 지운다(남는 것 그대로). "타이틀로"는 자리를 지키므로 이어하기가 그 쉼터에서.
  - 시험: `save` 4(기록 왕복·모르는 키·깨진 줄, 판이 끝나면 자리 지우기, 빈 저장 = 새로, 네이티브 파일 쓰기·지우기), `resuming_from_a_record_…`(쉼터·단계·물결 없음·지도에 없는 번호), 타이틀 줄. 헤드리스 `tools/test/save.js`(CI): 새 브라우저 = 시작·설정, 심어 둔 기록 → 이어하기 → 문 앞 쉼터, 처음부터 → 자리만 지워지고 잔불·끝낸 판·모르는 키 그대로, 새로 하기 두 번 → 지워짐.
