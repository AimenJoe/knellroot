# 0079. 연구소는 메뉴의 설정 바로 아래 줄, 개발판 타이틀에 커밋 해시

- 날짜: 2026-11-07
- 상태: **채택·구현**(개발판)
- 사장: "Dev 빌드는 화면에 버전 옆에 커밋해쉬 보여야 구분되겠다. 그리고 lab 은 연구소로 바꾸기로 한거 아냐? 위치랑.." → 자리를 물음 → "메뉴의 설정 바로 아래 줄"

## 연구소
- 0070 덧붙임(15)은 "Lab 은 연구실로, 설정 밑에"를 **설정 창 안의 줄**(조작 설정 위)로 읽었다.
  - 설정 창이 넘쳐 굴려야 보였다(언어 … 조준 표시 다음).
  - 사장이 뜻한 것은 **메뉴의 설정 바로 아래 줄**이었다.
- 이름은 **연구소**(영어 Lab)다.
- 자리(개발판에만):
  - 타이틀: [이어하기] · 시작하기 · 설정 · **연구소** · DEV
  - 멈춤: 계속 · 장비 · 설정 · **연구소** · 처음부터 · 타이틀로 · DEV
  - 설정 창에서는 뺐다(`SettingsRow::Lab` 없앰). F1은 그대로다.
  - 시험: `the_lab_sits_right_below_settings_in_both_menus`
- 운영판은 줄이 그대로다(연구소·DEV 없음 — 시험 스크립트는 개발판으로 돈다).
- 헤드리스 길(줄 수로 가는 것):
  - 멈춤의 타이틀로·처음부터는 한 줄씩 아래로 밀렸다: `shot.js` 5·3, `save.js` 4·5, `touch.js` 멈춤 일곱 줄.
  - 타이틀의 DEV도 한 줄 아래로 밀렸다: `leak.js` 3, `mouse.js` 2.
- DEV 창의 "lab (tuning)"은 개발 전용 화면이다(영어 기본 글꼴, 0013). 한글을 넣으면 안 그려져 그대로 둔다.

## 커밋 해시
- `build.rs`가 `BUILD_HASH`를 넣는다. CI는 `GITHUB_SHA`, 손 빌드는 `git rev-parse HEAD`, 앞 7자다.
  - deploy-web·build-android 모두 러너에서 바로 빌드하니 `GITHUB_SHA`가 보인다.
- 타이틀 오른쪽 위: 운영판 `v0.3.3`, 개발판 `v0.3.3 dev 674d4c8`(해시를 모르면 `v0.3.3 dev`, `title::version_label`).
- 개발 웹의 `build.txt`(전체 해시)와 앞 7자가 같다. GitHub 커밋 목록과 맞춰 볼 수 있다.
- 시험: `dev_builds_show_the_commit_next_to_the_version`
