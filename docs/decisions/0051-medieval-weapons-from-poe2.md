# 0051. 중세 무기 갈래 — Path of Exile 2를 참고해

- 날짜: 2026-11-04
- 상태: 채택·구현(사장: "각 무기에 따른 콤보 및 기술 추가해주고 다음 패치 버전 배포해줘") — 처음 넷 + 자세 막대 + 콤보, 사냥 창은 나중
- 계기: 사장 "우리 연구한 대로 모션도 넣어야겠지? 중세풍의 무기들 좋아. Path of Exile 2 참조해봐"
- 틀: 0048에서 무기 한 줄을 (X, RB) 짝으로 정했다. 근접 무기는 X 콤보 + RB 마법, 원거리 무기는 RB 사격 + X 수류탄이다.

## Path of Exile 2에서 가져올 것
출처 대부분은 2차다: poe2db 게임 데이터 추출, 언론 인터뷰. 1차로 읽은 것은 공식 0.5.0 패치 노트뿐이다.

- **무기마다 "행동"이 다르다**:
  - 메이스: 내려찍기, 느린 한 방, 스턴 누적.
  - 쿼터스태프: 빠른 연타. 빠르게 이어 쓰면 3·4타가 바뀐다.
  - 창: 근접 + 던지기. 박힌 창을 터뜨리고, 패리 뒤에 덤이 붙는다.
  - 쇠뇌: 장전한 볼트를 쏘고, 도화선이 있는 수류탄을 던진다.
- **Heavy Stun(자세 깨기)**:
  - 피해에 비례해 적의 막대가 차고, 다 차면 하던 행동이 끊기고 몇 초 무방비가 된다. 그 뒤 잠시는 다시 걸리기 어렵다.
  - 개발자 말: 엘든 링의 강인도 같은 것(2차).
  - 메이스의 일부 기술은 "깨지기 직전"인 적을 즉시 깬다.
- **수류탄 구조**:
  - 도화선·쓰는 수·재사용 대기가 있고, 늘 튕긴다.
  - 다른 기술로 맞히면 즉시 터진다.
  - 회피하면 장전하는 보조 기술이 있다.
- **몸을 맡기는 동작(commitment)**:
  - 거의 모든 동작은 회피로만 끊는다.
  - 0.2.0h에서 창 기술의 빠른 끊기를 없앴다.
  - "조금 느리게, 반응해서 싸우게" — Jonathan Rogers(2차).

## 처음 무기 넷(제안 — 귀엽지만 무겁게)

| 무기 | X(연타) | X 꾹(강타) | RB | 회피로 끊기 | PoE2 착상 |
|---|---|---|---|---|---|
| **순례자의 검**(지금 칼, 보통) | 3연타: 가로 → 반대 가로 → 찌르기. 다음 타 입력은 미리 받는다 | 지금 강타(넓게 가로 베기) | 마법탄 | 각 타의 판정 뒤 | — (기준 무기) |
| **종치기 망치**(양손, 무거움) | 2타, 느리고 넓게. 한 걸음씩 나아가며, 자세 막대가 크게 찬다 | 뛰어올라 둥근 내려찍기. 금 간 땅이 남고 1.5초 뒤 여진이 터진다. 깨지기 직전인 적은 즉시 자세가 깨진다 | 무거운 탄(느리고 짧지만 휘청) | 들어 올리는 동안은 안 됨. 친 뒤에만 | 스턴 준비 → 깨기, 지연 여진 |
| **순례자 지팡이**(빠름) | 4연타. 박자 안에 이으면 4타째가 회전 마무리 | 모았다 떼기. 딱 맞춰 떼면 둘레 넉백 + 덤 | 꿰뚫는 탄 | 각 타 판정 뒤 언제든 | 이어 쓰면 3·4타가 바뀜, 딱 맞춘 떼기 |
| **화약 쇠뇌**(원거리) | **X = 수류탄**: 튕기는 포물선, 도화선 1.5초, 2개 + 대기. 꾹 쥐면 조준선이 나오고 멀리 던진다 | (같은 버튼) | **RB = 조준 사격**: 탄창 4, 다 쓰면 자동 장전(느림), 회피하면 1발 장전. 볼트로 수류탄을 맞히면 즉시 터진다 | 장전·회수는 언제든, 쏘는 순간만 묶임 | 도화선 수류탄, 기폭, 회피 장전 |

- 다섯째 후보는 **사냥 창**이다.
  - 3연 찌르기, 사거리가 가장 길다. 패링 직후 X는 강화 찌르기가 된다.
  - 꾹 누르면 던진다. 박힌 창은 다시 눌러 터뜨린다.
- **우리 것과 엮기**: 땅 돌리기(LT·RT)를 해도 도화선과 여진 시계는 멈추지 않는다. 그래서 "돌리고 떨구기" 노림수가 생긴다.

## 같이 들어갈 장치
1. **콤보**(지금은 없다 — 평타 한 종류만 반복):
   - 타마다 다음 타 입력 창을 두고, 그 창 안에 누르면 이어진다.
   - 후딜 중에 누른 것은 미리 받아 둔다.
   - 마지막 타 뒤에는 콤보가 처음으로 돌아간다.
2. **무기 표 `weapons.rs`**. 한 줄에 담는 것:
   - X 단계 목록: 선딜·판정·후딜, 모양(부채꼴·원·띠), 거리·각, 피해, 자세 피해, 넉백, 히트스톱, 내딛기, 회피로 끊을 수 있는 시각, 다음 타 창, 동작 이름
   - 강타, RB, 원거리면 탄창·장전·수류탄 칸
   - 모델·손잡이 자리
   - 같은 무게의 기준값은 `tuning.rs`·랩에 두고, 무기 표는 그 배율·모양만 갖는다.
3. **자세 막대**(PoE2 Heavy Stun, 우리 강타 휘청을 넓힘):
   - 적마다 막대가 차고, 다 차면 1.5초 무방비가 되며 받는 피해가 늘어난다.
   - 패링으로 드러나는 것(0025)과 같은 "드러남" 표시를 쓴다.
   - 보스는 막대가 크다. 깬 뒤 잠깐은 다시 차지 않는다.
4. **동작**(KB `believable-cute-character-motion` 원칙):
   - 무기마다 키프레임 동작을 Blender 스크립트로 만든다(평타 셋·강타·RB).
   - 예비 동작은 선딜 안에서만 둔다. 끝맺음은 무기 무게에 맞춰 망치는 길게, 지팡이는 짧게 한다.
   - 부피 지키는 찌그러짐을 쓴다. 무기 머리는 1.3~1.5배로 키운다(위에서 읽히게).
5. **모델**: 무기마다 Blender 스크립트 하나 → GLB → 방랑자의 오른손 뼈에 붙인다.
   - 실루엣으로 서로 갈린다: 망치는 큰 사각 머리, 지팡이는 양끝 덧대기, 쇠뇌는 가로로 넓은 T자.

## 순서(제안)
1. 콤보 + 무기 표 + 검 3연타(동작 포함)
2. 자세 막대
3. 종치기 망치(모델·동작·여진)
4. 화약 쇠뇌(사격·장전·수류탄)
5. 지팡이 → 창

무기를 고르고 바꾸는 곳은 쉼터 메뉴다(0026 아이템 설계 — 지금은 개발 메뉴로 먼저).

## 구현(2026-11-04)
- **무기 표 `src/weapons.rs`**:
  - 줄마다: 콤보의 타(`Hit`: 시간·거리·각·내딛기 배율, 모양 부채꼴/원, 피해, 자세 피해, 넉백, 동작 이름), 강타(`Heavy`), RB(`Rb::Magic`/`Rb::Shot`), 수류탄, 모델 부위.
  - 시간·거리는 랩의 `attack.*`·`heavy.*`에 곱하는 배율이다 — 손맛의 바탕은 랩 한 곳에 둔다.
- **콤보**:
  - 누름을 `attack.buffer s` 동안 미리 받는다. 후딜의 `combo.link x`가 지나면 다음 타로 넘어가고, 그때 다시 겨눈다.
  - 끝난 뒤 `combo.keep s` 안에 누르면 다음 타부터 이어진다. 마지막 타 뒤에는 처음으로 돌아간다.
- **자세 막대**(`Enemy::poise`):
  - 크기: 잡몹은 `poise.base` + 체력 × `poise.per hp`, 보스는 `poise.boss`.
  - 다 차면 휘청(1.5초, 보스 1초)하고 드러난다(다음 한 대 치명타, 0025와 같은 표시). 깬 뒤 3초는 다시 차지 않는다.
  - 2초 맞지 않으면 초당 1씩 준다. `Event::Break`.
- **망치**:
  - 2타째는 몸 둘레 원으로 친다.
  - 강타는 앞으로 크게 뛰어 둘레를 치고, 금 간 땅이 1.5초 뒤 여진(반지름 2.6, 피해 2)으로 터진다.
  - 자세가 60% 넘게 찬 적은 강타 한 번에 깬다.
- **지팡이**:
  - 4타째는 회전 마무리다(원).
  - 다 모인 뒤 0.15초 안에 떼면 딱 맞춤: 피해 +1, 자세 피해 ×1.5, 넉백 ×1.5, `Event::Perfect`.
  - RB 탄이 꿰뚫는다.
- **쇠뇌**:
  - RB는 탄창 4발이고, 다 쓰면 1.2초 장전한다. 회피하면 한 발이 장전된다.
  - X는 수류탄이다: 2개, 하나 다시 차는 데 4초, 도화선 1.5초, 튕기고, 반지름 2.2, 피해 3. 볼트로 맞히면 즉시 터진다.
  - X를 꾹 쥐어 겨누고 멀리 던지기는 0055에서 넣었다.
- **그림**:
  - 무기 모델 셋(망치·지팡이·쇠뇌)은 오른손 뼈에 붙였다. 게임은 든 무기만 보이고 나머지는 크기 0이다.
  - 동작 열넷: attack2·3, hammer1·2·charge·slam, staff1~4·charge·release, xbow_shoot, throw.
  - 탄 색은 무기마다 다르고, 수류탄·금 간 땅·폭발 고리를 그린다. HUD는 쇠뇌일 때 탄창 막대 + 수류탄 칸.
- **바꾸기**: 멈춤의 "무기" 줄(좌우·확인)과 DEV에서 바꾼다. 설정과 함께 저장한다(쉼터 메뉴가 생기면 그리로).
