# 0286 — 맨손은 몽크: 보조무기 슬롯이 잠긴 한 손 종류

- 날짜: 2026-11-27
- 상태: **만듦**(판정 전 — 체크리스트 134)
- 사장(2026-11-27): **"맨손 일땐, 몽크도 넣어줘. 대신 몽크는 보조무시를 들수 없어."**(보조무시 = 보조무기). 늘 있는 규칙: 밸런스 —
  "멀티클래스가 퓨어보다 무조건적으로 쎄지면 안됨.. 밸런스를 지키도록 하자.", "뭐보다 뭐가 반드시 위력이 약해져야 한다가 아니라, 방패 장착이나
  미장착이나 밸런스가 맞아야 한다는거야..", 퓨어의 몫 — "퓨어일때의 베네핏도 있고", 동작 — Meshy에서 제 동작을 받는다(API는 불러도 된다, 쓴
  크레딧만 알린다).

## 읽은 뜻(사장이 되돌릴 수 있게)
- **"보조무기를 들 수 없다" = 보조무기 슬롯이 잠긴다 — 무기도 방패도.** 방패는 0224부터 보조무기와 같은 한 칸에 든다(장비 탭의 왼쪽 열에 방패
  칸은 따로 없다). 그래서 몽크는 방패도 들지 않는다고 읽었다. 방패만은 허락하려면 종류 표의 한 칸(`Quirks::one_slot`의 뜻을 "보조무기만"으로)과
  `Id::takes_shield`(맨손이 양손 계열이라 지금은 거짓)를 바꾸면 된다 — 체크리스트 134-1의 물음.
- 맨손은 **보조무기로도 메지 못한다**(0224~0285의 장비 탭은 보조무기 칸에 맨손을 냈다 — "빈 손으로 바꿔 드는" 길). 맨손을 메고 주무기와 바꿔 들면
  몽크가 보조무기(옛 주무기)를 든 꼴이 되어 사장의 말과 어긋난다.

### 보조무기 슬롯의 규칙(몽크)
- **장비 탭**: 보조무기 칸의 후보는 비우기 하나(목록이 열리지 않는다 — 누르면 "안 됨" 소리), 설명 칸은 "잠김: 맨손(몽크)으로 싸우는 동안은
  보조무기도 방패도 장착할 수 없다" + 빈 손의 결 한 줄(호박빛). 빠른 바꾸기 버튼(`step_sub`)도 돌지 않는다. 맨손은 어느 무기의 보조무기 후보에도
  없다(`Id::slings`).
- **맨손을 주무기로**: `App::wield`가 보조무기 · 방패를 칸에서 내린다 — 가진 무기 · 방패와 가방의 아이템은 그대로라 잃는 것이 없다(다른 무기를
  들면 다시 멜 수 있다). 장비가 바뀌는 길은 모두 `arm_world`를 지나고 거기서도 내린다(기록에 남은 것까지). `set_sub_weapon` · `set_shield`는
  잠긴 칸을 건드리지 않는다. 장비 탭의 견줌(`stats_with`)도 같은 셈.
- **옛 기록**: 읽을 때 `Progress::lock_off_hand` — 맨손 + 방패 · 맨손 + 보조무기 · 맨손을 보조무기로 멘 기록은 칸만 빈다. 키(`weapon.sub` ·
  `shield.worn`)와 뜻은 그대로(시험 `an_old_save_with_fists_and_a_shield_or_off_hand_loads_with_nothing_lost`).
- **월드**: `World::set_sub`는 몽크면 보조무기를 받지 않고 메지 못하는 무기도 받지 않는다 — 바꾸기 버튼은 바꿀 것이 없어 아무 일도 없다(바꾸기는
  보조무기가 있을 때만 — 그 전에도 빈 칸이면 그랬다). 방패를 넘겨도 막지도 던지지도 않는다(양손 계열).
- **개발 창**: "주무기 바꾸기"의 차례에 "맨손 + 방패"가 없다(양손 계열이라), 맨손을 고르면 놀이터의 보조무기 · 방패 · "비우기" 표시를 내린다
  (`dev_arm`), "보조무기 바꾸기"의 차례에 맨손이 없다(`sub_ids` → `slings`).

### 버린 안
- **주특성 = 자세 피해 ×**: 한 줄로 끝나지만 "빠르고 가깝고 받아치는" 결을 못 담고 망치의 물리력과 겹친다 — 흐름(빠르기 · 맞으면 끊김)을 골랐다.
- **흐름이 가득이면 평타가 기력을 쓰지 않는다**: 모의에서 거의 닿지 않았고(아래) 박자의 덤과 겹친다 — 버렸다.
- **새 RB(장풍 · 기공탄)**: 새 꼴 · 그림 · 소리가 드는 만큼 얻는 것이 없다 — 돌을 지닌다.
- **손에 감는 천(새 아이템 바탕)**: 맨손의 등급 · 옵션 길. 가방 · 장비 · 떨굼 · 도감의 규칙을 넓혀야 한다 — 벼리기가 더 작은 바꿈이라 그것만.

## 모의(`balance::monk_probe` — 40판, 봇은 0281의 손: 종류의 스킬 둘 3레벨 · 틈의 RB · 막거나 구르기, 틈에는 평타를 틱마다 누른다)
몽크는 손바닥 치기 + 할퀴기(p+r)와 손바닥 치기 + 쓸어 차기(p+s) 둘을 돌려 싸움마다 나은 쪽, 다른 종류는 장비마다(한손검 빈 손 · 망치 · 쌍단검 ·
창을 멘 것 · 방패 / 쌍단검 빈 손 · 한손검을 멘 것 / 망치 빈 손 · 방패) 가장 나은 줄. 칸 = 이길 때까지의 초(이긴 판의 초 ÷ 이긴 몫) · 받은 피해 ·
이긴 몫. 몸 B = 첫 도착(레벨 3), E = 작업층 도달(레벨 10). "몽크의 자리" = 이길 때까지의 초로 넷 가운데 몇째.

- **고친 것(가장 작은 걸음)**: 처음 값에서 몽크는 이른 몸의 종지기에서 두 성공률 모두 세 잣대 가장 나빴고(34.2초 · 40.1초), 잡몹 스물에서도
  둘. 견준 손잡이(몽크 줄만 다시, 같은 씨앗): 흐름 1.3 → 1.5(보스 1~3% — 평타가 빨라질수록 기력이 먼저 바닥나 거의 닿지 않는다, 되돌림) ·
  흐름 가득이면 기력 없이(거의 같다, 버림) · 자세 피해 ×1.5(종지기 34.2 → 27.4초 — 폭 안) · ×2(성공률 0.5 종지기에서 가장 좋은 곳이 생김) ·
  주는 피해 +3(작업층 종지기 · 수사슴에서 가장 좋은 곳). **맨손의 자세 피해 ×1.5**만 넣었다(평타 0.5 · 0.5 · 1.2 → 0.75 · 0.75 · 1.8, 대시 1.0 →
  1.5, 강공격 2.0 → 3.0 — 맨손 줄만), 그리고 쓸어 차기를 한 바퀴(장대 휩쓸기의 꼴) → 두 바퀴(휘돌이의 꼴, 쿨 9초 그대로 — 7초는 재 보니 차이가
  없어 되돌렸다).
- **봇을 고쳤다**(`close_gap`): 0285까지의 봇은 모든 무기가 몸 사이 1.3 m에 섰다 — 첫 평타가 그보다 짧게 닿는 무기(맨손 1.26 m · 쌍단검 1.44 m)는
