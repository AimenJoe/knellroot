# 0141. 이펙트 다듬기 — 타격의 겹(번쩍임·불똥·먼지), 휘두름의 초승달, 몸짓 먼지, 화로 불티

- 날짜: 2026-11-10
- 상태: **구현**(`release/v0.6`, 판정 전). 사장 2026-11-10: "각종 이펙트들도 다듬어줘. 고도화가 필요해."
- 바탕: KB `concepts/game-feel-particles-and-light.md`(입자 세 무리 — 타격은 짧고 밝게·몸짓은 흙빛·분위기는 길고 낮게, 꾸밈만 상한, 정보가 담긴 입자는 2px부터, 상태 없는 환경 입자)·`melee-light-and-charged-attack-feel.md`, 바깥 자료(2차, 검색 요약): 타격은 한 겹이 아니라 쌓음(한가운데 번쩍임 1~2프레임 → 불똥·부스러기 → 남는 먼지), 이펙트 하나는 2~3색, 베기 이펙트 = 무기가 지난 호 한 장(스미어), 먼지는 착지·뛰기에.
- 그림: `docs/art/fx-0141/`(틱마다 찍은 장면 — `hits.png` 타격·쓰러짐, `moves-and-embers.png` 마법·뛰기·화로·회피).

## 리뷰 — 무엇이 있었나
이펙트는 스물 남짓 있었지만 꼴이 넷뿐이었다: **바닥 고리·부채꼴**(박자·모으기·패링·내려찍기·폭발 …), **1px 선**(불똥·탄의 꼬리), **정육면체**(마법 탄·종 조각·수류탄·모으는 빛·휘청의 별), 그리고 색. 놀이 정보(어디가 맞나·언제인가)는 다 있는데 "맞았다"·"움직였다"의 그림이 없었다.
| 무리(KB) | 있던 것 | 빠진 것 |
|---|---|---|
| 타격 | 불똥 여섯(1px 선 — KB 함정 "1px는 폰에서 안 보인다"), 히트스톱·카메라 킥 | 맞힌 자리의 번쩍임, 치명타·강타·패링·튕김의 구별, 쓰러짐, 폭발의 겹 |
| 몸짓 | 없음 | 뛰기·착지·회피·달리기·적의 돌진과 내리침의 먼지, 무기가 지난 호 |
| 분위기 | 반딧불·먼지·떨어지는 흙·높이 안개 | 화로(쉼터)가 멈춘 그림 |

## 정한 것
### 구조 — 월드는 이펙트를 모른다
- 새 모듈 `src/fx.rs`: `Fx`(입자 목록)가 **월드 사건**(`on_events`)과 **상태 변화**(`watch` — 회피 시작·뛰어오름·착지·달리기·적의 돌진·내리친 틱)를 듣고 입자를 낸다. 소리(`sfx`·`world_sounds`)와 같은 길로 앱이 넘긴다 — `world.rs`는 그대로다.
- 로직은 순수하다(난수 대신 번호 해시, 그림 핸들 없음) — 그래서 시험이 된다. 렌더는 `Backdrop::fx`가 `Fx::parts`를 읽어 그리기만.
- 입자의 꼴 넷: `Dot`(네모 화소 덩이)·`Streak`(날아가는 쪽으로 늘어난 빛줄)·`Puff`(커지며 옅어지는 계단진 원판 — 먼지·재·연기)·`Star`(끝이 뾰족한 네 갈래 번쩍임). 모두 카메라를 보는 판, 법선 패스 밖.
- 상한: 꾸밈(먼지)은 220개를 넘으면 새로 내지 않고, 타격은 420개까지(넘으면 가장 오래된 것부터) — 떼싸움 한가운데서도 맞힌 번쩍임은 뜬다.
- 히트스톱 동안은 입자도 1/4 빠르기 — 번쩍임과 불똥이 멈춘 몸과 함께 남는다.
- 빨강은 쓰지 않는다(위험 예고 전용, 0037) — 시험이 본다.

### 사건마다(2~3색씩)
| 사건 | 그림 |
|---|---|
| 평타 `Hit` | 따뜻한 흰 별(0.07초) + 월드의 불똥(1px 선 → 두 화소 굵기 빛줄) |
| 치명타 `Crit` | 큰 금빛 별 + 금 알갱이 사방 |
| 강타 `Smash` | 큰 별 + 돌 부스러기 + 발밑 먼지 고리 |
| 패링 `Parry` | 차가운 흰빛 큰 별 + 사방으로 빠른 빛줄 열둘 |
| 튕김 `Deflect` | 쇳빛 작은 별 + 플레이어 쪽으로 되튀는 줄 |
| 자세 깨짐 `Break` | 금빛 별 + 금 알갱이 |
| 쓰러짐 `EnemyDown` | 바랜 재가 풀려 오르고 뿌리의 보라 알갱이가 흩어진다(0037 — 침식 = 색을 잃은 것) |
| 내려찍기·여진 | 둘레 먼지 고리 + 튀는 돌 부스러기 |
| 벽 쿵 `Slam` | 별 + 먼지 + 부스러기 |
| 폭발 `Boom` | 큰 번쩍임 + 사방 불티 + 피어오르는 연기 + 바닥 먼지 |
| 등잔 `Gulp` | 따뜻한 빛 알갱이가 몸 둘레에서 떠오른다 |
| 마법 `Cast` · 딱 맞춤 `Perfect` · 다 모임 `Charged` | 손끝의 작은 번쩍임(라벤더 / 금빛) |
| 보스 깨어남 `Rouse` | 호박빛 큰 별 + 불티 열여섯 + 넓은 먼지 고리 |
| 맞음 `PlayerHurt` | 가슴 높이의 흰 별 + 옅은 라벤더 알갱이 |

### 몸짓·무기·분위기
- **먼지**: 회피를 시작한 자리(반대쪽으로 밀림), 뛰어오름·착지, 달리기(1.3m마다 한 덩이), 적의 돌진(0.09초마다), 적이 내리친 틱의 발 앞. 가만히 서 있으면 아무것도 안 난다(목적이 있을 때만).
- **휘두름의 초승달**: 활성 구간 동안 칼끝이 지난 자리에 밝은 초승달이 따라가고 0.12초에 옅어진다(가로 베기는 지나간 쪽에서, 찌르기·세로는 가운데에서 양쪽으로 — `render::slash_arcs`). 판정을 보여 주는 박자 부채꼴(0087)은 그대로 두고 그 위에 얹는다.
- **정육면체 → 마름모·별**: 마법 탄(빛무리 + 알맹이 + 뒤로 작아지는 꼬리 셋)·종 조각·수류탄(도화선은 깜빡이는 별)·모으는 빛·휘청의 별.
- **화로 불티**: 화로마다 다섯, 그릇에서 떠올라 흔들리며 식는다(상태 없음 — 시각과 번호로 자리를 낸다). 마무리 패스(0140)의 번짐을 받는다.

### 도구
- **F6(개발판)**: 한 프레임 = 한 틱. 0.1초짜리 이펙트는 실제 시간으로는 볼 수도 찍을 수도 없다(헤드리스는 초당 8프레임 남짓) — `tools/test/fx.js`가 이것을 켜고 동작마다 연달아 찍는다.
- 랩 `render.fx 0off 1on`(얼린 값에 덧붙임): 끄면 사건의 입자·초승달·화로 불티를 그리지 않는다. 탄·불똥·별의 새 꼴은 늘 쓴다.

## 해 보고 고친 것
- 먼지를 바닥과 같은 빛(0.50·0.48·0.62, 빛무리 텍스처)으로 두니 "낮은 대비로 깔리는" 게 아니라 **안 보였다**(화소 확대로 확인) → 바닥보다 한 단 밝게 + 속이 찬 원판 텍스처.
- 먼지 텍스처 8칸은 락온 거리에서 네모 벽돌처럼 보였다 → 16칸.
- 별을 네모 팔 둘로 그리니 "+" 표지처럼 읽혔다 → 끝이 뾰족한 마름모 둘.

## 확인한 것 / 못 한 것
- 확인: 틱마다 찍은 장면(`docs/art/fx-0141/`)에서 평타의 별·초승달·쓰러짐의 재·뛰기 먼지·적 내리침의 먼지·마법의 번쩍임·화로 불티·떼싸움 속 번쩍임. 시험 일곱(타격마다 번쩍임이 있고 큰 타격은 더 크다 · 빨강 없음과 패링은 차갑다 · 입자는 다 사라지고 같은 사건 = 같은 그림 · 꾸밈만 상한 · 회피 먼지는 한 번·뒤로 · 화로 불티의 자리 · 초승달의 각), `cargo test` 367, fmt·clippy 다섯 갈래.
- 못 함: **패링 성공·치명타·폭발·튕김·자세 깨짐·보스 깨어남은 장면으로 잡지 못했다**(시험으로만 — 박자를 맞춰야 나는 사건이라 헤드리스 연사로 못 냈다). 실제 60fps에서의 느낌(과한지·모자란지), 핸드헬드 비용(입자는 많아야 420개 = 판 420장)은 사람·실기 몫.
- 이번에 손대지 않은 것: 바닥 고리·부채꼴의 꼴(놀이 정보 — 0076~0108의 판정이 걸려 있다), 공격 예고, 소리.

## 판정(사람)
- 평타의 별·초승달이 "맞았다"·"베었다"로 읽히나, 박자 부채꼴과 겹쳐 어지럽지 않나.
- 패링의 차가운 별과 빛줄이 평타와 확실히 갈리나, 치명타·강타가 더 크게 느껴지나.
- 쓰러질 때의 재·보라 알갱이가 "풀려난다"로 읽히나(잔불 조각과 섞여 어지럽지 않나).
- 먼지가 과하지 않나(달리기·적 돌진), 떼싸움에서 화면을 가리지 않나.
- 화로 불티가 쉼터를 살아 보이게 하나, 너무 눈을 끌지 않나.
