# 0032. 쉼터(화로 체크포인트) — 쉬기·다시 일어서기

- 날짜: 2026-11-04
- 상태: 채택·구현. 설계는 `docs/design/items.md` 1(화로), 0026의 "구역을 잇는 선형 + 화로 체크포인트".
- 사장: "쉼터 만들어줘."

## 규칙
- 지도 글자 `R` = 쉼터 화로(보통 화로 + 표지). 침묵의 성소에 둘: **입구**(시작 자리 곁)와 **성소 문 앞**(뜰 북동쪽).
- 곁(`REST_REACH` 2.4m)에서 **상호작용(Y / G, `Bind::Interact`)** = 쉬기: 체력·등잔·스태미나 가득, 이 쉼터가 **다시 일어설 곳**. 화면 아래에 "키 쉬기", 터치는 락온 위에 모닥불 버튼(곁일 때만).
- **깨어 있는 적이 10m(`REST_SAFE`) 안에 있으면 쉴 수 없다**("적이 가까워 쉴 수 없다") — 잠든 문지기는 괜찮다. 싸움 한가운데서 쉬어 체력을 채우는 길을 막는다.
- **쓰러지면**: 쉰 적이 없으면 예전처럼 끝(결과 창). 쉬었으면 **그 쉼터 곁에서 가득 찬 채로 다시** — 진행은 쉬던 때로 되돌린다(`StageOut::Respawned`, 앱은 카메라만 그 자리로 옮긴다):
  - 물결 전·중에 쉬었으면 → **입구 단계부터**: 물결 적을 지우고, 문 닫고, 뜰에 다시 들어서면 첫 물결부터.
  - 물결을 끝내고 쉬었으면 → **문 앞부터**: 문은 열린 채, 문지기는 잠든 채 가득(깨어남·반 아래 빨라짐 되돌림).
- 쉬면 진행이 되살아나지는 않는다(소울라이크의 "떼가 되살아남"은 이 스테이지의 물결이 대본이라 쓰러졌을 때만 되돌린다). 저장(기록)은 아직 없다 — 쉼터는 한 판 안에서만 기억(`items.md` 7, 구현 B).
- 월드는 쉼터를 모른다: 월드는 "상호작용을 눌렀고 손이 비었다"(`World::interact`)만 내고, 스테이지가 거리·안전·진행을 정한다(경계 그대로).

## 붙인 것
- `Bind::Interact = 8`(G·Y), 저장 칸 18·19(prefs `CELLS` 20, 옛 저장은 그 동작만 기본값 — 0031의 규칙).
- 쉼터 발밑 테: 안 쉰 곳은 옅게, 다시 일어설 곳은 금빛으로 숨 쉬듯, 쉬는 순간 빛이 퍼진다.
- 시험 넷: 쉬면 가득 + 다시 일어설 곳, 적이 가까우면 못 쉼, 쉰 뒤 쓰러지면 쉼터에서·물결 처음부터(다시 뜰에 들면 첫 물결), 문 앞에서 쉬었으면 결투만 다시(문 열림·문지기 가득·잠듦).

## 다시 볼 조건
- 쉬지 않고 가다 쓰러져 끝나는 게 억울하면 입구 쉼터를 처음부터 켜 둔다(시작 = 쉼).
- 쉼터 사이가 멀거나 가까우면 지도에서 `R`만 옮긴다.
- 기록(B)이 생기면 마지막 쉼터를 기록에 적는다.
