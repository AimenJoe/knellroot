# 0070. v0.3.x 패치: 패링 멈춤·락온 넘기기·장비 창 십자·대시 공격·패링 반격, 그리고 Select·랩·장비 창 제안

- 날짜: 2026-11-06
- 상태: **1~5 구현**(개발판), **6~8 제안**(사장 확인 전 — 0065: 새 꼴은 스터디 → 제안 → 확인)
- 처음 말(사장 2026-11-06, v0.3.0 판정 중): "패링할때 약간 뒤로 가는듯한 느낌이 들어. 장비에 지금 착용중인 녀석 나올 필요 없을것 같은데… 더 나은 ui 설계 찾아보자. start / select 버튼에 각각의 역할이 있어야 해, lab 은 메뉴로 빠지고, 지금 lab 은 기존 ui 없을때 만든거라 마이그레이션 필요해. 락온 한 적을 처치했을때는 바로 근처에 있는 상대에게 락온 걸린 상태(혹은 근처에 아무도 없다면 락온 해제) 이런식이어야 해. 그 근처는 포인터(조준 기준). 장비창에서도 좌우 버튼으로 바꾸는거, 좌우로는 커서가 움직이는게 더 직관적이야, 정 빠르게 바꾸고 싶으면 화면회전 버튼으로 바꾸는게 더 좋을듯. 대시 중 공격, 패링 성공 후 강공격 등의 요소도 필요함."

## 구현(개발판)
1. **패링이 뒤로 물러나는 느낌**
   - 원인: 몸이 실제로 밀리지는 않았다. 패링을 누르는 순간 속도가 0이 되어(`vel = ZERO`), 2차 동작 층(0039 `secondary.rs`의 기울기 스프링)이 멈춘 몸을 뒤로 한 번 출렁이게 했다. 시험 `starting_to_run_…`이 "멈추면 앞으로 넘었다 돌아온다"를 보는 바로 그 움직임이다.
   - 고침: 패링도 걸음을 멈출 때와 같은 감속(`move.accel`)으로 선다. 달리다 누르면 앞으로 0.1~0.6m 미끄러진다.
   - 막기 자세(`wanderer.py` guard)는 몸을 칼 쪽으로 조금 더 숙이고 무게를 앞발로 옮겼다.
   - 시험 `a_parry_from_a_run_brakes_like_a_stop_not_a_wall`.
2. **락온 넘기기**
   - 락온한 적이 쓰러지면, 쓰러진 자리(락온 중의 조준 기준 = 그 대상)에서 `LOCK_HANDOFF` 8m 안의 가장 가까운 깨어 있는 적으로 넘어간다. 플레이어에게서 락온 거리 안인 적만 본다. 없으면 풀린다.
   - 소울류의 "다음 적으로 넘기기"다. 시험 `a_fallen_lock_target_hands_off_to_the_nearest_enemy_or_lets_go`.
3. **장비 창 십자**
   - 십자·스틱은 칸이 놓인 자리대로 커서만 옮긴다. 좌우는 무기 칸 ↔ 장신구 칸이고, 오른쪽으로 가면 무기와 같은 높이인 가운데 칸에 선다. 위아래는 장신구 칸 셋 안에서 돈다.
   - 빨리 바꾸기는 땅 돌리기 버튼(LT·RT / Q·E)이다. 아래 안내 줄에 "갈아 끼우기"를 더했다.
   - 순수 함수 `equip::slot_nav` + 시험. 헤드리스 `save.js`의 길도 → ↓ E로 바꿨다.
4. **대시 공격**
   - 회피를 끊고 누른 공격, 또는 회피가 끝난 뒤 `DASH_ATTACK_LATE` 0.15초 안에 누른 공격은 무기 표의 `dash` 한 타다(`weapons::DASH`, `Weapon::hit`·`after`).
   - 무기마다 다르다:
     - 검: 달려들며 찌르기 — 내딛기 2.4배, 좁게, 피해 2
     - 망치: 달려들며 한 바퀴 — 둘레, 피해 2
     - 지팡이: 빠른 찌르기 — 피해 1
     - 쇠뇌: 없다(회피가 한 발을 장전한다, 0051)
   - 맞힌 뒤 콤보는 둘째 타부터 잇는다.
   - 동작은 지금 있는 타(attack3·hammer2·staff3)를 다시 쓴다. 전용 동작은 판정 뒤에 만든다.
   - 시험 `attacking_out_of_a_dodge_is_a_dash_attack_that_chains_into_the_second_hit`.
5. **패링 반격**
   - 튕긴 뒤 `RIPOSTE_WINDOW` 0.6초 안에 누른 공격은 모으기 없이 **다 모은 강타**로 바로 나간다. 튕긴 적은 드러난 상태라 치명타(+`parry.crit`)가 더해진다. 강타가 없는 쇠뇌는 평타다.
   - 시험 `attacking_right_after_a_parry_is_a_full_heavy_riposte`.
- 수치(`LOCK_HANDOFF`·`DASH_ATTACK_LATE`·`RIPOSTE_WINDOW`·대시 타)는 새 값이라 얼린 기본값(0013)을 바꾸지 않는다. `tuning.rs`의 상수로 두었고, 판정에서 손맛이 갈리면 랩 값으로 올린다.

## 제안(사장 확인 전)
### 6. Start / Select
- **스터디**:
  - KB `controller-layout-and-remapping`: 액션 로그라이트 관례는 Select = 지도, Start = 메뉴. nail도 Select = 지도, Start = 메뉴다.
  - 바깥(2차 — 공략·포럼, 서로 엇갈림): Elden Ring은 Select(View) = 지도. Diablo IV 콘솔은 View = 지도, Menu = 캐릭터 창(장비)이라는 글과 그 반대라는 글이 엇갈린다.
  - 지금: Start = 멈춤, Select = 랩(개발)이다. 운영판에서는 Select가 하는 일이 없다.
- 우리는 지도가 없다(구역 하나, 미니맵 없음 — 0060 W1). 안 넷:
  - **A(추천)**: Select = **장비 창 바로**(멈춤을 거치지 않고, Diablo의 캐릭터 창 자리). 지도가 생기면(v0.4.0 이후) Select = 지도로 옮기고, 장비는 멈춤 첫 줄에 둔다.
  - B: Select = 상태만 보는 작은 창(장비는 멈춤에서).
  - C: Select = 도감(v0.4.0 C5가 들어오면).
  - D: Select 꾹 = 랩(개발판만), 톡 = 장비(A와 함께).
- 키보드: Tab(또는 I) = 장비, F1 = 랩(개발판만, 지금처럼).

### 7. 랩을 메뉴로(마이그레이션)
- **지금**: 0066 이전에 만든 오버레이다. 영어 기본 글꼴, 손으로 그린 상자, 랩 전용 입력 아홉(`lab_*`, 십자·LB·Y·B)과 터치 버튼 여덟이 있다. 게임은 계속 돈다(바꾸며 느끼기, `docs/lab.md`).
- **제안**:
  - 랩 = 멈춤 메뉴의 개발 줄 "랩" → `Scene::Lab`(0066 줄 표 몰이꾼). 줄 = `이름 ◀ 값 ▶`(값 줄 `Step`)이고, 바뀐 값은 색으로 보인다. 위에 줄 넷: 슬롯 B에 담기 · A/B 바꾸기 · 내보내기 · 모두 되돌리기. 고른 줄에서 확인 = 그 값만 되돌리기, 땅 돌리기 버튼 = 10배 걸음(장비 창과 같은 자리).
  - 터치는 몰이꾼의 ◀▶ 탭·끌기 굴리기를 그대로 쓰고, 랩 전용 버튼 여덟은 지운다.
  - 랩 입력 아홉(`lab_*`)과 터치 `Kind::Lab*`를 걷어 내 입력이 한 갈래가 된다.
  - **바꾸며 느끼기**는 창을 닫으면(Start·뒤로) 곧장 싸움이고, 다시 열면 같은 줄에 커서가 있다(0066 스택). 게임이 돌면서 바꾸는 지금 방식은 놓는다. 대신 창은 반투명 오른쪽 반쪽이라 장면이 보인다.
- 운영판에는 없다(`dev` 기능).
- 개발 줄(F3)·넘침 검사(F4)는 그대로 둔다.

### 8. 장비 창 — "지금 착용중인 녀석" (두 가지로 읽힌다)
- (가) **후보 목록에 지금 낀 것이 다시 나온다**는 뜻이면:
  - Diablo IV 콘솔은 낀 것을 목록에서 빼고 칸에만 둔 채 비교 창으로 견준다. Elden Ring·Dark Souls는 목록에 넣고 "E" 표시를 한다(2차).
  - 추천: **그 칸에 지금 낀 것은 후보에서 뺀다**(칸 상자와 설명의 "지금 → 바뀐" 비교가 이미 보여 준다). "빈 칸"은 칸이 차 있을 때만 둔다. 다른 칸에 낀 장신구는 "칸 N" 표지를 달고 남긴다(맞바꾸기). 바꿀 것이 없으면 "아직 장신구가 없다" 한 줄.
- (나) **가운데 인형(장비를 입은 방랑자)이 필요 없다**는 뜻이면(0067 D의 인형):
  - 인형을 빼고 왼쪽을 칸 넷의 세로 목록(아이콘 + 이름 + 한 줄 효과)으로 한다(Hades·Hollow Knight처럼 장비가 몸에 안 보이는 게임의 꼴).
  - 고른 것의 3D 그림은 설명 칸에 그대로 둔다(0068). 인형 렌더가 빠지는 만큼 창이 가벼워지고 폰에서 글이 커진다.

## 사장이 정할 것

2. 랩: 위 7처럼 멈춤 메뉴 안의 창으로 옮기고 "게임이 돌며 바꾸기"를 놓아도 되나(추천: 된다 — 닫으면 곧장 싸움).
3. 장비 창: (가) 후보에서 낀 것 빼기 / (나) 인형 빼기 — 어느 뜻이었나.
4. 1~5의 손맛(판정): 대시 공격 거리·피해, 반격 창 0.6초, 넘기기 8m.
