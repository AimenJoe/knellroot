## 새긴 돌(지도 `N`, 위에서부터 = 글 차례)
| 자리 | 한국어 | English |
|---|---|---|
| 종탑 터(문지기 앞) | 종은 두 번 친다. / 해 뜨는 때, 그리고 모두 돌아왔을 때. | Ring it twice: / at sunrise, and when everyone is back. |
| 뿌리 사이 골목(기둥 곁) | (이름은 닳아 읽을 수 없다) / 여기까지 컸다. | (The name has worn away.) / Grew this tall. |
| 위쪽 거주지(도착 곁) | 셋째 날마다 물. 첫째 날은 장작. / 종이 울리면 광장으로. | Water every third day. Firewood on the first. / When the bell rings, to the square. |

- 셋 다 **누가 살았다**는 것만 — 떠난 이유·남은 이유·깨진 종과 땅 밑 종소리의 관계는 말하지 않는다(숨길 것 넷). "모두 돌아왔을 때"는 떠남을 확정하지 않는 생활의 규칙이고, 개발자 답(0069 땅 위로 올라감)과도 어긋나지 않는다.
- 장치: `StageDef::stones`(글 표) + 지도 `N` → `StageRun::stones`·`near_stone`·`take_read`. 곁(2.2m — 주민 말 걸기와 같게)에서 상호작용 = 읽기(HUD "읽기"), 새긴 줄이 옅게 밝아진다. 글 판은 화면 위쪽 가운데 6초, 같은 돌을 다시 누르면 닫힌다, 싸움을 멈추지 않는다. 새긴 줄(`\n`)마다 끊고 그 안에서만 폭에 맞춰 나눈다. 지역을 바꾸면 닫는다.
- 그림: 조금 기운 선돌 + 새긴 줄 셋 + 밑동 이끼(상자 단계, 코드).
- 개발: 스테이지 "둘째 지역 새긴 돌 곁에서(읽기)".
