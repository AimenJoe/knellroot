# 0106. G2·G4 — 기술 나무 표·점수·종소리 조각·나무 창

- 날짜: 2026-11-07
- 상태: **채택·구현**(개발판). 0096 G2·G4, 칸·점수·자리는 0102 4·5·7절(사장 2026-11-07 인터뷰 "0102 안"). 칸의 **동작은 G5**(다음) — 지금은 열어도 싸움이 바뀌지 않는다.

## 무엇을
- **표 한 곳** `progression.rs`: 갈래 셋(박자 · 맞받기 · 발걸음 — 이름 + 태도 한 줄) × 다섯 칸(`TREE`, 0102 4절의 이름·설명), 칸마다 1점, 앞 칸을 열어야 다음 칸. 갈래마다 숫자 칸 하나(시험), 칸 이름은 장신구 이름과 겹치지 않는다(시험 — 한국어·영어).
- **점수** = 문지기 핵(이길 때마다·셋까지, 0105) + 주운 **종소리 조각**. 남은 점수 = 점수 − 연 칸 수.
- **종소리 조각**: 숨은 물건(0105)의 셋째 종류 `Find::Shard`(지도 `K`, 기록 `sanctuary.shard.n`). 성소에 셋 — 입구 방 무너진 벽 조각 뒤, 뜰 서쪽 높은 단 뿌리 뒤(땅 돌리기로 각을 바꾸면 보인다), 성소 북쪽 턱 위(점프). 그림은 가늘고 긴 크림빛 조각이 천천히 돌며 떤다 — 덩어리(등잔·한 모금)와 모양이 다르고, 종 꼴이 아니다(lore — 이름이 출처를 정하지 않는다).
- **기록** `tree.beat`·`tree.riposte`·`tree.footing`(갈래마다 연 수 0~5 — 칸 이름이 아니라 수라 칸을 고쳐도 연 수는 그대로), `tree.pin`("갈래.깊이").
- **나무 창**(`Scene::Tree { view }`, `app/tree.rs`, KB `meta-progression-unlock-planning`): 다 보이기 — 갈래 셋을 세로 다섯 칸으로, 칸 밝기 네 단(열림 = 호박빛 면 · 열 수 있음 = 호박 테가 숨 쉼 · 점수 모자람 · 앞 칸 먼저 = 어둡게), 제목 줄에 남은 점수, 아래에 고른 칸의 이름 · 상태("1점으로 연다" · "거기까지 n점" · "목표까지 n점") · 설명 두 줄. 십자 좌우 = 갈래, 위아래 = 깊이, 터치는 고르고 다시 누르면 확인.
  - **화로**에서(`view = false`): 열 수 있는 칸에서 확인 = 묻는 창 `Ask::Tree`(커서 "열기") → 연다.
  - 아직 못 여는 칸에서 확인 = **목표 핀** 꽂기·빼기(◆). 화로의 "나무" 줄 설명이 "목표까지 n점"(메뉴에서도 길 표시), 그 칸을 열면 핀이 풀린다.
  - **멈춤** "나무"(`view = true`, 셋째 줄): 읽기·핀만, 열 수 있는 칸은 "칸은 쉼터 화로에서 연다".
- **화로 줄** 넷: 레벨 · 나무(남은 점수) · 가게 · 떠나기. 쉼터 빛남 = 살 것 · 올릴 단 · 열 칸 중 하나라도.
- 글 54줄(한국어·영어), 서브셋 다시(756자).

`shot.js`가 문 앞 시나리오를 여는 순간 `glBindTexture … already deleted` 6번. 이번 글은 아니고 원인은 옛 것: **개발 창 글(`i18n/dev.rs`)이 글자 미리 굽기(`ui::all_text`)에 빠져** 개발 창을 여는 프레임에 아틀라스가 커졌다(`text.rs` 주석의 macroquad 성질). 미리 굽는 글자가 늘어 아틀라스 여유가 없어지자 드러났다 — G3 커밋을 따로 빌드하면 0번, 지금 글꼴을 G3 것으로 바꿔도 6번, 지도를 되돌려도 6번으로 좁혔다. 개발 글 목록을 `i18n::dev_texts`로 빼 글꼴 시험과 미리 굽기가 같이 쓴다 → 0번. 운영판(개발 창 없음)은 해당 없음.
