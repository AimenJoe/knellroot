# 0256 — 설정의 전체 화면 줄 · 모션 보기의 소리 · 넘치는 탭 · 동작 다듬기(숙임·끝 자세·회피 길이·팔 가중치)

- 날짜: 2026-11-19
- 상태: 정함(사장 2026-11-19 — 아래 인용) — 실기 확인 전

## 사장의 말
"살정 매뉴의 전체화면 켬/끔은 왜 달라? · 개발 매뉴의 모션 플레이 에서 이상한 소리가 반복되네 · 뒤로뛰기, 점프는 거의가 너무 숙여져 있고
내려찍고 일어나기, 줍기는 끝 자세에서 고개가 숙여져 있음 · 회피는 너무 속도가 빨라 · 손이 움직이는 게 아니라 옷이 움직이는 게 있음(맨손으로 확인) ·
모션 메뉴의 탭도 화면을 벗어나는게 있네 — 다른 메뉴들도 이렇게 될지 확인 필요"

## 고친 것
1. **전체 화면 줄**: 혼자 화살 없는 값 줄(`Row::value`)이었다 — 다른 켬/끔 줄처럼 ◀▶ 줄(`Row::step`), 좌우로도 켜고 끈다.
2. **모션 보기의 반복 소리**: 모션 보기는 재생 시각을 장면(`Scene::Motions { t_ms }`)에 들고 다녀 틱마다 값이 바뀐다 — 메뉴 소리 한 곳(`App::frame`)이
   "장면이 바뀌었다"로 읽어 확인 소리(0.28초)를 틱마다 냈다(헤드리스: 22초에 80번). 모션 보기끼리는 바뀐 장면이 아니다 → 커서를 옮길 때만 소리.
3. **넘치는 탭**: 개발 창의 묶음 탭·모션 보기의 무기 탭은 한 줄에 다 넣고 남는 폭만 나눴다 — 모자라면 창 밖으로 나갔다(무기 여섯).
   `ui::tab_rects`: 한 줄에 들면 꽉 채우고, 안 들면 여러 줄로(줄마다 탭 수를 고르게). 큰 창의 탭 줄은 0233의 가로 띠(`ui::Strip`) 그대로,
   도감의 묶음 머리는 넷이라 들어간다 — 그 밖의 창은 헤드리스 넘침 검사(F4 `ui-check`)로 본다.
4. **숙임**: 뛰어넘기(`jump`)·뒤로 뛰기(`dodge_back`)를 `LEAN_CAP` (몸 18°·머리 20°)로 — 공중에서도 몸이 거의 선다.
5. **끝 자세**: 내려찍고 일어나기(`plunge_land`)·줍기(`pickup`)는 끝의 0.22·0.30초 동안 숙임 상한이 90° → 15°로 줄고(`END_UPRIGHT`),
   고개는 서기의 들기(15°)로 서서히(`HEAD_SETTLE` — `land`·`dodge_rise`도) — 중간의 숙임(내려찍은 순간·줍는 순간)은 그대로.
6. **회피 길이**: 0.25 → 0.32초(`tuning::DODGE_TIME` — 얼린 값을 사장 판정으로 바꿈, `docs/tuning-frozen.txt`), 거리 3 m 그대로라 초속 12 → 9.4 m.
   구르기·뒤로 뛰기의 시간표도 같은 배(×1.28). **무적도 회피 내내라 0.07초 길어진다** — 판정할 것.
7. **팔 가중치**: Meshy 자동 리깅이 망토 자락까지 팔 뼈에 묶었다(오른 위팔 정점 254개의 중앙값이 팔 뼈대에서 0.14 m, 가장 먼 것 0.3 m — 키 1.4 m 몸).
   주먹을 뻗으면 손 대신 망토 앞자락이 판자처럼 나갔다. `confine_arms`: 위팔·아래팔 가중치를 거리로 줄여(0.07 m 안 그대로 → 0.12 m 밖 0) 가슴으로 —
   정점 280개·가중치 10.2. 손·손가락 무리는 그대로.

## 덧입히기(몸 + 옷)를 했어야 했나
옷 갈아입기가 필요하면 그 길이 맞다. 이 주인공은 한 벌이라 한 메시의 가중치 손질이 싸다 — 덧입히면 옷이 몸을 뚫는 문제를 새로 풀어야 하고
그리는 정점도 는다(지금 4,795 / 예산 4,800). 덧옷(0176)을 몸에 그리기로 할 때 다시 본다.
