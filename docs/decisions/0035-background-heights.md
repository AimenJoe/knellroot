# 0035. 배경 높낮이 1단계(그림만) + 외곽선 껍데기 뒤로 밀기

- 날짜: 2026-11-04
- 상태: 채택·구현. 2단계(걸을 수 있는 층·경사로·적 길찾기)는 **다음 구역 때**(사장).
- 지금(2026-11-05 결정 검토, 0066 때): "2단계는 다음 구역 때"를 0043이 바로 했다.
- 사장: "배경에 높낮이를 넣으려면 어떠헤 해야할까?" → 세 단계(그림만 / 걸을 수 있는 층 / 점프로 오르내리기)를 보이자 "1단계 먼저 하고 2단계는 다음 구역 때 하자".

## 정한 것
- 지도와 같은 크기의 **둘째 격자** `StageDef::heights`(글자 `0`~`9` = (숫자 − 2)m, `2` = 바닥 높이, `.` = 기본). 걸을 수 있는 칸·문·표지에는 높이를 줄 수 없다(시험) — **월드는 평평한 땅 하나 그대로**(부딪힘·이동·타격 무관). 2단계 때 이 격자를 그대로 걸을 수 있는 높이로 넓힌다.
- 굽기(`scenery.rs`): 바깥 칸이 **높으면 바위 단**(이끼 낀 흙 윗면, 몇 칸엔 돌덩이, 가림 상자가 있어 카메라 앞을 막으면 옅어진다), **낮으면 꺼진 바닥 + 더 높은 이웃 쪽 벼랑면**(위 모서리는 벽돌빛, 바닥 쪽은 어둡게) + 떨어진 돌덩이. 꺼진 땅 곁의 성벽은 그 바닥까지 내려 그린다. 벽 칸에 높이를 주면 벽 꼭대기. 허공 판은 가장 깊은 꺼진 땅 아래로(`Scenery::void_y` — 깊이 버퍼가 생겨 허공 판이 구덩이를 덮었다).
- 침묵의 성소: **성소 둘레(북쪽 바깥)는 바깥·뒤로 갈수록 +2 → +7m로 오르는 바위 단** — 언덕을 파고든 성소(보스전 숄더뷰 뒤에 보인다). **입구 다리 길 양옆은 −2m 낭떠러지**, 남쪽 입구 둘레는 −1~−2m(땅 돌리기로 돌려 보면 벽 너머로 보인다). `docs/art/heights-0035/`.

## 덤 — 외곽선 껍데기를 카메라에서 0.18m 뒤로(0033 고침)
- 쿼터뷰(캐릭터 ≈ 30px)에서 부위마다 1px 안쪽 선이 몸을 까맣게 했다(팔·몸·소매 사이). 껍데기 정점을 카메라에서 `OUTLINE_PUSH` 0.18m 밀어, 뒤 부위가 그만큼 떨어져 있을 때만 안쪽 선이 남고 바닥·배경 앞의 바깥 테는 그대로(`docs/art/look-0033/outline-push.png`: 깊이만 / 0033 / 민 것).
- 방랑자가 여전히 어두운 것은 모델 팔레트(숯빛·청회)다 — 조사의 2번(텍스처 명도·고유 칸).

## 다음(2단계, 다음 구역)
- 칸 높이를 걸을 수 있게: 월드 땅 높이 함수(플레이어·적 y), 턱 = 벽, 경사로 칸, 적 격자 길찾기(BFS), 타격 높이 차, 그림자·예고·카메라 y. 턱 가장자리 표시(밝은 테·난간 — 쿼터뷰에서 턱이 안 읽힌다는 플레이 후기, 2차).
