## 고칠 일(제안)
- **W1 길 안내(S1)** — 미니맵 없이 세 겹:
  1. 환경: 문이 열리면 문틀과 문 너머에 호박색 빛(불이 켜진다). "호박색 불빛 = 갈 길"을 스테이지 내내 같은 규칙으로(관례: 순간의 길은 환경 단서로, 규칙은 일관되게 — 2차).
  2. 화면 밖 표시: 문이 화면 밖이면 잠깐 뒤 화면 가장자리에 문 아이콘 + 그쪽 화살(맥박), 화면 안에 들어오면 사라진다(nail 0159 `exit_at`와 같은 장치).
  3. 목표 글: "성소의 문이 열렸다" → 갈 곳을 말하는 글로(예: "열린 문으로").
  - 미니맵은 하지 않는다: 스테이지 하나·길이 거의 한 줄이고, 땅 돌리기로 화면이 90°씩 돌아 지도 위쪽과 화면 위쪽이 자주 어긋난다. 구역이 여럿이 되면 다시 본다.
- **W2 바닥(S4)** — 지금은 칸마다 같은 색 1m 석판 넷 + 회반죽 틈, 정점 색뿐이라 결이 없다. 레트로 로우폴리의 결은 대부분 작은 텍스처에서 온다:
  작은 픽셀 텍스처(석판·이끼·금·회반죽, 스크립트로 생성) + 칸마다 크기·색·높이 흔들림 + 벽 밑 그늘. 바닥은 이미 빛 지도 텍스처를 쓰므로(0044) 결과 빛을 한 장으로 굽는 식이 될 것.
  - → **0061이 고침**: t3ssel8r 풍 기준이라 높낮이·석판 모서리(밝은 선)·풀 빌보드·팔레트가 먼저, 텍스처는 보조.
- **W3 적 셋(S4)** — 0037의 2단계 그대로, 방랑자와 같은 길(0038: 그림 → Meshy → 부위 자르기·뼈·동작). 사람 할 일이 있다(그림·Meshy 실행). 순서는 화면에 가장 오래 있는 문지기부터(0037은 잔재부터였다).

## 구현
- **W1 길 안내(2026-11-05, 사장 "진행해")**: `StageRun::goal()`(문이 열리면 문, 핵이 남으면 핵, 싸우는 동안 없음) →
  - 렌더: 갈 곳에 호박색 빛기둥 둘(바깥 옅게·안쪽 밝게, 위로 갈수록 사라짐) + 발밑 고리, 숨 쉬듯. 같은 자리에 빛 하나를 더해 곁의 모델이 물든다(바닥은 구운 빛이라 그대로).
  - HUD: 갈 곳이 화면 밖에 1초 넘게 있으면 가장자리(테두리에서 12% 안)에 길쭉한 호박색 화살촉 + 갈 곳 마름모, 어두운 테두리, 맥박(`camera::world_to_ndc`·`edge_marker`, `hud::draw_goal_arrow`). 카메라 뒤에 있어도 그쪽 가장자리.
  - 목표 글: "성소의 문이 열렸다" → "열린 문으로 성소에 들어가라"(영어 "Enter the sanctum through the open gate").
  - 시험: `a_goal_off_screen_gets_an_edge_arrow_pointing_at_it`, 스테이지 대본 시험에 갈 곳(문 → 없음 → 핵). 헤드리스: 문 앞에서 빛기둥, 걸어 나가 돌아서면 왼쪽 위 가장자리 화살이 빛기둥 쪽을 가리킴.
  - 사람이 볼 것: 문이 열린 뒤 처음 하는 사람이 헤매지 않는지(S1), 빛기둥이 지나치게 밝거나 싸움을 가리지 않는지.

- **W2 바닥(2026-11-05, 0061 기준)** — `scenery.rs`:
  - 바닥을 걷는 면 아래로 판다: 회반죽 −8cm, 석판 꼭대기 −5~−1.5cm(`MORTAR_Y`·`SLAB_*`) — 예고·그림자·고리(바닥 위 2~3cm)가 석판에 묻히지 않게(처음엔 석판을 3~9cm 올렸다가 이것을 보고 내렸다).
  - 석판: 칸(2m)마다 1m 넷, 짝 둘은 28%로 긴 판 하나, 높이 들쭉날쭉, 15%는 한 변이 3cm 들림, 7%는 빠져 흙 + 풀 셋. **옆면**이 있어 카메라 쪽 모서리에 0061의 밝은 선이 붙는다(옆면 법선은 바깥).
  - 풀 다발(`tuft`): 굵은 세모 잎 일곱(폭 10cm·키 30~50cm — 화면 1px ≈ 3.5cm라 처음의 7cm·16cm는 안 보였다), 밑동 어둡고 끝 밝은 바랜 청록, 법선 위(바닥과 같은 빛). 빠진 석판 자리와 벽 칸에 닿은 변의 반.
  - 벽 밑 그늘: 빛 지도를 구울 때 벽 칸까지 0.6m 안이면 최대 45% 어둡게.
