# 0034. 방랑자 동작 더하기 — 락온 게걸음·뒷걸음, 모으기·강타 다시, 땅 돌리기 휙, 등잔 들기

- 날짜: 2026-11-04
- 상태: 채택·구현(스크립트 `tools/art/blender/wanderer.py` → `wanderer.glb`).
- 사장: "에니메이션도 몇개 추가되어야해, 락온시 좌우 스텝이라던지, 강공격에 대한 모으기 및 공격모션. 그리고 화면 회전시 몸을 낮추고 획 도는 회전 모션, 물약 사용 모션 등등."

## 더한 것·바꾼 것
| 동작 | 길이 | 모양 | 게임이 고르는 때 |
|---|---|---|---|
| `strafe_l`·`strafe_r` | 0.6초 고리 | 칼을 앞에 겨눈 채 다리를 벌렸다 모으는 게걸음, 몸을 가는 쪽으로 살짝 | 락온 중, 걷는 쪽이 옆(옆 성분 > 앞 성분 × 1.2) — `render::move_anim` |
| `walk_back` | 0.7초 고리 | 겨눈 채 짧게 뒤로 | 락온 중, 걷는 쪽이 뒤 |
| `charge` | 0.3초(끝 자세를 쥔다) | 두 손으로 칼을 오른 어깨 뒤 높이, 몸을 낮게 비틀어 감고 망토가 뒤로 | `PState::Charging`. **다 모이면 몸이 잘게 떤다**(렌더 흔들림 1.8cm) |
| `heavy` | 0.58초 | 크게 내디디며 낮게 내리치기(칼끝이 땅 가까이), 무게로 잠깐 머문다 | `PState::Heavy` |
| `turn_r`·`turn_l` | 0.25초 | 낮췄다가(0.06) 윗몸이 도는 쪽으로 먼저 휙(0.13) 몸이 따라와 선다 | `PState::Turn` — 쪽은 `world::turn_is_right`. **몸 방향 돌기도 직선 → 천천히-빠르게-천천히**(smoothstep) — 동작과 같은 박자 |
| `drink` + 등잔 | 0.8초 | 왼손에 **등잔**(놋쇠 몸 + 스스로 빛나는 불꽃)이 나타나 입에 대고 내린다 | `PState::Drink` |
- 등잔은 평소에 크기 0인 뼈(`Model.hide`, `common.py` — 동작이 `'s': 1`을 줄 때만 보인다). 다른 동작엔 손대지 않아도 숨는다.
- 옛 `turn`은 `turn_r`·`turn_l`로 갈렸다(렌더는 없으면 `turn`으로).
- 정점 684(예산 700 — 등잔 받침은 빼서 맞춤), `check_glb.py`가 새 동작 여덟을 길이까지 본다.
- 시험: `move_anim`(락온 옆 = 게걸음, 뒤 = 뒷걸음, 락온 아님 = 걷기), `turn_is_right`(오른쪽 버튼 = 오른쪽 동작).

## 보지 못한 것·다음
- 게걸음의 다리 벌림·뒷걸음은 헤드리스 화면이 작아 잘 안 보인다 — 개발판에서 손으로.
- 뒷걸음 중 카메라가 기둥에 걸려 화면이 기둥으로 찼다(락온 카메라 충돌, 동작과 별개) — 따로 본다.
- 잡몹·보스 동작은 그대로.
