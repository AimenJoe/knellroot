## 원칙(이 게임에)
1. **세 겹을 지킨다**(KB): 무기 = 모양, 장신구 = 갈아 끼우는 수치, 영구 = 레벨(숫자) + 나무(동작). 셋 다 `Stats::compute` 한 곳으로.
2. **실력 창은 성장으로 흐리지 않는다.** 박자 창·패링 창·딱 맞춰 떼기 창은 레벨로 넓히지 않는다 — 넓히는 것은 장신구(종지기의 귀)처럼 **맞바꿈이 있는 것**만. 나무는 창을 넓히는 대신 "맞혔을 때 더 좋은 일"을 준다.
3. **정수 피해**: 무기 피해가 1~3이라 "힘 +1"은 피해를 두 배로 만든다. 힘은 자세 피해(%)·강타에 얹고, 평타 피해 +1은 드물게(단계 끝).
4. **화폐는 둘을 넘지 않는다**(KB: 작은 게임은 화폐 하나 + 앞 칸 잠금이 읽기 쉽다). 잔불(돈) + 하나.
5. **다 보이게**(KB `meta-progression-unlock-planning`): 나무의 모든 칸·값·거기까지의 합계, 목표 핀.
6. 갈래는 이 게임의 동사로 — 새 동사를 늘리기보다 있는 동사의 깊이.

## 제안(추천)
### A. 레벨 = 잔불로, 화로에서(숫자)
- 화로 메뉴에 "레벨" — 능력치 **셋** 중 하나를 한 단 올린다. 레벨 숫자 = 세 줄 단의 합(타이틀·이어하기 목록에 보일 수 있다).

| 줄 | 한 단 | 단 수(초안) | 메모 |
|---|---|---|---|
| **생명** | 최대 체력 +1(하트) | 5(5 → 10) | 지금 핵의 "체력 +1"을 여기로 |
| **기력** | 최대 기력 +12, 3·5단에 기력 차는 빠르기 +10% | 5 | 회피·달리기·패링·평타가 모두 기력이라 "더 오래 싸움" |
| **힘** | 자세 피해 +12%, 3단에 강타 피해 +1, 5단에 평타 피해 +1 | 5 | 정수 피해를 지키려 대부분 자세(0051)에 |

- 값: 다음 단 값이 오른다(초안: 30 → 45 → 65 → 90 → 120, 줄마다 같은 표). 모두 올리면 대략 1,050 — 한 구역 몇 판 + 둘째 구역에서 채워지는 크기. 둘째 구역이 오면 단을 늘린다(표 한 줄).
- 단마다 상한이 있는 **짧은 하드 캡**. 소프트 캡보다 1인 개발·판정이 쉽다(값 표가 곧 곡선).
- 잔불은 잃지 않는다(0026 그대로) — 소울식 "주우러 가기"는 넣지 않는다.
- 되돌리기(다시 나누기): 처음엔 없음. 둘째 구역 화로에 "기억을 푼다"(잔불 조금)로 나중에.

### B. 기술 나무 = 핵으로(동작)
- 문지기 핵 + 숨은 곳의 **"종소리 조각"**(새 줍는 것, 구역마다 둘~셋)이 기술 점수. 화폐 둘(잔불·조각)로 끝.
- 갈래 **셋 × 다섯 칸**(nail 재주 나무의 꼴, 칸 모양은 같고 내용만 이 게임 것). 앞 칸을 열어야 다음 칸. 한 게임에서 받는 점수는 칸 수보다 적게(초안: 둘째 구역까지 8~9점 / 15칸) — 갈래 하나는 끝까지, 하나는 반쯤.
- 칸은 **동작을 바꾸는 것**이 중심, 숫자 칸은 갈래마다 하나까지(같은 덤 ≤ 2, KB).

| 갈래 | 키우는 동사 | 칸 예(초안 — 정할 것 3) |
|---|---|---|
| **박자**(칼) | 평타 콤보·박자·딱 맞춰 떼기 | ① 박자 셋을 잇달아 맞히면 다음 타에 작은 충격파 ② 박자 타가 자세 피해 +50% ③ 딱 맞춰 뗀 강타가 기력을 돌려줌 ④ 콤보 마지막 타도 박자를 탐(지금은 없음) ⑤ 박자 다섯 잇기 = 잠깐 기력 0 소모 |
| **맞받기**(방패) | 패링·이어 패링·모으기 패링·반격 | ① 패링 성공 기력 +10 더 ② 이어 패링 첫 창 +0.05초가 아니라 "튕긴 적이 드러나는 시간 +30%" ③ 반격 강타가 둘레 적도 휘청 ④ 모으기 패링 성공 시 강타 피해 +1 ⑤ 뿌리 파동(못 받는 공격)을 반쯤 받음 |
| **발걸음**(바람) | 회피·달리기·땅 돌리기·점프·내려찍기 | ① 회피 끝에 대시 공격 창 +0.2초 ② 달리기 기력 −30% ③ 땅 돌리기 휘청 범위 +1m ④ 내려찍기가 작은 고리를 한 번 더 ⑤ 완벽 회피(맞기 직전 회피) 뒤 잠깐 느려지는 시간 |

- 화면: 화로 메뉴 "나무"와 멈춤 탭(읽기 전용), KB 꼴 그대로 — 다 보이기·칸 그림·밝기 네 단·거기까지 n점·목표 핀.
- 지금의 **핵 고르기는 나무로 대체**: 체력은 레벨(생명)로, 등잔 +1·한 모금 +1은 **가게·숨은 물건**으로(소울의 에스트 조각처럼 — 탐험의 보상).

### C. 장비는 그대로
- 무기(모양)·장신구(수치, 세 칸) 그대로. 장신구는 레벨·나무와 겹치지 않게 "맞바꿈이 있는 것" 위주로 늘린다(0069 C6).

## 다른 안
| 안 | 무엇 | 좋은 점 | 아쉬운 점 |
|---|---|---|---|
| **추천 = A + B** | 숫자는 잔불 레벨, 동작은 핵·조각 나무 | 잔불이 끝까지 쓸 곳, 빌드가 동작으로 갈림, 실력 창은 그대로 | 만들 화면 둘(레벨·나무), 조각 놓을 곳 설계 |
| 레벨만(소울식) | 잔불로 능력치, 나무 없음 | 가장 작다 | 동사가 커지지 않음 — 숫자만 커진다 |
| 나무만(Sekiro식) | 레벨 없이 잔불 = 기술 점수(일정량마다 1점) | 화폐 하나, 실력 게임에 맞다 | 잔불을 다 쓴 뒤 다시 쌓이기만 함, 체력 성장 길이 따로 필요 |
| 레벨 점수로 나무까지 | 레벨 오를 때마다 능력치 + 나무 점수 | 한 줄로 다 됨 | 잔불을 모으면 나무까지 다 열려 고를 맛이 줄어듦 |

## 정할 것(사장)
1. 큰 틀: **A + B(추천)** / 레벨만 / 나무만 / 레벨 점수로 나무까지.
2. 레벨 줄 셋(생명·기력·힘)이 맞는지 — 넷째로 "집중"(마법 칸·등잔 회복)을 둘지.
3. 나무 갈래 셋(박자·맞받기·발걸음)과 칸 내용 — 위는 초안. 더하거나 뺄 동작.
4. 핵 고르기를 나무로 바꾸고 등잔 +1·한 모금 +1을 가게·숨은 물건으로 옮길지.
5. 언제: v0.4.0(둘째 구역, 0069)에 같이 / v0.3.x 패치로 레벨만 먼저 / v0.5.0.

## 순서(채택하면, 단계마다 패치)
1. `progression.rs`: 레벨 표(줄·단·값)·나무 표(갈래·칸·덤), 기록 키(`lv.*`·`tree.*`·`shard.*`), `Stats::compute`에 한 줄씩 + 시험(값 곡선·상한·같은 덤 ≤ 2·모든 칸이 그림을 가짐).
2. 화로 메뉴 "레벨"(줄 표 화면 0066) — 숫자는 장비 창과 같은 `지금 → 다음 ▲`.
3. 나무 화면(화로·멈춤 탭, KB 꼴) + 핵 고르기 걷기(옛 기록의 핵 고르기는 레벨·점수로 옮겨 잃지 않게).
4. 동작 칸들(갈래마다 시험 하나 이상) + 종소리 조각 자리.
5. 값·단 판정(사람) → 얼림(0013).
