# 0239 — 큰 머리로 구르기: 땅 위로 띄워 뛰어들며 구른다

- 날짜: 2026-11-18
- 상태: **결정 + 만듦**(개발판 `release/v0.7`, 판정 전)
- 사장: "머리가 큰게 문제구나, 구를때 몸을 아무리 둥글게 말고 굴러도 옆으로 구르거나 땅속에 머리가 박히는것 처럼 보일수 있겠네.. 조금 점프 해서 구르면 괜찮나?"

## 잰 것
- 원본 Roll_Dodge_3(어른 몸의 Meshy 동작)을 방랑자 몸(키 1.4 m, 머리가 크다)에 입혀 원본 프레임마다 몸의 가장 낮은 정점을 쟀다:
  머리가 바닥 아래 **0.57 m**(12~14 — 키의 40%), 닿을 때 다리·꼬리가 0.3 m(20~24). 엉덩이(0.4 m)를 축으로 도는데 머리 끝이 엉덩이에서 0.7 m라
  아무리 말아도 땅을 판다 — 사장의 짐작 그대로.

## 고침(`wanderer_skin.py` `GROUND_CLEAR`)
- 그 원본을 쓰는 동작(구르기·일어나기)의 엉덩이를 원본 프레임마다 "가장 낮은 정점이 바닥 + 2 cm 위"에 필요한 만큼 올린다 — 필요량마다 종 모양(폭 4프레임)을
  겹친 위 테두리라 매끈하고, 같은 원본의 곡선이라 구르기 → 일어나기 이음매도 같다. 결과는 저절로 **뛰어들며 구르기**(Enter the Gungeon의 구르기 꼴):
  꼭대기 0.59 m.
- 게임 쪽은 그대로(회피 0.25초·3 m·무적, 충돌은 발 자리) — 몸만 뜨고 그림자는 땅에 남아 뛴 것이 읽힌다.

## 확인
- 옆에서 본 미리보기(앞·뒤 10장씩): 고치기 전엔 4~5장에서 머리가 바닥선 아래, 고친 뒤엔 내내 바닥 위. `check_glb`(새 지적 없음), `cargo test` 742.

## 남긴 것
- 0.59 m는 키의 40%라 "작은 점프"보다는 공중제비에 가깝다 — 낮추려면 몸을 더 마는 원본(짧은 구르기)이 필요하다(Meshy 동작 라이브러리에서 고르면 크레딧 없이).
