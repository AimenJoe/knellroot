# 0227 — 원거리 조준 다시 보기: 0223 버튼 맞바꿈 뒤 어긋난 곳 둘

- 날짜: 2026-11-17
- 상태: **고침**(개발판 `release/v0.7`, v0.7.0 PR #28에 함께)
- 사장: "원거리 무기 조준 방식 다시 확인해줘"
- 바탕: 0213(쇠뇌는 가까운 적을 찾지 않는다), 0217(터치 끌어 조준), 0218(곧은 볼트·진실한 표시), 0219(패드 보조·숄더뷰 = 카메라 앞,
  "근접의 쪽은 섞지 않는다"), 0222(숄더뷰 크로스헤어), 0223(RB = 평타 — 원거리는 평타가 사격·특수가 수류탄).

## 지금의 규칙(한 장으로)
| 보기 · 장치 | 원거리가 겨누는 쪽 | 표시 |
|---|---|---|
| 쿼터뷰 · 마우스 | 커서가 땅에 닿는 점 쪽(몸도 그쪽을 본다, 0058) | 쏘거나 모으는 동안만 연한 띠 |
| 쿼터뷰 · 패드 | 오른쪽 스틱 쪽 + 그 쪽 ±8° 안의 적에 붙임(스틱을 안 기울이면 없음) | 스틱을 기울인 동안 연한 띠 |
| 쿼터뷰 · 키보드만 | 겨누는 손이 없다 → 락온 > 바라보는 쪽 | 쏘는 동안 띠 |
| 쿼터뷰 · 터치 | 끌면 끈 쪽(락온보다 앞), 톡이면 가까운 적, 가운데로 되돌리면 취소 | 끄는 동안 띠·터지는 원 |
| 숄더뷰 · 모든 장치 | 화면 가운데 시선이 지나는 적 > 카메라 앞(패드면 ±8° 보조) | 화면 가운데 크로스헤어(적이 걸리면 호박빛) |
| 락온 | 대상 (터치로 끈 것만 앞선다) | — |

- 쇠뇌는 겨누는 손이 없으면 가까운 적을 찾지 않는다(0213), 마법 탄은 찾는다. 높이는 0218의 곧은 줄(줄 위 첫 적의 몸통).
- 버튼: 원거리 무기는 평타(RB·왼쪽 클릭·J·터치 큰 버튼) = 사격(꾹 = 모은 사격), 특수(X·오른쪽 클릭·U·터치 별 버튼) = 수류탄.

## 고친 것
1. **숄더뷰에서 크로스헤어가 적을 지나면 걷던 몸이 그 적에게 돌아갔다.** 0222가 크로스헤어의 적을 커서 칸(`Actions::aim_at`)에
   넣었는데, 그 칸은 쿼터뷰에서 마우스의 "조준"이라 몸을 돌리고(`face`) 근접 자동 조준의 원뿔을 정한다. 0219가 정한
   "숄더뷰의 겨눔은 원거리의 쪽만 — 근접·몸은 섞지 않는다"를 어겼다. 검을 들고 있어도(마법 탄의 사거리 안이면) 같았다.
   → 새 칸 `Actions::aim_sight`(크로스헤어의 적 자리)를 원거리의 쪽(`ahead`)에만 쓴다. 크로스헤어가 적을 잡으면 패드 보조는 붙이지 않는다.
   시험 `the_shoulder_crosshair_steers_the_shot_not_the_body`(옛 길로 돌리면 몸이 (-0.57, -0.82)로 돌아 실패하는 것을 확인).
2. **터치로 쇠뇌를 끌면 미리보기가 뒤바뀌었다.** 0223에서 쇠뇌의 큰 버튼이 사격·별 버튼이 수류탄이 됐는데, 땅 위 미리보기를 고르는
   `App::aim_show`는 버튼 이름(큰 버튼 = 수류탄)으로 골랐다 → 사격을 끌면 수류탄 원이, 수류탄을 끌면 사격 띠가 그려졌다(0218 "진실한 표시"
   위반, 실제로 나가는 것은 맞았다). → `touch_aim_show(버튼, 원거리인가)` 순수 함수 + 시험 `a_dragged_touch_button_previews_what_it_now_does`.

## 그대로 둔 것(판정 거리)
- 쿼터뷰 마우스의 겨눔은 땅의 **발 높이 면**에 비춘 점 — 높은 턱 위의 적을 가리키면 수평 쪽이 조금 비낀다(가까운 적일수록). 볼트의
  세로는 0218이 맞추니 대개 맞는다. 판정에서 빗나감이 느껴지면 커서 시선이 지나는 적의 몸으로 붙이는 길(숄더뷰와 같은 꼴)이 있다.
