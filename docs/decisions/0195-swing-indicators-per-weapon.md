# 0195 — 무기별 휘두름 표시 정리: 휘두른 쪽으로 사라짐 · 세로는 양 끝부터 · 빌린 동작의 시계

- 날짜: 2026-11-15
- 상태: 채택(개발판, 판정 전)
- 사장: "맨손을 포함해서 무기별로 확인해서 어색한 인디케이터 수정해줘. 기본적으로 휘두르는 방향대로, 수평이 아닌 수직 기술일 경우에는
  양끝쪽에서부터 사라지는 형식."

## 잰 것(무기마다 평타·대시 공격·강타, 판정 구간의 칼끝 — 맨손은 주먹)
- 검·망치·지팡이: 표(`weapons::SWEEPS`)의 쪽과 모델이 맞았다(0193에서 맞춘 것). 대시 공격도 같은 동작이라 같은 쪽.
- **맨손**: 검의 동작(`attack`·`attack2`·`attack3`·`heavy`)을 빌리는데 동작 시계를 늦추지 않아 **판정(0.05초)이 주먹이 나가기 전(동작의 0.08초)**에
  왔다 — 초승달·박자 부채꼴이 휘두름보다 먼저 떴다. 대시 공격(검 `attack3` 1.0배 · 망치 `hammer2` 1.6배 · 지팡이 `staff3` 0.8배)도 동작이
  만든 구간(1.2·2.0·0.75배)과 조금씩 어긋났다.
- **강타의 초승달**은 무기와 상관없이 늘 "가운데"였다 — 지팡이 강타(`staff_release`)는 가로로 도는데 가운데에서 펴졌다.
- 세로(가운데) 초승달은 가운데에서 양쪽으로 펴진 뒤 그 모양으로 옅어지기만 했고, 가로 초승달도 활성 뒤에는 그 자리에서 옅어지기만 했다.

## 바꾼 것
1. **동작 시계 = 판정에 맞춘다**: `SWEEPS`에 동작이 만든 판정 구간(Blender `HIT_WINDOWS` 그대로 — 시험 `swing_windows_match_the_blender_table`)을 두고,
   `weapons::clip_rate(동작, 판정 시작)` = 동작의 판정 시작 / 타의 판정 시작. 렌더(평타·강타)와 모션 보기가 이 배로 동작을 돌린다 — 맨손은
   검의 동작을 1.67배로, 판정의 순간에 주먹이 닿는다(시험 `borrowed_swings_play_faster_so_the_blow_lands_on_the_hit`). 랩 값을 바꿔도 따라간다.
2. **초승달의 규칙**(`render::overlays::slash_arcs(… q, gone)`):
   - 가로: 머리가 칼끝을 따라 한쪽 끝에서 반대쪽으로(그대로), **활성 뒤에는 꼬리가 머리를 따라잡아 휘두른 쪽으로 사라진다**.
   - 세로·찌르기(가운데): **머리(밝고 두꺼운 곳) = 바라보는 쪽**, 꼬리 = 양 끝. 활성의 앞 40%에 가운데에서 양쪽으로 펴지고,
     **활성 뒤에는 양 끝에서부터 가운데로 줄어 사라진다**.
   - 박자 부채꼴은 원래 같은 규칙(휘두른 쪽부터 · 가운데는 양 끝부터)이었다 — 표가 맞으니 그대로.
3. **강타의 초승달도 표의 쪽**(`sweep_of(anim_heavy)`): 검·망치·맨손 강타 = 세로, 지팡이 강타 = 왼쪽 → 오른쪽.
4. 땅울림·충격파의 초승달은 같은 꼴(가운데가 밝다)로 바뀌되 줄어들지 않는다(퍼지는 파도라서). 휘돌이·던진 날의 초승달은 그대로.
5. 시험 `melee_swings_cross_the_front_in_the_table_direction`이 맨손(주먹 — 가운데 35°·가로 45° 기준)과 대시 공격까지 동작 시계로 다시 잰다.
