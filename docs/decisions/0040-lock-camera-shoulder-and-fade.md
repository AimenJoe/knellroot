# 0040. 락온 카메라를 어깨 너머로 더 비키고, 그래도 가리면 방랑자를 옅게

- 날짜: 2026-11-04
- 상태: 채택(사장: "아까 a, b 둘다 하자" — a = 카메라 비켜두기 + 0009 기준 풀기, b = 가리면 옅게).
- 왜: 0038의 방랑자는 두건이 몸보다 넓어 락온 구도 가운데에서 과녁 아래쪽을 가린다.

## 정한 것
1. **락온 리그 기본값**: 어깨 0.8 → **1.6**m, 주시점 옆 밀기 1.3 → **2.3**m, 높이 2.5 → **3.0**m(`cam.lock.shoulder`·`frame x`·`height`). 다섯 벌을 게임에서 찍어 고름(`docs/art/meshy-0038/result-v2/lock_camera_variants.png`): 핵·머리는 늘 보이고 바닥 예고가 더 보인다.
2. **0009 시험 기준**: "전환이 대상의 어느 쪽에서든 비슷하게 부드럽다"의 최악/최선 1.8배 → **2.1배**. 어깨를 비켜 둔 만큼 먼 쪽으로 도는 전환이 길어진다(지금 124~258°/s = 2.07배). 최악 절대값 한계 340°/s와 머리에서 4m는 그대로. 옛 값(0.8/1.3/2.5)도 1.77배로 경계였다.
3. **가리면 옅게**(`camera::occlusion`, 렌더): 눈에서 본 방랑자 공(가운데 키의 45%, 반지름 1.2 × 몸 반지름)과 과녁 공(가운데 키의 절반, 반지름 max(몸 반지름, 키 × 0.4))의 각도 원판 겹침이 0.35면 다 옅어져 `render.lock fade`(0.45)까지, 부드럽게(1/10초 남짓). 락온일 때만.

## 왜 카메라만으로 안 되나
원근: 카메라를 옆으로 s만큼 옮기면 가까운 방랑자(7m)와 먼 과녁(12~17m)이 같이 밀리고, 둘 사이 각도는 s/7 − s/(7+L)뿐이다. 넓고 가까운 보스는 1.6m로도 다 못 비켜난다 — 그래서 b를 함께.

## 다시 볼 것
- 옅어질 때 외곽선이 함께 빠진다(반투명 길) — 실루엣이 약하면 외곽선만 남기는 쪽.
- 잡몹 떼 속(작은 과녁)에서 깜빡이듯 옅어졌다 돌아오면 겹침 문턱(0.35)을 올린다.
