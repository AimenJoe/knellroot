# 0119. 지역 환경(v0.5.0 T2) — 땅 위·땅속을 한 표로, 천장 틈 빛줄기

- 날짜: 2026-11-08
- 상태: **채택·구현**(`release/v0.5`) — 빛줄기의 빛은 0124에서 기둥 빛으로(몸이 비치게). 0116 4절 T2, 0114 T2 표("하늘·달 vs 뿌리 천장·빛줄기·떨어지는 흙, 안개 색, 식생 종류").
- 스터디: KB `concepts/conveying-descent`(방 안의 위 — 얕은 굴은 천장 틈 빛줄기·바닥 빛 웅덩이·떨어지는 흙, 월드 칸에 붙인다), `concepts/surroundings-beyond-the-play-area`(0063 원경·안개·상태 없는 입자). 마을 지역 문서(뿌리는 물방울이 떨어지는 물리적 풍경 — 위협으로만 연출하지 않는다).

## 왜
- 성소에 맞춰진 원경(해 질 녘 하늘·달·반딧불·나무)이 지하 40m 마을에 그대로면 T1의 단면 전환이 "내려왔다"를 말해도 닿은 곳이 같은 하늘 아래다(0069 Z1).
- 지역마다 코드를 가르지 않고 **표 한 줄**(`StageDef::env`)로 — 콘텐츠는 표·파일 밖에서 쌓지 않는다.

## 정한 것
| 무엇 | 땅 위 `SURFACE`(성소) | 땅속 `UNDERGROUND`(떠난 마을) |
|---|---|---|
| 원경 | 해 질 녘 하늘 띠·달·산등성이 세 겹·뿌리 아치(0063 그대로) | 같은 꼴, 흙빛 띠(지평선 쪽 조금 밝고 위로 짙게), 달 없음, 산등성이 높이 ×2.2 = 동굴 벽, 아치 = 뿌리 천장 |
| 달빛 | 1.0 | 0.4(굽는 지형·배우의 `lit` 달빛 몫 — `render::set_moonlight`) |
| 안개·허공 | 남보라 | 같은 계열을 흙빛 쪽으로 낮춤 |
| 떠다니는 것 | 달빛 먼지·반딧불 | 먼지·떨어지는 흙(천장 6m에서 곧게) |
| 식생 | 나무·덤불·벽 뿌리 | 벽 뿌리만 |
- **천장 틈 빛줄기** 지도 `S`(땅속): 옅은 빛(굽는 지형·배우가 받는 `Light`) + 위는 좁고 아래는 넓은 비스듬한 기둥(위가 밝다, 기울기 = 달빛 쪽) + 바닥 빛 웅덩이, 천천히 숨 쉰다. 마을 빈 지도에 넷.
- 시험: 땅 위 지역만 달·반딧불·나무, 땅속은 달 없음·약한 달빛·떨어지는 흙·빛줄기 하나 이상. 떨어지는 흙도 상자 안·가장자리 옅게(기존 시험에 더함).

## 하지 않은 것
- 물방울(KB: 깊은 굴은 빛줄기 대신 물방울) — 마을 지도(C1)의 "뿌리 사이 골목"에서 자리와 함께.
- 환경음(땅속 바람·물방울) — 소리는 지도와 주민(C1·C7) 때.
- 풀 빌보드는 그대로(땅속 이끼로 읽힌다) — 판정에서 이상하면 지역 표에 칸을 더한다.

## 확인(헤드리스)
- 마을: 바닥이 성소보다 어둡고, 오른쪽 위 빛줄기가 비스듬한 옅은 기둥 + 웅덩이로 읽혔다. 성소는 그대로.
