## 시안이 바꾸는 것
- **묶음마다 판**(어두운 면 0.6 + 창과 같은 금빛 테 두 겹): 왼쪽 위 = 몸(체력·기력·등잔·마법·잔불), 오른쪽 아래 = 스킬, 아래 가운데 = 보스, 오른쪽 위 = 목표.
- **체력**: 굵은 막대 + 열 눈금마다 칸 금 + 남은 수. 방금 잃은 몫이 밝게 남았다 줄어드는 것(0143)·한 대 남으면 붉게 뛰는 것은 그대로.
- **기력**: 두께를 두 배쯤(체력보다는 가늘게). 막혔을 때 떨림·박자 타의 금빛 반짝임은 그대로.
- **등잔·마법·잔불**: 그림을 키우고 한 줄에(쓴 등잔은 꺼진 꼴, 빈 마법 칸은 테만).
- **스킬 칸**: 큰 창의 기술 칸과 같은 그림·같은 금빛 테. 대기 중이면 어둡게 덮이고 남은 초, 쓸 수 있으면 밝은 테. 키캡은 칸 아래. 큰 기술 게이지는 칸 위의 굵은 막대(가득 차면 테가 숨 쉰다 — KB).
- **보스 띠**: 이름을 가운데에, 체력 굵게 + 그 아래 자세 막대, 뒤에 판.
- 자리는 지금 그대로(손이 외운 자리 — KB), 터치에서는 지금처럼 멈춤 버튼·터치 버튼을 비킨다.
