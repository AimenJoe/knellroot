# 0121. 떠난 마을 지도(v0.5.0 C1) — 비탈 아래로, 사다리 지름길, 주민 자리는 끈 밖

- 날짜: 2026-11-08
- 상태: **채택·구현(지도·규칙 — 주민 배우는 C7)** — 사다리 지름길은 0124에서 걷었다, 적은 0124에서 33으로(`release/v0.5`). 0114 C1, 0116, 0115·지역 설계 문서 `docs/design/stages/abandoned-village-residents.md`(구역 다섯·전투 안전 설계). 사장 2026-11-08 인터뷰 — 지름길 = **내리는 사다리**, 엘리트 = **셋, 지금 성질만**.

## 지도(생성기 `tools/maps/village.py`, 45×60칸 = 90×120m — 성소 43×66과 비슷하게)
```
        [종탑 터 −1m: 깨진 종 · 문지기 · 빛줄기]          ← 구역 넷째(끝)
              ↓ 경사로(가운데)
 [아래쪽 광장 0m: 싸움터 · 화로(종탑 앞) · 장치 V(서쪽) · 꿰매는 사람 턱 +1m(남동)]
   ║사다리 길(G 문, 여덟 칸 0 → +4m)     ↑ 경사로(동쪽)
   ║                [뿌리 사이 골목 +2.5m: 뿌리 벽으로 구불구불 · 화로 · 물 모으는 사람 곁방(동쪽)]
   ║                     ↑ 경사로(서쪽)
 [위쪽 거주지 +4m: 오르는 길 U · 도착 · 화로 · 불 지키는 사람(동쪽)]   ← 구역 첫째(도착)
```
- **비탈 아래로**: 도착(거주지, 높다) → 골목 → 광장 → 종탑 터(가장 낮다). 북쪽 = 깊은 곳(0113 구역 규칙 그대로).
- **사다리 지름길**(인터뷰): 광장 서쪽 장치 `V`를 당기면 거주지로 오르는 좁은 길의 문 `G`가 열린다 — 아래에서만 연다(위에서 보면 막혀 있다), 기록 `gates`(판을 넘어 열린 채). 새 칸 `StageDef::gate_shortcut`: 처음부터 문이 열린 단계(문지기·목표는 문과 상관없다), 문은 장치(기록)만 따른다 — 쉬어도·다시 서도·문지기가 깨어나도 그대로. 당기면 카드 `card_lever`("위로 오르는 사다리가 내려왔다"). 그림은 아직 성소 문(사다리 모양은 모델 단계).
- **화로 셋**: 거주지(도착)·골목 동쪽(광장으로 내려가는 경사로 위)·종탑 터 앞(광장 북쪽).
- **적**: 서 있는 잔재 5·가시짐승 2·등딱지짐승 3·꼬투리 3·청소자 2 + 엘리트 셋(인터뷰 — 굳은 등딱지짐승 광장 가운데 · 되풀이 꼬투리 골목(두 번 심는다) · 남는 잔재 광장 동쪽). 등급 2(0112·0116).
- **주민 자리**(C7에서 배우를 세운다): `1` 불 지키는 사람(거주지 동쪽) · `2` 물 모으는 사람(골목 동쪽 곁방, 한 칸 틈) · `3` 꿰매는 사람(광장 남동 턱 위). 0115 "AI보다 레벨 배치로 먼저" — **모든 적의 제자리에서 끈 + 3m(21m) 밖**(시험). 대피 AI는 없다.
- 숨은 물건: 종소리 조각(골목 서쪽 끝)·한 모금(광장 서쪽 구석). 상자·장신구는 C6. 새긴 돌 자리는 C4에서 글과 함께.
- 빛줄기 다섯(거주지·골목·광장·종탑 터·물 곁방).

## 시험
- 모든 지역: 모든 바닥에 닿고 모든 적이 싸움 자리로 걸어온다, 모든 화로에서 쉬기 전 적이 알아차리지 않는다(기존 시험을 지역마다).
- 주민 자리는 모든 서 있는 적·엘리트·문지기의 제자리에서 끈 + 3m 밖, 마을에 주민 셋.
- 사다리: 처음엔 닫힘·쉬어도 닫힘·장치로 열림(기록), 문과 상관없이 종탑 터에 들어서면 문지기가 깬다.

## 판정에서 볼 것(사람)
- 비탈을 내려간다고 읽히나(단의 높이·벽), 길을 잃지 않나(갈 곳 화살은 종탑 터).
- 광장에서 사다리 장치를 찾고, 열린 뒤 거주지 화로 → 광장이 짧아지는 게 느껴지나.
- 골목의 좁은 길에서 꼬투리·등딱지짐승 조합이 새 판단을 부르나(Z2).
