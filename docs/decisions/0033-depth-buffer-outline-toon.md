# 0033. 깊이 버퍼 붙이기 + 외곽선·툰 빛·가장자리 빛(모델 다듬기 1단계)

- 날짜: 2026-11-04
- 상태: 채택·구현(값은 랩에서 바꾼다). 핸드헬드 비용은 사람이 잰다.
- 사장: "모델링 더 다듬을수 있는 방법 고려해보자" → 조사(아래 출처) → 추천 1번 "빛 단계 + 1px 외곽선을 랩에서 켜고 끄는 실험" → "응 그러자 진행해".

## 무엇을 찾았나 — 깊이 버퍼가 없었다(버그)
- 외곽선(키운 상자의 뒷면)을 넣었더니 앞면을 버리든 뒷면을 버리든 몸이 통째로 검게 덮였다. 따라가 보니 **3D 렌더 타깃에 깊이 버퍼가 없었다**: macroquad `render_target(w, h)`는 `RenderTargetParams::default()` = `depth: false`(0.4.16 `texture.rs` 소스 1차). `Camera3D`가 깊이 시험을 켜도 붙은 버퍼가 없어 **그린 순서로만 덮였다** — 모델 부위 상자끼리도, 벽끼리도.
- `render_target_ex(.., depth: true)`로 바꾸자 **효과 없이도 모델이 바로 읽힌다**: 문지기의 얼굴·핵이 앞에, 방랑자 등 뒤로 가슴 띠가 비치던 것이 사라지고, 입구 벽은 겹친 얇은 판에서 덩어리로(`docs/art/look-0033/*.png`, 왼쪽 = 전, 가운데 = 깊이만, 오른쪽 = 깊이 + 효과). 비용은 재지 못할 만큼 작다(헤드리스 개발 줄 그대로).
- 지금까지의 "상자 더미" 인상의 일부는 모델이 아니라 이 버그였다.

## 효과 셋(랩 `render.*`, 기본 켬)
- **툰 빛** `render.toon`: 달빛 n·l을 2단, 화로 세기를 3단으로 끊는다 — 바닥의 빛 웅덩이가 둥근 그러데이션 대신 또렷한 고리(t3ssel8r 쪽). 지형은 굽혀 있어 켜고 끄면 다시 굽는다.
- **가장자리 빛** `render.rim` 0.35: 배우만, 카메라에서 비스듬한 면일수록 `(1 - n·v)²`만큼 차가운 달빛 색 — 어두운 바닥 위 실루엣.
- **외곽선** `render.outline px` 1: 배우(`Batch::model`)의 부위 상자를 가운데에서 축마다 바깥으로 민 껍데기(면마다 정점이 따로라 법선으로 밀면 모서리가 벌어진다), **앞면을 버리는 재질**(macroquad 기본 3D 셰이더 그대로, `CullFace::Front`)로 따로 보낸다. 두께는 그 거리에서 화면 1px = `2·거리·tan(시야/2)/270`m — 쿼터뷰·락온 어디서나 1px. 부위 사이에도 선이 생겨 팔·몸이 갈린다. GL에서만(Metal이면 재질을 만들지 않고 끈다).
  - 깊이가 없을 때는 `Front`·`Back` 둘 다 몸을 덮었다(깊이 시험이 없으니 감김과 상관없이) — 깊이를 붙인 뒤 `Front`가 맞았다(스크린숏).
