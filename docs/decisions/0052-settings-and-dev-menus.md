# 0052. 설정 화면과 개발 메뉴(nail의 틀)

- 날짜: 2026-11-04
- 상태: 채택·구현(사장: "이제 슬슬 메뉴에 설정 추가해야겠다. 개발 빌드에서는 개발 메뉴도 만들어야겠어. Nail 쪽 구현된 거 참조해서")
- 근거: nail `origin/release/v1.0`
  - `src/app/settings.rs`: `Row` enum, 값 줄과 누르는 줄, 좌우로 바꾸기, 뒤로 하면 저장, 타이틀·멈춤 두 곳에서 들어감
  - `Scene::Dev` + `scenario::LIST`
  - prefs 칸을 뒤에 붙이면 MAGIC은 그대로(0 = 기본값)

## 정한 것
1. **타이틀**은 시작 · 설정 · (개발판) DEV 세 줄이다. 흩어져 있던 조작 설정·언어·전체 화면(0046)은 설정으로 옮겼다.
2. **설정**(`Scene::Settings { from_pause }`, `flow::SettingsRow`):
   - 줄: 언어 · 전체 화면(쓸 수 있을 때만) · 화면 흔들림(0~100%, 10% 단위) · 조작 설정 · 돌아가기.
   - 값 줄은 좌우·확인으로 바꾼다. 터치는 탭할 때마다 다음 값이다.
   - 뒤로 가면 온 곳(타이틀·멈춤)으로 간다. 조작 설정에서 뒤로 가면 설정으로 돌아온다.
3. **멈춤**: 계속 · 무기(좌우로 바꿈, 0051) · 설정 · 처음부터 · 타이틀로.
4. **DEV**(개발판에만, `#[cfg(feature = "dev")]`, 글은 영어 그대로 — 0013): 문 앞에서 시작(보스) · 무기 < > · PoC 시나리오 < 이름 > · 돌아가기.
   - 시나리오 줄은 좌우로 고르고, 무엇을 보는지(`checks`)를 아래에 보인다.
   - 시나리오에서 멈춤을 누르면 DEV로 돌아온다.
5. **저장**(`prefs.rs`): 20번 칸 화면 흔들림, 21번 칸 든 무기. 뒤에 붙인 칸이라 MAGIC은 그대로다. 옛 저장은 흔들림 100%·검으로 읽는다. 흔들림은 카메라 trauma에 배율로 곱한다.
- 시험·도구:
  - 시험: `flow` 메뉴 시험, prefs 옛 저장 시험.
  - `tools/test/shot.js`·`leak.js`의 메뉴 길도 고쳤다. 0046 때 타이틀 줄이 늘어 연기 시험이 엉뚱한 줄을 골랐던 것도 같이 바로잡았다.
