# 0245 — 방랑자 텍스처 256 → 512

- 날짜: 2026-11-19
- 상태: **만듦**(판정 전 — 체크리스트 91-7)
- 사장: "Meshy 모델이 저사양 모델이니, 고사양으로 다시 하나 뽑을까?" → (원본은 이미 고사양 — Meshy-6, 원본 10MB. 게임에 넣을 때 줄인다) → 텍스처만 올려 보기 "해봐"

## 왜 다시 뽑지 않았나
게임의 방랑자가 거칠어 보인 것은 Meshy 원본이 아니라 우리가 줄인 두 가지 때문: 정점 4,753(예산 4,800 — CPU 스키닝, 핸드헬드 프레임)과
텍스처 256×256(`wanderer_skin.py TEX`). 다시 뽑아도 같은 자리로 줄이니 크레딧(생성 약 30 + 리깅·동작)만 든다.

## 한 것
- `TEX` 256 → 512(원본 텍스처에서 다시 줄임 — 몸 512 + 코드 아틀라스를 붙인 한 장 1024×512). 정점·동작은 그대로(4,753).
- 비용: GLB 2.14 → 2.40MB, wasm 8.35 → 8.61MB(+258KB). GPU 메모리 +1.5MB 안팎. 그리기 비용은 그대로.
- 비교: `docs/art/wanderer-tex-256-vs-512.png`(상태 탭 인형, 3배 — 왼쪽 256 · 오른쪽 512): 눈·벨트 버클·끈의 바늘땀·털 가장자리가 또렷하고 얼룩이 준다.
  쿼터뷰(몸 100px 남짓)에서는 차이가 작고, 숄더뷰·락온·인형에서 보인다.

## 남은 것
- 정점 예산을 올리는 것(실루엣이 매끈해진다)은 폰에서 CPU 스키닝 프레임을 잰 뒤(체크리스트 k20 꼴).
- 덧옷(0244)도 같은 길: 원본은 고사양으로 받고 게임에 넣을 때 줄인다(텍스처는 512).
