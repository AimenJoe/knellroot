# 0027. 점프는 기본 동작 · 소모품(퀵슬롯)은 뺀다

- 날짜: 2026-11-03
- 상태: 채택(사장: "점프.. 만들자. 차라리 소모성 아이템을 빼자."). 0026의 "소모품 퀵슬롯"을 걷는다.
- 지금(2026-11-05 결정 검토, 0066 때): "상호작용 Y/G"는 0048이 점프 버튼과 합쳤다(쉼터·상자는 점프 버튼).

## 조사(요약 — 모두 2차 출처, 공식 문서·게임 화면은 못 봄)
쿼터뷰·탑다운 액션에서 점프는 세 갈래다.
1. **점프 없음**: Tunic·Death's Door·Hyper Light Drifter·Diablo IV. 회피·대시가 점프 몫을 하고 높낮이는 사다리·지름길·스위치 다리로 푼다. Diablo IV 개발진은 "땅에 붙은 전투"를 의도했다고 말했다(PCGamesN).
2. **찾는 도구**: 젤다 꿈꾸는 섬의 로크의 깃털. 구덩이 넘기·지진 피하기·보스 패턴 넘기. 레벨이 "깃털이 있어야 건너는 곳"으로 짜인다.
3. **기본 동작**: 엘든 링(A / F). 미야자키(Famitsu 인터뷰 번역 기사)는 탐험의 차원·점프 공격·낮게 휘두르는 공격 넘기를 이유로 들었다. 이스 VIII·IX는 점프 + 공중 콤보(3인칭).
- 쿼터뷰의 어려움: 높이가 안 읽힌다. 개발자 글(포럼·블로그 수준)의 해법은 공중에서 작아지는 바닥 그림자, 일정한 빛 방향.

세션의 추천은 2(나중에 찾는 도구)였지만, 사장은 3을 골랐다. 조작이 늘어나는 비용은 **소모품 퀵슬롯을 빼서** 갚는다 — 버튼 둘(사용·다음 칸)과 HUD 띠, 표 하나, 기록 칸이 사라진다.

## 정한 것
- **점프 = 기본 동작**, 패드 A / 키보드 F(엘든 링 자리). `Bind::Jump`, 저장 칸은 뒤에 붙임(옛 저장은 점프만 기본값).
- 탄도는 높이·체공 시간 둘로(`jump.height m` 0.9, `jump.time s` 0.55): 처음 속도 `4h/T`, 중력 `8h/T²`, 정확한 적분이라 꼭대기가 높이 그대로. 스태미나 12.
- **공중 조종은 약하게**(`jump.air control x` 0.3): 뛰기 전 속도를 잇고, 입력이 있을 때만 조금 바꾼다 — 달려서 뛰면 멀리 간다.
- **뛰는 일**: 문지기의 **뿌리 파동**을 넘는다(`jump.clear m` 0.35보다 높이 떠 있으면 안 맞는다). 무적은 없다 — 원판·부채꼴·돌진은 공중에서도 맞는다(회피의 몫과 겹치지 않게).
- **내려찍기**: 공중에서 공격 → 빨리 떨어져(×2.5) 내려앉은 자리 둘레 `plunge.range m` 1.6 안을 `plunge.damage` 2로 친다(드러난 적이면 치명타). 떼 한가운데 들어가는 수단. 대가는 착지 빈틈 `plunge.land s` 0.35(보통 착지 0.1).
- **높이 읽기**: 바닥 그림자가 높이에 따라 작아지고 옅어진다. 내려찍기는 착지 고리.
- 터치: 회피 왼쪽에 위 화살표 버튼.
- 수치 아홉 줄은 `tuning.rs` SPECS 끝에 붙이고 얼린 값도 뒤에 붙였다(0013).

## 빼는 것
- 0026·`items.md`의 **소모품 층**(종 파편·뿌리 송진·퀵슬롯 띠·사용 Y/R·다음 칸 십자 아래/Tab), 구현 단계 C.
- 등잔(충전식 병)은 남는다 — 소모품이 아니라 화로에서 다시 차는 장비. 마시기 버튼은 따로 둔다(`items.md` 8).
- 상호작용은 A를 점프에 내주고 Y / G로.

## 다시 볼 조건
- 구역에 높낮이(턱·틈)를 넣게 되면: 점프로 넘는 곳의 거리 규칙(최대 수평 거리 = 달리기 속도 × 체공 시간)을 레벨 규칙으로 적는다.
- 점프가 떼싸움에서 회피보다 늘 나으면(내려찍기 남용) 착지 빈틈·스태미나를 랩에서 올린다.
- 던지는 것이 아쉬우면 소모품이 아니라 **무기의 특기**(무기 표 한 줄)로 되살린다.
