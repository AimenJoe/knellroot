# 0015. 땅 돌리기 좌우 버튼을 뒤집는다 — 누르는 쪽으로 쟁반의 가까운 쪽이 간다

- 날짜: 2026-11-03
- 상태: 채택·구현(사장: "왼쪽 오른쪽 돌리는 버튼이 반대로 맵핑되어야 할 듯").

## 무엇이 반대였나
- 0012에서는 오른쪽 버튼(RB·E·터치 오른쪽) = `turn_cw` = 땅이 화면에서 **시계 방향**(카메라 요 +90°). 계산하면 이때 카메라는 자기 오른쪽으로 돌고, 화면 위(먼 쪽)의 땅은 오른쪽으로 가지만 **화면 아래(가까운 쪽, 주인공 발치)의 땅은 왼쪽으로** 간다. 쟁반을 잡는 쪽은 가까운 쪽이라 손과 반대로 느껴졌다.
- (처음 설명에서 "지금 오른쪽 버튼이 카메라를 왼쪽으로 돌린다"고 했는데 틀렸다 — 시험으로 계산을 다시 해 바로잡았다.)

## 결정
- 왼쪽 버튼(LB·Q·터치 왼쪽) = `turn_cw`(땅 시계 방향, 가까운 쪽이 왼쪽으로), 오른쪽 버튼(RB·E·터치 오른쪽) = `turn_ccw`(땅 반시계, 가까운 쪽이 오른쪽으로). 월드·카메라의 cw/ccw 뜻은 그대로, 버튼만 바꿨다.
- 터치 그림: ↺ ↻(땅이 도는 쪽) 대신 아래쪽 반원 화살표가 누르는 쪽 끝에서 위로 — "가까운 쪽이 그쪽으로 간다". 터치 버튼 종류도 `TurnLeft`·`TurnRight`(자리 이름)로.
- 시험: `the_right_turn_button_turns_the_ground_counter_clockwise`(터치 오른쪽 버튼 → `turn_ccw`, 오른쪽 버튼이 화면 오른쪽), `a_counter_clockwise_turn_moves_the_near_side_of_the_ground_to_the_right`(카메라 쪽 뜻).

## 다시 볼 조건
- 사람마다 "먼 쪽 기준"(카메라가 그쪽으로 돈다)이 맞다고 느낄 수 있다 — 갈리면 설정에 "돌리기 방향 뒤집기"를 둔다(첫 게임처럼 바꿀 수 있는 키 배치와 함께).
