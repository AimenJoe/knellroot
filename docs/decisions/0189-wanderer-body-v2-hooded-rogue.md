## 정한 것
- 원본 `tools/art/sources/meshy/raccoon_v2.glb`(17만 삼각형, 텍스처 2048 셋) → `meshy_convert.py … 1.4 2800 256` → `raccoon_v2_low.glb`(glTF 정점 2,505).
- `wanderer.py`에 몸 스위치 `BODY`(환경 `KR_WANDERER_BODY`, 기본 `v2`, `v1` = 옛 몸으로 다시 굽기). v2 자르기 `classify_v2`: 목 0.82m 위 = 머리(두건),
  0.16m 아래 = 발, 등 뒤(+y 0.22)·엉덩이 아래 = 꼬리, 어깨(±0.24, 0.64) → 손(±0.385, 0.45) 원기둥 0.085 = 팔. 10cm 격자를 그은 앞·옆 렌더와 높이 띠
  정점 분포로 쟀다. 뼈 자리(머리·다리·꼬리·두건 끝·손·어깨)도 v2 치수로 — 동작 표 50개는 그대로.
- v1에만 하던 꼬리 옮기기·두건 고르기·코드 주머니는 v2에서 하지 않는다(원본에 주머니·띠가 있다 — 주인공에 코드 꼴을 덧붙이지 않는다, 0157).
- **망토 밝히기**: 원본의 짙은 보라는 정원·뿌리 굴 같은 어두운 땅속 바닥에서 바닥과 같은 밝기의 덩어리가 됐다(게임 화면). 원본은 두고 게임용
  텍스처 사본에서 보라·자주 칸(색상 0.70~0.97)만 V를 (1 − V) × 0.45 올리고 채도 × 0.8 — 얼굴·털·가죽·꼬리 줄무늬는 그대로(`lift_purples`,
  환경 `KR_WANDERER_LIFT`, 0 = 원본 색). 0과 0.45를 같은 정원 장면에서 견줘 0.45로.
