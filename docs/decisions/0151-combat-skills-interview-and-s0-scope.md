## 2. 0150에서 달라지는 것
- **스킬 "땅 기울이기"는 뺀다**(쏟기가 돌리기에 남으니 겹친다) — 액티브는 여덟. 큰 기술 "쟁반 뒤집기"는 남긴다(둘레 전체를 바깥으로 — 돌리기의 쏟기와 방향·크기가 다르다).
- **돌리기는 뜻이 그대로**(0012·0023·0028 — 화면 90° + 쏟기 + 대기 4초). 자리만 옮긴다: 패드 십자 키 ←·→, 키보드 Z·C(브라우저가 Ctrl·Alt 조합을 가로채서 조합이 아니라 낱 키 — 이것은 묻지 않고 0150의 안대로 했다, 조작 설정에서 바꿀 수 있다), 터치는 멈춤 버튼 아래 작은 버튼 둘.
  - 십자 키는 싸움에서 더는 걷지 않는다(메뉴에서는 그대로). 랩·메뉴가 "돌리기 버튼 둘"로 하던 빠른 바꾸기(장비 칸·도감·개발 탭)는 **스킬 버튼 둘**(LT·RT / Q·E)이 물려받는다.
  - 0048의 "마법 직후 돌리기 누름 버리기"(RB 바로 밑이 RT라서)는 걷는다 — RT는 이제 스킬이고, RB → RT로 잇는 것이 바라는 쓰임이다.
- **X = 평타 · RB = 스페셜**:
  - 근접 무기는 지금 그대로다 — 이미 무기마다 제 RB가 있다(검·맨손 = 마법 탄, 망치 = 무거운 탄, 지팡이 = 꿰뚫는 탄, 쥐면 모은 탄). 이름만 "마법" → "무기 기술".
  - **쇠뇌는 둘을 맞바꾼다**: X = 사격(쥐면 모은 사격), RB = 수류탄(쥐면 멀리). 공중에서는 X가 내려 쏘기. 박자는 X를 탄다.
  - 맨손의 "잡아 던지기"·망치의 "충격파" 같은 새 스페셜은 S1 뒤에 따로 판정(지금 것이 부족하면).
- **큰 기술은 S0부터**: 게이지 + "쟁반 뒤집기" 하나. 나머지 둘(몰아치기·한 줄기)은 S1.

## 3. 두 버튼을 "함께" — 늦추지 않고 바꿔치기
큰 기술 = LT + RT(Q + E)를 함께. 사람 손은 같은 프레임에 두 버튼을 못 누른다.
- 흔한 길 둘(2차 출처 — 포럼·블로그, 직접 재 보지 않음): ① 첫 누름 뒤 몇 프레임을 모았다가 정한다(모든 누름이 그만큼 늦는다), ② 공격의 시동을 한 프레임 늦춘다. 창을 넓히면 이어 누르기와 부딪힌다는 것이 공통된 경고.
- 여기서는 **늦추지 않는다**: 스킬은 누른 틱에 나가고, 그 스킬의 **시동 안**(`skill.chord s`, 0.12초)에 다른 스킬 버튼이 눌리고 게이지가 가득이면 그 스킬을 **큰 기술로 바꿔친다**(쓴 대기는 돌려준다). 같은 틱에 둘이 눌리면 바로 큰 기술. 게이지가 안 찼으면 둘째 누름은 그냥 다음 스킬로 받아 둔다. 낱 누름의 반응은 그대로다.
- 터치는 게이지가 차면 두 스킬 버튼 사이에 뜨는 버튼 하나(상황 버튼, 0053).

## 4. S0 — 만드는 것
끝난 것으로 보는 때: **떼 장면에서 "모으고 → 쓸고"가 되는지 사장 판정**.

| 갈래 | 무엇 |
|---|---|
| 조작 | `Pad::DLeft`·`DRight`(배치표에 올릴 수 있는 버튼으로), `Bind::Skill1`·`Skill2`(칸은 뒤에), 기본 배치(패드 LT·RT = 스킬, 십자 ←·→ = 돌리기 / 키보드 Q·E = 스킬, Z·C = 돌리기), prefs `MAGIC` 올림(배치만 기본으로), 터치 배치·픽토그램, 조작 화면·글, 쇠뇌의 X·RB 맞바꾸기 |
| 틀 | `skills.rs` 표(이름·대기·시간·모양·피해), `PState::Skill`, 대기·기세·게이지(`Player`), `Event::Skill`·`SkillDenied`·`Ult`·`UltReady`, 캔슬 줄, 랩 값 `skill.*` |
| 스킬 | **휘돌이 · 가로지르기 · 끌어모으기 · 땅울림** + 큰 기술 **쟁반 뒤집기** |
| 화면 | HUD(스킬 둘의 그림 + 대기 덮개 + 게이지), 터치 버튼, 끼우는 화면(멈춤 → "기술": 칸 둘에 넷 가운데 고르기 — S0에서는 넷을 다 가진 것으로), 기록 키 `skill.1`·`skill.2` |
| 느낌 | 이펙트(0141 문법 — 금·민트·흰색, 빨강 없음)·소리는 있는 것을 겹쳐 쓴다. 동작은 있는 것(무기 동작)을 빌린다 — **스킬 전용 동작(Blender)은 S1** |
| 시험 | 스킬마다 하나(넓이·보스에게 덜 듣는 것), 기세, 바꿔치기, 쇠뇌 버튼, 배치 저장, 터치 그림 |

S0에서 하지 않는 것: 나머지 스킬 넷·큰 기술 둘(S1), 패시브(S2), 얻는 법·떼의 수·난이도 다시 재기(S3), 튜토리얼·안내 줄, 스킬 전용 동작.

## 5. 값(시작값 — 랩에서 맞춘다)
| 스킬 | 대기 | 시동 | 모양 | 피해 | 덤 |
|---|---|---|---|---|---|
| 휘돌이 | 7초 | 0.15초 | 둘레 3m, 두 번 | 1 × 2 | 바깥으로 밀림 |
| 가로지르기 | 8초 | 0.12초 | 6m 길, 폭 2.4m | 2 | 끝에서 멈춤, 적을 지나간다 |
| 끌어모으기 | 9초 | 0.2초 | 앞 부채꼴 7m·120° | 0 | 방랑자 앞 1.8m로 모임 + 휘청 0.6초. 보스·엘리트는 안 끌린다 |
| 땅울림 | 10초 | 0.3초 | 앞 부채꼴 5m·100° | 2 | 휘청 0.8초, 자세 피해 큼 |
| 쟁반 뒤집기 | 게이지 | 0.3초(세계 멈춤) | 둘레 9m | 0(벽에 박히면 2) | 바깥으로 쏟기 + 휘청 2초. 보스는 휘청만 짧게 |

- 기세: 스킬이 아닌 것으로 쓰러뜨리면 모든 대기 −0.6초, 스킬로는 −0.3초.
- 게이지: 맞힌 휘두르기 한 번에 +1/40(광역이 몇 배로 채우지 않는다), 패링 +4/40, 딱 맞춘 떼기 +2/40. 스킬·큰 기술의 타격은 채우지 않는다. 화로에서 쉬어도 그대로.
- 스킬은 기력을 쓰지 않는다. 시동에 맞으면 끊긴다(대기는 쓴 채 — 헛쓴 것).

## 6. 위험·남는 것
- **v0.6.0을 main에 내기 전에 S0 판정을 닫는다**: 조작이 바뀌는 일이라 켬·끔 스위치로 숨길 수 없다. 접기로 하면 S0 커밋 묶음을 되돌린다(그래서 S0는 이어진 커밋으로 둔다).
- 얼린 값(0013): `skill.*`은 덧붙임. 돌리기 값은 그대로(뜻이 안 바뀐다).
- prefs: 배치 칸의 뜻이 바뀐다(옛 Q·E·LT·RT = 돌리기) — `MAGIC`을 올려 **배치만** 기본으로 되돌린다(다른 설정은 그대로 읽는다).
- 십자 키로 걷던 사람(스틱이 없는 패드)은 걷지 못한다 — 조작 설정에서 돌리기를 다른 버튼으로 옮겨도 십자 키는 걷기로 돌아오지 않는다. 판정 때 본다.
- 정체성(0150 9절)은 그대로 남은 위험: 스킬이 세면 패링·박자가 "안 해도 되는 것"이 된다 — 기세·게이지가 평타·패링에서만 찬다는 것이 막는 장치.
