## 2. 통합 — 나무 하나, 화폐 하나
- **화폐**: 마디(핵 + 종소리 조각)를 **기술 점수에 합친다**. 가진 점수 = 총 레벨 + 엘리트 첫 쓰러뜨림 + **보스를 이길 때마다(셋까지) + 종소리 조각**. 지금 내용으로 15 + 6 + 6 + 3 = **30**. 줍는 화폐는 잔불 하나만 남는다(0095 원칙 4가 더 단순해진다).
- **칸**: 패시브 15칸은 한 칸 1점(지금과 같다), 스킬은 다섯 단·큰 기술은 세 단(0158 그대로). 다 익히려면 48 + 15 = **63** — 반이 조금 안 된다.
- **갈래 셋**(지금 나무의 셋에 스킬을 태도로 나눠 넣는다):
  | 갈래 | 패시브(있는 것) | 스킬 | 큰 기술 |
  |---|---|---|---|
  | **흐름**(박자) | 고른 호흡 · 이어지는 박자 · 맺음타 · 빈틈의 박자 · 끝맺음 | 휘돌이 · 가로지르기 · 땅울림 | 몰아치기 |
  | **맞받기** | 받아내기 · 되돌려 치기 · 모은 맞받기 · 무너진 틈 · 맞서는 자 | 버팀 · 되울림 | 한 줄기 |
  | **자리**(발걸음) | 멈추지 않는 걸음 · 비껴서기 · 기우는 땅 · 착지의 순간 · 길을 여는 발 | 끌어모으기 · 던지기 · 잔불 흩기 | 쟁반 뒤집기 |
- **잠금**: 줄 셋 — 처음부터 / 쓴 점수 4 / 쓴 점수 8(0158의 규칙을 패시브에도). 패시브의 "앞 칸을 열어야 다음 칸"은 걷는다(줄 안에서는 자유 — 규칙이 하나가 된다).
- **옛 기록**: 연 패시브 칸은 그대로 연 채로(그만큼 쓴 점수로 센다), 핵·조각은 점수의 샘이 된다 — 잃는 것이 없다.
- 되돌리기(잔불)는 패시브까지 한꺼번에.

## 3. GUI — 창 하나, 탭 여섯
- **창은 하나**(늘 같은 자리·같은 크기), 위에 **탭**: 상태 · 장비 · 기술 · 도감 · 가게 · 설정. 탭 넘기기는 스킬 버튼 둘(LT·RT / Q·E — 지금의 "빠른 바꾸기"와 같은 손).
  - 멈춤과 화로가 **같은 창**을 연다. 화로에서는 올리기·사기가 켜지고(가게 탭이 보인다), 멈춤에서는 읽기·끼우기만(지금 규칙 그대로). 처음부터·타이틀로는 설정 탭 끝으로.
  - 멈춤의 아홉 줄 목록과 화로의 다섯 줄 목록이 없어진다 — 무엇이든 탭 한 번.
- **기술 탭**(시안 1): 왼쪽에 갈래 셋 × 줄 셋의 **칸 그림**(스킬 = 네모 + 단의 점 다섯, 패시브 = 동그라미, 큰 기술 = 마름모 — 그림은 지금 터치 버튼의 도트 그림을 쓰고 패시브 15개는 새로 찍는다), 오른쪽에 **고른 칸의 모든 것**(하는 일 · 다섯 단을 한 줄씩 · 두 고르기를 나란히 · 다음 단의 값 · 끼운 칸). 밝기 넷: 익힘 / 지금 살 수 있음(민트 점선) / 잠김 / 고른 칸(흰 테).
  - 십자 키로 칸 사이를 걷고(격자 — 돌지 않는다), 확인 = 올리기, 고르기 바꾸기 = 땅 돌리기 버튼 둘, 끼우기 = 공격 버튼. 터치는 칸을 누른다.
- **상태 탭**(시안 2): 왼쪽 인형과 막대, 가운데 레벨 셋(단의 점 다섯 + "지금 → 다음" + 값), 오른쪽에 지금의 수치와 장신구. 레벨 화면이 따로 없다.
- **꾸밈의 규칙**: 테 두 겹 + 탭 줄 + 아래 버튼 안내 한 줄(늘 같은 자리), 금빛 = 내 것·고른 것 / 민트 = 지금 할 수 있는 것 / 흐림 = 잠김, 묶음마다 작은 머리글, 값은 글 대신 점·막대로. 빨강은 여전히 위험 전용.
