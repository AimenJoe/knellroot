# 0132. 떠난 마을의 모델 — Gemini 그림 → Meshy → 부위·뼈·동작(첫째: 등딱지짐승)

- 날짜: 2026-11-09
- 상태: **채택·진행 중**(`release/v0.5`). 사장 2026-11-09: "Meshy에 넣을 이미지 작성을 위한 프롬프트 및 참조 이미지 줘" → 프롬프트·참조 그림(`docs/art/gemini-prompts-0132.md`·`docs/art/refs-0132/`). 사장이 그림을 만들고(등딱지짐승 v1 → v2 셋 중 가운데) Meshy GLB를 받아 넘겼다.
- 흐름은 0038·0060 W3와 같다(KB `guides/ai-mesh-to-rigid-part-model.md`): `meshy_convert.py`(줄이기 + 새 UV + 색 굽기) → 모델 스크립트(`classify`로 부위, 뼈, `darken_grey`, 동작) → `assets/models/<이름>.glb` → `build.rs`가 저절로 넣는다.

### 등딱지짐승에서 정한 것
- **가운데 맞추기**: `meshy_convert`는 위 45%의 가운데를 원점에 둔다 — 결정 뿌리가 한쪽(+X)에 솟아 몸이 −X로 0.11m 비껴 왔다. 모델 스크립트가 부위를 +0.11m 옮긴다(`SHIFT_X`, 자르는 치수도 옮긴 자리로). 다시 변환하지 않는다(15분).
- **눈**: 눈은 따로 된 면이 아니라 텍스처의 호박빛 점이다(가시짐승은 면이 있었다). 정면 직교 렌더를 텍스처째 찍어 호박빛 화소를 3D로 되짚어 잰 자리(±0.10, −0.47, 0.365)의 타원 안 면을 `glow_eyes`로 잘랐다.
- **공격 = 앞을 들고 쿵**(`Atk::Smash` = 둘레 원판): 0.15 움츠림 → 머리를 등딱지 안으로 쏙 넣고 앞을 35~38° 들어 앞발이 허공에 늘어진다(0.6 정점 — 예고 동안 여기서 버틴다) → 0.72 쿵 내려앉아 등딱지가 납작(맞는 틱). 앞을 드는 셈은 가시짐승 `charge_windup`과 같다(뒷발 둘레로 root를 돌리고 옮김).
- **예고가 몸으로 읽힌다**: 쿼터뷰 위에서는 쉬는 동안 얼굴이 챙에 가려 눈만 조금 보이는데, 앞을 들면 얼굴과 호박빛 눈이 통째로 드러난다 — 그것이 "곧 쿵"의 신호(0065·0073 모션이 주).
- 처음 시안은 앞발을 −60°로 들어 몸이 들린 만큼 더해져 수평(대포처럼)이 됐다 → 앞발은 몸 기울기에 맡기고 거의 수직으로 늘어뜨린다.
- 잿빛은 다른 적과 같이 0.6배(`GREY_K`·`GREY_SAT`, 0060 W3).
