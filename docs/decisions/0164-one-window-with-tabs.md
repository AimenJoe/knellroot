# 0164. 창 하나 + 탭 — 멈춤과 화로가 같은 창을 연다

- 날짜: 2026-11-13
- 상태: **만듦, 판정 전** — 0160 3절의 제안을 기술 화면(0161·0163)의 생김새로. 사장 2026-11-13 "응 괜찮아 보이네"(기술 화면) → "기술/장비 등이 탭 형식으로 좀 유기적으로 메뉴에 녹아져 있으면 좋겠어".

## 왜
멈춤은 여덟 줄, 화로는 네 줄의 목록이었고 그 줄마다 생김새가 다른 창(장비 440×226 · 도감 440×236 · 설정 340 · 가게 300 · 레벨 300 · 기술 464×228)이 열렸다. 무엇을 보든 "목록 → 줄 → 창 → 닫기 → 목록"을 거쳤고, 창마다 자리·크기·닫는 법의 안내가 달랐다. 사장의 말은 틀만 같은 여섯 화면이 아니라 **한 메뉴의 여섯 면**이다.

## 정한 것
| 무엇 | 결정 |
|---|---|
| 창 | **하나**(464×228 — 기술 화면의 틀 `app/frame.rs`). 늘 같은 자리·같은 크기·같은 탭 머리·같은 지갑(기술 점수 · 잔불). 탭을 넘기면 몸만 바뀐다 |
| 멈춤(Esc·Start) | 목록을 거치지 않고 **바로 이 창**: 탭 = 상태 · 장비 · 기술 · 도감 · 설정. "계속" = 닫기(뒤로·✕·Start·창 밖). 이 판에서 마지막에 보던 탭에서 다시 열린다(새 판은 상태) |
| 화로(쉬기) | 같은 창, 탭 = 상태 · 장비 · 기술 · 도감 · **가게** · 설정. 늘 상태 탭에서 열린다(첫 일이 레벨 올리기). "떠나기" = 닫기. 올리기·사기·되돌리기는 여기서만 켜진다(멈춤은 읽기·끼우기 — 0104·0161의 규칙 그대로) |
| 타이틀의 설정 | 같은 틀에 탭 하나(지갑 없음). 조작 설정은 지금처럼 위에 얹는다 |
| 처음부터 · 타이틀로 · (개발판) 개발 | 멈춤의 **설정 탭 끝 줄**(조작 설정 아래 — 묻는 창 그대로). 화로·타이틀의 설정에는 없다. 설정의 "돌아가기" 줄은 없앴다(창이 닫는다) |
| 탭 넘기기 | **스킬 버튼 둘**(LT·RT / Q·E) + 탭 머리 누르기(터치·마우스). 끝에서 돈다. 넘기면 스택의 맨 위 칸을 **바꾼다**(`Go::Swap` — 쌓지 않는다: 어느 탭에서든 뒤로 한 번에 닫힌다). 탭 위에 얹은 작은 목록·묻는 창이 떠 있는 동안은 넘기지 않는다 |
| Select(Tab) | 싸움에서 장비 탭을 바로(0070 그대로), 장비 탭에서 다시 누르면 닫힌다 |
| 몸의 문법 | 어느 탭이나 **왼쪽 = 고르는 것(칸·줄) · 가운데 세로 선 · 오른쪽 = 고른 것의 상세 · 아래 = 같은 자리의 버튼 안내**(자리는 기술 화면의 270 / 166 그대로). 오른쪽 칸의 머리는 그림 · 이름 · 갈래 한 줄 · 상태 한 줄, 그 아래 글·수치 줄(넘치면 읽는 사람이 굴린다 — 0068). 창 안에 또 창(테·제목 줄)을 그리지 않는다 |
| 색 | 금빛 = 내 것·고른 탭 / 민트 = 지금 할 수 있는 것 / 흐림 = 잠김·모자람. 빨강은 위험 전용(나빠지는 값의 ▼만 옛 그대로 붉은 계열) |

## 탭마다
- **상태**(새 화면 — 옛 화로 목록·레벨 창을 대신한다): 왼쪽에 방랑자 인형(장비 탭과 같은 3D)·총 레벨·체력과 기력의 막대, 그 옆 고르는 줄 여섯 — 레벨 셋(이름 · 한마디 · 단의 점 다섯 · 다음 단의 잔불)과 끼운 장신구 세 칸. 오른쪽은 고른 줄의 "지금 → 다음"(올릴 수 있으면 민트)과 지금의 수치. 화로에서 확인 = 올리기(묻는 창), 멈춤에서는 읽기만(상태 줄 "쉼터 화로에서 올린다").
- **장비**: 왼쪽에 인형과 칸 넷(옛 자리 그대로 — 무기는 왼쪽, 장신구 셋은 오른쪽), 오른쪽에 고른 것의 그림·이름·숫자·설명·상태. 확인하면 **그 칸 곁에** 후보의 작은 목록이 뜨고(기술 탭의 "칸에 할 수 있는 일" 목록과 같은 꼴) 오른쪽이 커서가 놓인 후보를 지금 것과 견준다(`값 → 값 ▲▼`). 옛 창의 아래 왼쪽 설명 칸·오른쪽 후보 칸은 없다.
- **기술**: 그대로(0161·0163). 머리 줄만 탭 줄이 되었다.
- **도감**: 왼쪽 위에 묶음 머리(◀ 적 · 장신구 ▶ — 밑줄 하나짜리 작은 글, 위 탭과 다른 꼴)와 목록, 오른쪽에 그림·이름·나오는 곳·관찰 줄. 묶음은 **좌우**(십자 ←→ / A·D)와 누르기로 넘긴다 — 스킬 버튼은 위 탭의 것이다.
- **가게**: 왼쪽 살 것의 줄(이름 … 잔불), 오른쪽에 도는 그림 · 이름 · "장신구 · 잔불 60" · 살 수 있나(민트) · 하는 일과 세계 안의 말. "떠나기" 줄은 없다.
- **설정**: 왼쪽 줄 표(이름 · ◀ 값 ▶), 오른쪽에 고른 줄이 무엇을 하는지 한두 문장(새 글 열둘).

## 탭 사이의 이음(둘만)
1. **상태 탭의 장신구 칸에서 확인 → 장비 탭의 그 칸**(탭을 바꾸고 커서를 그 칸에 — 멈춤·화로 모두).
2. **탭 머리의 민트 점** = 그 탭에 지금 할 수 있는 것이 있다: 올릴 단이 있는 상태 · 남은 점수로 살 것이 있는 기술 · 살 것이 있는 가게. 쉬는 동안(화로)에만 뜬다 — 멈춤에서는 살 수 있는 것이 없다.

## 이 걸음에서 정한 작은 것
- **멈춤이 여는 탭**: 이 판에서 멈춤 창이 마지막에 보던 탭(Select로 연 장비 탭도 센다). 장면 스택 밖의 한 칸이라 `App`에 화면별 커서 필드를 늘리는 대신 판의 것으로 두었다(`App::pause_tab` — 지역 잇기의 `stage`·`down`·`rest_at` 곁, 새 판을 세우면 상태로). 탭 안의 커서는 탭을 넘기면 처음 자리에서 시작한다(기술 = 화로면 살 수 있는 첫 칸·아니면 배운 첫 스킬).
- **장비의 빨리 바꾸기**: 스킬 버튼 둘이 탭 넘기기가 되어 **공격 버튼 하나**(다음 것으로 돈다)로 옮겼다. 그런데 공격 버튼이 메뉴에서 이미 다른 일을 하는 장치가 있다 — 키보드만 배치의 J는 확인이고, 키보드+마우스 배치의 왼쪽 클릭은 누르기다. 그 장치에서는 빨리 바꾸기를 끄고 안내 줄에도 띄우지 않는다(`input::swap_free` — 확인 → 후보 목록으로 바꾼다). 패드 기본 배치(공격 = X)와 공격을 다른 키로 옮긴 키보드에서만 된다. **사장이 볼 것: 패드에서만 되는 빨리 바꾸기를 둘지, 아예 뺄지.**
- **지갑은 어느 탭에서나 둘 다**(기술 점수 · 잔불): 탭마다 지갑이 달라지면 탭 머리가 밀린다. 탭 줄은 지갑까지의 폭에 맞춰 옆 여백부터 줄이고(18 → 6) 그래도 넘치면 글을 줄인다(`ui::window_tabs` — 영어 여섯 탭이 그렇다).
- **창 밑에 HUD를 깔지 않는다**(옛 멈춤은 깔았다): 창이 화면을 거의 다 쓰고 체력·기력은 상태 탭이, 잔불은 지갑이 보인다.
- **알림**(산 것·올린 것·안 되는 까닭)은 오른쪽 칸의 상태 줄 자리에 잠깐 대신 뜬다(기술 화면이 하던 대로) — 창이 화면을 다 써서 위쪽 알림 자리가 없다.
- **상태 탭의 터치**: 다른 줄은 고르기만, 고른 줄을 다시 누르면 확인(장비·기술 탭과 같은 두 걸음). 가게·설정의 줄은 줄 표라 한 번에.
- 넘치는 줄 목록의 ▲▼는 줄 끝과 세로 선 사이에(머리 줄에는 지갑이 있다). 안내 줄은 좁은 화면에서 0.6배까지 줄인 뒤에 자른다(기술 탭 4:3 영어 — 되돌리기 단추와 나란히).
- 영어: 탭 이름 "Gear"(Equipment는 탭 줄에 길다), 설정 줄 "Auto aim after"(값 "1s"와 이어 읽힌다 — 설명이 오른쪽에 있다).
- 개발 창 → 도구 → "기술 끼우기"는 멈춤의 기술 탭을 연다(탭을 넘길 수 있다).

## 코드
- `app/flow.rs`: `Host`(타이틀·멈춤·화로)·`Tab`·`tabs`·`tab_scene`·`tab_of`·`tab_step`·`tab_pick`·`pause_opens`·`remembered`·`Go::Swap`, 설정 줄 `settings_rows(…, host)`·`choose_settings`. 장면 `Scene::Status`·`Equip`·`Skills`·`Codex`·`Settings`가 연 곳을 들고 다닌다(`Shop`은 화로뿐). 옛 `Scene::Pause`·`Hearth`·`Level`, `PauseItem`·`choose_pause`는 없다.
- `app/stack.rs`: `Go::Swap`(맨 위 칸만 바꾼다), `Stack::any`.
- `app/tabs.rs`(새): 탭 줄·지갑·넘기기(`tab_input`·`show`·`draw_tab_window`·`tab_foot`), 몸의 문법(`draw_left_list`·`draw_pane_head`·`draw_pane`·`Ln`), 민트 점의 규칙 `tab_marked`.
- `app/status.rs`(새 — 옛 `hearth.rs`), `equip.rs`·`codex.rs`·`shop.rs`·`settings.rs`·`skills.rs`는 몸만. `pause.rs`는 없앴다.
- `ui.rs`: `window`가 탭의 표시와 누를 자리를 다루고(`window_tabs`), 줄 표를 창의 배로 그리는 `list_k`. `input.rs`: `Act::Tabs`·`swap_free`.
- 시험: 탭 줄과 장면의 짝·넘기기(돌기·연 곳 유지)·멈춤이 여는 탭·설정 줄(멈춤에만 끝 줄)·스택이 자라지 않음·민트 점·상태 탭의 줄과 올리기 규칙·장신구 칸의 이음·빨리 바꾸기가 꺼지는 장치·탭 줄 맞추기.

## 아직 아닌 것
- **HUD**(0160 5절)는 손대지 않았다.
- 패드·Android·iOS 실기에서 LT·RT로 탭을 넘기는 것과 X의 빨리 바꾸기는 **실기로 확인하지 못했다**(헤드리스 시험은 키보드·터치뿐 — 규칙은 단위 시험).
- 탭마다의 커서를 기억하지 않는다(넘기면 처음 자리). 화로는 늘 상태에서 열린다.
- 설정 탭의 오른쪽 칸은 글이 한두 문장이라 비어 보인다 — 채울 것(조작 표 미리보기 등)은 판정 뒤에.
- 도감의 적 그림 칸(52×72)은 옛 크기 그대로 — 오른쪽 칸이 좁아져 키우지 않았다.
- 4:3·영어에서는 탭 줄이 빽빽하다(여백 6·글 조금 줄임) — "Skill points"를 줄이면 풀린다(0161에서 받아들인 글이라 두었다).
