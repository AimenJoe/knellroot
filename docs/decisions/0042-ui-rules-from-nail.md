# 0042. UI는 첫 게임(nail) 방식대로 — 짧은 안내 + 키캡, fit·wrap, 개발 넘침 검사(F4)

- 날짜: 2026-11-04
- 상태: 채택(사장: "UI 어떻게 만드는지는 under the roots 꺼랑 kb 확인해서 봐봐").
- 계기: 0041(640×360)로 검은 테두리가 사라지자, 게임 화면보다 넓던 타이틀·멈춤의 조작 안내 줄(아홉 항목)이 창 밖으로 잘렸다. 처음엔 두 줄로 나눴지만 nail이 이미 버린 길이었다.
- 근거: KB `guides/second-game-project-day-one.md`("가져올 코드: `ui::wrap/fit`, F3 글자 넘침 검사"), `guides/small-game-localization.md`(넘침을 기계로 거르기·고정 칸의 마지막 안전장치 `fit`·한 줄 안내는 짧게), `concepts/hud-readability-and-quick-slots.md`(창이 덮는 HUD는 뺀다). nail 0089(넘침 검사기 + 헤드리스 순회), 0153(키캡, 타이틀 안내는 두 항목), 0036(안내는 지금 장치를 따른다 — 이미 있음).

## 정한 것
1. **안내는 짧게**: 타이틀·멈춤·결과·조작 설정 아래에는 메뉴 안내(고르기·확인)만. 전체 조작은 "조작 설정" 화면에 있다 — 그래서 그 화면의 공격 줄을 "공격(꾹: 강공격)"으로(넘치면 `fit`). 안 쓰게 된 글(`verb_move`·`verb_pause`)과 `Act` 변형은 걷었다.
2. **키캡**(`ui::key`, `KEY_OPEN`·`KEY_CLOSE`): 안내 속 키 이름은 테두리 칸 + 밝은 글, 나머지 흐린 글은 본문 색으로 올린다. `width`가 칸 여백까지 세어 가운데 맞춤·`fit`이 그대로 된다.
3. **`fit`**(넘치면 "…") — 고정 칸의 마지막 안전장치. **`wrap`/`wrap_with`**(단어 단위 + CJK 글자 단위·금칙) — 시작 이야기 두 줄·결과 문장은 `text_center_wrapped`로 화면 폭 90% 안에서 줄을 바꾼다. 시험 셋(단어·CJK 금칙·키캡 조각).
4. **넘침 검사기**(`ui::check`, 개발 빌드, **F4**로 켬 — F3은 개발 줄): `Ui::text`가 그린 칸을 모아 화면 밖·게임 화면 밖·겹침·`fit` 잘림을 콘솔에 한 번씩. 헤드리스 순회(`shot.js` 흐름을 F4 켜고 한국어·영어로)로 걸렀다: 보스전 멈춤에서 메뉴 안내가 아래 보스 띠와 겹침 → 멈춤 밑 HUD에서 보스 띠를 뺐다(`hud::draw(.., under_menu)`). 그 뒤 두 언어 모두 0.

## 새 화면을 만들 때
F4를 켜고 한국어·영어로 본다(언어가 늘면 가장 긴 언어로). 콘솔의 `[ui-check]` 줄이 없어야 한다.
