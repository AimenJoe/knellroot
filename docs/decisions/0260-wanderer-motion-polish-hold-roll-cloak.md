# 0260 — 방랑자 동작 다듬기: 걸을 때 무기 쥔 팔 · 구르기 끝 정면 쪽 · 망토가 손을 따라가지 않게

- 날짜: 2026-11-20
- 상태: 채택(개발판 — 판정 전, 체크리스트 101)
- 사장: "모션쪽 좀더 다듬자. 걷기, 달리기 무기가 손에 안붙음 / 회피 구른 후 너무 옆이야 각도 좀 줄여줘 정면과 가깝게 / 망토가 손이랑 같이 움직이는 경우가 많음"

모두 Blender 원본 `tools/art/blender/wanderer_skin.py`에서 고쳤다(게임 코드는 그대로 — GLB만 다시 구움).

## 1. 걷기·달리기에 무기가 손에서 떨어져 보임 → 오른팔을 쉬는 자세 쪽으로 붙든다
- 잰 것: 무기는 손뼈를 1cm 안으로 따라간다(붙어 있다). 그런데 Meshy 걷기·달리기 원본은 팔을 내려 흔들어 **손이 망토 안**(높이 0.36~0.48m, 서기는 0.65m)으로
  들어가 무기 자루만 망토 밖에 떠 보였다.
- 정한 것: `ARM_HOLD` — 걷기·뒷걸음 0.7, 달리기 0.5만큼 오른팔 사슬(어깨·위팔·아래팔·손)의 지역 돌림을 서기 첫 자세 쪽으로 섞는다(`hold_arm`, 쿼터니언 slerp).
  왼팔·다리·몸통의 흔들림은 원본 그대로 — 걷는 맛은 남고 무기를 쥔 손이 몸 앞에 보인다.

## 2. 구른 뒤 몸이 너무 옆을 봄 → 끝 방향을 −15°로
- 잰 것: 구르기(`dodge`)의 끝 자세 엉덩이 방위 −70°/−74°(정면 0°, 서기 −24°).
- 정한 것: `ROLL_FACE = −15°` — 웅크리기 들어갈 때·풀 때의 자세를 그 차이만큼 돌려(`craft_roll`의 `placed(..., extra)`) 처음·끝이 정면 쪽 −15°에
  닿게. 게임의 몸 돌림 표(`TRAVEL_TURNS`)도 같은 몫으로 맞췄다(구른 쪽 = 몸 앞은 그대로 — 시험 `wanderer_clips_start_and_end_facing_front_and_do_not_spin` 통과).

## 3. 망토가 손을 따라감 → 망토 정점은 팔 사슬·덤 뼈에서 가슴으로
- 잰 것(주먹 2타에서 가장 많이 움직인 정점): 자동 리깅이
  - 망토 자락을 **어깨**(정점 314 가운데 보라 191)·위팔(100 가운데 76)에 묶었고,
  - 오른손 밑의 덤 뼈 **`Bone_061`**(mixamo 이름이 아닌 뼈)에 망토 판 정점 30개(무게 18.7)를 100% 묶었다 — 주먹을 뻗으면 이 판이 0.9m를 같이 나갔다.
    왼손 밑 `Bone_060`은 빈 뼈.
- 정한 것(`confine_arms`에 둘을 더함 — 0256의 거리 가두기는 그대로):
  - **망토 정점 고르기 `cloak_verts`**: 굽힌 텍스처의 색을 정점마다 평균해 보라(색상 0.70~0.92 · 채도 0.25 위)인 정점 → 팔 사슬(어깨·위팔·아래팔·손) 무게를 모두 가슴(Spine2)으로.
  - **팔 사슬 밑의 덤 뼈 `stray_arm_bones`**: mixamo 이름이 아니고 조상에 팔 사슬이 있는 뼈의 무게는 색과 상관없이 모두 가슴으로.
  - 어깨는 거리 가두기도 더한다(`CONFINE_MORE` — 0.10~0.18m). 손은 망토 정점이 없어(보라 0) 거리 규칙을 걸지 않는다(손목 털까지 끊긴다).
  - 결과: 정점 500개의 무게 49.9가 가슴으로, 내보낸 GLB에서 `Bone_061`에 묶인 정점 0.
