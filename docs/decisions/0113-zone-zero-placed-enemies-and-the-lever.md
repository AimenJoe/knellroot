# 0113. 0번째 지역 — 물결 대신 서 있는 적, 넓은 지도, 문 장치(지름길)

- 날짜: 2026-11-08
- 상태: **채택·구현**(`release/v0.4` → 이어서 `release/v0.5`의 바탕). 사장 2026-11-08: "웨이브라는 건 필요 없어. 테스트·PoC·특별한 기믹의 스테이지에서 필요한 것. 일반적으로는 지역을 더 넓게 만들고 몹들의 밀집도를 조정하는 것으로 하자. 지금의 맵은 PoC를 기준으로 작게 만들어진 것이니 실제 0번째 지역으로 확장하자." → 인터뷰 넷 다 추천대로.

## 왜
- 물결은 "방에 들어서면 적이 쏟아진다" — 시험(PoC 판정)엔 좋지만 소울류 지역의 맛(탐험·자리 잡은 적·고리 지름길)이 없다. 지도가 작아(약 50×74m) 길도 한 줄이었다.
- 바깥(2차 — 비평·분석 글, 개발사 1차 출처 없음): 화톳불에서 쉬면 보스·중간 보스 빼고 적이 되살아나 되돌아가는 길에 값이 생긴다, 지역은 지름길로 이어진 고리(나선) — 열면 되돌아가기가 줄어든다, 넓은 싸움터(open arena)와 좁은 길을 번갈아(긴장·쉼), 적의 자리가 앞길·물러설 길을 막는다. KB `wayfinding-without-a-minimap`(갈 곳이 빛난다 — 문 장치도 호박빛).

## 정한 것(인터뷰)
| 물음 | 고른 것 |
|---|---|
| 적이 언제 다시 서나 | **화로에서 쉬면(쓰러져 다시 설 때도), 엘리트·보스 빼고** — 이 판에 쓰러뜨린 엘리트는 다시 서지 않는다 |
| 언제 싸움에 들어오나 | **보면 깨고, 멀어지면 제자리로**: 시야 `SIGHT_RANGE` 9m(벽·턱 너머는 못 봄 — 길찾기 `nav.clear`), 발소리 `HEAR_RANGE` 3m(벽 너머도), 높이 차 `SIGHT_DY` 2.5m 안, 맞으면 깸, 깨면 곁 `ALERT_RADIUS` 4.5m의 동료도 깸. 제자리에서 `LEASH_RANGE` 18m보다 멀어지고 플레이어도 그만큼 멀면 돌아가 **가득 찬다**(끌고 가 깎는 꼼수 막기). 플레이어가 제자리 끈 밖이면 알아차리지 않는다(왕복 없음) |
| 문은 어떻게 열리나 | **돌아가는 길 끝의 장치**(`V`): 서쪽 성벽길 북쪽 끝에서 당기면 문이 열리고 **기록에 남는다**(`gates` — 판을 넘어 열린 채, 지름길). 성벽길 끝 틈으로 뜰에 뛰어내리면 문 앞 화로까지 한 고리 |
| 얼마나 키우나 | **약 3배, 고리 하나**: 43×66칸(86×132m) |

## 0번째 지역 "침묵의 성소"(지도는 `tools/maps/sanctuary.py`가 생성)
```
            [성소: 잠든 문지기]            ← 그대로
   ┌V──────────GGGGG─────────R────┐
   │성│        뿌리의 뜰(싸움터)     │탑 │ ← 북서 단 +1m · 가운데 꺼진 터 · 남동 단(Y 되풀이 가시짐승) · 가운데 X 굳은 잔재
   │벽│                               │+1m│   동쪽 무너진 탑: 상자·등잔 +1
   │길│──────────┐     ┌──────────────┘
   │+3│          │무너진│
   └/─┴뿌리 굴 R──┤ 길  │                ← 뿌리 굴: 화로·Z 남는 잔재(성벽길 경사로 발치)
                  └┐ ┌─┘
                   다리(낭떠러지)
               [무너진 입구 R · P]
```
- 화로 셋(문 앞·뿌리 굴·입구), 상자 둘(탑·입구), 숨은 물건 여섯(등잔 1·한 모금 2·종소리 조각 3 — 수는 그대로라 v0.4 기록의 수와 맞는다), 서 있는 보통 적 24(잔재 17·가시짐승 7) + 엘리트 3. 구역 카드 넷(무너진 입구 → 무너진 길 → 뿌리의 뜰 → 닫힌 성소).
- 길: 입구 → 다리 → 무너진 길 → 뜰(문은 닫혀 있다, 목표 "성소 문을 열 길을 찾아라") → 길 서쪽 뿌리 굴 → 경사로(3m를 여섯 칸) → 성벽길 → 장치 → 뛰어내리기 → 문 → 성소.
- 문을 한 번 열면 다음 판부터는 입구 → 뜰 → 문으로 곧장(소울의 열린 지름길).

## 코드
- `enemy.rs`: `EState::Idle`(제자리에서 제 일 — 바라보던 쪽으로)·`Return`(제자리로, 닿으면 가득), `Enemy::home`·`place`·`notice`.
- `world.rs` `tick_enemies`: 알아차림·동료 깨우기·끈, 돌아가는 길은 제자리 칸마다 거리 지도 하나를 만들어 둔다(`home_flows`).
- `stage/mod.rs`: `StageDef::spawns`(서 있는 적)·`elites`(물결 번호 없이)·`obj_explore`, `StageRun::populate`(시작·쉬기 때), 문 장치 `LEVER_GLYPH`·`near_lever`·`gate_opened`·`take_gate_new`·`set_gate_opened`. 물결(`waves`)은 남겨 둔다 — 시험·기믹 스테이지용, 비면 쓰지 않는다. 쉴 수 있나는 싸우는 적만 센다(제자리의 적은 아니다). 마지막 구역(성소) 판정은 구역 수로.
- `save.rs` `gates`, 옛 기록의 "판 안에서 문이 열렸다"(`run.gate`)는 이어할 때 한 번 `gates`로 옮긴다. `hud.rs` "키 당기기", `render.rs` 장치(돌 기둥 + 손잡이, 당기기 전 호박빛).
- 개발 "문 앞"은 보스만 남긴다(문 앞 가시짐승이 바로 덮쳤다).
- 시험: 알아차림 셋(시야·벽·발소리 / 맞음·동료 / 끈·가득)·서 있는 적·문 장치·이미 연 문·쉬면 다시 섬(쓰러뜨린 엘리트 빼고)·**화로 곁은 처음부터 안전**(이 시험이 문 앞 화로 옆 엘리트 배치를 잡았다 — 남동 단으로 옮김)·엘리트 첫 덤·`gates` 기록·지도 도달·높이.
- 성능(네이티브 릴리스, 틱만): 적 28이 모두 쫓을 때 0.13ms/틱, 다 제자리일 때 0.04ms/틱. 그리기(모델 28)는 Android 실기에서 봐야 한다.

## 판정(사람)
- 지역이 "넓어졌다·길을 찾는다"로 느껴지나, 길을 잃지 않나(목표 글 + 장치의 호박빛만으로).
- 적 밀도: 한 무리(2~4)씩 끊어 싸우게 되나, 몰려오지 않나(시야 9m·동료 4.5m가 맞나).
- 끈: 도망치면 돌아가는 게 자연스럽나(가득 차는 게 억울하지 않나).
- 장치 → 뛰어내림이 "아, 이어졌다"로 읽히나. 문이 다음 판에도 열려 있는 게 맞나.
- 처음 한 판 길이(10~15분 목표), Android 30fps(적 28).
