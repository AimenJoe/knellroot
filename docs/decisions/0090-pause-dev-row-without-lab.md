# 0090. 멈춤 창에서 연구소를 빼고 그 자리에 개발 줄

- 날짜: 2026-11-07
- 상태: **채택·구현**(개발판)
- 사장: "이제 멈춤 메뉴에 연구소는 빼주고 그자리에 개발 메뉴만 남으면 되겠지."

## 전(0079·0083)
- 개발판 멈춤 창: 계속·장비·설정·연구소·처음부터·타이틀로·개발(끝).
- 0083에서 개발 창이 nail 꼴(묶음 탭)이 되며 첫 탭 "도구"의 첫 줄이 연구소라서, 멈춤 창에 연구소가 두 번 있는 셈이었다.

## 결정
- 멈춤 창: 계속·장비·설정·**개발**·처음부터·타이틀로. 개발 줄은 개발판에만 있고 연구소가 있던 자리(설정 아래)에 둔다.
- 연구소는 타이틀(설정 아래 줄)과 개발 창 도구 탭에서 연다.
- 운영판 멈춤 창은 그대로다(계속·장비·설정·처음부터·타이틀로).
- 처음부터·타이틀로의 줄 자리는 바뀌지 않아 시험 스크립트 길은 그대로다. 터치 스크립트의 줄 수만 7 → 6.
