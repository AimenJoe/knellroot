## 본 것 — 왜 그랬나
| 무엇 | 어땠나 | 까닭 |
|---|---|---|
| 무기 넷 | 검 = 납작한 상자 날 + 상자 끝, 망치 = 정육면체 + 띠, 지팡이 = 막대 + 구슬, 쇠뇌 = 상자 셋의 T | 0037·0051 때 상자 부위(`box`)로만 지었다. 0139에서 소품용으로 만든 도구(돌린 꼴·꺾인 관)를 무기에는 안 썼다 |
| 등잔 | 덩어리 하나 | 같음 |
| 장신구 아홉 | 종의 걸이가 상자 십자, 굶주린 뿌리가 상자 더미, 잔불 주머니가 항아리로 보임, 종 조각이 덩어리 + 상자, 짚신의 깃이 막대 | 0068 때 `blob` + `box`만 |
| 두건 | 뒤에서(게임이 늘 보는 쪽) 무늬 없는 보라색 공 + 뿔 같은 귀. 0153에서 붙인 "두건 꼬리"는 뒤통수에 붙은 넥타이 같은 띠 | Meshy 원본의 두건이 민짜 공이다(앞 그림 한 장에서 지어낸 뒤통수). 0153의 띠는 뒤통수 **가운데에서** 시작해 곧게 늘어져, 두건의 일부가 아니라 덧붙인 것으로 읽혔다. 줄이며 생긴 울퉁불퉁한 면에 툰 음영이 얼룩으로 감겼다 |

## 한 것
### 무기(`wanderer.py` `weapons`) — 약속은 그대로: 손 자리·길이·넓은 면의 방향(`item_view.rs` 각도), 부위 이름
| 무기 | 꼴 |
|---|---|
| 검 | 마름모 단면의 **잎 꼴 날**(등줄기에 밝은 선) · 날 쪽으로 굽은 코등이와 끝 구슬 · 감은 손잡이 · 자루 끝 |
| 망치 | 가로로 누운 **통 머리**(양 끝 금빛 테 · 가운데 띠) · 감은 자루 · 목 테와 마개 |
| 지팡이 | 긴 대 · 앞 끝은 **두 갈래가 하늘빛 결정을 품는다**(결정만 각지게) · 감은 천과 늘어진 끝 · 뒤 끝 물미 |
| 쇠뇌 | **굽은 활**(끝이 쏘는 이 쪽으로) · 걸린 시위(V) · 촉과 깃이 달린 볼트 · 개머리가 굵은 몸 · 발걸이 · 방아쇠 |
| 등잔 | 배 부른 병 + 금빛 테 + 손잡이 고리, 불꽃은 물방울 꼴 |

### 장신구(`charms.py`) — 이름(= 기록 키)·하는 일은 그대로
종지기의 귀(벌어진 입술의 종 + 고리 + 추) · 굶주린 뿌리(굽은 송곳니를 각진 뿌리가 감아 오른다) · 잔불 주머니(조인 목 + 주름 입 + 비치는 불씨 + 늘어진 끈) · 깨진 종 조각(누운 종의 깨진 반쪽 + 떨어진 조각) · 가벼운 발(엇건 끈 + 잎 꼴 깃) · 단단한 껍질(테 + 돔 + 비늘판 다섯) · 물 받는 항아리(돌린 꼴) · 꿰맨 천(엇건 땀 + 실을 문 바늘). 무거운 손은 그대로.

### 두건(`wanderer.py` `dress_hood`)
- 0153의 띠를 **뺐다**.
- **꼭지**: 정수리 뒤에서 솟아 뒤로 넘어가 늘어지는 끝 + 크림 끝단 + 작은 금빛 종(가슴의 종과 짝). 뒤·옆 실루엣이 "공"에서 "두건"이 된다. 제 뼈(`hood_tip`)라 걸을 때·서 있는 몸짓 때 따로 흔들린다.
- **뒤통수의 솔기**: 꼭지 밑에서 아랫단까지의 가는 줄(짙은 안감 색) — 실제 두건 면에 광선을 쏴 그 위에 앉힌다.
- **면 고르기**: 텍스처가 라벤더인 면에만 닿은 정점을 이웃 평균으로(여섯 번) — 얼굴·귀·잘린 목은 그대로, UV는 안 바뀐다.
- 해 보고 뺀 것: **아랫단 말림**(돔의 처마 밑이라 게임 눈(뒤 위)에서 안 보인다) · **귀 구멍의 테**(귀 옆면을 타고 흘러 지저분했다 — 타원체 어림으로 두면 떠서 고리가 됐고, 실제 면에 쏘면 귀에 걸렸다).

## 사장이 볼 것
- **두건 꼭지는 새로 더한 생김새다**(원본 그림에 없다 — 0153의 띠를 대신한다). 고깔 같아 싫으면 `dress_hood`의 꼭지 한 덩이를 빼면 솔기와 고른 면만 남는다.
- 지팡이의 **결정 갈래**·쇠뇌의 **굽은 활**도 생김새를 정한 것이다 — 세계관(순례자의 지팡이·화약 쇠뇌)과 어긋나면 말해 달라.
- 더 나아가려면: 두건 자체의 주름·테는 텍스처에 있어야 한다 — 뒷모습 그림을 같이 주고 Meshy에서 다시 뽑는 길(0153의 같은 메모).
