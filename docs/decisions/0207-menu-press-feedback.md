# 0207 — 메뉴 누름 피드백: 확인을 0.09초 붙잡아 눌린 꼴을 보인 뒤 넘긴다

- 날짜: 2026-11-15
- 상태: 채택(개발판, 판정 전)
- 사장: "UI 메뉴에서 버튼 눌리는 감이 없으니 눌리는 효과 추가해줘."
- KB: `concepts/game-menu-scene-stack-and-focus.md` ⑥(이 결정으로 더함)

## 까닭
확인을 누른 그 틱에 장면이 바뀌어, 고른 줄은 눌린 모습 없이 사라지고 다음 창이 떴다. 소리(`UiConfirm`)도 장면이 바뀐 뒤에 났다.
바깥 자료(2차): UI 누름 피드백은 100~160 ms, 눌림 = 살짝 가라앉거나 어둡게, 넘어가기 전에 짧은 지연이 없으면 눌린 꼴이 안 보인다.

## 바꾼 것
- `App::hold_press`(`app/mod.rs`): 메뉴 장면(`Scene::is_menu`, 조작 설정 빼고)의 **확인**과 **줄·칸·탭 머리·✕ 탭**은 바로 넘기지 않고
  `PRESS_HOLD` 0.09초 붙잡았다가 그대로 넘긴다. ◀▶·▲▼·휠·끌기는 바로(값·창은 바로 움직여야 한다).
- 소리는 누르는 순간(`UiConfirm`), 넘긴 틱의 "장면이 바뀜" 확인 소리는 다시 내지 않는다(뒤로는 그대로).
- 붙잡은 동안의 입력은 버리지 않고 줄 세웠다가 차례로(`press_queue`) — 누르는 순간의 입력만(`is_edge`: 쥔 스틱은 쌓이면 지연이 남는다).
- 눌린 꼴(`Ui::press`·`press_overlay`): 호박색 번쩍 + 위·왼쪽 어두운 턱 + 호박색 테, 단추는 면이 그림자 자리로 가라앉고, 가운데 메뉴 줄은
  글이 한 칸 내려간다. 키·패드 확인은 고른 줄·단추가 그리고, 줄 표가 아닌 화면은 앱이 지난 프레임의 누를 자리에서 고른 줄을 찾아
  덧그린다. 탭은 누른 자리에.
- 시험 `press_tests::only_edges_queue_while_a_press_is_held`.

## 확인
- 헤드리스: 타이틀에서 한 틱씩 찍어 "설정" 줄이 눌린 꼴로 그려지고 다음 틱에 설정 창이 열림.
- 메뉴를 걷는 헤드리스 시험(shot·touch·pwa·save·hearth — 키 70 ms 간격) 통과.
