# 0028. 땅 돌리기 = 화면만 버튼 쪽으로 90°, 캐릭터는 그대로 움직인다 — 0023을 고침

- 날짜: 2026-11-03
- 상태: 채택·구현. 0023의 "오른쪽 면을 화면 위로 맞추고 몸을 돌리기"를 대신한다.
- 사장(v0.1.1 뒤): "수정사항 제대로 반영된거 맞니? 화면 회전에 대해서, 대상이 되는 화면 축이 올바른지 다시 한번 확인해줘"
  → 16가지 탐침을 보여 묻자 "캐릭터 기준으로 90도 도는거잖아" → (몸까지 돌리는 판을 만들어 설명하자) "아니지 캐릭터는 그대로 움직이게 해야하는거 아냐?"
  → "스틱을 위로 쥔 채 북쪽으로 걷다 RT를 누르면?"에 **"북쪽으로 계속"**.

## 무엇이 틀렸나(0023)
0023은 "누르기 전 캐릭터의 오른쪽 면이 새 정면"을 **"그 면이 화면 위가 되게 + 몸도 그쪽으로 돌리기"**로 읽었다. 화면 위는 넷뿐이라 걷던 쪽에 따라 화면이 0°·90°·180°, 도는 쪽도 바뀌었고, 몸은 0.25초(`turn.plant s`) 멈춰 섰다.
- 시뮬레이션 탐침(월드 + 카메라, 걷는 쪽 넷 × 버튼 둘 × 스틱 쥔 채·놓고 = 16, 쿼터뷰 요 35°):
  - 위로 걷다 오른쪽: 화면 오른쪽으로 90° — 여기만 맞았다.
  - 오른쪽으로 걷다 오른쪽: 화면 **180°**, 쥔 스틱이면 **왔던 길로 되돌아감**.
  - 오른쪽으로 걷다 왼쪽: 화면 **그대로**, 몸만 돎.
  - 아래로 걷다 오른쪽: 시점이 **왼쪽으로** 90°.

## 정한 것
- **화면**: 오른쪽 버튼 = 늘 오른쪽으로 90°(요 -90°, 화면 오른쪽에 있던 것이 위로), 왼쪽은 거울. 카메라는 플레이어를 따라가는 점 둘레로 돈다. 캐릭터가 어디를 보든 같다(`world::turn_quarters`).
- **캐릭터**: 건드리지 않는다. 멈추지도(옛 `PState::Turn`·`turn.plant s` 없앰 — 값은 얼린 표에 남지만 쓰지 않는다) 몸을 돌리지도 않는다. 걷는 중에도 누를 수 있다(서 있기·걷기·스윙 후딜레이).
- **쥔 스틱**: 놓을 때까지 돌기 전 기준을 붙잡는다(`hold`, 시간 제한 없음) — 지도 위 같은 쪽으로 계속 걷는다(화면에서는 옆으로 걷는 것처럼 보인다). 놓았다 다시 밀면 새 화면 기준: 위로 밀면 돌기 전 화면의 오른쪽(왼쪽)으로 간다 — "누르기 전 오른쪽 면이 정면, 직진할 수 있는 상태".
- 쏟기(땅에 실린 적)·대기 4초·락온 중 금지는 그대로.
- 시험: `a_turn_is_always_ninety_degrees_the_buttons_way`, `turning_leaves_the_body_alone`, `after_a_turn_the_held_stick_keeps_walking_the_same_way_until_let_go`(걷는 쪽 넷 × 버튼 둘: 120틱 동안 방향·빠르기 그대로, 놓고 위로 = 새 화면 위), `turning_has_a_cooldown_keeps_the_player_walking_and_is_off_while_locked`.

## 다시 볼 조건
- 쥔 스틱을 오래 붙잡는 것(0010식)이 돌린 뒤 방향 바꾸기를 헷갈리게 하면, 스틱 방향이 크게(45° 넘게) 바뀔 때도 풀리게 한다.
- 쿼터뷰 요(35°)가 지도 축과 어긋나 있어 새 화면 위도 대각이다. 복도에서 어색하면 요 값을 다시 본다.
