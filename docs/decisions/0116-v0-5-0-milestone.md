# 0116. v0.5.0 "확장" 마일스톤 — 인터뷰로 정한 것

- 날짜: 2026-11-08
- 상태: **채택**(사장 2026-11-08, 인터뷰 네 번 — 열여섯 물음 모두 추천안). 준비 문서 0114의 "정할 것"과 0115(떠난 마을의 남은 주민)에서 이어진 물음을 닫는다. 이름 넷은 따로 후보를 내 고른다(아래 6).
- 바탕: 0069(둘째 구역 안), 0101(lore), 0112(엘리트·구역 등급), 0113(0번째 지역 구조), 0114(준비), 0115(떠난 마을·주민).

## 1. 세계관(개발자 답 — 플레이어에게 말하지 않는 것 포함)
| 물음 | 정한 것 | 상태 |
|---|---|---|
| 보라 뿌리의 뜻 | **주인 없는 실** — 할매가 놓아준 실이 땅속에 남아, 쥐는 이 없이 붙잡던 버릇만 남아 자란다. 왜 지금 다시 자라는지는 열어 둔다 | CANON(개발자 답, 게임 글로 말하지 않음) |
| 마을 사람들이 떠난 이유 | **플레이어·주민은 모른다**(MYSTERY). 개발자 답은 0069대로(새싹이 큰 나무가 되고 후손들은 땅 위로) — 단서는 이 답과 어긋나지 않게 | MYSTERY(게임 안) / 개발자 답 고정 |
| 남은 주민은 누구 | **여러 작은 동물**(귀여움 문법 0036). nail 이웃 종의 후손일 수 있으나 말하지 않는다. 화면 글은 "사람" 대신 **"주민"** | CANON |
| 방랑자 = 포포처럼 손이 실을 느낌 | **걸어 둔다** — 핵에 손을 뻗는 몸짓까지, 후손인지는 말하지 않음 | CANON(말하지 않음) |
| ECO-05 죽은 것이 움직이는 조건 | **조건은 열고 행동 규칙만**: 재활동체는 생전의 일·역할을 되풀이하고, 의식·기억을 단정하지 않으며, 모두 공격하지는 않는다(ecology 4·7.2). 시작 글 "뿌리가 닿은 곳마다, 죽은 것이 일어선다"는 관찰로 남는다 | 조건 MYSTERY / 행동 규칙 CANON |
| ECO-10 지역 생태끼리 주고받나 | **주고받는다 — 같은 종이 다른 역할**: 첫 지역의 잔재 일부가 마을에도 있되 다른 일을 한다(예: 청소자). 새 적 둘 + 낯익은 적의 다른 모습 | CANON |
| 잔류형(엘리트 "남는") | **정본(관찰 수준)** — 끝난 곳에 무언가 남는 일이 관찰된다. 왜·무엇은 정하지 않는다. 도감에 관찰로 적을 수 있다 | CANON(관찰) |

## 2. 마을 주민(0115에서 이어진 것)
| 물음 | 정한 것 |
|---|---|
| 불 지키는 주민(V01)의 불 | **집 아궁이** — 쉬는 화로와 다른 불, 생김새도 다르다. "화로가 왜 안전한가"(ecology 10)는 계속 열어 둔다 |
| 재방문 변화의 조건 | **그 주민을 처음 본 판이 끝난 뒤, 다른 판에서 마을에 다시 들어서면** 바뀐다(주민마다 한 번, 단방향, 기록). 대화 횟수·보스 처치와 묶지 않는다 |
| 플레이어 공격이 주민에게 | **닿지 않는다** — 휘두르기·탄·수류탄·땅 돌리기가 지나가고, 락온·자동 조준에도 잡히지 않는다 |
| 대화 창 | **머리 위 말풍선** — 멈추지 않고 몇 초 떠 있다 사라진다, 다시 누르면 다음 줄(nail 말 걸기 말풍선 꼴, 0065) |

## 3. 지역·적
| 물음 | 정한 것 |
|---|---|
| 구역 등급 2(마을) 값 | **체력 ×1.5 · 자세 ×1.3 · 잔불 ×1.6**(올림), 피해 2는 등급 3부터. 예고 길이·움직임은 그대로 — 잔재 3→5, 가시짐승 2→3 |
| 둘째 문지기 | **거리·공간형**(0069 안): 땅을 쳐 울림 고리 두 겹(사이에 서거나 점프로 넘기), 깨진 종 조각 부채꼴 던지기(되받아치기 = 패링), 종을 끌어 돌진 띠, 체력 반 아래 예고 짧게 + 고리 셋. 마을 종은 이미 깨져 있다(0115) |
| 두 지역 잇기 | **내려가는 길 + 되돌아갈 수 있음**: 첫 문지기 핵을 거둔 뒤 성소 바닥이 열린 길 → 지층 단면 전환 + 깊이 숫자(KB conveying-descent) → 마을 입구 화로. 걸어서 첫 지역으로 오를 수 있다(오르는 길), 화로 사이 순간 이동은 없다 |
| 도감 | **v0.5.0에 넣는다**: 적·장신구 탭, 본 것은 그림 + 관찰, 못 본 것은 실루엣 + 나오는 곳. 관찰과 해석을 가른다(ecology) — 엘리트 성질·잔류형·같은 종의 다른 역할을 관찰로 |

## 4. 할 일(0114 표를 이 결정으로 고정)
T1 지역 잇기(내려가는 길·되돌아가는 길·`run.stage`) → T2 지역 환경(뿌리 천장·빛줄기) → T3 구역 등급(위 값) → C2 새 적 둘(상자, ECO-05 행동 규칙) + 마을의 잔재(다른 역할) → C1 마을 지도(생성기 — 주민 생활 구역은 적 시야·끈·광역 밖) → C7 주민 셋(상자 배우·말풍선·재방문 기록·공격이 지나감) → C3 둘째 문지기(상자) → C6 장신구 셋 → C4 글(새긴 돌·주민 대사 — 한국어·영어) → C5 도감 → 모델·동작.

## 5. 판정(v0.5.0 — 0069 Z1~Z5에 주민 더함)
Z1 내려간다고 느끼나 · Z2 새 적·낯익은 적의 다른 역할이 새 판단을 부르나 · Z3 둘째 문지기가 첫째와 다른가 · Z4 nail을 한 사람·안 한 사람 모두에게 읽히나 · Z5 두 지역이 이어지나(오르내림·기록) · **Z6 마을이 "고요하고 쓸쓸한, 누가 사는 곳"으로 읽히나, 주민이 싸움을 방해하지 않나** · P5 성능(Android 30fps).

## 6. 이름(2026-11-08 짧은 인터뷰)
| 무엇 | 이름 | 고른 까닭 |
|---|---|---|
| 둘째 지역 | **떠난 마을** | 정본(0115) 그대로 — 이름이 "망한 게 아니라 떠났다"를 말하고 남은 주민과 부딪히지 않는다. "잠든 마을"은 nail의 "실에 잠기기"·저주로 읽힐 수 있어 뺐다 |
| 막는 적(앞을 등딱지로 막아 평타를 튕김, 0069 "웅크린 것") | **등딱지짐승** | "가시짐승"과 같은 꼴 — 생김새로, 무엇을 막는지는 말하지 않는다(lore 결과로만) |
| 심는 적(멀리서 바닥에 예고를 심음, 0069 "뿌리의 씨앗") | **꼬투리** | 짧고 귀엽다. "뿌리의 ~"(0102 금지어)를 피하고, 뿌리에서 났다고 정하지 않는다(ECO-02 열린 채) |
| 둘째 문지기 | **깨진 종지기** | 초안 그대로(사장) — 장신구 "종지기의 귀"와 이어진다. 깨진 것이 종인지 지기인지는 열어 둔다. 종소리의 근원과 잇지 않는다(울리는 종은 보여 주지 않는다) |

영어 이름은 i18n을 넣을 때 정한다(초안: The Deserted Village · Shellbeast · Pod · The Broken Bellkeeper — 장신구 영어 이름과 맞춘다). 코드 이름(`Kind`)은 영어 식별자로 따로.
