# 0043. 걸을 수 있는 높낮이 — 경사로 + 낮은 턱 점프, 성소 전체

- 날짜: 2026-11-04
- 상태: 채택(사장: "우리 terrain 만들어야지, 높낮이가 있는.." → 고른 것: **경사로 + 낮은 턱 점프**, 그림자는 **구운 + 캐릭터 실시간**, 적용은 **바로 성소 전체**). 0035의 "2단계"를 지금 한다.

## 규칙(`src/ground.rs`, 순수 + 시험)
- 칸(2m)마다 땅 높이(0.5m 단위) 또는 경사로. 경사로는 같은 줄로 이어진 경사로 묶음의 양 끝 이웃 높이를 곧게 잇는다(이음매에 턱 없음).
- **걸음**: 발보다 `GROUND_STEP` 0.3m 넘게 높은 칸은 벽. **공중**이면 발이 턱 높이를 넘어야 올라선다 → 0.5m 턱은 점프(0.9m)로 오르고 1m 벼랑은 못 오른다. **뛰어내리기**는 어디서든(몸 높이는 이어진다 — 걷다 떨어지면 점프 상태로, 회피·공격 중이면 동작은 그대로 몸만 떨어진다).
- **적**은 경사로로만 오르내린다(낮은 칸도 벽). 곧게 못 가거나 높이가 다르면 칸 격자 너비 우선 거리 지도(`Ground::flow`)를 따라 돌아오고, 그동안 공격을 고르지 않는다. 길이 없으면 그 자리에서 기다린다 — 0.5m 디딤단·1.5m 성소 안쪽 단은 플레이어만 오른다.
- **치고 맞기**: 높이 차 `HIT_DY` 0.75m 넘으면 칼·발톱·내려찍기가 안 닿는다(0.5m 턱 너머는 닿는다). 문지기 파동은 몸이 그 적의 땅보다 `jump.clear` 넘게 높으면 넘는다(높은 단 위도).
- 월드: 배우의 `pos.y` = 발밑 땅 높이(`collide`가 맞춘다), 플레이어 몸 = `pos.y + air`. 렌더·카메라·예고·그림자는 `pos`를 그대로 쓰니 높이를 따른다. 땅이 없으면(개발 시나리오) 예전 그대로 0.

## 지도(`Level::with_heights`, 0035 격자를 넓힘)
- 한 글자 = 0.5m 단위: 36진수 v → (v − 4) × 0.5m(`4` = 0, `6` = +1, `c` = +4, `0` = −2), `/` = 경사로. 0035 성소 배경 격자는 이 단위로 옮겼다.
- `Level::ground()` → `World::ground`, `Level::settle()`이 소품·불빛·시작 자리를 땅 위에.
- 굽기(`scenery.rs`): 바닥이 땅을 따르고(경사로는 기운다), 이웃보다 높은 변에 옹벽면, 걸음보다 높으면 위 모서리에 **밝은 테**(쿼터뷰에서 턱이 읽히게). 벽은 곁 바닥만큼 높게.

## 성소
- 입구 −1m → 좁은 길 세 칸 경사로 → 뜰 0.
- 뜰: 서쪽 단 +1m(동쪽 경사로) + 북쪽 디딤단 +0.5m(점프 두 번, 플레이어만), 가운데 꺼진 광장 −0.5m(남북 경사로), 동남쪽 연단 +0.5m(서쪽 경사로).
- 문 앞 경사로 → 성소 +1m, 안쪽 단 +1.5m(점프로만).
- 시험: 모든 바닥에 플레이어가 가고, 모든 스폰·보스 표지에서 적이 걸어서 시작 자리·문 앞까지 온다.
