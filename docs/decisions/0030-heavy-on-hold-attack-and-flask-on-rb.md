# 0030. 강공격 = 공격 버튼 꾹(X·J) · 등잔 마시기 = RB / R

- 날짜: 2026-11-04
- 상태: 강공격 채택·구현. 등잔 버튼은 설계만(구현은 아이템 A단계, `docs/design/items.md` 7).
- 사장: "모으기 강공걱 아직 있니?" → (없다, 만든다면 X 꾹 추천) → "Rb 에 그럼 아이템 넣을수 있나?" → "응 RB로 고쳐두고 강공격은 X 꾹으로 만들어줘".

## 강공격 — 왜 꾹인가
- KB `concepts/melee-light-and-charged-attack-feel.md`(첫 게임 nail 0161·0255에서 온 것): "떼면 평타, 오래 쥐면 모으기"는 **모든 평타가 손가락을 떼는 시간(0.05~0.1초)만큼 늦는다**(INVERSUS·Project Ghost Knight 사례, 2차). 그래서 **평타는 누르는 순간 그대로**, 활성이 끝날 때까지 쥐고 있으면 모으기로 들어선다. 잃는 것은 "첫 타부터 모으기"뿐.
- 소울라이크는 강공격이 RT(따로 버튼)다. 우리는 RT가 땅 돌리기(0024)라 버튼을 늘리지 않고 같은 버튼 꾹으로 — RB는 등잔에 쓴다(아래).

## 강공격 — 규칙
- 누름 → 평타(그대로). **한 번 누른 채 놓지 않고 `heavy.hold start s` 0.25초**를 쥐었고 평타의 활성 구간(0.18초)이 끝났으면 `PState::Charging` — 서서 모은다(스틱·조준으로 돌아볼 수 있다). 톡 누름(사람 0.08~0.15초)은 늘 평타 하나.
  - 처음엔 "활성이 끝날 때 쥐고 있나"만 봤다. 사장 "근데 급하면 막 연타할텐데…?" → 휘두르기 도중에 누른 짧은 누름(무시되는 누름)이 활성 끝에 걸리면 0.05초만 쥐어도 모으기로 샜다(1틱 누름·2틱 사이의 연타에서 재현). 그래서 **누른 뒤 계속 쥔 시간**(`Player::attack_hold`, 새 누름이면 0)으로 바꿨다 — nail `HEAVY_HOLD_START`와 같은 꼴.
  - 시험 `mashing_never_charges_a_heavy`: 누름 1~9틱 × 사이 2~14틱 × 4초 연타에서 모으기·강타 0번(고치기 전 코드에서는 실패하는 것을 확인).
- **떼면 늘 강타**(nail 0255 "들어선 뒤 떼면 늘"). `heavy.charge s` 0.5초를 다 모았으면 `full`:
  | | 덜 모음 | 다 모음 |
  |---|---|---|
  | 피해 | `heavy.damage` 2 | 2 + `heavy.full bonus` 1 = 3 |
  | 잡몹 휘청 | 0.4초 | `heavy.stagger s` 0.8초 |
  | 보스 휘청 | 없음 | `heavy.boss stagger s` 0.25초 |
  - 넓고 길게(범위 2.2·부채꼴 160°, 평타 1.8·120°), 넉백 ×2, 내딛기 0.6m, 히트스톱 ×2, 강타 흔들림.
  - 선딜 0.06·활성 0.12·후딜 0.4초. 후딜은 활성 뒤 회피로 끊는다(평타와 같은 캔슬 자리). 모으는 중엔 회피·패링으로 언제든 끊는다.
  - 스태미나: 평타 12(누를 때) + 강타 15(뗄 때). 없으면 강타가 나가지 않고 선다.
- **시간을 내준 만큼(KB)**: 평타 + 다 모은 강타 = 피해 4 / 1.33초 = 3.0/초, 평타만 = 1 / 0.43초 = 2.3/초 — 1.2배 넘게(시험 `a_full_heavy_pays_back_the_time_it_takes`). 거기에 휘청(예고를 끊는다)·드러난 적 치명타(+2).
- 보여 주기: 모으는 동안 발밑 고리가 안쪽에서 차오르고 다 차면 금빛 깜빡 + 작은 "탁"(`Event::Charged`), 강타의 활성엔 넓은 부채꼴, 맞으면 `Event::Smash`(흔들림 0.5). 방랑자 동작 `charge`(평타 끝 자세에서 칼을 어깨 뒤로 끌어올림)·`heavy`(크게 가로질러 낮게).
- 입력: `Actions::attack_held`(상태 — 키보드 `is_key_down`, 패드 `is_currently_pressed`, Android 키, 터치는 공격 버튼을 짚은 손가락이 화면에 남아 있는 동안). 같은 공격 배치를 쓰니 조작 설정은 그대로.
- 수치는 `tuning.rs` `heavy.*` 열네 줄(얼린 값 뒤에 붙임, 0013). 랩 "Heavy".

## 등잔 마시기 = RB / R
- 소모품을 뺐으니(0027) "아이템" = 등잔 하나. RB는 비어 있고(강공격을 꾹으로 했으니 계속 빔), 엄지를 스틱에서 떼지 않고 마실 수 있다 — 마시는 동안 느리게 걸어 피하는 설계(0.8초)와 맞는다.
- 걱정: 어깨 버튼은 실수로 눌리기 쉽고 RT(돌리기) 바로 위다. 등잔은 한 번에 1회분과 0.8초를 쓴다.
  - 처음 안은 "마시기 시작 0.15초 안에 다시 누르면 취소"였다. 사장: **"물약이 더 큰 문제 아냐?"** — 급하면 RB도 연타한다. 그러면 마시기·취소가 번갈아 나와 회복이 안 되고, 누름을 쌓으면 연달아 마셔 등잔을 버린다. 그래서 바꿨다(`items.md` 2):
  - 한 번 누름 = 한 모금, 다시 누르기 취소 없음. 마시는 동안 + 끝난 뒤 0.3초의 누름은 버린다(쌓지 않는다).
  - 체력이 가득이면 안 마신다, 등잔이 0이면 동작 없이 깜빡만.
  - 등잔은 삼키는 순간(0.35초)에만 준다 — 그 전에 회피하거나 맞으면 끊기고 등잔 그대로. 실수 누름은 회피로 무른다.
  - 소울 시리즈가 마시는 도중 누름을 어떻게 다루는지, 맞으면 등잔이 주는지는 찾지 못했다(검색에 1차·2차 출처 없음 — 기억에 기대지 않는다). 우리 규칙으로 정했다.
- 조작 설정에서 바꿀 수 있다.
- 소울라이크(엘든 링)는 아이템이 X(얼굴 버튼) — 우리는 X가 공격이라 쓸 수 없다(0024).

## 다시 볼 조건
- 강타가 평타보다 늘 낫다(떼싸움이 꾹만 남는다) → `heavy.charge s`·후딜을 올린다. 반대로 아무도 안 쓰면 휘청·피해를 올린다.
- 그래도 연타가 모으기로 새면 `heavy.hold start s`를 올린다. 너무 늦게 모인다고 느끼면 내린다(0.18초 아래로는 의미 없다 — 평타 활성 끝).
- RB 마시기가 실수로 자주 나가면 0.15초 쥐기로 바꾼다.
