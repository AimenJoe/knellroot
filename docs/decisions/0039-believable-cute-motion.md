# 0039. 동작은 "실감나게 귀엽게" — 애니메이션 원칙 + 덧붙이는 2차 동작 층

- 날짜: 2026-11-04
- 상태: 채택(사장: "모션 관련해서, 논문이나 팁, 노하우 등 검색할 수 있으면 검색하고 kb 담은 후 best practices 를 따르자. 실감나면 좋아. 귀엽더라도 실감나게 귀여운 동작일수도 있지.").
- 근거: KB `concepts/believable-cute-character-motion.md`(Lasseter 1987의 원칙, Cooper "Game Anim"의 게임판, Normoyle & Jörg 2014 반응 대 자연스러움, Saerbeck & Bartneck 2010, Allen Chou 2015 스프링 식).

## 정한 것
1. **반응 시간은 게임 수치가 정한다**: 공격 선딜 0.08초·강타 0.06초 등 판정 시각은 그대로. 플레이어 입력 앞에 예비 동작을 늘리지 않는다(Cooper: 플레이어 예비는 짧게, Normoyle & Jörg: 덜 반응하는 조작이 성과·조작감을 해침). 실감은 **뒤(끝맺음)와 위(덧붙이는 층)**에 둔다.
2. **2차 동작 층**(`src/secondary.rs`, 렌더가 그릴 때만): 키프레임 동작 위에 모델 공간으로 덧붙인다(`Model::pose_with`).
   - 꼬리·머리 = 그 덩어리 자리를 감쇠 스프링으로 따라가는 점이 늦는 만큼 돌린다 → 출발에 뒤로 처지고, 멈추면 앞으로 한 번 넘었다 선다(따라가기·겹치기, "무거운 부분이 더 늦고 더 천천히 멈춘다").
   - 몸 = 같은 늦음의 반대쪽, 즉 가속하는 쪽으로 기운다.
   - 발(뿌리) = 공중에서 세로 속도만큼 늘어나고, 내려앉는 순간 그 속도로 찌그러졌다 한 번 튀며 선다. **부피 그대로**(세로 k, 가로 1/√k).
   - 스프링은 암시적 오일러(프레임이 튀어도 안정). 덩어리 자리는 모델에서 읽는다(뼈 아래 메시 정점 가운데) — 모델을 바꿔도 숫자를 안 고친다.
   - 랩 값(새로 더함, 0013대로 기존 줄은 그대로): `anim.tail gain`·`anim.tail hz` 2.4·`anim.tail damp` 0.3·`anim.head gain`·`anim.lean gain`·`anim.squash`(이득 0 = 끔). 고정값 `SEC_*`는 `tuning.rs`.
3. **키프레임**(`wanderer.py`, `sq(k)` = 부피 지키는 세로 배율): 공격은 당길 때 웅크리고(0.92) 벨 때 늘어나며(1.07) 끝자세에 눌린다, 머리는 몸보다 한 박자 늦게 돌아온다. 강타는 모은 자세에서 더 웅크리고(0.9)·휘두를 때 늘어나(1.1)·내려치는 순간 크게 눌린다(0.84). 맞기는 눌렸다(0.86) 튄다(1.05). 회피는 던질 때 늘어나고 구를 때 웅크린다. 땅 돌리기는 낮출 때 눌리고 휙 감길 때 늘어난다. 마시기는 삼킬 때 꿀꺽 눌리고 다 마시면 기분 좋게 한 번 늘어난다. 걷기는 디딤에 눌리고 지날 때 늘어난다(통통), 쉬기는 들숨에 조금 늘어난다.
4. **과장**: 화면에서 20~50px — 몇 도짜리 움직임은 안 보인다. 찌그러짐은 0.84~1.1, 착지는 스프링으로 약 0.8까지.

## 확인한 것
- 시험 다섯(`secondary::tests`): 스프링이 목표에 서고 감쇠비가 낮을 때만 넘는다, 프레임이 1초씩 튀어도 안 터진다, 앞으로 달리기 시작하면 꼬리·머리가 뒤로·몸은 앞으로, 멈추면 꼬리가 앞으로 넘었다 선다, 요가 달라도 캐릭터 기준으로 같다, 점프에 늘어나고 착지에 0.85 아래로 찌그러졌다 1을 넘어 튀고 선다(부피 늘 1).
- 동작 띠는 화면을 고정해 찍는다(`motion_strips.py` — 예전에는 칸마다 크기에 맞춰 찌그러짐이 지워졌다). `docs/art/meshy-0038/motion-0039/`.
- 게임 화면 연속 프레임(쿼터뷰·락온): 걸음마다 꼬리 출렁임, 착지 납작함. 쿼터뷰는 거의 두건 꼭대기라 차이가 작다 — 락온·컷씬에서 더 보인다.

## 다시 볼 것
