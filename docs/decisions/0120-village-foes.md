# 0120. 떠난 마을의 적(v0.5.0 C2) — 등딱지짐승·꼬투리·청소자 잔재

- 날짜: 2026-11-08
- 상태: **채택·구현(상자 모델)**(`release/v0.5`). 0069 C2 안 + 0116 이름(등딱지짐승·꼬투리)·ECO-05(재활동체는 생전의 일을 되풀이, 모두 공격하지는 않는다)·ECO-10(같은 종이 다른 역할). 사장 2026-11-08 인터뷰 셋 — 다 추천대로.
- 스터디: KB `concepts/timing-parry`(막는 적은 패링의 거울 — 튕기고, 강타·옆으로 뚫는다), `ranged-boss-for-melee-player`(바닥 위험 = 표시 끝이 판정), 0069 Z2("새 적이 새 판단을 부르나").

## 정한 것(인터뷰)
| 물음 | 고른 것 |
|---|---|
| 등딱지짐승 앞을 평타로 치면 | **짧게 튀고 콤보가 끊긴다**: 피해·자세 0, 0.35초 뒤로 튐(`PState::Recoil` — 붉게 번쩍이지 않는다, 맞은 게 아니라서), 받아 둔 누름도 버린다. 패링당한 것보다 짧다. 기력은 이미 썼다 |
| 꼬투리에게 다가가면 | **깡충 물러나 다시 심는다**: 3.5m 안이면 3.2m 뒤로 한 번(곧게 갈 수 있는 바닥 — 반대쪽부터 옆으로 돌려 본다), 다시 뛰기까지 2.6초. 구석에 몰면 잡힌다 |
| 마을의 잔재(청소자) | **맞으면 싸운다**: 보고 들어도 제자리에서 먹는다(싸움이 없으면 2.5초마다 체력 1). 맞거나 곁의 동료가 깨면 싸운다 — 잡을지 둘지가 판단 |

## 수치·규칙
- **등딱지짐승**(`Kind::Shell`): 체력 5·느림 1.9m/s·둘레 내려치기(닿는 거리 1.6, 예고 0.7초)·잔불 4. 앞 120°(`guard_arc`)에서 온 **평타·탄**을 튕긴다(`Enemy::guards`). 뚫는 길: **강타**(앞에서도 들어간다 — 공격을 쥐고 있으면 첫 평타가 튕겨도 튀지 않아 모으기가 이어진다), **옆·뒤**(땅 돌리기·돌아 들어가기), **내려찍기**·수류탄·여진(둘레 피해). 휘청·자세가 깨진 동안은 막지 못한다.
- **꼬투리**(`Kind::Pod`, `Behavior::Planter`): 체력 2·느림 1.6m/s·잔불 3. 9m 안이면 **예고를 시작한 순간의 플레이어 자리**에 원판(반지름 1.4m, 1.1초)을 심고 끝에 터진다 — 그 순간 원판 안이면 맞는다. 원판은 받아치지 못한다(`parryable` 거짓 — 피하는 것). 예고는 몸이 아니라 심은 자리에 그린다(`Enemy::tele_at`).
- **청소자**: 같은 `Kind::Husk`, 스테이지 표 `StageDef::docile`의 지도 표지(`e`)에 선 것만 `Enemy::docile`.
- 소리: 튕김 = 패링 쇳소리(패링의 거울), 화면 흔들림은 맞힘만큼. 모델은 아직 상자(`shellback`·`pod` 없음 — 0061 체크리스트로 C2 판정 뒤).
- 마을 빈 지도에 등딱지짐승 둘·꼬투리 둘·청소자 둘. 개발 시나리오 "등딱지짐승 + 꼬투리 + 청소자".

## 시험
- 등딱지: 앞·120° 안은 막고 옆·뒤·자세 깨짐·잔재는 아니다 / 앞 평타 = 튕김(피해 0·튕김 사건·반동), 뒤 평타·앞 강타 = 들어감.
- 꼬투리: 심은 자리에 서 있으면 한 번 맞고 비켜 서면 안 맞는다, 멀면 다가오기만, 가까우면 깡충 물러나 더 멀리 내려앉고 쉼이 생긴다.
- 청소자: 보여도 제자리, 먹어서 체력이 차고, 맞으면 쫓는다.
- 종류 표: 심는 거리 > 물러나는 거리 > 원판, 막는 각 0..180.

## 판정에서 볼 것(사람, 0069 Z2)
- 글 안내 없이 등딱지를 강타·옆·위로 뚫게 되나, 튕김 0.35초가 답답하지 않은가.
- 꼬투리에게 다가갈지 피할지 고르게 되나, 떼와 섞이면 판단이 생기나.
- 청소자를 그냥 지나가는 사람과 잡는 사람이 갈리나.
