# 0263 — 화로 창에 장비·가방 탭을 둔다(0261의 "멈춤 창을 위에 여는" 링크를 걷음)

- 날짜: 2026-11-21
- 상태: 채택(개발판 `release/v0.7` — v0.7.5 몫, 판정 전, 체크리스트 104)
- 사장(2026-11-21, v0.7.4 배포 뒤): "화톳불 메뉴에 장비 정도는 들어가야겠다. 따로 링크로 들어가는게 더 헷갈려."

## 바뀐 것(0261 2절을 고친다)
- 화로 = **성장 · 장비 · 가방 · 기술 · 가게 · 설정**(여섯). 멈춤 = 장비 · 가방 · 기술 · 기록 · 설정(그대로).
- 걷은 것: 화로 창에서 멈춤·Select를 누르면 멈춤 창을 그 위에 여는 길(`flow::hearth_menu`), 가게 끝 줄 "가방 — 여벌을 잔불로"(`ShopRow::Bag`),
  "화로 위의 멈춤 창이면 잔불로가 켜진다"(`App::at_hearth`), 안내 줄의 "SELECT 장비·가방"(`Act::Gear`) — 링크가 한 창 안에서 다른 창을 열어
  탭 줄이 바뀌고 닫으면 돌아오는 꼴이 더 헷갈렸다.
- 가방도 화로에 둔 까닭: 여벌을 잔불로 바꾸는 일은 쉬는 동안에만 한다(0226) — 가방이 화로에 없으면 다시 링크가 필요하다. 화로의 가방은 `Host::edits`로
  잔불로·여벌 정리가 켜진다(0226 그대로).
- 화로의 Select(Tab) = 같은 창의 장비 탭(`flow::hearth_select`), 멈춤의 Select는 그대로 장비 탭(`SELECT_OPENS`).
- 기록(도감·여정)은 화로에 두지 않는다 — 읽는 것이라 쉬는 곳의 일이 아니다(멈춤에서).
