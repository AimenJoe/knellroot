# 0267 — 쉬는 곳의 화톳불을 조명 화로와 가른다

- 날짜: 2026-11-22
- 상태: 채택 · v0.8.0
- 사장(2026-11-22): "화톳불이랑 그냥 조명 불이랑 구분이 안됨....."

## 왜
- 쉬는 곳(지도 `R`)과 조명(`b`)이 같은 소품(`brazier.glb` — 받침 위의 그릇)·같은 빛이었다. 처음 그 모델은 "쉼터의 화로"로 빚었는데 조명에도
  같이 쓰면서 둘이 섞였다.

## 정한 것
- 쉬는 곳 = **땅에 놓인 낮고 넓은 화톳불** `hearth.glb`(`props.py` — 지름 약 1.9m의 돌 고리 아홉 · 재 · 원뿔로 세운 장작 다섯 + 누운 장작 ·
  큰 불꽃(끝 약 1.75m, 곁 혀 셋) · 곁에 앉는 넓적한 돌 둘). `PropKind::Hearth`, 부딪힘 반폭 0.75m(쉬는 거리 2.4m 안).
- 조명 = 받침 위의 그릇 `brazier.glb` 그대로(키 큰 실루엣) — 실루엣부터 갈린다: 낮고 넓은 땅불 vs 키 큰 그릇.
- 쉬는 곳의 빛은 더 넓게(`stage::HEARTH_LIGHT_R` 9m — 조명 7m), 높이는 낮게(1.0m).
- 꺼진 화로(0171)는 화톳불도 같은 길로 어둡게 굽는다(불꽃 부위 `glow_flame`).
- 새 모델은 코드로 빚었다(Meshy 안 씀).
