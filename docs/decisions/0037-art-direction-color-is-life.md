## 정한 것
- 방랑자 = **B 작은 동물**: 둥근 너구리 얼굴(눈 둘레 무늬·크림 주둥이·코, 입 없음), 두건 밖 귀(안쪽 분홍), 줄무늬 꼬리(뼈 하나 — 쉴 때·걸을 때 흔들림), 콩 모양 민트 망토·복숭아 목도리·작은 장화·허리의 작은 금빛 종. 2등신(키 ≈ 1.4m 게임 단위), 정점 2,042. 얼굴 첫 판은 어두운 무늬 위 작은 눈이 묻히고 크림 주둥이가 네모 판이었다 → 눈 키우고 무늬는 눈보다 조금 큰 고리, 주둥이는 작고 둥글게.
- **세계·적까지 "색 = 생명"**(1단계 = 색만): 공용 팔레트 `PAL`을 해 질 녘으로(돌 → 남회색, 이끼 → 청록, 뿌리 → 보라, 뼈 → 잿빛) 바꾸고 모델 열둘을 다시 내보냈다. 지형 색(`scenery.rs`)·바탕빛·달빛·바탕·아지랑이를 남보라로, 외곽선은 검정 → 짙은 자두빛.
- 2단계(다음): 적 셋을 같은 문법으로 다시 빚기 — 잔재 = 색 잃은 작은 것(시안 넷째), 가시짐승 = 바랜 멧돼지 + 보라 가시 갈기, 문지기 = 큰 둥근 돌 몸 + 뿌리 왕관 + 호박색 핵. 그리고 "핵을 거두면 구역에 색이 돌아옴".
- 세계관 D2(0004): 방랑자를 동물로 정했으니 **(a) nail과 같은 세계의 먼 뒷이야기** 쪽으로 기운다 — 이야기 세부(누구인가·마을과의 관계)는 아직 열려 있다.
