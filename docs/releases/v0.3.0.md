# Knellroot v0.3.0 — 남는 판: 잔불·기록·장신구·성장·소리

마일스톤 "남는 판"(0064)의 판입니다. 지난 판까지는 한 판이 끝나면 아무것도 남지 않았습니다. 이제는 쓰러져도, 껐다 켜도 모은 것이 남습니다. **아직 초안**이라 그림·소리·수치는 모두 바뀔 수 있습니다.

## 바뀐 것
- **잔불**: 쓰러진 적이 잔불 조각을 흩습니다. 조각은 잠깐 뒤 방랑자에게 끌려옵니다. 가진 잔불은 쓰러져도 잃지 않습니다.
- **기록(슬롯 3개)**:
  - 타이틀의 "이어하기"·"시작하기"에서 슬롯을 고릅니다.
  - 마지막으로 쉰 쉼터에서 이어 합니다.
  - 덮어쓰기와 지우기는 두 번 눌러야 됩니다.
  - 든 무기도 슬롯마다 따로 남습니다.
- **장신구**:
  - 세 칸에 장신구를 낍니다.
  - 장신구는 6가지입니다. 상자 2개에서 2개, 문지기에게서 1개를 얻고, 나머지 3개는 쉼터에서 삽니다.
  - 체력·패링 창·공격 속도 같은 수치가 바뀌고, 어떤 것은 맞바꿈이 있습니다.
- **장비 창**(멈춤 → 장비):
  - 가운데에 무기를 든 방랑자 인형이 섭니다.
  - 칸을 고르면 가진 것 가운데에서 바꿉니다.
  - 끼우면 바뀌는 값이 ▲▼와 색으로 미리 보입니다.
  - 무기와 장신구는 실제 모양으로 보이고, 고른 것은 크게 흔들립니다.
  - 넘치는 설명은 직접 굴려 읽습니다(패드 오른쪽 스틱, 마우스 휠, 끌기).
- **성장**:
  - 문지기를 이기면 핵에서 하나를 고릅니다(최대 체력·등잔 횟수·한 모금 회복량).
  - 쉼터에서 쉬면 화로 가게가 열립니다(장신구 3개·등잔 기름을 잔불로).
  - 살 것이 있으면 쉼터가 빛납니다.
- **소리 첫 층**:
  - 휘두르기·맞힘·회피·패링·잔불·상자·메뉴 소리가 납니다.
  - 적의 예고는 모양마다 소리가 다릅니다(부채꼴·돌진·파동·잔재).
  - 문지기가 깨어날 때 땅이 울리고, 성소에는 바람과 먼 종소리가 깔립니다.
  - 설정에 "소리 크기"가 생겼습니다.
- **메뉴**:
  - 창을 닫으면 연 줄로 돌아갑니다.
  - 창에 ✕가 있고, 창 밖을 누르면 닫힙니다.
  - 되돌릴 수 없는 일(처음부터·타이틀로·사기)은 한 번 묻습니다. 커서는 취소에서 시작합니다.

## 출처
- 방랑자·문지기·잔재·가시짐승의 몸: **AI 생성**. Gemini(나노바나나) 그림을 Meshy(https://www.meshy.ai) Image to 3D 무료 플랜으로 만든 결과물이며 **CC BY 4.0**입니다("Cozy Bell Raccoon"·"Sleepy Stone Guardian"·"Crystal Gloom Bear"·"Crystalback Piglet", Meshy로 만듦). 이 레포의 스크립트가 줄이고 부위로 잘라 뼈와 동작을 붙였습니다.
- 장신구·무기·소품 모델, 지형·하늘·나무·아이콘: 이 레포의 스크립트와 코드(`tools/art/blender/`, `src/scenery.rs`·`backdrop.rs`·`flora.rs`, `tools/icons/`). 스크립트와 코드는 Claude(AI)가 썼습니다.
- 효과음 16: **CC0 1.0**. Kenney(Impact·Interface·RPG Audio)와 OpenGameArt(SubspaceAudio, artisticdude, Bobjt, Kenney), 첫 게임 nail-under-the-roots에서 다듬은 것을 그대로 썼습니다(`assets/LICENSES.md`).
- 패링·예고·깨어남·쉼터·등잔 소리와 성소 환경음: 이 레포의 코드가 시작할 때 만듭니다(`src/sfx.rs`, Claude(AI)가 씀).
- 글꼴: 고운바탕(SIL OFL 1.1, Gowun Batang Project Authors)에서 게임 글자만 남긴 서브셋.
- 엔진: macroquad / miniquad(MIT·Apache-2.0). Android 패드·몰입 모드는 패치본입니다.

**English (short)**:
- Embers: fallen enemies scatter embers that fly to you. You keep them when you fall.
- Saves: three slots (Continue / Start → pick a slot). You continue from the last shrine you rested at.
- Charms: three slots, six charms (two chests, one from the gatekeeper, three for sale at shrines).
- Equipment screen: a paper doll with live stat previews (▲▼). Items are shown as their actual 3D shapes.
- Growth: beat the gatekeeper to pick a core upgrade. Resting opens the shrine shop.
- First sound layer: hits, parries, dodges, menus and embers. Each telegraph shape has its own warning sound. The sanctum has an ambience track, and there is a volume setting.
- Menus: closing a window returns to the row that opened it. Irreversible actions ask first.
- Known: charm models are a first draft, values are placeholders, handheld performance has not been measured, and there is still one zone.
