# Knellroot v0.7.5 — 화로 창에 장비·가방 · 기술 판 설명 바로잡기 · 대사 다듬기

v0.7.4 뒤의 패치. 화로 창에서 장비와 가방을 바로 다루고, 기술 판의 설명을 실제 효과에 맞췄습니다. 주민의 말과 새긴 기록도 다듬었습니다.

## 바뀐 것
- **화로 창**(0263): 성장 · 장비 · 가방 · 기술 · 가게 · 설정.
  - 화로에서 멈춤 창을 위에 띄우던 길과 가게의 "가방" 줄은 없앴습니다 — 장비를 바꾸고 여벌을 잔불로 바꾸는 일을 화로 창 안에서 합니다.
  - 화로에서 Select(Tab)는 장비 탭으로 넘어갑니다.
- **기술 판 설명**(#33): 효과의 수치와 조건을 실제 동작대로 적었습니다.
  - 잘못 적혀 있던 배율을 바로잡았습니다 — 빈틈의 박자·비껴서기의 자세 피해는 ×1.5(×2로 적혀 있었다).
  - 받아내기(문지기 12.5%)·되돌려 치기(2m · 0.35초)·착지의 순간(0.3초 뒤 1.8배 고리)·엉킨 뿌리(30% 느리게)·뿌리내린 몸(0.4초 · 회피 거리 35% 줄어듦)·결의 거리와 값을 숫자로.
  - "되찾는 살"의 이름을 "되찾는 생기"로.
- **대사와 새긴 기록**(#35): 떠난 마을 주민의 말, 새긴 돌, 작업층의 작업 일지, 도입부 글을 한국어·영어 모두 자연스럽게 다듬었습니다(뜻은 그대로).

## English short
A patch after v0.7.4.

- The hearth window now holds gear and bag: growth, gear, bag, skills, shop, settings. The pause-window-over-the-hearth shortcut and the shop's "bag" row are gone; Select (Tab) at the hearth jumps to the gear tab.
- Skill board descriptions now match what the skills actually do (several poise multipliers were listed as ×2 but are ×1.5; ranges, durations and values are spelled out). "Mend" is now "Renewed Vigor".
- Villager lines, carved stones, work logs and the opening text read more naturally in both languages.
