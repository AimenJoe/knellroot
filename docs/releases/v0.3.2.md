# Knellroot v0.3.2 — Select = 장비 창, 장비 후보 정리

v0.3.x 패치(결정 0070)의 둘째 판입니다.

## 바뀐 것
- **Select = 장비 창**: 싸우는 중에 패드 Select(키보드 Tab)를 누르면 멈춤을 거치지 않고 장비 창이 열리고, 다시 누르면 닫힙니다. 조작 설정에서 Tab을 게임 동작에 붙였으면 Tab은 그 동작만 합니다.
- **장비 후보 정리**:
  - 칸을 골라 후보 목록을 열면, 그 칸에 지금 낀 것은 목록에 다시 나오지 않습니다. 칸 상자와 바뀌는 값 미리보기가 이미 보여 줍니다.
  - 빈 장신구 칸에는 "빈 칸" 줄이 없습니다.
  - 바꿀 것이 없으면 목록이 열리지 않습니다.

## 알려진 것
- 대시 공격은 아직 콤보 동작을 다시 씁니다.
- 장신구 모델은 첫 시안입니다.
- 핸드헬드 성능은 아직 재지 않았습니다.
- 개발용 값 조정 창(랩)은 개발판에서 멈춤 메뉴 안으로 옮겼습니다. 운영판에는 없습니다.

**English (short)**:
- Select (Tab on keyboard) opens the equipment screen straight from combat. Press it again to close.
- The candidate list no longer repeats what is already worn in that slot.
- The dev tuning lab now lives inside the pause menu on the dev build only.
