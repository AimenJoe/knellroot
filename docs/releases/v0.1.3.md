# Knellroot v0.1.3 — 중세 무기 넷, 마법, 설정, 꽉 찬 화면

v0.1.2 위에 싸움의 손맛과 화면을 크게 손봤습니다. **아직 초안**이라 그림·소리·수치는 모두 바뀔 수 있습니다.

## 바뀐 것
- **무기 넷**(멈춤 → 무기에서 바꿉니다. Path of Exile 2를 참고했습니다)
  - **순례자의 검**: 3연타(가로 → 되돌려 가로 → 찌르기). 꾹 누르면 강타입니다.
  - **종치기 망치**: 느리고 넓은 2타이고, 2타째는 몸 둘레를 칩니다.
    - 꾹 누르면 뛰어올라 내려찍고, 금 간 땅이 1.5초 뒤 여진으로 터집니다.
    - 자세가 반 넘게 무너진 적은 강타 한 번에 깨집니다.
  - **순례자 지팡이**: 빠른 4연타이고, 4타째는 회전 마무리입니다.
    - 다 모인 순간 딱 맞춰 떼면 더 세집니다. 마법탄이 적을 꿰뚫습니다.
  - **화약 쇠뇌**: RB = 조준 사격(탄창 4발, 다 쓰면 장전, 회피하면 한 발 장전), X = 수류탄(튕기고 1.5초 뒤 폭발, 볼트로 맞히면 바로 터짐).
- **콤보**: 연타하면 다음 타로 이어지고, 미리 누른 것도 받습니다.
- **자세 막대**: 무거운 타격일수록 적의 자세가 무너집니다. 다 무너지면 휘청하고, 다음 한 대가 치명타입니다.
- **RB 마법**: 오른쪽 스틱으로 겨누며 쏩니다(안 겨누면 가까운 적).
  - 세 칸이 있고, 근접으로 맞힐 때마다 채워집니다. 쉼터에서 가득 찹니다.
  - 쏘는 동작을 새로 만들었습니다.
- **새 버튼 배치**: 등잔은 **Y / R**, 마법은 **RB / U**입니다. 쉼터 곁에서는 **A(점프) / F**가 쉬기를 합니다. RB를 누른 직후에는 땅 돌리기를 잠깐 무시합니다(RB 바로 밑이 RT).
  - 저장해 둔 키 배치는 이번에 한 번 기본값으로 돌아갑니다(언어는 그대로).
- **손맛**
  - 강공격을 모으는 동안 느리게 걸을 수 있습니다.
  - 점프 중에도 몸을 돌려 내려찍기를 겨눌 수 있습니다.
- **락온 카메라**: 더 높은 곳에서(19°) 보고, 방랑자가 가운데에 가까워졌습니다. 적과의 거리를 재기 쉽습니다.
- **설정**: 타이틀·멈춤 → 설정에 언어, 전체 화면, 화면 흔들림(0~100%), 조작 설정을 모았습니다.
- **꽉 찬 화면**
  - Android(11 이상)에서 상태·내비게이션 바를 숨깁니다. 가장자리를 쓸면 잠깐 보입니다.
  - 웹은 브라우저 창 크기에 맞춰 검은 테두리 없이 꽉 찹니다.
  - 폰 웹에서는 "시작"을 누르면 전체 화면 + 가로가 됩니다.
- **글자**: 일부 폰 브라우저에서 글자가 검게 나오던 것을 고쳤습니다(글자 텍스처를 작게).
- **터치 버튼 정리**
  - 공격 둘레에 회피·패링·마법·점프를 둡니다.
  - 돌리기 둘은 한 캡슐로 묶었습니다.
  - 락온·등잔은 쓸 수 있을 때만 제 자리에 뜹니다. 싸울 때 버튼이 10개 남짓에서 7~9개로 줄었습니다.

## 알려진 것
- 소리가 없습니다. 적 셋은 아직 예전 모양에 새 색만 입혔습니다.
- 무기 동작은 첫 판입니다.
  - 모으며 걸을 때 다리가 미끄러져 보입니다.
  - 쇠뇌 X를 꾹 눌러 멀리 던지기는 아직 없습니다.
  - 무기는 멈춤 메뉴에서 바꿉니다(쉼터 메뉴는 나중에).
- 저장되는 것은 설정(언어·키 배치·흔들림·무기)뿐이고, 진행은 한 판으로 끝납니다.

- 무기 모델·다른 모델·아이콘: 이 레포의 스크립트(`tools/art/blender/`, `tools/icons/`). 스크립트는 Claude(AI)가 썼습니다.

**English (short)**:
- Four medieval weapons, switched from the pause menu:
  - Pilgrim's Sword: 3-hit combo.
  - Bell-ringer's Hammer: slow sweeping hits; the leaping slam leaves an aftershock.
  - Pilgrim's Staff: 4-hit combo with a spin finisher and a perfect-release bonus.
  - Powder Crossbow: aimed shots from a 4-bolt magazine, plus bouncing grenades on X.
- Combat:
  - Combos accept buffered input.
  - Enemies have a poise bar; breaking it staggers them and sets up a critical hit.
  - RB magic: aim with the right stick; charges refill on melee hits.
  - New layout: flask on Y, magic on RB; jump doubles as interact at rest sites.
  - Charging a heavy attack now lets you walk slowly, and you can turn in mid-air.
- Screen and camera:
  - Higher lock-on camera.
  - True fullscreen on Android 11+, and a borderless fit in browser windows.
  - Fixed black text on some phone browsers.
- Menus and touch:
  - New Settings menu (language, fullscreen, screen shake, controls).
  - Decluttered touch layout: an arc of buttons around attack, with context buttons that appear only when they can be used.
