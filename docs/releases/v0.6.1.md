# Knellroot v0.6.1 — 벼리기와 시점

v0.6.0 "다듬기"의 패치(결정 0179 — 무기 강화 W1은 여기로). 무기 강화(0180)·시점 거리 단계와 자유 숄더뷰(0181)·문구 다듬기(PR #20).

## 들어온 것
- **무기 강화 — 숫돌로 벼리기**(0180): 지도에 놓인 **숫돌**(쇠의 푸른 빛기둥 · 성소 1 · 마을 3)과 잔불로 무기마다 세 단을 벼립니다. 화로의 가게 탭에서 "벼리기", "거두기"를 하면 숫돌은 돌아오고 잔불은 돌아오지 않습니다 — 다른 무기로 옮겨 벼릴 수 있습니다.
  - 근접 무기는 단마다 모든 타의 피해 +5. 쇠뇌는 탄창부터(+1 · +1 · +2), 2단부터 볼트·수류탄 피해 +5 · +10.
  - 벼린 단은 들고 있는 무기에만, 이름에 "+n"이 붙습니다.
- **시점 거리 단계 · 자유 숄더뷰**(0181):
  - 패드 십자 ↑ = 당기기 · ↓ = 밀기(키보드 ↑↓ · 마우스 휠 · 터치 두 손가락). 쿼터뷰 거리 셋, 가장 가까운 단계에서 한 번 더 당기면 **숄더뷰**.
  - 숄더뷰에서는 **오른쪽 스틱**(마우스 · 키보드만은 ←→ · 터치는 화면 오른쪽 반을 끌기)으로 시점을 돌립니다. 스틱 위 = 카메라 앞.
  - 락온한 적이 쓰러지고 넘길 적이 없으면 숄더뷰에 머뭅니다. 버튼으로 풀면 락온한 곳(쿼터뷰·숄더뷰)으로 돌아갑니다.

## 바뀐 것
- **키보드 화살표는 더 이상 걷지 않습니다**(0181) — ↑↓ = 시점 거리, ←→ = 숄더뷰 시점. 걷기는 W·A·S·D. 메뉴에서는 그대로.
- **마우스**: 숄더뷰에서는 커서를 잡아 시점으로 씁니다(웹은 포인터 잠금 — 처음 한 번 클릭이 필요할 수 있습니다). 메뉴를 열면 놓습니다.
- **문구**(PR #20): 시작 문장·지역 목표·튜토리얼 풀이·주민 대사·도감 추측·알림을 다듬었습니다(한국어·영어). 문구 가이드 `docs/writing/voice-and-copy.md`.

## 알려진 것
- 판정 전: 체크리스트 35(무기 강화) · 36(시점). 한 단의 값(+5)은 인터뷰의 +10에서 반으로 — 보스 모의 기록은 0180.
- 실제 패드의 오른쪽 스틱, 마우스 포인터 잠금, 터치 끌기·꼬집기는 헤드리스로는 다 못 봤습니다.
- 소개 페이지의 대표 문장은 옛 시작 문장 그대로입니다(게임 안 시작 문장은 PR #20에서 다듬음).
