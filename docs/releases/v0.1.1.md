# Knellroot v0.1.1 — 소울라이크식 손, 패링, 점프

v0.1.0 첫 판에 손을 더했다. 키 배치를 소울라이크식으로 바꾸고, 패링과 점프를 넣었다. **아직 초안**이라 그림·소리·수치는 모두 바뀔 수 있다.

## 바뀐 것
- **키 배치를 소울라이크식으로 바꿨다**(공격만 우리식 X / J).
  - 회피 B / Space, 패링 LB / K, 점프 A / F
  - 땅 돌리기 LT·RT / Q·E, 락온 R3 / L
- **조작 설정**: 타이틀이나 멈춤 메뉴에서 키·버튼을 다시 붙일 수 있다. 바꾼 배치는 언어 설정과 함께 저장되고, 다시 켜도 남는다.
- **패링**
  - 적의 공격이 닿기 직전에 누르면 튕겨 낸다(앞쪽 근접 공격만).
  - 튕기면 적이 휘청이고 드러난다. 드러난 적은 다음 한 대가 치명타다.
  - 헛치면 잠깐 묶인다.
  - 문지기의 뿌리 파동은 받을 수 없다. 예고 가운데 X 표시로 알린다.
- **점프**
  - 뿌리 파동은 뛰어서 넘는다.
  - 달리다 뛰면 멀리 간다.
  - 공중에서 공격하면 **내려찍기**로, 내려앉은 자리 둘레의 적을 친다.
  - 공중에서는 바닥 그림자가 작아져 얼마나 떴는지 보인다.
- **땅 돌리기**: 누르기 전 캐릭터의 오른쪽(왼쪽) 면이 새 정면이 된다. 쥐고 있던 스틱은 그대로 새 정면으로 곧게 간다.
- **손맛**: 회피는 적을 뚫고 지나간다. 맞으면 화면이 흔들리고 몸이 젖혀진다.
- **오래 켜 두기**: 오래 켜 두면 화면이 하얗게 되다 꺼지던 GPU 메모리 누수를 고쳤다.
- **앱 아이콘**: 음영과 외곽선을 넣었다. 뿌리는 방울에서 돋아 퍼지게 다시 그렸다.

**English (short)**: Soulslike-style controls (attack stays on X / J): dodge B / Space, parry LB / K, jump A / F, turn the ground LT·RT / Q·E, lock on R3 / L. Controls can now be remapped from the title or pause menu and are saved. New: parry (stagger + exposed for a critical hit), jump (clears the root wave, plunge attack from the air, shrinking ground shadow). Ground turns now make the side you turned toward the new front. Fixed a GPU memory leak on long sessions. **Uninstall v0.1.0 before installing this APK** (the signing key changed once; it is fixed from now on).
