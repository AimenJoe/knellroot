# Knellroot v0.2.0 — 침묵의 성소를 닫는 판: 길 안내, 새 그림, 주위 환경

첫 스테이지 "침묵의 성소" 마일스톤(0060)의 판입니다. 고칠 일 3가지(길 안내·바닥·적 3종)와 그림 기준(0061), 주위 환경(0063), 웹 로딩·설치(0062)가 들어갔습니다. **아직 초안**이라 그림·소리·수치는 모두 바뀔 수 있습니다.

## 바뀐 것
- **길 안내**: 성소 문이 열리면 갈 곳에 호박색 빛기둥이 서고, 화면 밖에 있으면 가장자리에 화살이 나옵니다. 목표 글은 갈 곳을 말합니다("열린 문으로 성소에 들어가라"). 미니맵은 없습니다.
- **새 적 3종**: 잠들지 않는 문지기(졸린 조약돌), 뿌리의 잔재(색을 잃은 아기곰 — 한쪽 눈은 불씨), 가시짐승(등에 보라 가시 갈기를 단 아기 멧돼지). 귀여운 꼴은 같고 뿌리에 먹혀 색을 잃었습니다.
- **그림(3D 도트)**: 물체 가장자리는 어두운 선, 볼록한 모서리는 밝은 선. 바닥은 높낮이가 있는 석판, 빠진 석판 자리의 흙, 풀 다발, 벽 밑 그늘.
- **주위 환경**:
  - 낭떠러지 아래와 벽 너머는 검은 허공 대신 아래로 깊어지는 안개입니다.
  - 반딧불과 달빛 먼지가 떠다닙니다.
  - 숄더뷰 뒤로 해 질 녘 하늘, 먼 산등성이, 거대한 뿌리 아치, 달(남서쪽)이 보입니다.
  - 바위 단에 나무와 덤불, 벽에는 뿌리가 탑니다.
- **웹**: 불러오는 동안 종이 흔들리고 막대가 찹니다. 폰에서 "홈 화면에 추가"하면 가로 전체 화면 앱으로 뜨고, 한 번 연 판은 오프라인에서도 열립니다. 새 판은 다음에 열 때부터 적용됩니다.

## 해 보기

## 알려진 것
- 소리가 없습니다.
- 마일스톤 판정 5개(0060 S1~S4·P5)은 이 판으로 합니다. 고칠 것은 v0.2.x 패치로 냅니다.
- 핸드헬드 성능은 아직 재지 않았습니다(선·그림자·안개·원경·식생은 개발판 랩에서 하나씩 끌 수 있습니다).
- 적은 부위를 통째로 돌리는 방식이라, 크게 움직일 때 팔·다리 이음매가 벌어져 보일 수 있습니다.
- 저장되는 것은 설정뿐이고, 진행은 한 판으로 끝납니다.

**English (short)**:
- Wayfinding: once the sanctum gate opens, an amber light column marks where to go, with an edge arrow when it is off screen. There is no minimap.
- New models for all three enemies (the gatekeeper, the root husk and the thorn beast): cute shapes drained of colour by the roots.
- 3D pixel look: dark outlines, bright convex edges, and a reworked stone floor with grass.
- Surroundings: height fog below the cliffs, fireflies and dust, a dusk sky with distant ridges, giant root arches and a moon behind the shoulder view, and trees and roots around the sanctum.
- Web: a loading bell and bar. The game installs as a landscape full-screen app and opens offline after the first visit.
- Known: no sound yet, handheld performance not measured yet, saves keep only settings.
