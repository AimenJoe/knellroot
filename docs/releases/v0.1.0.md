# Knellroot v0.1.0 — 첫 판: 침묵의 성소

레트로 로우폴리 3D 액션. 쿼터뷰로 떼를 상대하다가, 락온을 누르면 어깨 너머로 내려가 보스와 1:1. **초안이다** — 그림·소리·수치는 모두 바뀐다.

## 들어 있는 것
- **첫 스테이지 "침묵의 성소"**: 무너진 입구 → 뿌리의 뜰(세 물결) → 성소의 문 → 잠든 문지기가 깨어난다 → 결투 → 남은 핵을 거두면 끝.
- 적 셋: 느리게 몰려드는 **뿌리의 잔재**, 띠를 그리고 곧게 들이받는 **가시짐승**, 부채꼴 내려치기·돌진·퍼지는 뿌리 파동을 쓰고 반 아래에서 빨라지는 **잠들지 않는 문지기**.
- **땅 돌리기**: 왼쪽·오른쪽 버튼으로 땅을 90° 비틀어, 둘레의 적을 쏟아 휘청이게 한다. 좌우는 캐릭터가 바라보는 쪽 기준.
- **락온**: 보스와 1:1일 때 카메라가 어깨 너머로.
- 공격하며 한 발 내딛기, 맞으면 짧은 경직·화면 흔들림, 스태미나(회피·공격), 회피는 적을 뚫고 지나간다.
- 타이틀·멈춤·결과 화면, 한국어·영어(고운바탕 글꼴), 키보드·패드·터치.

## 해 보기
- 웹: https://knellroot.netlify.app (PC·폰 브라우저, 패드 지원)
- Android: 이 Release의 `knellroot.apk`(게이밍 핸드헬드·폰, 가로). 출처를 알 수 없는 앱 설치를 허용해야 한다.
- 조작: 이동 WASD / 왼쪽 스틱 · 조준 오른쪽 스틱 · 공격 J / X · 회피 K / A · 땅 돌리기 Q·E / LB·RB · 락온 L / R3 · 멈춤 Esc / Start

## 알려진 것
- 소리가 없다. 저장이 없다(한 판).
- 그림은 Blender 스크립트로 만든 초안 모델이다.

**English (short)**: First playable draft of Knellroot — a retro low-poly 3D action game. Fight crowds in a quarter view, then lock on for over-the-shoulder boss duels. One stage, "The Silent Sanctuary": clear three waves in the courtyard, open the sanctum gate, and defeat the Sleepless Warden. Turn the ground 90° to spill enemies off balance. Web (https://knellroot.netlify.app) and Android APK. No sound or saving yet.
